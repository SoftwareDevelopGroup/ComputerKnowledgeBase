第2章在 [[数据库原理]] 的 SQL 基础之上，进入数据库端的编程：把 SQL 从一次性查询升级为可复用、可封装、可触发的过程对象。本章解决“业务逻辑放在应用层还是数据库端”这一设计抉择。

## 学习目标

- 能编写视图并理解更新限制与 `WITH CHECK OPTION`
- 能用存储过程封装业务、用触发器实现审计与级联
- 能区分函数与存储过程的调用语义
- 能在存储过程中正确使用游标并评估性能
