# 4.3 字符数组与字符串

> [!abstract] 核心问题
> 如何使用字符数组存储字符串？常用的字符串处理函数有哪些？

## 一、字符数组

### 1. 定义

```c
char str[20];   // 字符数组，长度为20
```

### 2. 初始化

```c
// 方式1：逐个字符初始化
char str[6] = {'H', 'e', 'l', 'l', 'o', '\0'};

// 方式2：字符串常量初始化
char str[6] = "Hello";

// 方式3：省略长度
char str[] = "Hello";  // 长度为6（包括'\0'）
```

### 3. 字符串结束标志

字符串以`'\0'`（空字符）作为结束标志，ASCII码值为0。

```c
char str[6] = "Hello";
// 在内存中存储为：'H', 'e', 'l', 'l', 'o', '\0'
```

> [!warning] 易错点
> 如果字符数组不以`'\0'`结尾，就不是字符串，而是普通的字符数组！

## 二、字符串输入输出

### 1. 字符串输出

```c
char str[] = "Hello";
printf("%s", str);  // 输出字符串
puts(str);          // 输出字符串并换行
```

### 2. 字符串输入

```c
char str[20];
scanf("%s", str);   // 输入字符串，遇到空格或回车结束
gets(str);          // 输入字符串，包括空格
```

> [!warning] 易错点
> scanf输入字符串时，变量名前不需要加`&`！但要注意缓冲区溢出问题。

## 三、字符串处理函数

### 1. strlen：求字符串长度

```c
#include <string.h>
char str[] = "Hello";
int len = strlen(str);  // len = 5，不包括'\0'
```

### 2. strcpy：字符串复制

```c
#include <string.h>
char dest[20];
char src[] = "Hello";
strcpy(dest, src);  // 将src复制到dest
```

> [!warning] 易错点
> 使用strcpy时，目标数组必须足够大，否则会导致缓冲区溢出！

### 3. strcat：字符串连接

```c
#include <string.h>
char str[20] = "Hello, ";
char add[] = "World!";
strcat(str, add);  // str = "Hello, World!"
```

### 4. strcmp：字符串比较

```c
#include <string.h>
char str1[] = "Apple";
char str2[] = "Banana";
int result = strcmp(str1, str2);
// result < 0: str1 < str2
// result == 0: str1 == str2
// result > 0: str1 > str2
```

比较规则：按ASCII码值逐字符比较。

### 5. strncpy、strncat、strncmp

安全版本，指定最大操作长度。

```c
strncpy(dest, src, n);   // 最多复制n个字符
strncat(str, add, n);    // 最多连接n个字符
strncmp(str1, str2, n);  // 最多比较n个字符
```

## 四、字符串处理示例

### 1. 字符串逆序

```c
#include <string.h>

void reverse(char str[]) {
    int len = strlen(str);
    for (int i = 0; i < len / 2; i++) {
        char temp = str[i];
        str[i] = str[len - i - 1];
        str[len - i - 1] = temp;
    }
}
```

### 2. 字符串查找

```c
#include <string.h>

char* find_char(char str[], char ch) {
    for (int i = 0; str[i] != '\0'; i++) {
        if (str[i] == ch) {
            return &str[i];
        }
    }
    return NULL;
}
```

## 五、字符数组 vs 字符串指针

### 1. 字符数组

```c
char str[20] = "Hello";
str[0] = 'h';  // 可以修改
```

### 2. 字符串指针

```c
char *str = "Hello";
str[0] = 'h';  // 未定义行为！字符串常量不能修改
```

> [!warning] 易错点
> 字符串指针指向的是字符串常量，不能修改！修改字符串常量是未定义行为。
