# 4.1 一维数组

> [!abstract] 核心问题
> 一维数组如何定义、初始化和访问？数组名的含义是什么？

## 一、数组定义

### 1. 基本形式

```c
类型 数组名[数组长度];
```

### 2. 示例

```c
int arr[10];      // 整型数组，长度为10
float score[5];   // 浮点型数组，长度为5
char name[20];    // 字符数组，长度为20
```

### 3. 注意事项

- 数组长度必须是常量表达式
- 数组长度不能是变量

## 二、数组初始化

### 1. 完全初始化

```c
int arr[5] = {1, 2, 3, 4, 5};
```

### 2. 部分初始化

```c
int arr[5] = {1, 2};  // 未初始化的元素默认为0
// arr = [1, 2, 0, 0, 0]
```

### 3. 省略长度

```c
int arr[] = {1, 2, 3, 4, 5};  // 长度由初始化列表决定，为5
```

### 4. 静态数组

```c
static int arr[5];  // 静态数组，未初始化时元素默认为0
```

## 三、数组访问

### 1. 下标访问

```c
int arr[5] = {10, 20, 30, 40, 50};
printf("%d", arr[0]);  // 输出第一个元素，10
printf("%d", arr[4]);  // 输出最后一个元素，50
```

### 2. 数组下标

- 数组下标从0开始
- 长度为n的数组，下标范围是0~n-1

### 3. 数组越界

```c
int arr[5];
arr[5] = 10;  // 数组越界，可能导致程序崩溃或数据错误
```

> [!warning] 易错点
> C语言不检查数组越界！访问越界元素是未定义行为。

## 四、数组名

### 1. 数组名的含义

数组名代表数组首元素的地址，是一个常量指针。

```c
int arr[5] = {1, 2, 3, 4, 5};
printf("%p", arr);    // 输出数组首地址
printf("%p", &arr[0]); // 与上面相同
```

### 2. 数组名与指针

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;         // p指向数组首元素
printf("%d", *p);     // 输出1
printf("%d", *(p+1)); // 输出2
```

## 五、数组遍历

```c
int arr[5] = {1, 2, 3, 4, 5};

// 使用下标遍历
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}

// 使用指针遍历
int *p = arr;
for (int i = 0; i < 5; i++) {
    printf("%d ", *(p+i));
}
```

## 六、数组作为函数参数

### 1. 传递方式

```c
void print_array(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
}

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    print_array(arr, 5);
    return 0;
}
```

### 2. 注意事项

- 数组作为函数参数时，退化为指针
- 函数无法获取数组的长度，需要额外传递长度参数
