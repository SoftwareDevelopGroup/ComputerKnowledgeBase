# 1.3 编译运行流程

> [!abstract] 核心问题
> C程序的编译运行流程是什么？每个阶段做什么？

## 一、编译运行流程

### 1. 流程图

```mermaid
flowchart LR
  A[编辑源文件] --> B[编译]
  B --> C[链接]
  C --> D[运行]
  D --> E[输出结果]
```

### 2. 四个阶段

| 阶段 | 输入 | 输出 | 作用 |
|-----|------|------|------|
| **编辑** | 文本编辑器 | `.c`源文件 | 编写程序代码 |
| **编译** | `.c`源文件 | `.obj`目标文件 | 检查语法错误，生成汇编代码并转换为机器码 |
| **链接** | `.obj`目标文件 | `.exe`可执行文件 | 将目标文件与库文件链接 |
| **运行** | `.exe`可执行文件 | 运行结果 | 执行程序 |

## 二、编译阶段

### 1. 预编译
- 处理`#include`指令
- 处理`#define`宏定义
- 删除注释

### 2. 编译
- 词法分析：识别关键字、标识符、常量
- 语法分析：检查语法规则
- 语义分析：检查语义正确性
- 生成中间代码

### 3. 汇编
- 将中间代码转换为汇编语言
- 将汇编语言转换为机器语言
- 生成目标文件

## 三、链接阶段

### 1. 静态链接
- 将库函数的代码直接复制到可执行文件中
- 优点：运行速度快
- 缺点：可执行文件较大

### 2. 动态链接
- 运行时才加载库函数
- 优点：可执行文件较小
- 缺点：运行速度稍慢

## 四、常见开发环境

### 1. Windows平台
- **Dev-C++**：轻量级IDE，适合初学者
- **Code::Blocks**：跨平台IDE
- **Visual Studio**：功能强大的IDE

### 2. Linux平台
- **GCC**：GNU编译器
- **Vim/Emacs**：文本编辑器

### 3. macOS平台
- **Xcode**：Apple官方IDE
- **CLion**：JetBrains IDE

## 五、编译命令

### 1. GCC编译命令

```bash
# 编译单个源文件
gcc hello.c -o hello

# 编译多个源文件
gcc file1.c file2.c -o program

# 启用警告信息
gcc -Wall hello.c -o hello

# 调试模式
gcc -g hello.c -o hello
```

### 2. 编译步骤

```bash
# 预处理
gcc -E hello.c -o hello.i

# 编译
gcc -S hello.i -o hello.s

# 汇编
gcc -c hello.s -o hello.o

# 链接
gcc hello.o -o hello
```

> [!warning] 易错点
> 编译错误和链接错误是不同的！编译错误是语法错误，链接错误是找不到符号或库文件。
