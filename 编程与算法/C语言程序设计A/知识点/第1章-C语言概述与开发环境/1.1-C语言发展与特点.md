# 1.1 C语言发展与特点

> [!abstract] 核心问题
> C语言是如何发展起来的？它有哪些特点？应用在哪些领域？

## 一、C语言的发展历程

### 1. 起源
- 1972年，丹尼斯·里奇（Dennis Ritchie）在贝尔实验室开发
- 源于B语言，用于编写UNIX操作系统

### 2. 标准化
- 1989年，ANSI发布C89标准
- 1999年，C99标准，增加了许多新特性
- 2011年，C11标准，支持多线程、原子操作
- 2018年，C17标准，修正了C11的一些缺陷

## 二、C语言的特点

### 1. 简洁紧凑
- 只有32个关键字
- 语法简洁，表达能力强

### 2. 高效灵活
- 接近汇编语言，执行效率高
- 可以直接访问内存地址

### 3. 可移植性强
- 代码可以在不同平台上运行
- 标准C不依赖具体硬件

### 4. 面向过程
- 程序由函数组成
- 结构化程序设计

### 5. 功能强大
- 支持指针操作
- 支持位运算
- 支持内存管理

## 三、C语言的应用领域

### 1. 系统软件
- 操作系统：UNIX、Linux、Windows内核
- 编译器、解释器

### 2. 嵌入式开发
- 单片机程序
- 嵌入式系统驱动

### 3. 科学计算
- 数值计算
- 模拟仿真

### 4. 游戏开发
- 游戏引擎
- 图形渲染

### 5. 网络编程
- 网络协议
- 服务器端程序

> [!warning] 易错点
> C语言是面向过程的语言，不是面向对象的语言。虽然可以用结构体模拟面向对象，但这不是C语言的原生特性。
