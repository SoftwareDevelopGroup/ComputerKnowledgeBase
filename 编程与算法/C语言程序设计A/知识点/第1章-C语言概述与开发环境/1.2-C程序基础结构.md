# 1.2 C程序基础结构

> [!abstract] 核心问题
> C程序的基本结构是什么？main函数的作用是什么？如何编写第一个C程序？

## 一、C程序的基本结构

### 1. 程序示例

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

### 2. 结构分析

| 组成部分 | 作用 |
|---------|------|
| `#include <stdio.h>` | 包含标准输入输出头文件 |
| `int main()` | 主函数，程序入口 |
| `printf("Hello, World!\n")` | 输出字符串 |
| `return 0` | 返回值，表示程序正常结束 |

## 二、头文件

### 1. 定义
头文件包含函数声明、宏定义、数据类型定义等。

### 2. 常用头文件

| 头文件 | 功能 |
|-------|------|
| `stdio.h` | 标准输入输出 |
| `stdlib.h` | 标准库函数 |
| `math.h` | 数学函数 |
| `string.h` | 字符串处理函数 |
| `time.h` | 时间函数 |

### 3. 包含方式

```c
#include <stdio.h>    // 系统头文件，用尖括号
#include "myheader.h" // 用户自定义头文件，用双引号
```

## 三、main函数

### 1. 定义
main函数是C程序的入口，程序从main函数开始执行。

### 2. 返回值
- `return 0`：表示程序正常结束
- `return 非0`：表示程序异常结束

### 3. 函数参数

```c
// 无参数
int main() {
    return 0;
}

// 带参数
int main(int argc, char *argv[]) {
    return 0;
}
```

## 四、语句

### 1. 表达式语句
```c
a = 1;
printf("Hello");
```

### 2. 复合语句
```c
{
    int a = 1;
    int b = 2;
    printf("%d", a + b);
}
```

### 3. 空语句
```c
;  // 什么也不做
```

## 五、注释

### 1. 单行注释
```c
// 这是单行注释
```

### 2. 多行注释
```c
/*
这是多行注释
可以跨越多行
*/
```

> [!warning] 易错点
> 多行注释不能嵌套！
