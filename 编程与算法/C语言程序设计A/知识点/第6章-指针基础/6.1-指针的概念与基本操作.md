# 6.1 指针的概念与基本操作

> [!abstract] 核心问题
> 什么是指针？如何定义和使用指针？指针与数组有什么关系？

## 一、指针的概念

### 1. 定义

指针是一个变量，其值是另一个变量的地址。

### 2. 内存地址

```c
int a = 10;
// a的地址可能是0x7fff5fbff7ac
```

### 3. 指针变量

```c
int *p;  // 定义一个指向int类型的指针
p = &a;  // p指向a的地址
```

## 二、指针的基本操作

### 1. 取地址运算符 &

```c
int a = 10;
int *p = &a;  // p = a的地址
```

### 2. 解引用运算符 *

```c
int a = 10;
int *p = &a;
printf("%d", *p);  // 输出10，通过指针访问a的值
*p = 20;           // 修改a的值为20
```

### 3. 指针赋值

```c
int a = 10;
int b = 20;
int *p = &a;
p = &b;  // p现在指向b
```

### 4. 指针比较

```c
int *p1 = &a;
int *p2 = &b;
if (p1 == p2) {
    // p1和p2指向同一个地址
}
```

## 三、指针与数组

### 1. 数组名即指针

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;  // p指向arr[0]
```

### 2. 指针访问数组

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

printf("%d", *p);     // 输出arr[0]
printf("%d", *(p+1)); // 输出arr[1]
printf("%d", *(p+2)); // 输出arr[2]
```

### 3. 指针运算

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

p++;         // p指向arr[1]
p += 2;      // p指向arr[3]
int diff = p - arr;  // diff = 3
```

### 4. 数组下标与指针

```c
arr[i] 等价于 *(arr + i) 等价于 *(p + i)
```

## 四、指针类型

### 1. 不同类型的指针

```c
int *p1;    // 指向int
float *p2;  // 指向float
char *p3;   // 指向char
```

### 2. 指针类型的意义

- 决定指针运算的步长
- 决定解引用时访问的字节数

```c
int *p1;    // p1++ 移动4字节
char *p2;   // p2++ 移动1字节
```

## 五、空指针

### 1. 定义

```c
int *p = NULL;  // NULL是0的宏定义
```

### 2. 作用

表示指针不指向任何有效地址。

### 3. 判断空指针

```c
if (p == NULL) {
    // 指针为空
}
```

## 六、指针示例

### 1. 交换两个整数

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 3, y = 5;
    swap(&x, &y);
    printf("%d %d", x, y);  // 输出5 3
    return 0;
}
```

### 2. 指针遍历数组

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

for (int i = 0; i < 5; i++) {
    printf("%d ", *(p+i));
}
```

> [!warning] 易错点
> 指针未初始化时，值是不确定的！使用未初始化的指针会导致未定义行为。
