# 6.2 指针与函数

> [!abstract] 核心问题
> 如何使用指针作为函数参数？如何返回指针？什么是函数指针？

## 一、指针作为函数参数

### 1. 传递地址

```c
void modify(int *p) {
    *p = 20;
}

int main() {
    int a = 10;
    modify(&a);  // 传递a的地址
    printf("%d", a);  // 输出20
    return 0;
}
```

### 2. 修改数组

```c
void modify_array(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        arr[i] *= 2;
    }
}
```

### 3. 返回多个值

```c
void divide(int a, int b, int *quotient, int *remainder) {
    *quotient = a / b;
    *remainder = a % b;
}

int main() {
    int q, r;
    divide(10, 3, &q, &r);
    printf("%d %d", q, r);  // 输出3 1
    return 0;
}
```

## 二、返回指针的函数

### 1. 基本形式

```c
类型 *函数名(参数列表) {
    // 返回指针
}
```

### 2. 示例

```c
int *create_array(int n) {
    int *arr = (int *)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        arr[i] = i;
    }
    return arr;
}
```

### 3. 注意事项

- 不能返回局部变量的指针
- 返回的指针需要在调用方释放

```c
int *bad_function() {
    int x = 10;
    return &x;  // 错误！x是局部变量，函数结束后释放
}
```

> [!warning] 易错点
> 不要返回局部变量的指针！局部变量在函数结束后会被释放，返回的指针会变成悬空指针。

## 三、函数指针

### 1. 定义

函数指针是指向函数的指针。

```c
int (*fp)(int, int);  // 指向返回int、接受两个int参数的函数
```

### 2. 赋值

```c
int add(int a, int b) {
    return a + b;
}

int (*fp)(int, int) = add;  // fp指向add函数
```

### 3. 调用

```c
int result = (*fp)(3, 5);  // 调用add(3, 5)
int result = fp(3, 5);     // 等价写法
```

### 4. 示例

```c
int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }

void calculate(int a, int b, int (*fp)(int, int)) {
    printf("%d", fp(a, b));
}

int main() {
    calculate(3, 5, add);      // 输出8
    calculate(3, 5, subtract); // 输出-2
    return 0;
}
```

## 四、指针数组

### 1. 定义

```c
int *arr[5];  // 数组，每个元素是int*类型的指针
```

### 2. 示例

```c
int a = 10, b = 20, c = 30;
int *arr[3] = {&a, &b, &c};
printf("%d", *arr[0]);  // 输出10
```

### 3. 字符串数组

```c
char *str[] = {"Apple", "Banana", "Cherry"};
printf("%s", str[0]);  // 输出Apple
```

## 五、指向指针的指针

### 1. 定义

```c
int **pp;  // 指向指针的指针
```

### 2. 示例

```c
int a = 10;
int *p = &a;
int **pp = &p;

printf("%d", **pp);  // 输出10
**pp = 20;           // 修改a的值为20
```

### 3. 用途

- 动态二维数组
- 修改指针变量本身
