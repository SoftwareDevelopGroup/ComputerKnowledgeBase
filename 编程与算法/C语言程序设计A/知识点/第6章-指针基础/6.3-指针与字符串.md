# 6.3 指针与字符串

> [!abstract] 核心问题
> 如何使用指针处理字符串？如何实现字符串处理函数？

## 一、字符串与指针

### 1. 字符串的表示

```c
char str[] = "Hello";
char *p = "Hello";
```

### 2. 指针访问字符串

```c
char *p = "Hello";
printf("%c", *p);     // 输出'H'
printf("%c", *(p+1)); // 输出'e'
```

### 3. 遍历字符串

```c
char *p = "Hello";
while (*p != '\0') {
    printf("%c", *p);
    p++;
}
```

## 二、字符串处理函数的实现

### 1. strlen

```c
int my_strlen(char *str) {
    int len = 0;
    while (*str != '\0') {
        len++;
        str++;
    }
    return len;
}
```

### 2. strcpy

```c
char *my_strcpy(char *dest, char *src) {
    char *temp = dest;
    while (*src != '\0') {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0';
    return temp;
}
```

### 3. strcat

```c
char *my_strcat(char *dest, char *src) {
    char *temp = dest;
    while (*dest != '\0') {
        dest++;
    }
    while (*src != '\0') {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0';
    return temp;
}
```

### 4. strcmp

```c
int my_strcmp(char *str1, char *str2) {
    while (*str1 != '\0' && *str2 != '\0') {
        if (*str1 != *str2) {
            return *str1 - *str2;
        }
        str1++;
        str2++;
    }
    return *str1 - *str2;
}
```

## 三、字符串数组

### 1. 字符数组数组

```c
char str[3][20] = {"Apple", "Banana", "Cherry"};
printf("%s", str[0]);  // 输出Apple
```

### 2. 字符指针数组

```c
char *str[] = {"Apple", "Banana", "Cherry"};
printf("%s", str[0]);  // 输出Apple
```

### 3. 对比

| 对比项 | 字符数组数组 | 字符指针数组 |
|-------|------------|------------|
| 存储方式 | 每个字符串存放在连续空间 | 字符串常量，指针指向它们 |
| 修改 | 可以修改 | 不可以修改字符串内容 |
| 内存 | 占用较大 | 占用较小 |

## 四、指针处理字符串示例

### 1. 字符串逆序

```c
void reverse(char *str) {
    char *start = str;
    char *end = str + strlen(str) - 1;
    char temp;
    
    while (start < end) {
        temp = *start;
        *start = *end;
        *end = temp;
        start++;
        end--;
    }
}
```

### 2. 字符串查找字符

```c
char *find_char(char *str, char ch) {
    while (*str != '\0') {
        if (*str == ch) {
            return str;
        }
        str++;
    }
    return NULL;
}
```

### 3. 字符串复制（安全版本）

```c
char *my_strncpy(char *dest, char *src, int n) {
    char *temp = dest;
    for (int i = 0; i < n && *src != '\0'; i++) {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0';
    return temp;
}
```

## 五、常见错误

### 1. 修改字符串常量

```c
char *p = "Hello";
*p = 'h';  // 错误！字符串常量不能修改
```

### 2. 未检查空指针

```c
void func(char *str) {
    printf("%s", str);  // 如果str为NULL，会崩溃
}
```

### 3. 缓冲区溢出

```c
char dest[5];
char src[] = "Hello";
strcpy(dest, src);  // 错误！dest不够大
```

> [!warning] 易错点
> 字符串指针指向的是字符串常量，不能修改！使用字符串函数时，要注意缓冲区溢出问题。
