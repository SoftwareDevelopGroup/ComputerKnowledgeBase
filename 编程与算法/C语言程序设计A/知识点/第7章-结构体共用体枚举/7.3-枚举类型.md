# 7.3 枚举类型

> [!abstract] 核心问题
> 什么是枚举类型？如何定义和使用枚举？枚举的应用场景是什么？

## 一、枚举定义

### 1. 基本形式

```c
enum 枚举名 {
    枚举常量1,
    枚举常量2,
    // ...
};
```

### 2. 示例

```c
enum Weekday {
    Monday,
    Tuesday,
    Wednesday,
    Thursday,
    Friday,
    Saturday,
    Sunday
};
```

### 3. 默认值

枚举常量默认从0开始递增。

```c
enum Weekday {
    Monday,     // 0
    Tuesday,    // 1
    Wednesday,  // 2
    Thursday,   // 3
    Friday,     // 4
    Saturday,   // 5
    Sunday      // 6
};
```

### 4. 指定值

```c
enum Weekday {
    Monday = 1,
    Tuesday,    // 2
    Wednesday,  // 3
    Thursday,   // 4
    Friday,     // 5
    Saturday,   // 6
    Sunday      // 7
};
```

## 二、枚举变量

### 1. 定义

```c
enum Weekday today;
today = Monday;
```

### 2. 初始化

```c
enum Weekday today = Wednesday;
```

### 3. 使用

```c
enum Weekday today = Monday;
if (today == Monday) {
    printf("周一\n");
}
```

## 三、枚举的特点

### 1. 枚举常量是整数

```c
enum Weekday w = Monday;
printf("%d", w);  // 输出0或1（取决于定义）
```

### 2. 可以进行比较

```c
if (today < Friday) {
    printf("工作日\n");
}
```

### 3. 不能直接输入输出

```c
enum Weekday w;
// scanf("%d", &w);  // 不推荐直接输入
w = (enum Weekday)1;  // 需要强制转换
```

## 四、枚举 vs 宏定义

| 对比项 | 枚举 | 宏定义 |
|-------|------|--------|
| 类型 | 有类型 | 无类型 |
| 作用域 | 遵循作用域规则 | 文件作用域 |
| 调试 | 可以查看枚举名 | 只能查看值 |
| 扩展性 | 可以添加新常量 | 需要修改宏定义 |

## 五、枚举的应用场景

### 1. 表示状态

```c
enum Status {
    SUCCESS,
    FAILURE,
    PENDING
};
```

### 2. 表示选项

```c
enum Color {
    RED,
    GREEN,
    BLUE,
    YELLOW
};
```

### 3. 表示错误码

```c
enum ErrorCode {
    NO_ERROR = 0,
    FILE_NOT_FOUND,
    PERMISSION_DENIED,
    OUT_OF_MEMORY
};
```

## 六、枚举示例

### 1. 星期几

```c
#include <stdio.h>

enum Weekday {
    Monday = 1,
    Tuesday,
    Wednesday,
    Thursday,
    Friday,
    Saturday,
    Sunday
};

int main() {
    enum Weekday today = Monday;
    
    switch (today) {
        case Monday:
            printf("周一\n");
            break;
        case Tuesday:
            printf("周二\n");
            break;
        // ...
        default:
            printf("周日\n");
            break;
    }
    
    return 0;
}
```

### 2. 状态机

```c
enum State {
    IDLE,
    RUNNING,
    PAUSED,
    STOPPED
};

enum State current_state = IDLE;

void start() {
    if (current_state == IDLE) {
        current_state = RUNNING;
    }
}
```

## 七、typedef与枚举

### 1. 简化类型名

```c
typedef enum Weekday {
    Monday,
    Tuesday,
    Wednesday,
    Thursday,
    Friday,
    Saturday,
    Sunday
} Weekday;

Weekday today = Monday;  // 不需要写enum
```

> [!warning] 易错点
> 枚举常量是整数，不能直接用于字符串输出！需要使用switch或数组进行转换。
