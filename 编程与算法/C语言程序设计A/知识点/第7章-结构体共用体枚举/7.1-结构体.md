# 7.1 结构体

> [!abstract] 核心问题
> 如何定义结构体？如何访问结构体成员？结构体数组和结构体指针如何使用？

## 一、结构体定义

### 1. 基本形式

```c
struct 结构体名 {
    成员类型1 成员名1;
    成员类型2 成员名2;
    // ...
};
```

### 2. 示例

```c
struct Student {
    char name[20];
    int age;
    float score;
};
```

## 二、结构体变量

### 1. 定义方式

```c
// 方式1：先定义结构体，再定义变量
struct Student {
    char name[20];
    int age;
    float score;
};
struct Student s1;

// 方式2：定义结构体的同时定义变量
struct Student {
    char name[20];
    int age;
    float score;
} s1, s2;

// 方式3：匿名结构体
struct {
    char name[20];
    int age;
    float score;
} s1;
```

### 2. 初始化

```c
struct Student s1 = {"张三", 18, 90.5};

struct Student s2;
s2.age = 19;
strcpy(s2.name, "李四");
s2.score = 85.0;
```

### 3. 成员访问

```c
struct Student s = {"张三", 18, 90.5};
printf("%s", s.name);   // 使用.访问成员
printf("%d", s.age);    // 使用.访问成员
```

## 三、结构体数组

### 1. 定义

```c
struct Student students[3];
```

### 2. 初始化

```c
struct Student students[3] = {
    {"张三", 18, 90.5},
    {"李四", 19, 85.0},
    {"王五", 20, 95.0}
};
```

### 3. 访问

```c
printf("%s", students[0].name);
students[1].age = 20;
```

### 4. 遍历

```c
for (int i = 0; i < 3; i++) {
    printf("%s %d %.2f\n", students[i].name, students[i].age, students[i].score);
}
```

## 四、结构体指针

### 1. 定义

```c
struct Student s = {"张三", 18, 90.5};
struct Student *p = &s;
```

### 2. 成员访问

```c
struct Student *p = &s;
printf("%s", (*p).name);   // 使用(*p).访问
printf("%s", p->name);     // 使用->访问，更简洁
```

### 3. 动态分配

```c
struct Student *p = (struct Student *)malloc(sizeof(struct Student));
p->age = 18;
strcpy(p->name, "张三");
p->score = 90.5;
free(p);
```

## 五、结构体作为函数参数

### 1. 值传递

```c
void print_student(struct Student s) {
    printf("%s %d %.2f", s.name, s.age, s.score);
}
```

### 2. 地址传递

```c
void modify_student(struct Student *p) {
    p->age = 20;
}
```

### 3. 返回结构体

```c
struct Student create_student(char *name, int age, float score) {
    struct Student s;
    strcpy(s.name, name);
    s.age = age;
    s.score = score;
    return s;
}
```

## 六、结构体嵌套

### 1. 定义

```c
struct Date {
    int year;
    int month;
    int day;
};

struct Student {
    char name[20];
    int age;
    struct Date birthday;
};
```

### 2. 访问

```c
struct Student s;
s.birthday.year = 2000;
s.birthday.month = 1;
s.birthday.day = 1;
```

> [!warning] 易错点
> 结构体作为函数参数时，值传递会复制整个结构体，效率较低。建议使用指针传递。
