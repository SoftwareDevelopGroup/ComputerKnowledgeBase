# 7.2 共用体

> [!abstract] 核心问题
> 共用体是什么？与结构体有什么区别？应用场景是什么？

## 一、共用体定义

### 1. 基本形式

```c
union 共用体名 {
    成员类型1 成员名1;
    成员类型2 成员名2;
    // ...
};
```

### 2. 示例

```c
union Data {
    int i;
    float f;
    char c;
};
```

## 二、共用体变量

### 1. 定义和初始化

```c
union Data d;
d.i = 10;
```

### 2. 成员访问

```c
union Data d;
d.i = 10;
printf("%d", d.i);  // 输出10
d.f = 3.14;
printf("%f", d.f);  // 输出3.14
```

## 三、共用体的特点

### 1. 内存共享

共用体的所有成员共享同一块内存空间。

```c
union Data d;
printf("%d", sizeof(d));  // 输出4（最大成员的大小）
```

### 2. 同一时刻只能使用一个成员

```c
union Data d;
d.i = 10;
d.f = 3.14;  // 覆盖了d.i的值
printf("%d", d.i);  // 输出不确定的值
```

### 3. 初始化

```c
union Data d = {10};  // 只能初始化第一个成员
```

## 四、结构体 vs 共用体

| 对比项 | 结构体 | 共用体 |
|-------|--------|--------|
| 内存分配 | 各成员独立分配 | 所有成员共享 |
| 内存大小 | 所有成员大小之和 | 最大成员的大小 |
| 使用方式 | 可以同时访问所有成员 | 同一时刻只能访问一个成员 |
| 初始化 | 可以初始化所有成员 | 只能初始化第一个成员 |

## 五、共用体的应用场景

### 1. 节省内存

当多个变量不同时使用时，可以共用同一块内存。

```c
union Value {
    int int_val;
    float float_val;
    char str_val[20];
};
```

### 2. 类型转换

```c
union Converter {
    int i;
    float f;
};

union Converter c;
c.f = 3.14;
printf("%d", c.i);  // 输出3.14的二进制表示
```

### 3. 数据解析

```c
union Packet {
    struct {
        unsigned int type : 4;
        unsigned int data : 12;
    } parts;
    unsigned short value;
};

union Packet p;
p.value = 0x1234;
printf("%d", p.parts.type);   // 输出4
printf("%d", p.parts.data);   // 输出0x123
```

## 六、共用体示例

### 1. 数据存储

```c
#include <stdio.h>

union Data {
    int i;
    float f;
    char c;
};

int main() {
    union Data d;
    
    d.i = 10;
    printf("d.i = %d\n", d.i);
    
    d.f = 3.14;
    printf("d.f = %f\n", d.f);
    
    d.c = 'A';
    printf("d.c = %c\n", d.c);
    
    printf("共用体大小: %d\n", sizeof(d));
    return 0;
}
```

### 2. 位域

```c
struct Flags {
    unsigned int flag1 : 1;
    unsigned int flag2 : 1;
    unsigned int flag3 : 2;
};

struct Flags f;
f.flag1 = 1;
f.flag2 = 0;
f.flag3 = 3;
```

> [!warning] 易错点
> 共用体的成员共享内存，修改一个成员会影响其他成员的值！
