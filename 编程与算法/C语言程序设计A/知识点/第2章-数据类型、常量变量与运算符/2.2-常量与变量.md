# 2.2 常量与变量

> [!abstract] 核心问题
> 什么是常量？什么是变量？如何定义和使用它们？

## 一、常量

### 1. 字面常量

```c
100      // 整型常量
3.14     // 浮点型常量
'A'      // 字符常量
"Hello"  // 字符串常量
```

### 2. const常量

```c
const int MAX = 100;
const float PI = 3.14;
```

特点：
- 必须初始化
- 值不能修改
- 有类型

### 3. 宏定义

```c
#define MAX 100
#define PI 3.14
#define SQUARE(x) ((x) * (x))
```

特点：
- 无类型
- 预处理阶段替换
- 注意括号的使用

## 二、变量

### 1. 变量声明

```c
int a;           // 声明但未初始化
int b = 10;      // 声明并初始化
int c, d, e;     // 同时声明多个变量
```

### 2. 变量命名规则

- 只能包含字母、数字、下划线
- 不能以数字开头
- 不能使用关键字
- 区分大小写

### 3. 变量初始化

```c
int a = 0;       // 显式初始化
int b;           // 未初始化，值不确定
b = 5;           // 赋值
```

> [!warning] 易错点
> 未初始化的变量值是不确定的，使用前必须赋值！

## 三、符号常量 vs 变量

| 对比项 | 符号常量 | 变量 |
|-------|---------|------|
| 值是否可变 | 不可变 | 可变 |
| 内存占用 | 不占用（宏定义）或占用（const） | 占用 |
| 类型 | 无（宏定义）或有（const） | 有 |
| 作用域 | 全局 | 取决于声明位置 |

## 四、左值和右值

### 1. 左值
可以放在赋值运算符左边的表达式，代表一个内存位置。

```c
int a = 10;   // a是左值
a = 20;       // 正确，a是左值
```

### 2. 右值
只能放在赋值运算符右边的表达式，代表一个值。

```c
10 = a;       // 错误，10是右值
int b = a + 5;  // a + 5是右值
```
