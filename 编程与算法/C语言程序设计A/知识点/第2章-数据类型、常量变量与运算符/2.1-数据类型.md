# 2.1 数据类型

> [!abstract] 核心问题
> C语言有哪些数据类型？各种数据类型的大小和范围是什么？

## 一、数据类型分类

### 1. 基本数据类型

| 类型 | 说明 | 大小 | 范围 |
|-----|------|------|------|
| `char` | 字符型 | 1字节 | -128~127或0~255 |
| `short` | 短整型 | 2字节 | -32768~32767 |
| `int` | 整型 | 4字节 | -2^31~2^31-1 |
| `long` | 长整型 | 4或8字节 | 更大范围 |
| `float` | 单精度浮点型 | 4字节 | 约10^-38~10^38 |
| `double` | 双精度浮点型 | 8字节 | 约10^-308~10^308 |

### 2. 构造数据类型
- 数组
- 结构体
- 共用体
- 枚举

### 3. 指针类型
- 指向变量的指针
- 指向数组的指针
- 指向函数的指针

### 4. 空类型
- `void`：表示无类型

## 二、整型数据

### 1. 整型常量

```c
// 十进制
100
-50

// 八进制（以0开头）
0123   // 等于十进制83

// 十六进制（以0x开头）
0x1A   // 等于十进制26
0XFF   // 等于十进制255
```

### 2. 整型变量

```c
int a;           // 声明整型变量
int b = 10;      // 声明并初始化
short c = 5;     // 短整型
long d = 100000L; // 长整型，加L后缀
```

## 三、浮点型数据

### 1. 浮点型常量

```c
// 小数形式
3.14
-0.5

// 指数形式
1.5e10   // 1.5 × 10^10
2.0E-5   // 2.0 × 10^-5
```

### 2. 浮点型变量

```c
float x = 3.14f;   // 单精度，加f后缀
double y = 3.14;   // 双精度
```

## 四、字符型数据

### 1. 字符常量

```c
// 普通字符
'A'
'b'
'1'

// 转义字符
'\n'   // 换行
'\t'   // 制表符
'\\'   // 反斜杠
'\''   // 单引号
'\"'   // 双引号
'\0'   // 空字符
```

### 2. 字符变量

```c
char ch = 'A';
char newline = '\n';
```

### 3. 字符与ASCII码

字符在内存中以ASCII码形式存储：

| 字符 | ASCII码 |
|-----|--------|
| '0' | 48 |
| 'A' | 65 |
| 'a' | 97 |
| '\n' | 10 |

## 五、类型转换

### 1. 隐式转换

```c
int a = 10;
float b = 3.14;
float c = a + b;  // a自动转换为float
```

转换规则：
- 低精度 → 高精度
- char/short → int → float → double

### 2. 显式转换

```c
int a = (int)3.14;   // 强制转换为int，结果为3
double b = (double)5 / 2;  // 结果为2.5，不是2
```

> [!warning] 易错点
> 整型除法会截断小数部分！`5/2`的结果是2，不是2.5。要得到浮点结果，需要进行类型转换。
