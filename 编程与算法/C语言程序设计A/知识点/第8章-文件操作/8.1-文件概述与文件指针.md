# 8.1 文件概述与文件指针

> [!abstract] 核心问题
> 什么是文件？文件类型有哪些？什么是文件指针？

## 一、文件概述

### 1. 文件定义

文件是存储在外部介质上的数据集合。

### 2. 文件分类

#### 按数据格式分类

| 类型 | 说明 | 示例 |
|-----|------|------|
| 文本文件 | 以ASCII码形式存储 | .txt、.c、.h |
| 二进制文件 | 以二进制形式存储 | .exe、.jpg、.dat |

#### 按访问方式分类

| 类型 | 说明 |
|-----|------|
| 顺序文件 | 从头到尾顺序读写 |
| 随机文件 | 可以任意位置读写 |

## 二、文件指针

### 1. 定义

文件指针是指向FILE结构体的指针。

```c
FILE *fp;  // 定义文件指针
```

### 2. FILE结构体

FILE结构体包含文件的相关信息：
- 文件描述符
- 文件位置指针
- 缓冲区大小
- 读写模式

### 3. 标准文件指针

C语言提供了三个标准文件指针：

| 文件指针 | 含义 | 设备 |
|---------|------|------|
| `stdin` | 标准输入 | 键盘 |
| `stdout` | 标准输出 | 屏幕 |
| `stderr` | 标准错误 | 屏幕 |

## 三、文件操作流程

### 1. 流程图

```mermaid
flowchart LR
  A[打开文件] --> B[读写操作]
  B --> C[关闭文件]
```

### 2. 步骤说明

| 步骤 | 操作 | 函数 |
|-----|------|------|
| **打开** | 创建或打开文件 | `fopen()` |
| **读写** | 读取或写入数据 | `fscanf()`、`fprintf()`、`fgetc()`、`fputc()`等 |
| **关闭** | 关闭文件 | `fclose()` |

## 四、文件操作示例

### 1. 标准输入输出

```c
#include <stdio.h>

int main() {
    int a;
    printf("请输入一个整数：");
    scanf("%d", &a);
    printf("你输入的是：%d\n", a);
    return 0;
}
```

### 2. 文件操作框架

```c
#include <stdio.h>

int main() {
    FILE *fp;
    
    // 打开文件
    fp = fopen("test.txt", "w");
    if (fp == NULL) {
        printf("文件打开失败\n");
        return 1;
    }
    
    // 写入数据
    fprintf(fp, "Hello, World!\n");
    
    // 关闭文件
    fclose(fp);
    
    return 0;
}
```
