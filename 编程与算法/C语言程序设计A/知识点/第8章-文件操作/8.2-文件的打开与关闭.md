# 8.2 文件的打开与关闭

> [!abstract] 核心问题
> 如何打开和关闭文件？文件打开模式有哪些？

## 一、文件打开

### 1. fopen函数

```c
FILE *fopen(const char *filename, const char *mode);
```

### 2. 参数说明

| 参数 | 说明 |
|-----|------|
| `filename` | 文件名（可以包含路径） |
| `mode` | 打开模式 |

### 3. 返回值

- 成功：返回文件指针
- 失败：返回NULL

### 4. 文件打开模式

| 模式 | 含义 |
|-----|------|
| `"r"` | 只读，文件必须存在 |
| `"w"` | 只写，文件不存在则创建，存在则清空 |
| `"a"` | 追加，文件不存在则创建，在末尾追加 |
| `"r+"` | 读写，文件必须存在 |
| `"w+"` | 读写，文件不存在则创建，存在则清空 |
| `"a+"` | 读写，文件不存在则创建，在末尾追加 |
| `"rb"` | 只读二进制 |
| `"wb"` | 只写二进制 |
| `"ab"` | 追加二进制 |
| `"rb+"` | 读写二进制 |
| `"wb+"` | 读写二进制 |
| `"ab+"` | 读写二进制 |

### 5. 示例

```c
FILE *fp;

// 打开文本文件只读
fp = fopen("test.txt", "r");

// 打开文本文件只写
fp = fopen("test.txt", "w");

// 打开二进制文件读写
fp = fopen("data.dat", "rb+");
```

### 6. 错误处理

```c
FILE *fp = fopen("test.txt", "r");
if (fp == NULL) {
    printf("文件打开失败\n");
    perror("错误原因");
    return 1;
}
```

## 二、文件关闭

### 1. fclose函数

```c
int fclose(FILE *fp);
```

### 2. 返回值

- 成功：返回0
- 失败：返回EOF（-1）

### 3. 示例

```c
FILE *fp = fopen("test.txt", "w");
// ... 操作 ...
fclose(fp);
```

### 4. 为什么要关闭文件

- 释放文件资源
- 确保数据写入磁盘
- 避免文件损坏

## 三、文件操作示例

### 1. 打开和关闭文件

```c
#include <stdio.h>

int main() {
    FILE *fp;
    
    // 打开文件
    fp = fopen("example.txt", "w");
    if (fp == NULL) {
        printf("文件打开失败\n");
        return 1;
    }
    
    printf("文件打开成功\n");
    
    // 关闭文件
    if (fclose(fp) == 0) {
        printf("文件关闭成功\n");
    } else {
        printf("文件关闭失败\n");
    }
    
    return 0;
}
```

### 2. 检查文件是否存在

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) {
        printf("文件不存在\n");
    } else {
        printf("文件存在\n");
        fclose(fp);
    }
    return 0;
}
```

> [!warning] 易错点
> 打开文件后一定要检查返回值！如果文件不存在或权限不足，fopen会返回NULL。使用完文件后一定要关闭！
