# 8.3 文件的读写操作

> [!abstract] 核心问题
> 如何读写文件？常用的文件读写函数有哪些？

## 一、字符读写

### 1. fputc函数

```c
int fputc(int ch, FILE *fp);
```

写入一个字符到文件。

```c
FILE *fp = fopen("test.txt", "w");
fputc('A', fp);
fclose(fp);
```

### 2. fgetc函数

```c
int fgetc(FILE *fp);
```

从文件读取一个字符。

```c
FILE *fp = fopen("test.txt", "r");
char ch = fgetc(fp);
printf("%c", ch);
fclose(fp);
```

### 3. 示例：复制文件

```c
#include <stdio.h>

int main() {
    FILE *src, *dest;
    char ch;
    
    src = fopen("source.txt", "r");
    dest = fopen("dest.txt", "w");
    
    while ((ch = fgetc(src)) != EOF) {
        fputc(ch, dest);
    }
    
    fclose(src);
    fclose(dest);
    return 0;
}
```

## 二、字符串读写

### 1. fputs函数

```c
int fputs(const char *str, FILE *fp);
```

写入一个字符串到文件。

```c
FILE *fp = fopen("test.txt", "w");
fputs("Hello, World!\n", fp);
fclose(fp);
```

### 2. fgets函数

```c
char *fgets(char *str, int n, FILE *fp);
```

从文件读取一行字符串。

```c
FILE *fp = fopen("test.txt", "r");
char str[100];
fgets(str, 100, fp);
printf("%s", str);
fclose(fp);
```

### 3. 示例：读取文件内容

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("test.txt", "r");
    char str[100];
    
    while (fgets(str, 100, fp) != NULL) {
        printf("%s", str);
    }
    
    fclose(fp);
    return 0;
}
```

## 三、格式化读写

### 1. fprintf函数

```c
int fprintf(FILE *fp, const char *format, ...);
```

格式化写入数据到文件。

```c
FILE *fp = fopen("data.txt", "w");
int a = 10;
float b = 3.14;
fprintf(fp, "a = %d, b = %.2f\n", a, b);
fclose(fp);
```

### 2. fscanf函数

```c
int fscanf(FILE *fp, const char *format, ...);
```

格式化读取数据从文件。

```c
FILE *fp = fopen("data.txt", "r");
int a;
float b;
fscanf(fp, "a = %d, b = %f", &a, &b);
printf("%d %.2f", a, b);
fclose(fp);
```

### 3. 示例：写入和读取结构体

```c
#include <stdio.h>

struct Student {
    char name[20];
    int age;
    float score;
};

int main() {
    struct Student s = {"张三", 18, 90.5};
    
    // 写入文件
    FILE *fp = fopen("student.txt", "w");
    fprintf(fp, "%s %d %.2f", s.name, s.age, s.score);
    fclose(fp);
    
    // 读取文件
    struct Student s2;
    fp = fopen("student.txt", "r");
    fscanf(fp, "%s %d %f", s2.name, &s2.age, &s2.score);
    printf("%s %d %.2f", s2.name, s2.age, s2.score);
    fclose(fp);
    
    return 0;
}
```

## 四、二进制读写

### 1. fwrite函数

```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *fp);
```

写入二进制数据到文件。

```c
struct Student s = {"张三", 18, 90.5};
FILE *fp = fopen("student.dat", "wb");
fwrite(&s, sizeof(struct Student), 1, fp);
fclose(fp);
```

### 2. fread函数

```c
size_t fread(void *ptr, size_t size, size_t count, FILE *fp);
```

读取二进制数据从文件。

```c
struct Student s;
FILE *fp = fopen("student.dat", "rb");
fread(&s, sizeof(struct Student), 1, fp);
printf("%s %d %.2f", s.name, s.age, s.score);
fclose(fp);
```

## 五、文件定位

### 1. fseek函数

```c
int fseek(FILE *fp, long offset, int origin);
```

移动文件位置指针。

| origin | 含义 |
|-------|------|
| `SEEK_SET` | 文件开头 |
| `SEEK_CUR` | 当前位置 |
| `SEEK_END` | 文件末尾 |

```c
FILE *fp = fopen("test.txt", "r");
fseek(fp, 5, SEEK_SET);  // 移动到第5个字节
fclose(fp);
```

### 2. ftell函数

```c
long ftell(FILE *fp);
```

获取当前文件位置。

```c
FILE *fp = fopen("test.txt", "r");
long pos = ftell(fp);
printf("%ld", pos);
fclose(fp);
```

### 3. rewind函数

```c
void rewind(FILE *fp);
```

将文件位置指针移到文件开头。

```c
FILE *fp = fopen("test.txt", "r");
// 读取内容...
rewind(fp);  // 回到开头
// 重新读取...
fclose(fp);
```

## 六、文件操作函数总结

| 函数 | 功能 |
|-----|------|
| `fputc` | 写入一个字符 |
| `fgetc` | 读取一个字符 |
| `fputs` | 写入一个字符串 |
| `fgets` | 读取一行字符串 |
| `fprintf` | 格式化写入 |
| `fscanf` | 格式化读取 |
| `fwrite` | 二进制写入 |
| `fread` | 二进制读取 |
| `fseek` | 移动文件指针 |
| `ftell` | 获取文件位置 |
| `rewind` | 重置文件指针 |

> [!warning] 易错点
> 使用fscanf读取字符串时，遇到空格会停止！如果需要读取包含空格的字符串，使用fgets。
