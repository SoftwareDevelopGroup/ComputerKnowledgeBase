# 5.3 变量的作用域与存储类别

> [!abstract] 核心问题
> 变量的作用域是什么？存储类别有哪些？它们的区别是什么？

## 一、变量的作用域

### 1. 局部变量

定义在函数内部的变量。

```c
void func() {
    int x = 10;  // 局部变量
    printf("%d", x);
}

int main() {
    // printf("%d", x);  // 错误，x不可见
    return 0;
}
```

特点：
- 作用域仅限于定义它的函数
- 函数调用时分配内存，函数结束时释放内存
- 默认值不确定

### 2. 全局变量

定义在函数外部的变量。

```c
int x = 10;  // 全局变量

void func() {
    printf("%d", x);  // 可以访问
}

int main() {
    printf("%d", x);  // 可以访问
    return 0;
}
```

特点：
- 作用域是整个程序
- 程序开始时分配内存，程序结束时释放内存
- 默认值为0

## 二、存储类别

### 1. auto变量

自动变量，默认的存储类别。

```c
void func() {
    auto int x = 10;  // 等价于 int x = 10;
}
```

特点：
- 自动分配和释放内存
- 局部变量默认是auto类型

### 2. static变量

静态变量。

```c
void func() {
    static int count = 0;
    count++;
    printf("%d ", count);
}

int main() {
    func();  // 输出1
    func();  // 输出2
    func();  // 输出3
    return 0;
}
```

特点：
- 只初始化一次
- 函数结束后不释放内存
- 值会保留到下次调用

### 3. extern变量

外部变量，用于声明其他文件中定义的全局变量。

```c
// file1.c
int x = 10;

// file2.c
extern int x;  // 声明外部变量
printf("%d", x);  // 输出10
```

### 4. register变量

寄存器变量，建议编译器将变量存储在寄存器中。

```c
void func() {
    register int i;
    for (i = 0; i < 100000; i++) {
        // 频繁使用的变量
    }
}
```

特点：
- 访问速度快
- 数量有限
- 不能取地址

## 三、static的作用

### 1. 局部静态变量

```c
void func() {
    static int x = 0;
    x++;
    printf("%d", x);
}
```

特点：
- 只初始化一次
- 值会保留到下次调用

### 2. 全局静态变量

```c
static int x = 10;  // 只能在本文件中访问
```

特点：
- 作用域仅限于本文件
- 其他文件无法访问

## 四、作用域与存储类别总结

| 存储类别 | 作用域 | 生命周期 | 默认值 |
|---------|-------|---------|--------|
| auto | 局部 | 函数调用期间 | 不确定 |
| static（局部） | 局部 | 整个程序 | 0 |
| static（全局） | 文件 | 整个程序 | 0 |
| extern | 全局 | 整个程序 | 0 |
| register | 局部 | 函数调用期间 | 不确定 |

## 五、同名变量的处理

当局部变量和全局变量同名时，局部变量优先。

```c
int x = 10;  // 全局变量

void func() {
    int x = 20;  // 局部变量，覆盖全局变量
    printf("%d", x);  // 输出20
}

int main() {
    printf("%d", x);  // 输出10
    func();
    return 0;
}
```

> [!warning] 易错点
> 尽量避免局部变量和全局变量同名，以免造成混淆！
