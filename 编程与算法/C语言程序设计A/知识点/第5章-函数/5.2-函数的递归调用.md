# 5.2 函数的递归调用

> [!abstract] 核心问题
> 什么是递归？如何编写递归函数？递归和迭代有什么区别？

## 一、递归的概念

### 1. 定义

递归是指函数调用自身的过程。

### 2. 递归的条件

- **递归公式**：将问题分解为规模更小的子问题
- **递归终止条件**：当问题规模足够小时，直接返回结果

## 二、递归示例

### 1. 阶乘

```c
int factorial(int n) {
    if (n == 0 || n == 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

执行过程：

```mermaid
flowchart LR
  A[factorial(5)] --> B[5 * factorial(4)]
  B --> C[4 * factorial(3)]
  C --> D[3 * factorial(2)]
  D --> E[2 * factorial(1)]
  E --> F[1]
```

### 2. 斐波那契数列

```c
int fibonacci(int n) {
    if (n == 1 || n == 2) {
        return 1;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

### 3. 递归求和

```c
int sum(int arr[], int n) {
    if (n == 0) {
        return 0;
    }
    return arr[n - 1] + sum(arr, n - 1);
}
```

## 三、递归的优缺点

### 1. 优点

- 代码简洁，易于理解
- 适合解决分治类问题

### 2. 缺点

- 效率较低，有重复计算
- 占用大量栈空间
- 可能导致栈溢出

## 四、递归与迭代

### 1. 迭代实现阶乘

```c
int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
```

### 2. 对比

| 对比项 | 递归 | 迭代 |
|-------|------|------|
| 代码简洁性 | 高 | 低 |
| 效率 | 低 | 高 |
| 内存消耗 | 高（栈空间） | 低 |
| 可读性 | 好 | 较差 |

## 五、递归调用的执行过程

### 1. 栈帧

每次函数调用都会在栈上创建一个栈帧，存储：
- 函数的参数
- 局部变量
- 返回地址

### 2. 执行过程

```c
int factorial(int n) {
    if (n == 1) return 1;
    return n * factorial(n - 1);
}

// 调用 factorial(3) 的执行过程：
// 1. 创建栈帧：n=3
// 2. 调用 factorial(2)
// 3. 创建栈帧：n=2
// 4. 调用 factorial(1)
// 5. 创建栈帧：n=1，返回1
// 6. 返回：2 * 1 = 2
// 7. 返回：3 * 2 = 6
```

## 六、尾递归

### 1. 定义

尾递归是指递归调用在函数的最后一步。

### 2. 示例

```c
int factorial_tail(int n, int accumulator) {
    if (n == 1) {
        return accumulator;
    }
    return factorial_tail(n - 1, n * accumulator);
}

// 调用：factorial_tail(5, 1)
```

### 3. 特点

- 尾递归可以被编译器优化为循环
- 不会增加栈空间

> [!warning] 易错点
> 不是所有编译器都支持尾递归优化！编写递归函数时，要注意栈溢出问题。
