### 简答题答案

1. int（4字节）、float（4字节）、double（8字节）、char（1字节）、short（2字节）、long（4或8字节）。

2. 常量值不可修改，变量值可以修改；常量有const常量和宏定义，变量必须声明。

3. 优先级从高到低：()、单目运算符、算术运算符、关系运算符、逻辑运算符、条件运算符、赋值运算符。

4. 隐式转换：低精度→高精度；显式转换：使用(type)强制转换。

5. 左值：可以放在赋值运算符左边，代表内存位置；右值：只能放在赋值运算符右边，代表值。

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

int main() {
    printf("char: %d\n", sizeof(char));
    printf("short: %d\n", sizeof(short));
    printf("int: %d\n", sizeof(int));
    printf("long: %d\n", sizeof(long));
    printf("float: %d\n", sizeof(float));
    printf("double: %d\n", sizeof(double));
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

int main() {
    int result = (3+5)*2-10/2;
    printf("%d\n", result);
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

int main() {
    char ch;
    printf("请输入一个小写字母：");
    scanf("%c", &ch);
    ch = ch - 32;
    printf("大写字母是：%c\n", ch);
    return 0;
}
```
