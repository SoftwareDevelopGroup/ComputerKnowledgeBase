### 填空题答案

2. 取地址

3. 解引用

### 简答题答案

1. 指针是一个变量，其值是另一个变量的地址。定义：类型 *指针名;

2. &：取地址运算符，获取变量的地址；*：解引用运算符，访问指针指向的变量。

3. 数组名是常量指针，代表数组首元素的地址；arr[i]等价于*(arr+i)。

4. 将实参的地址传递给形参指针，通过解引用修改实参的值。

5. 函数指针是指向函数的指针，可以存储函数的地址，通过函数指针调用函数。

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 3, y = 5;
    swap(&x, &y);
    printf("%d %d\n", x, y);
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int *p = arr;
    for (int i = 0; i < 5; i++) {
        printf("%d ", *(p+i));
    }
    printf("\n");
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }

int main() {
    int (*fp)(int, int);
    fp = add;
    printf("%d\n", fp(3, 5));
    fp = subtract;
    printf("%d\n", fp(3, 5));
    return 0;
}
```
