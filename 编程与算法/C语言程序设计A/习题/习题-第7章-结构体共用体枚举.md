### 填空题答案

1. struct

2. .

5. 最大成员的大小

6. 0

8. struct 结构体名 数组名[长度]

### 简答题答案

1. struct 结构体名 { 成员类型 成员名; ... };

2. 使用.运算符访问结构体变量的成员，使用->运算符访问结构体指针的成员。

3. 结构体各成员独立分配内存，大小是所有成员大小之和；共用体所有成员共享内存，大小是最大成员的大小。

4. 枚举类型用于定义一组相关的常量，提高代码可读性。

5. struct 结构体名 数组名[长度] = { {成员1}, {成员2}, ... };

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

struct Student {
    char name[20];
    int age;
    float score;
};

int main() {
    struct Student s = {"张三", 18, 90.5};
    printf("%s %d %.2f\n", s.name, s.age, s.score);
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

struct Student {
    char name[20];
    int age;
    float score;
};

int main() {
    struct Student students[3] = {
        {"张三", 18, 90.5},
        {"李四", 19, 85.0},
        {"王五", 20, 95.0}
    };
    for (int i = 0; i < 3; i++) {
        printf("%s %d %.2f\n", students[i].name, students[i].age, students[i].score);
    }
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

enum Weekday {
    Monday,
    Tuesday,
    Wednesday,
    Thursday,
    Friday,
    Saturday,
    Sunday
};

int main() {
    printf("%d %d %d\n", Monday, Tuesday, Sunday);
    return 0;
}
```
