### 填空题答案

1. 返回值类型 函数名(参数列表) { 函数体 }

2. 值传递、地址传递

3. 终止条件

4. 定义它的函数

5. 整个程序

6. 只初始化一次，值会保留到下次调用

7. 告诉编译器函数的名称、返回类型和参数类型

8. 退化为指针

### 简答题答案

1. 返回值类型 函数名(参数列表) { 函数体 return 返回值; }

2. 值传递：实参的值复制给形参，形参的修改不影响实参；地址传递：实参的地址传递给形参，可以通过指针修改实参。

3. 递归函数调用自身，必须有终止条件，将问题分解为规模更小的子问题。

4. 局部变量定义在函数内部，作用域仅限于函数；全局变量定义在函数外部，作用域是整个程序。

5. static变量只初始化一次，函数结束后不释放内存，值会保留到下次调用。

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
    printf("%d\n", add(3, 5));
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

int factorial(int n) {
    if (n == 0 || n == 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main() {
    printf("%d\n", factorial(5));
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

void count() {
    static int num = 0;
    num++;
    printf("第%d次调用\n", num);
}

int main() {
    count();
    count();
    count();
    return 0;
}
```
