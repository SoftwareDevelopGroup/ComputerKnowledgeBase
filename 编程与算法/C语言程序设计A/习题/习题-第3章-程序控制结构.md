## 一、选择题

### 单选题

1. 以下哪个是选择结构语句（ ）
   A. if
   B. for
   C. while

2. if语句的条件表达式结果为（ ）时执行if块
   A. 0
   B. 非0
   C. 正数
   D. 负数

3. switch语句的表达式类型必须是（ ）
   A. 整型或字符型
   B. 浮点型
   C. 字符串
   D. 任意类型

4. switch语句中，break的作用是（ ）
   A. 跳过当前case
   B. 跳出switch语句
   C. 继续执行下一个case
   D. 重新开始switch

5. while循环和do-while循环的区别是（ ）
   A. while先执行后判断，do-while先判断后执行
   B. while先判断后执行，do-while先执行后判断
   C. 没有区别
   D. while循环次数不确定，do-while循环次数确定

6. for循环的三个表达式分别是（ ）
   A. 初始化、条件、更新
   B. 条件、初始化、更新
   C. 更新、条件、初始化
   D. 条件、更新、初始化

7. break语句可以用于（ ）
   A. 结束if语句
   B. 结束switch语句和循环语句
   C. 结束函数
   D. 结束程序

8. continue语句的作用是（ ）
   A. 结束循环
   B. 跳过当前循环的剩余部分，继续下一次循环
   C. 跳出当前函数
   D. 重新开始循环

## 参考答案

### 选择题答案

**单选题**：
1. A
2. B
3. A
4. B
5. B
6. A
7. B
8. B

**多选题**：
1. ABC
2. ABCD
3. ABCD

### 填空题答案

1. 顺序结构、选择结构、循环结构
2. 非0
3. break
4. 先判断后执行
5. 先执行后判断
6. for(初始化; 条件; 更新)
7. switch语句、循环语句
8. 跳过当前循环的剩余部分，继续下一次循环

### 简答题答案

1. 顺序结构、选择结构、循环结构。

2. 如果条件表达式为真，执行if块；否则执行else块（如果有）。

3. break用于跳出switch语句，防止继续执行后续的case。

4. while先判断后执行，循环体可能一次都不执行；do-while先执行后判断，循环体至少执行一次。

5. 初始化表达式、条件表达式、更新表达式。

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

int main() {
    int n;
    printf("请输入一个整数：");
    scanf("%d", &n);
    if (n % 2 == 0) {
        printf("%d是偶数\n", n);
    } else {
        printf("%d是奇数\n", n);
    }
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

int main() {
    int score;
    printf("请输入成绩：");
    scanf("%d", &score);
    if (score >= 90) {
        printf("优秀\n");
    } else if (score >= 80) {
        printf("良好\n");
    } else if (score >= 60) {
        printf("及格\n");
    } else {
        printf("不及格\n");
    }
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            printf("%d*%d=%d ", j, i, j*i);
        }
        printf("\n");
    }
    return 0;
}
```
