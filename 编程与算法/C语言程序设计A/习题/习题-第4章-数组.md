### 简答题答案

1. 类型 数组名[长度];

2. 数组名代表数组首元素的地址，是常量指针。

3. '\0'，ASCII码值为0。

4. strlen（求长度）、strcpy（复制）、strcat（连接）、strcmp（比较）。

5. 按行优先顺序存储，即先存储第一行，再存储第二行，以此类推。

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += arr[i];
    }
    printf("数组元素的和是：%d\n", sum);
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    for (int i = 4; i >= 0; i--) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

int my_strlen(char *str) {
    int len = 0;
    while (*str != '\0') {
        len++;
        str++;
    }
    return len;
}

int main() {
    char str[] = "Hello";
    printf("%d\n", my_strlen(str));
    return 0;
}
```
