### 简答题答案

1. 简洁紧凑、高效灵活、可移植性强、面向过程、功能强大。

2. C程序基本结构：包含头文件、main函数、语句、注释。

3. 编辑→编译→链接→运行：编辑源文件，编译检查语法错误生成目标文件，链接目标文件和库文件生成可执行文件，运行可执行文件。

4. 头文件包含函数声明、宏定义、数据类型定义等。常用头文件：stdio.h、stdlib.h、math.h、string.h、time.h。

5. main函数是程序入口，程序从main函数开始执行。可以有参数：int main(int argc, char *argv[])。

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

int main() {
    printf("Hello, C语言!\n");
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

int main() {
    printf("姓名：张三\n");
    printf("学号：20230001\n");
    printf("专业：计算机科学与技术\n");
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

int main() {
    int a, b, sum;
    printf("请输入两个整数：");
    scanf("%d%d", &a, &b);
    sum = a + b;
    printf("它们的和是：%d\n", sum);
    return 0;
}
```
