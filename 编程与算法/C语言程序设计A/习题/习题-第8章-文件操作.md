### 填空题答案

### 简答题答案

1. 文件指针是指向FILE结构体的指针，用于操作文件。定义：FILE *fp;

2. fopen(const char *filename, const char *mode)；返回值：成功返回文件指针，失败返回NULL。

3. "r"（只读）、"w"（只写）、"a"（追加）、"r+"（读写）、"w+"（读写）、"a+"（读写）、带b的二进制模式。

4. fputc、fgetc、fputs、fgets、fprintf、fscanf、fwrite、fread。

5. 释放文件资源，确保数据写入磁盘，避免文件损坏。

### 编程题答案

**题1答案**：
```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) {
        printf("文件打开失败\n");
        return 1;
    }
    fprintf(fp, "Hello, File!\n");
    fclose(fp);
    return 0;
}
```

**题2答案**：
```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) {
        printf("文件打开失败\n");
        return 1;
    }
    char ch;
    while ((ch = fgetc(fp)) != EOF) {
        printf("%c", ch);
    }
    fclose(fp);
    return 0;
}
```

**题3答案**：
```c
#include <stdio.h>

int main() {
    FILE *src = fopen("source.txt", "r");
    FILE *dest = fopen("dest.txt", "w");
    if (src == NULL || dest == NULL) {
        printf("文件打开失败\n");
        return 1;
    }
    char ch;
    while ((ch = fgetc(src)) != EOF) {
        fputc(ch, dest);
    }
    fclose(src);
    fclose(dest);
    return 0;
}
```
