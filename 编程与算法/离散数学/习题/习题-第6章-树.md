### 简答题答案

1. 树是连通无回路的无向图。等价定义：连通且有n-1条边；无回路且有n-1条边；任意两顶点间有唯一路径；连通且每条边都是桥。

2. 性质：n个顶点的树有n-1条边；树是最小连通图（去掉任一边不连通）；树是最大无回路图（添加任一边有回路）；树中至少有两个叶子节点。

3. 生成树是连通图的包含所有顶点的极小连通子图。求法：破圈法（去掉回路中的边）、避圈法（添加边不形成回路）。

4. 最小生成树是边权之和最小的生成树。Prim：从顶点出发，每次添加与当前顶点集相连的最小权边；Kruskal：按边权排序，依次添加不形成回路的边。

5. 二叉树是每个节点最多有两个子节点的有序树。遍历方式：前序（根-左-右）、中序（左-根-右）、后序（左-右-根）、层次遍历。

### 综合应用题答案

**题1答案**：
设度数为1的顶点有3个（叶子），度数为2的有x个，度数为3的有y个，度数为4的有z个。
顶点数：3+x+y+z=7 ⇒ x+y+z=4
度数和：3×1 + 2x + 3y + 4z = 2×6=12 ⇒ 2x+3y+4z=9
可能解：x=2, y=1, z=1（验证：2+1+1=4；2×2+3×1+4×1=4+3+4=11，不对）
正确解：x=3, y=1, z=0（验证：3+1+0=4；2×3+3×1+4×0=6+3+0=9，正确）
或x=1, y=2, z=1（验证：1+2+1=4；2×1+3×2+4×1=2+6+4=12，不对）
正确答案：度数为2的有3个，度数为3的有1个，度数为4的有0个

**题2答案**：
(1) Prim算法（从顶点1开始）：
- 添加(1,4,1)，顶点集{1,4}
- 添加(3,4,1)，顶点集{1,3,4}
- 添加(1,2,2)，顶点集{1,2,3,4}
- 添加(3,5,2)，顶点集{1,2,3,4,5}
最小生成树边：(1,4),(3,4),(1,2),(3,5)，总权重=1+1+2+2=6

(2) Kruskal算法：
按权重排序：(1,4,1),(3,4,1),(1,2,2),(2,3,2),(3,5,2),(1,3,3),(2,5,3),(4,5,4)
依次添加：(1,4),(3,4),(1,2),(3,5)（跳过(2,3)形成回路）
最小生成树边：(1,4),(3,4),(1,2),(3,5)，总权重=6

**题3答案**：
前序：ABCDEFG，中序：BDCAEGF
根是A，左子树中序BDC，右子树中序EGF
左子树前序BCD，根是B，左子树为空，右子树中序DC

右子树前序EFG，根是E，左子树为空，右子树中序GF

**题4答案**：
(1) 二叉树是树的特殊形式，树有n-1条边，故二叉树也有n-1条边。

(2) 设n₁为度数为1的节点数。
总节点数：n=n₀+n₁+n₂
总度数：n₀×0 + n₁×1 + n₂×2 = n₁+2n₂
握手定理：n₁+2n₂ = 2(n-1) = 2n₀+2n₁+2n₂-2
化简：0 = 2n₀+n₁-2 ⇒ n₁=2-2n₀（矛盾，重新推导）

正确推导：
总度数 = n₁×1 + n₂×2 = n₁+2n₂
边数 = n-1 = n₀+n₁+n₂-1
握手定理：n₁+2n₂ = 2(n-1) = 2n₀+2n₁+2n₂-2
⇒ 0 = 2n₀+n₁-2 ⇒ n₁=2-2n₀

但n₁≥0，故2-2n₀≥0 ⇒ n₀≤1（只适用于某些二叉树）

实际上，对于任意二叉树，n₀=n₂+1：
n₁+2n₂ = 2(n₀+n₁+n₂-1)
⇒ n₁+2n₂ = 2n₀+2n₁+2n₂-2
⇒ 0 = 2n₀+n₁-2
对于完全二叉树，n₁=0或1：
若n₁=0，则2n₀-2=0 ⇒ n₀=1，n₂=0，符合n₀=n₂+1
若n₁=1，则2n₀+1-2=0 ⇒ 2n₀=1，不符合

正确公式：n₀=n₂+1对所有二叉树成立
