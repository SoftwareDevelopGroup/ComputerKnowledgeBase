# 3.4 有限集合的计数

> [!abstract] 核心问题
> 如何计算有限集合的元素个数？容斥原理是什么？

## 一、基本计数公式

### 1. 并集的大小

```
|A ∪ B| = |A| + |B| - |A ∩ B|
```

### 2. 差集的大小

```
|A - B| = |A| - |A ∩ B|
```

### 3. 对称差的大小

```
|A ⊕ B| = |A| + |B| - 2|A ∩ B|
```

## 二、容斥原理

### 1. 两个集合的容斥

```
|A ∪ B| = |A| + |B| - |A ∩ B|
```

### 2. 三个集合的容斥

```
|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|
```

### 3. n个集合的容斥

```
|A₁ ∪ A₂ ∪ ... ∪ Aₙ| = Σ|Aᵢ| - Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ Aₖ| - ... + (-1)ⁿ⁺¹|A₁ ∩ A₂ ∩ ... ∩ Aₙ|
```

## 三、容斥原理示例

### 示例1

**问题**：某班有50名学生，其中25人选修数学，20人选修物理，10人同时选修数学和物理。问有多少人两门都没选？

**解**：

```
|A ∪ B| = |A| + |B| - |A ∩ B| = 25 + 20 - 10 = 35
两门都没选 = 50 - 35 = 15
```

### 示例2

**问题**：求1到100之间能被2或3整除的数的个数。

**解**：

```
|A ∪ B| = |A| + |B| - |A ∩ B|
|A| = 50（能被2整除）
|B| = 33（能被3整除）
|A ∩ B| = 16（能被6整除）
|A ∪ B| = 50 + 33 - 16 = 67
```

### 示例3

**问题**：求1到1000之间不能被5、6、8整除的数的个数。

**解**：

```
|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|
|A| = 200（能被5整除）
|B| = 166（能被6整除）
|C| = 125（能被8整除）
|A ∩ B| = 33（能被30整除）
|A ∩ C| = 25（能被40整除）
|B ∩ C| = 41（能被24整除）
|A ∩ B ∩ C| = 8（能被120整除）
|A ∪ B ∪ C| = 200 + 166 + 125 - 33 - 25 - 41 + 8 = 400
不能被整除的数 = 1000 - 400 = 600
```

## 四、鸽巢原理

### 1. 鸽巢原理定义

**鸽巢原理（Pigeonhole Principle）**：如果 $n+1$ 个物体放入 $n$ 个盒子中，则至少有一个盒子包含至少两个物体。

### 2. 鸽巢原理推广

如果 $kn+1$ 个物体放入 $n$ 个盒子中，则至少有一个盒子包含至少 $k+1$ 个物体。

### 示例

**例1**：证明任意13个人中至少有两个人生日在同一个月。

**证明**：12个月看作12个盒子，13个人看作13个物体，由鸽巢原理得证。

**例2**：证明任意5个整数中至少有3个数的和能被3整除。

**证明**：整数模3的余数只有0、1、2三种情况。

- 如果余数0、1、2都出现，则取各一个，和为0+1+2=3，能被3整除
- 如果只出现两种余数，则由鸽巢原理，至少有一种余数出现至少3次，取这3个数，和能被3整除
- 如果只出现一种余数，则任意3个数的和都能被3整除

## 五、计数应用

### 1. 排列组合

| 类型 | 公式 |
|-----|------|
| **排列** | $P(n, k) = \frac{n!}{(n-k)!}$ |
| **组合** | $C(n, k) = \frac{n!}{k!(n-k)!}$ |

### 2. 多重集合计数

**多重集合排列**：$\frac{n!}{n₁!n₂!...nₖ!}$

**多重集合组合**：$C(n + k - 1, k - 1)$

## 六、易错点提示

> [!warning] 常见误区
> - **"容斥原理中符号错误"**：交替加减，注意符号。
> - **"鸽巢原理应用错误"**：正确识别"鸽子"和"鸽巢"。
> - **"计数时重复计算"**：使用容斥原理避免重复。
