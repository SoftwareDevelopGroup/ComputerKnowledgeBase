# 3.3 集合恒等式

> [!abstract] 核心问题
> 集合运算有哪些基本恒等式？如何证明集合恒等式？

## 一、基本恒等式表

### 1. 幂等律

```
A ∪ A = A
A ∩ A = A
```

### 2. 交换律

```
A ∪ B = B ∪ A
A ∩ B = B ∩ A
```

### 3. 结合律

```
(A ∪ B) ∪ C = A ∪ (B ∪ C)
(A ∩ B) ∩ C = A ∩ (B ∩ C)
```

### 4. 分配律

```
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
```

### 5. 同一律

```
A ∪ ∅ = A
A ∩ U = A
```

### 6. 零律

```
A ∪ U = U
A ∩ ∅ = ∅
```

### 7. 排中律

```
A ∪ \overline{A} = U
```

### 8. 矛盾律

```
A ∩ \overline{A} = ∅
```

### 9. 双重否定律

```
\overline{\overline{A}} = A
```

### 10. 吸收律

```
A ∪ (A ∩ B) = A
A ∩ (A ∪ B) = A
```

### 11. 德摩根律

```
\overline{A ∪ B} = \overline{A} ∩ \overline{B}
\overline{A ∩ B} = \overline{A} ∪ \overline{B}
```

## 二、恒等式证明方法

### 1. 元素法

证明两个集合相等，即证明它们包含相同的元素。

**步骤**：

| 步骤 | 说明 |
|-----|------|
| 1 | 任取 $x \in A$ |
| 2 | 证明 $x \in B$ |
| 3 | 任取 $x \in B$ |
| 4 | 证明 $x \in A$ |
| 5 | 结论：$A = B$ |

### 示例1

**证明**：$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$

**证明**：

```
(1) 任取 x ∈ A ∩ (B ∪ C)
    ⇒ x ∈ A ∧ x ∈ (B ∪ C)
    ⇒ x ∈ A ∧ (x ∈ B ∨ x ∈ C)
    ⇒ (x ∈ A ∧ x ∈ B) ∨ (x ∈ A ∧ x ∈ C)
    ⇒ x ∈ (A ∩ B) ∨ x ∈ (A ∩ C)
    ⇒ x ∈ (A ∩ B) ∪ (A ∩ C)

(2) 任取 x ∈ (A ∩ B) ∪ (A ∩ C)
    ⇒ x ∈ (A ∩ B) ∨ x ∈ (A ∩ C)
    ⇒ (x ∈ A ∧ x ∈ B) ∨ (x ∈ A ∧ x ∈ C)
    ⇒ x ∈ A ∧ (x ∈ B ∨ x ∈ C)
    ⇒ x ∈ A ∧ x ∈ (B ∪ C)
    ⇒ x ∈ A ∩ (B ∪ C)

(3) 由(1)(2)得：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
```

### 2. 文氏图法

用文氏图直观表示集合关系。

### 3. 代数法

利用已知恒等式进行推导。

### 示例2

**证明**：$A - (B ∩ C) = (A - B) ∪ (A - C)$

**证明**：

```
A - (B ∩ C) = A ∩ \overline{(B ∩ C)}      （差集定义）
            = A ∩ (\overline{B} ∪ \overline{C})  （德摩根律）
            = (A ∩ \overline{B}) ∪ (A ∩ \overline{C})  （分配律）
            = (A - B) ∪ (A - C)              （差集定义）
```

## 三、扩展恒等式

### 1. 关于差集的恒等式

```
A - B = A ∩ \overline{B}
A - (B ∪ C) = (A - B) ∩ (A - C)
A - (B ∩ C) = (A - B) ∪ (A - C)
```

### 2. 关于对称差的恒等式

```
A ⊕ B = (A ∪ B) - (A ∩ B)
A ⊕ B = B ⊕ A
(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)
A ⊕ ∅ = A
A ⊕ A = ∅
```

## 四、易错点提示

> [!warning] 常见误区
> - **"证明时漏掉双向包含"**：证明集合相等需要证明双向包含。
> - **"德摩根律中补集位置错误"**：并集的补集是补集的交集。
> - **"差集和对称差混淆"**：差集是单向的，对称差是双向的。
