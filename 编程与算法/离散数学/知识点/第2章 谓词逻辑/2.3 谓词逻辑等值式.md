# 2.3 谓词逻辑等值式

> [!abstract] 核心问题
> 谓词逻辑中有哪些重要的等值式？如何应用等值式进行推理？

## 一、命题逻辑等值式的推广

### 1. 基本等值式

所有命题逻辑中的等值式都可以推广到谓词逻辑中。

```
¬(A ∧ B) ⇔ ¬A ∨ ¬B      （德摩根律）
A → B ⇔ ¬A ∨ B          （蕴含等值式）
(A ∧ B) ∧ C ⇔ A ∧ (B ∧ C) （结合律）
```

## 二、量词相关等值式

### 1. 量词否定等值式

```
¬∀x A(x) ⇔ ∃x ¬A(x)
¬∃x A(x) ⇔ ∀x ¬A(x)
```

### 2. 量词分配等值式

```
∀x (A(x) ∧ B(x)) ⇔ ∀x A(x) ∧ ∀x B(x)
∃x (A(x) ∨ B(x)) ⇔ ∃x A(x) ∨ ∃x B(x)
```

### 3. 注意：不分配的情况

```
∀x (A(x) ∨ B(x)) ≠ ∀x A(x) ∨ ∀x B(x)
∃x (A(x) ∧ B(x)) ≠ ∃x A(x) ∧ ∃x B(x)
```

## 三、量词辖域扩张与收缩

### 1. 基本扩张收缩等值式

```
∀x (A(x) ∨ B) ⇔ ∀x A(x) ∨ B
∀x (A(x) ∧ B) ⇔ ∀x A(x) ∧ B
∃x (A(x) ∨ B) ⇔ ∃x A(x) ∨ B
∃x (A(x) ∧ B) ⇔ ∃x A(x) ∧ B
```

### 2. 条件式的扩张收缩

```
∀x (A(x) → B) ⇔ ∃x A(x) → B
∀x (B → A(x)) ⇔ B → ∀x A(x)
∃x (A(x) → B) ⇔ ∀x A(x) → B
∃x (B → A(x)) ⇔ B → ∃x A(x)
```

## 四、多量词等值式

### 1. 相同量词交换

```
∀x ∀y A(x, y) ⇔ ∀y ∀x A(x, y)
∃x ∃y A(x, y) ⇔ ∃y ∃x A(x, y)
```

### 2. 不同量词顺序

```
∀x ∃y A(x, y) ≠ ∃y ∀x A(x, y)
```

## 五、等值演算示例

### 示例1

**证明**：$\neg \forall x (P(x) \to Q(x)) \Leftrightarrow \exists x (P(x) \land \neg Q(x))$

```
¬∀x (P(x) → Q(x))
⇔ ∃x ¬(P(x) → Q(x))        （量词否定等值式）
⇔ ∃x ¬(¬P(x) ∨ Q(x))       （蕴含等值式）
⇔ ∃x (P(x) ∧ ¬Q(x))        （德摩根律）
```

### 示例2

**证明**：$\forall x P(x) \to \exists x Q(x) \Leftrightarrow \exists x (P(x) \to Q(x))$

```
∀x P(x) → ∃x Q(x)
⇔ ¬∀x P(x) ∨ ∃x Q(x)        （蕴含等值式）
⇔ ∃x ¬P(x) ∨ ∃x Q(x)        （量词否定等值式）
⇔ ∃x (¬P(x) ∨ Q(x))         （量词分配等值式）
⇔ ∃x (P(x) → Q(x))          （蕴含等值式）
```

## 六、易错点提示

> [!warning] 常见误区
> - **"量词可以随意交换"**：不同类型量词顺序不能随意交换。
> - **"全称量词对析取分配"**：$\forall x (A \lor B) \neq \forall x A \lor \forall x B$
> - **"存在量词对合取分配"**：$\exists x (A \land B) \neq \exists x A \land \exists x B$

## 七、示例与练习

### 练习题

1. 证明 $\neg \exists x (P(x) \land Q(x)) \Leftrightarrow \forall x (P(x) \to \neg Q(x))$
2. 化简 $\forall x \forall y ((P(x) \land Q(y)) \to R(x, y))$
3. 判断 $\forall x (P(x) \to Q(x))$ 和 $\forall x P(x) \to \forall x Q(x)$ 是否等值
