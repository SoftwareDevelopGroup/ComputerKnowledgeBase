# 2.4 谓词逻辑推理

> [!abstract] 核心问题
> 谓词逻辑中如何进行有效推理？常用的推理规则有哪些？

## 一、推理的定义

### 1. 推理概念

**推理（Inference）**：从前提集合推出结论的过程。

若 $\forall x_1 \forall x_2 \dots \forall x_n (A_1 \land A_2 \land \dots \land A_k \to B)$ 是永真式，则称推理有效。

## 二、基本推理规则

### 1. 命题逻辑推理规则推广

所有命题逻辑中的推理规则都可以推广到谓词逻辑中。

| 规则 | 形式 |
|-----|------|
| 假言推理 | $A \to B, A \vdash B$ |
| 拒取式 | $A \to B, \neg B \vdash \neg A$ |
| 析取三段论 | $A \lor B, \neg A \vdash B$ |
| 假言三段论 | $A \to B, B \to C \vdash A \to C$ |

### 2. 量词消去规则

#### 全称量词消去（US）

```
∀x A(x) ├ A(c)
```

其中 c 是论域中的任意个体常元。

#### 存在量词消去（ES）

```
∃x A(x) ├ A(c)
```

其中 c 是论域中使 A(c) 为真的特定个体常元。

### 3. 量词引入规则

#### 全称量词引入（UG）

```
A(x) ├ ∀x A(x)
```

其中 x 是自由变元，且在推导过程中没有受到其他量词约束。

#### 存在量词引入（EG）

```
A(c) ├ ∃x A(x)
```

其中 c 是论域中的某个个体常元。

## 三、推理证明示例

### 示例1

**证明**：$\forall x (P(x) \to Q(x)), \forall x P(x) \vdash \forall x Q(x)$

```
(1) ∀x (P(x) → Q(x))    前提引入
(2) P(x) → Q(x)          (1) US
(3) ∀x P(x)              前提引入
(4) P(x)                 (3) US
(5) Q(x)                 (2)(4) 假言推理
(6) ∀x Q(x)              (5) UG
```

### 示例2

**证明**：$\forall x (P(x) \to Q(x)), \exists x P(x) \vdash \exists x Q(x)$

```
(1) ∃x P(x)              前提引入
(2) P(c)                 (1) ES
(3) ∀x (P(x) → Q(x))    前提引入
(4) P(c) → Q(c)          (3) US
(5) Q(c)                 (2)(4) 假言推理
(6) ∃x Q(x)              (5) EG
```

## 四、注意事项

### 1. ES规则的使用

ES规则引入的个体常元必须是**新的**，不能在之前的推导中出现。

### 2. US规则的使用

US规则引入的个体常元可以是任意的，但要注意与其他规则的配合。

### 3. UG规则的限制

UG规则要求引入全称量词的变元在推导过程中**不能**是通过ES规则引入的。

### 4. 推理顺序

通常先使用ES规则，再使用US规则，以避免变元冲突。

## 五、常见推理错误

| 错误类型 | 示例 | 说明 |
|---------|-----|------|
| **ES后US** | ∃x P(x), ∀x Q(x) ⊢ P(c) ∧ Q(c) | c可能不是同一个个体 |
| **UG不当** | P(c) ⊢ ∀x P(x) | c是通过ES引入的，不能UG |
| **量词顺序错误** | ∀x ∃y P(x,y) ⊢ ∃y ∀x P(x,y) | 不同量词顺序不能互换 |

## 六、易错点提示

> [!warning] 常见误区
> - **"ES引入的常元可以随意使用"**：ES引入的常元是特定的，不能随意替换。
> - **"UG可以无条件使用"**：UG有严格限制，不能对ES引入的变元使用。
> - **"推理规则可以随意组合"**：量词规则和命题规则的组合需要遵循一定顺序。

## 七、示例与练习

### 示例

**例1**：证明 $\forall x (P(x) \lor Q(x)), \forall x \neg P(x) \vdash \forall x Q(x)$

```
(1) ∀x (P(x) ∨ Q(x))    前提引入
(2) P(x) ∨ Q(x)          (1) US
(3) ∀x ¬P(x)             前提引入
(4) ¬P(x)                (3) US
(5) Q(x)                 (2)(4) 析取三段论
(6) ∀x Q(x)              (5) UG
```

### 练习题

1. 证明 $\exists x (P(x) \land Q(x)) \vdash \exists x P(x) \land \exists x Q(x)$
2. 证明 $\forall x (P(x) \to Q(x)), \neg Q(c) \vdash \neg P(c)$
3. 判断推理 $\forall x (P(x) \lor Q(x)) \vdash \forall x P(x) \lor \forall x Q(x)$ 是否有效
