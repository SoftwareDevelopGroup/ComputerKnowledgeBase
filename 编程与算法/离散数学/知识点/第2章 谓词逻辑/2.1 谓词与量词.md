# 2.1 谓词与量词

> [!abstract] 核心问题
> 命题逻辑无法表达"所有"和"存在"的概念，如何扩展逻辑表达能力？

## 一、谓词的概念

### 1. 谓词定义

**谓词（Predicate）**是描述个体性质或个体之间关系的语句。

| 组成 | 说明 |
|-----|------|
| **个体词** | 表示研究对象，可以是具体的或抽象的 |
| **谓词** | 描述个体性质或关系 |

### 2. 谓词示例

| 语句 | 谓词 | 个体词 |
|-----|------|-------|
| "张三是学生" | 是学生 | 张三 |
| "3大于2" | 大于 | 3, 2 |
| "点A在点B和点C之间" | 在...和...之间 | A, B, C |

### 3. 谓词符号化

- 一元谓词：$P(x)$ 表示 $x$ 具有性质 $P$
- 二元谓词：$P(x, y)$ 表示 $x$ 和 $y$ 具有关系 $P$
- $n$ 元谓词：$P(x_1, x_2, \dots, x_n)$

## 二、量词

### 1. 全称量词

**全称量词（Universal Quantifier）**：$\forall$

表示"对所有的"、"对任意的"、"每一个"。

```
∀x P(x) 表示"对所有x，P(x)为真"
```

### 2. 存在量词

**存在量词（Existential Quantifier）**：$\exists$

表示"存在"、"有一个"、"至少有一个"。

```
∃x P(x) 表示"存在x，使P(x)为真"
```

### 3. 量词的真值

| 量词形式 | 真值条件 |
|---------|---------|
| $\forall x P(x)$ | 当且仅当论域中所有个体都满足 $P(x)$ |
| $\exists x P(x)$ | 当且仅当论域中至少有一个个体满足 $P(x)$ |

### 4. 量词否定

```
¬∀x P(x) ⇔ ∃x ¬P(x)
¬∃x P(x) ⇔ ∀x ¬P(x)
```

## 三、谓词公式符号化

### 1. 符号化示例

**例1**：将"所有学生都要学习离散数学"符号化

**解析**：
- 设 $P(x)$：$x$ 是学生
- 设 $Q(x)$：$x$ 学习离散数学
- 符号化：$\forall x (P(x) \to Q(x))$

**例2**：将"存在一些学生喜欢编程"符号化

**解析**：
- 设 $P(x)$：$x$ 是学生
- 设 $Q(x)$：$x$ 喜欢编程
- 符号化：$\exists x (P(x) \land Q(x))$

### 2. 多量词使用

**例3**：将"对任意两个不同的实数，存在一个有理数介于它们之间"符号化

**解析**：
- 设 $P(x)$：$x$ 是实数
- 设 $Q(x)$：$x$ 是有理数
- 设 $R(x, y)$：$x < y$
- 符号化：$\forall x \forall y ((P(x) \land P(y) \land x \neq y) \to \exists z (Q(z) \land (R(x, z) \land R(z, y) \lor R(y, z) \land R(z, x))))$

## 四、量词的辖域

### 1. 辖域定义

**量词的辖域（Scope）**：量词后面紧跟的谓词公式。

### 2. 自由变元和约束变元

| 类型 | 说明 |
|-----|------|
| **约束变元** | 受量词约束的变元 |
| **自由变元** | 不受量词约束的变元 |

### 示例

```
∀x (P(x) → ∃y Q(x, y))
```

- $x$：约束变元（受 $\forall$ 约束）
- $y$：约束变元（受 $\exists$ 约束）

## 五、易错点提示

> [!warning] 常见误区
> - **"全称量词用合取"**：全称量词应使用蕴含，存在量词使用合取。
> - **"量词顺序无关"**：$\forall x \exists y$ 和 $\exists y \forall x$ 含义不同。
> - **"否定量词时忘记改变量词"**：否定全称量词变为存在量词，反之亦然。

## 六、示例与练习

### 示例

**例1**：判断 $\forall x P(x) \lor \forall x Q(x)$ 和 $\forall x (P(x) \lor Q(x))$ 是否等值

**解析**：不等值。前者要求所有个体满足 $P$ 或所有个体满足 $Q$，后者只要求每个个体满足 $P$ 或 $Q$。

### 练习题

1. 将"没有人不犯错误"符号化
2. 将"有一个学生既学数学又学计算机"符号化
3. 判断 $\exists x (P(x) \land Q(x))$ 和 $\exists x P(x) \land \exists x Q(x)$ 是否等值
