# 2.2 谓词公式与解释

> [!abstract] 核心问题
> 什么是谓词公式？如何确定谓词公式的真值？

## 一、谓词公式定义

### 1. 公式的递归定义

**谓词公式（Predicate Formula）**由以下规则生成：

| 规则 | 说明 |
|-----|------|
| 1 | 原子谓词公式是公式 |
| 2 | 如果 A 是公式，则 ¬A 是公式 |
| 3 | 如果 A 和 B 是公式，则 A∧B、A∨B、A→B、A↔B 是公式 |
| 4 | 如果 A 是公式且 x 是自由变元，则 ∀x A 和 ∃x A 是公式 |
| 5 | 有限次应用上述规则得到的是公式 |

### 2. 公式示例

| 公式 | 是否合法 |
|-----|---------|
| ∀x P(x) | 是 |
| ∃x ∀y P(x, y) | 是 |
| ∀x P(x) → Q | 是 |
| ∀x ∧ P(x) | 否 |

## 二、解释的概念

### 1. 解释定义

**解释（Interpretation）**：为谓词公式指定具体的论域和谓词含义。

### 2. 解释的组成

| 组成 | 说明 |
|-----|------|
| **论域 D** | 个体的集合 |
| **谓词指派** | 给每个谓词符号指定具体含义 |
| **函数指派** | 给每个函数符号指定具体函数 |
| **常量指派** | 给每个常量符号指定具体值 |

### 3. 示例

**例1**：给定解释

- 论域 D = {1, 2}
- P(1) = T, P(2) = F
- Q(1, 1) = T, Q(1, 2) = F, Q(2, 1) = F, Q(2, 2) = T

求 ∀x ∃y Q(x, y) 的真值。

**解析**：
- x=1时，∃y Q(1, y)：Q(1, 1)=T，故为T
- x=2时，∃y Q(2, y)：Q(2, 2)=T，故为T
- 因此 ∀x ∃y Q(x, y) = T

## 三、永真式与永假式

### 1. 永真式

**永真式（Tautology）**：在所有解释下都为真

```
∀x P(x) → ∃x P(x)
```

### 2. 永假式

**永假式（Contradiction）**：在所有解释下都为假

```
∀x P(x) ∧ ∃x ¬P(x)
```

### 3. 可满足式

**可满足式（Satisfiable）**：至少存在一个解释使其为真

## 四、谓词逻辑等值式

### 1. 基本等值式

| 等值式 | 说明 |
|-------|------|
| $\forall x (A \land B) \Leftrightarrow \forall x A \land \forall x B$ | 全称量词对合取分配 |
| $\exists x (A \lor B) \Leftrightarrow \exists x A \lor \exists x B$ | 存在量词对析取分配 |
| $\neg \forall x A \Leftrightarrow \exists x \neg A$ | 量词否定等值式 |
| $\neg \exists x A \Leftrightarrow \forall x \neg A$ | 量词否定等值式 |
| $\forall x A \lor \forall x B \Rightarrow \forall x (A \lor B)$ | 全称量词对析取蕴含 |
| $\exists x (A \land B) \Rightarrow \exists x A \land \exists x B$ | 存在量词对合取蕴含 |

### 2. 量词辖域扩张与收缩

```
∀x (A(x) ∨ B) ⇔ ∀x A(x) ∨ B
∀x (A(x) ∧ B) ⇔ ∀x A(x) ∧ B
∃x (A(x) ∨ B) ⇔ ∃x A(x) ∨ B
∃x (A(x) ∧ B) ⇔ ∃x A(x) ∧ B
```

## 五、前束范式

### 1. 前束范式定义

**前束范式（Prenex Normal Form）**：所有量词都在公式开头

```
Q₁x₁ Q₂x₂ ... Qₙxₙ A
```

其中 $Q_i$ 是量词，A 是不含量词的公式。

### 2. 求前束范式步骤

| 步骤 | 说明 |
|-----|------|
| 1 | 消去 → 和 ↔ |
| 2 | 否定深入到原子公式 |
| 3 | 换名（避免变元冲突） |
| 4 | 量词辖域扩张 |

### 示例

**例1**：求 ∀x P(x) → ∃x Q(x) 的前束范式

```
∀x P(x) → ∃x Q(x)
⇔ ¬∀x P(x) ∨ ∃x Q(x)
⇔ ∃x ¬P(x) ∨ ∃x Q(x)
⇔ ∃x (¬P(x) ∨ Q(x))
```

## 六、易错点提示

> [!warning] 常见误区
> - **"全称量词对析取分配"**：$\forall x (A \lor B) \neq \forall x A \lor \forall x B$
> - **"存在量词对合取分配"**：$\exists x (A \land B) \neq \exists x A \land \exists x B$
> - **"换名时忘记替换所有出现"**：换名必须替换量词及其辖域内所有出现的变元。

## 七、示例与练习

### 示例

**例1**：求 ∀x P(x) ∧ ∃x Q(x) 的前束范式

**解析**：

```
∀x P(x) ∧ ∃x Q(x)
⇔ ∀x P(x) ∧ ∃y Q(y)    （换名）
⇔ ∀x ∃y (P(x) ∧ Q(y))
```

### 练习题

1. 求 ∃x P(x) → ∀x Q(x) 的前束范式
2. 判断 ∀x ∃y P(x, y) 和 ∃y ∀x P(x, y) 是否等值
3. 证明 ∀x (P(x) ∧ Q(x)) ⇔ ∀x P(x) ∧ ∀x Q(x)
