# 4.5 函数

> [!abstract] 核心问题
> 什么是函数？函数有哪些类型？如何求函数的复合与逆？

## 一、函数的定义

### 1. 函数概念

**函数（Function）**：设 $A$ 和 $B$ 是非空集合，$f$ 是从 $A$ 到 $B$ 的关系，如果对每个 $x \in A$，存在唯一的 $y \in B$ 使得 $(x, y) \in f$，则称 $f$ 是从 $A$ 到 $B$ 的函数，记作 $f: A \to B$。

### 2. 函数的表示

| 表示方法 | 说明 | 示例 |
|---------|------|-----|
| **解析法** | 用公式表示 | $f(x) = x^2$ |
| **列表法** | 列出所有映射 | $f = \{(1, a), (2, b)\}$ |
| **图像法** | 用图形表示 | 直角坐标系中的曲线 |

### 3. 函数与关系的区别

| 特征 | 关系 | 函数 |
|-----|------|------|
| **定义域** | 可以是 $A$ 的子集 | 必须是整个 $A$ |
| **唯一性** | 一个 $x$ 可以对应多个 $y$ | 一个 $x$ 只能对应一个 $y$ |

## 二、函数的类型

### 1. 单射

**单射（Injective / One-to-One）**：$f: A \to B$ 是单射当且仅当 $\forall x_1, x_2 \in A, f(x_1) = f(x_2) \Rightarrow x_1 = x_2$

### 2. 满射

**满射（Surjective / Onto）**：$f: A \to B$ 是满射当且仅当 $\forall y \in B, \exists x \in A, f(x) = y$

### 3. 双射

**双射（Bijective / One-to-One Correspondence）**：既是单射又是满射。

### 4. 函数类型对比

| 类型 | 条件 | 图示特征 |
|-----|------|---------|
| **单射** | 不同输入映射到不同输出 | 水平线上最多一个点 |
| **满射** | 每个输出都有输入映射到它 | 覆盖整个值域 |
| **双射** | 既是单射又是满射 | 一一对应 |

### 示例

**例1**：判断下列函数的类型：

1. $f: ℤ \to ℤ, f(x) = x + 1$ —— 双射
2. $f: ℤ \to ℤ, f(x) = x^2$ —— 既不是单射也不是满射
3. $f: ℕ \to ℕ, f(x) = 2x$ —— 单射但不是满射

## 三、函数的运算

### 1. 函数的复合

**复合（Composition）**：设 $f: A \to B$，$g: B \to C$，则复合函数 $g \circ f: A \to C$ 定义为：

```
(g ∘ f)(x) = g(f(x))
```

### 复合运算性质

| 性质 | 说明 |
|-----|------|
| **结合律** | $(h \circ g) \circ f = h \circ (g \circ f)$ |
| **单射保持** | 若 $f$ 和 $g$ 都是单射，则 $g \circ f$ 是单射 |
| **满射保持** | 若 $f$ 和 $g$ 都是满射，则 $g \circ f$ 是满射 |
| **双射保持** | 若 $f$ 和 $g$ 都是双射，则 $g \circ f$ 是双射 |

### 示例

**例2**：设 $f: ℤ \to ℤ, f(x) = x + 1$，$g: ℤ \to ℤ, g(x) = 2x$，求 $g \circ f$ 和 $f \circ g$。

**解**：

```
(g ∘ f)(x) = g(f(x)) = g(x + 1) = 2(x + 1) = 2x + 2
(f ∘ g)(x) = f(g(x)) = f(2x) = 2x + 1
```

### 2. 函数的逆

**逆函数（Inverse Function）**：设 $f: A \to B$ 是双射，则逆函数 $f^{-1}: B \to A$ 定义为：

```
f^{-1}(y) = x 当且仅当 f(x) = y
```

### 逆函数性质

| 性质 | 说明 |
|-----|------|
| **唯一性** | 双射的逆函数唯一 |
| **互逆性** | $f^{-1} \circ f = I_A$，$f \circ f^{-1} = I_B$ |
| **双射保持** | 逆函数也是双射 |

### 示例

**例3**：设 $f: ℤ \to ℤ, f(x) = x + 1$，求 $f^{-1}$。

**解**：

```
f^{-1}(y) = y - 1
```

## 四、常用函数

### 1. 恒等函数

**恒等函数（Identity Function）**：$I_A: A \to A, I_A(x) = x$

### 2. 常函数

**常函数（Constant Function）**：$f: A \to B, f(x) = c$（$c$ 是常数）

### 3. 绝对值函数

**绝对值函数**：$f: ℝ \to ℝ, f(x) = |x|$

### 4. 取整函数

**取整函数（Floor Function）**：$\lfloor x \rfloor$ 表示不大于 $x$ 的最大整数

**取整函数（Ceiling Function）**：$\lceil x \rceil$ 表示不小于 $x$ 的最小整数

### 示例

**例4**：计算：

```
⌊3.7⌋ = 3
⌈3.7⌉ = 4
⌊-2.3⌋ = -3
⌈-2.3⌉ = -2
```

## 五、函数的应用

### 1. 密码学

**置换密码**：使用双射函数进行加密和解密。

### 2. 数据压缩

**压缩函数**：使用单射函数将数据映射到更小的空间。

### 3. 哈希函数

**哈希函数**：将任意长度的数据映射到固定长度的哈希值。

## 六、易错点提示

> [!warning] 常见误区
> - **"函数和关系混淆"**：函数是特殊的关系，要求每个输入有唯一输出。
> - **"复合函数顺序搞反"**：$g \circ f$ 是先 $f$ 后 $g$。
> - **"任何函数都有逆函数"**：只有双射才有逆函数。
