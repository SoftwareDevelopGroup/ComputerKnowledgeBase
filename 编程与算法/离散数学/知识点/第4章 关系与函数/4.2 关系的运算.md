# 4.2 关系的运算

> [!abstract] 核心问题
> 关系有哪些运算？如何计算关系的闭包？

## 一、关系的基本运算

### 1. 并、交、差、补

```
R ∪ S = {(x, y) | (x, y) ∈ R ∨ (x, y) ∈ S}
R ∩ S = {(x, y) | (x, y) ∈ R ∧ (x, y) ∈ S}
R - S = {(x, y) | (x, y) ∈ R ∧ (x, y) ∉ S}
\overline{R} = A × A - R
```

### 2. 复合运算

**复合（Composition）**：$R \circ S = \{(x, z) | \exists y, (x, y) \in R \land (y, z) \in S\}$

### 复合运算性质

| 性质 | 说明 |
|-----|------|
| **结合律** | $(R \circ S) \circ T = R \circ (S \circ T)$ |
| **对并分配** | $R \circ (S \cup T) = (R \circ S) \cup (R \circ T)$ |
| **对交包含** | $R \circ (S \cap T) \subseteq (R \circ S) \cap (R \circ T)$ |

### 示例

**例1**：设 $R = \{(1, 2), (2, 3), (3, 4)\}$，$S = \{(2, 5), (3, 6), (4, 7)\}$，则

```
R ∘ S = {(1, 5), (2, 6), (3, 7)}
```

### 3. 逆运算

**逆（Inverse）**：$R^{-1} = \{(y, x) | (x, y) \in R\}$

### 逆运算性质

| 性质 | 说明 |
|-----|------|
| **双重逆** | $(R^{-1})^{-1} = R$ |
| **对并分配** | $(R \cup S)^{-1} = R^{-1} \cup S^{-1}$ |
| **对交分配** | $(R \cap S)^{-1} = R^{-1} \cap S^{-1}$ |
| **复合的逆** | $(R \circ S)^{-1} = S^{-1} \circ R^{-1}$ |

### 示例

**例2**：设 $R = \{(1, 2), (2, 3), (3, 4)\}$，则

```
R^{-1} = {(2, 1), (3, 2), (4, 3)}
```

## 二、关系的幂运算

### 1. 幂运算定义

```
R⁰ = I_A = {(x, x) | x ∈ A}
R¹ = R
Rⁿ = Rⁿ⁻¹ ∘ R (n ≥ 2)
```

### 2. 幂运算性质

| 性质 | 说明 |
|-----|------|
| **指数律** | $R^{m+n} = R^m \circ R^n$ |
| **幂律** | $(R^m)^n = R^{mn}$ |

### 示例

**例3**：设 $R = \{(1, 2), (2, 3), (3, 1)\}$，求 $R^2$ 和 $R^3$

```
R² = R ∘ R = {(1, 3), (2, 1), (3, 2)}
R³ = R² ∘ R = {(1, 1), (2, 2), (3, 3)} = I_A
```

## 三、关系的闭包

### 1. 闭包定义

**闭包（Closure）**：包含关系 $R$ 且具有某种性质的最小关系。

| 闭包类型 | 符号 | 性质 |
|---------|-----|------|
| **自反闭包** | $r(R)$ | 自反 |
| **对称闭包** | $s(R)$ | 对称 |
| **传递闭包** | $t(R)$ | 传递 |

### 2. 自反闭包

```
r(R) = R ∪ I_A
```

### 示例

**例4**：设 $R = \{(1, 2), (2, 3)\}$，则

```
r(R) = {(1, 2), (2, 3), (1, 1), (2, 2), (3, 3)}
```

### 3. 对称闭包

```
s(R) = R ∪ R^{-1}
```

### 示例

**例5**：设 $R = \{(1, 2), (2, 3)\}$，则

```
s(R) = {(1, 2), (2, 3), (2, 1), (3, 2)}
```

### 4. 传递闭包

**Warshall算法**：计算传递闭包的有效算法。

```
t(R) = R ∪ R² ∪ R³ ∪ ... ∪ Rⁿ
```

### Warshall算法步骤

| 步骤 | 说明 |
|-----|------|
| 1 | 初始化传递闭包矩阵为关系矩阵 |
| 2 | 对每个中间顶点k |
| 3 | 对每个顶点i |
| 4 | 对每个顶点j |
| 5 | 如果i到k有路径且k到j有路径，则i到j有路径 |

### 示例

**例6**：设 $R = \{(1, 2), (2, 3), (3, 4)\}$，求 $t(R)$

```
R² = {(1, 3), (2, 4)}
R³ = {(1, 4)}
R⁴ = ∅
t(R) = {(1, 2), (2, 3), (3, 4), (1, 3), (2, 4), (1, 4)}
```

## 四、闭包性质

### 1. 闭包的基本性质

| 性质 | 说明 |
|-----|------|
| **最小性** | 闭包是满足性质的最小关系 |
| **包含性** | $R \subseteq r(R), R \subseteq s(R), R \subseteq t(R)$ |
| **保持性** | 如果R已具有该性质，则闭包就是R本身 |

### 2. 闭包运算顺序

```
rs(R) = sr(R)
rt(R) = tr(R)
st(R) ⊆ ts(R)
```

## 五、易错点提示

> [!warning] 常见误区
> - **"复合运算顺序搞反"**：$R \circ S$ 是先R后S。
> - **"闭包运算顺序无关"**：$st(R)$ 和 $ts(R)$ 不一定相等。
> - **"传递闭包只需计算到Rⁿ⁻¹"**：对于n个元素的集合，最多需要计算到Rⁿ。
