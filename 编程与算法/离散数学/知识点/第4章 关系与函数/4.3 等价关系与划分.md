# 4.3 等价关系与划分

> [!abstract] 核心问题
> 什么是等价关系？等价关系和划分有什么联系？

## 一、等价关系定义

### 1. 等价关系概念

**等价关系（Equivalence Relation）**：满足自反性、对称性和传递性的关系。

### 2. 等价关系示例

| 关系 | 是否等价关系 | 理由 |
|-----|------------|------|
| "等于" | 是 | 自反、对称、传递 |
| "同余" | 是 | 自反、对称、传递 |
| "相似" | 是 | 自反、对称、传递 |
| "大于" | 否 | 不自反、不对称 |

### 示例

**例1**：设 $A = \{1, 2, 3, 4, 5, 6\}$，$R = \{(x, y) | x \equiv y \pmod{3}\}$，判断是否为等价关系。

**解**：

- **自反性**：$x \equiv x \pmod{3}$，成立
- **对称性**：$x \equiv y \pmod{3} \Rightarrow y \equiv x \pmod{3}$，成立
- **传递性**：$x \equiv y \pmod{3} \land y \equiv z \pmod{3} \Rightarrow x \equiv z \pmod{3}$，成立

因此，$R$ 是等价关系。

## 二、等价类

### 1. 等价类定义

**等价类（Equivalence Class）**：设 $R$ 是 $A$ 上的等价关系，$x \in A$，则 $[x]_R = \{y | y \in A \land (x, y) \in R\}$

### 2. 等价类性质

| 性质 | 说明 |
|-----|------|
| **非空性** | $[x]_R \neq \emptyset$ |
| **互斥性** | $[x]_R \cap [y]_R = \emptyset$ 或 $[x]_R = [y]_R$ |
| **覆盖性** | $\bigcup_{x \in A} [x]_R = A$ |

### 示例

**例2**：设 $A = \{1, 2, 3, 4, 5, 6\}$，$R = \{(x, y) | x \equiv y \pmod{3}\}$，求等价类。

**解**：

```
[1]_R = {1, 4}
[2]_R = {2, 5}
[3]_R = {3, 6}
```

## 三、划分

### 1. 划分定义

**划分（Partition）**：设 $A$ 是非空集合，$A$ 的划分是 $A$ 的非空子集的集合 $\pi = \{A_1, A_2, \dots, A_k\}$，满足：

| 条件 | 说明 |
|-----|------|
| **非空性** | $A_i \neq \emptyset$ |
| **互斥性** | $A_i \cap A_j = \emptyset$ (i ≠ j) |
| **覆盖性** | $\bigcup A_i = A$ |

### 示例

**例3**：设 $A = \{1, 2, 3, 4, 5, 6\}$，则 $\pi = \{\{1, 4\}, \{2, 5\}, \{3, 6\}\}$ 是一个划分。

## 四、等价关系与划分的对应

### 1. 定理

设 $R$ 是 $A$ 上的等价关系，则等价类集合 $\{[x]_R | x \in A\}$ 是 $A$ 的一个划分。

反之，设 $\pi$ 是 $A$ 的一个划分，则定义关系 $R = \{(x, y) | \exists A_i \in \pi, x \in A_i \land y \in A_i\}$ 是 $A$ 上的等价关系。

### 2. 对应关系

| 等价关系 | 划分 |
|---------|------|
| 自反性 | 每个元素在某个子集中 |
| 对称性 | 同一子集中元素相互关联 |
| 传递性 | 同一子集中元素形成等价类 |

### 示例

**例4**：设 $A = \{a, b, c\}$，求所有可能的划分。

**解**：

```
1. {{a}, {b}, {c}} - 三个单元素子集
2. {{a, b}, {c}} - 一个二元子集和一个单元素子集
3. {{a, c}, {b}} - 同上
4. {{b, c}, {a}} - 同上
5. {{a, b, c}} - 一个三元子集
```

共5种划分。

## 五、商集

### 1. 商集定义

**商集（Quotient Set）**：设 $R$ 是 $A$ 上的等价关系，则商集 $A/R = \{[x]_R | x \in A\}$

### 示例

**例5**：设 $A = \{1, 2, 3, 4, 5, 6\}$，$R = \{(x, y) | x \equiv y \pmod{3}\}$，则

```
A/R = {{1, 4}, {2, 5}, {3, 6}}
```

## 六、等价关系的判定

### 判定步骤

| 步骤 | 说明 |
|-----|------|
| 1 | 检查自反性：$\forall x, (x, x) \in R$ |
| 2 | 检查对称性：$\forall x, y, (x, y) \in R \Rightarrow (y, x) \in R$ |
| 3 | 检查传递性：$\forall x, y, z, (x, y) \in R \land (y, z) \in R \Rightarrow (x, z) \in R$ |

### 示例

**例6**：判断 $R = \{(1, 1), (2, 2), (3, 3), (1, 2), (2, 1), (1, 3), (3, 1), (2, 3), (3, 2)\}$ 是否为等价关系。

**解**：

- **自反性**：成立
- **对称性**：成立
- **传递性**：成立

因此，$R$ 是等价关系。

## 七、易错点提示

> [!warning] 常见误区
> - **"等价类和划分混淆"**：等价类是元素的集合，划分是等价类的集合。
> - **"等价关系只需满足两个性质"**：必须同时满足自反性、对称性和传递性。
> - **"划分中的子集可以为空"**：划分中的子集必须非空。

## 八、示例与练习

### 练习题

1. 设 $A = \{1, 2, 3, 4\}$，$R = \{(x, y) | x + y$ 是偶数$\}$，判断 $R$ 是否为等价关系，并求等价类。
2. 设 $A = \{a, b, c, d\}$，求所有可能的划分。
3. 设 $R$ 是等价关系，证明 $[x]_R = [y]_R$ 当且仅当 $(x, y) \in R$。
