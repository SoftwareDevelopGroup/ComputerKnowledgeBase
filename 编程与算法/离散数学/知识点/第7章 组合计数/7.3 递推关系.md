# 7.3 递推关系

> [!abstract] 核心问题
> 什么是递推关系？如何求解递推关系？

## 一、递推关系定义

### 1. 递推关系概念

**递推关系（Recurrence Relation）**：用前面的项来定义后面的项。

### 示例

**例1**：斐波那契数列

```
F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2) (n ≥ 2)
```

### 2. 递推关系组成

| 组成 | 说明 |
|-----|------|
| **递推式** | 定义项之间的关系 |
| **初始条件** | 确定递推的起点 |

## 二、递推关系类型

### 1. 线性递推关系

**线性递推关系**：项的线性组合。

```
a_n = c₁a_{n-1} + c₂a_{n-2} + ... + c_k a_{n-k} + f(n)
```

### 示例

**例2**：等差数列

```
a_n = a_{n-1} + d
```

### 2. 非线性递推关系

**非线性递推关系**：项的非线性组合。

```
a_n = a_{n-1} × a_{n-2}
```

### 3. 齐次递推关系

**齐次递推关系**：不含常数项。

```
a_n = c₁a_{n-1} + c₂a_{n-2}
```

### 4. 非齐次递推关系

**非齐次递推关系**：含常数项。

```
a_n = c₁a_{n-1} + c₂a_{n-2} + f(n)
```

## 三、递推关系求解

### 1. 迭代法

**迭代法**：逐步展开递推式。

### 示例

**例3**：求解 $a_n = a_{n-1} + 2n$，$a_0 = 0$

**解**：

```
a_n = a_{n-1} + 2n
    = a_{n-2} + 2(n-1) + 2n
    = ...
    = a_0 + 2(1+2+...+n)
    = 0 + 2 × n(n+1)/2
    = n(n+1)
```

### 2. 特征方程法

**特征方程法**：用于求解线性齐次递推关系。

### 步骤

| 步骤 | 说明 |
|-----|------|
| 1 | 写出特征方程 |
| 2 | 求解特征根 |
| 3 | 根据根的情况写出通解 |
| 4 | 利用初始条件确定系数 |

### 示例

**例4**：求解斐波那契数列

**解**：

特征方程：$r² - r - 1 = 0$

特征根：$r = (1 ± √5)/2$

通解：$F(n) = A((1+√5)/2)^n + B((1-√5)/2)^n$

利用初始条件 $F(0)=0, F(1)=1$：

```
A + B = 0
A((1+√5)/2) + B((1-√5)/2) = 1

解得：A = 1/√5, B = -1/√5

F(n) = ((1+√5)/2)^n / √5 - ((1-√5)/2)^n / √5
```

### 3. 生成函数法

**生成函数法**：用幂级数表示数列。

### 示例

**例5**：用生成函数求解 $a_n = a_{n-1} + 1$，$a_0 = 0$

**解**：

设生成函数 $G(x) = Σ a_n x^n$

```
G(x) = a_0 + a_1 x + a_2 x² + ...
     = 0 + (a_0+1)x + (a_1+1)x² + ...
     = x(G(x) + 1) + x²(G(x) + 1) + ...
     = xG(x)/(1-x) + x/(1-x)

解得：G(x) = x/(1-x)² = Σ n x^n

所以 a_n = n
```

## 四、常见递推关系

### 1. 等差数列

```
a_n = a_{n-1} + d
a_n = a_0 + nd
```

### 2. 等比数列

```
a_n = r a_{n-1}
a_n = a_0 r^n
```

### 3. 斐波那契数列

```
F(n) = F(n-1) + F(n-2)
F(n) = ((1+√5)/2)^n / √5 - ((1-√5)/2)^n / √5
```

### 4. 汉诺塔问题

```
H(n) = 2H(n-1) + 1
H(n) = 2^n - 1
```

### 5. Catalan数

```
C(n) = Σ_{k=0}^{n-1} C(k)C(n-1-k)
C(n) = C(2n, n)/(n+1)
```

## 五、递推关系应用

### 1. 算法分析

**时间复杂度**：用递推关系分析算法复杂度。

### 示例

**例6**：快速排序的时间复杂度

```
T(n) = 2T(n/2) + O(n)
T(n) = O(n log n)
```

### 2. 组合计数

**计数问题**：用递推关系解决计数问题。

### 3. 动态规划

**动态规划**：用递推关系求解最优问题。

## 六、易错点提示

> [!warning] 常见误区
> - **"特征方程法适用条件"**：只适用于线性齐次递推关系。
> - **"迭代法计算错误"**：注意展开时的项数和系数。
> - **"初始条件遗漏"**：递推关系需要初始条件才能确定唯一解。

### 练习题

2. 求解递推关系 $a_n = 3a_{n-1} - 2a_{n-2}$，$a_0 = 0$，$a_1 = 1$
3. 证明汉诺塔问题的递推关系 $H(n) = 2H(n-1) + 1$ 的解是 $H(n) = 2^n - 1$
