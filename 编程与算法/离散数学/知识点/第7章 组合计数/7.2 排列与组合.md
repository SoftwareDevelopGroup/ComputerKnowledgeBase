# 7.2 排列与组合

> [!abstract] 核心问题
> 什么是排列和组合？如何计算它们？

## 一、排列

### 1. 排列定义

**排列（Permutation）**：从 $n$ 个元素中选 $k$ 个元素的有序排列数，记为 $P(n, k)$ 或 $A(n, k)$。

### 2. 排列公式

```
P(n, k) = n × (n-1) × ... × (n-k+1) = n! / (n-k)!
```

### 示例

**例1**：计算 $P(5, 3)$

**解**：$P(5, 3) = 5! / (5-3)! = 120 / 2 = 60$

### 3. 全排列

**全排列**：$P(n, n) = n!$

### 示例

**例2**：5个人排成一行，有多少种排法？

**解**：$5! = 120$

### 4. 多重排列

**多重排列**：有重复元素的排列。

```
公式：n! / (n₁!n₂!...nₖ!)
```

### 示例

**例3**：单词"MISSISSIPPI"有多少种不同的排列？

**解**：字母计数：M:1, I:4, S:4, P:2

```
11! / (1!4!4!2!) = 34650
```

## 二、组合

### 1. 组合定义

**组合（Combination）**：从 $n$ 个元素中选 $k$ 个元素的无序组合数，记为 $C(n, k)$ 或 $\binom{n}{k}$。

### 2. 组合公式

```
C(n, k) = n! / (k!(n-k)!)
```

### 示例

**例4**：计算 $C(5, 3)$

**解**：$C(5, 3) = 5! / (3!2!) = 10$

### 3. 组合性质

| 性质 | 公式 |
|-----|------|
| **对称性** | $C(n, k) = C(n, n-k)$ |
| **递推式** | $C(n, k) = C(n-1, k-1) + C(n-1, k)$ |
| **二项式定理** | $(a+b)^n = Σ C(n, k)a^{n-k}b^k$ |
| **总和** | $Σ C(n, k) = 2^n$ |

### 示例

**例5**：验证对称性

```
C(5, 2) = 10, C(5, 3) = 10，相等
```

### 4. 多重组合

**多重组合**：从多重集合中选元素。

```
公式：C(n + k - 1, k - 1)
```

### 示例

**例6**：从无限多个红球、蓝球、黄球中选5个球，有多少种选法？

**解**：$C(5 + 3 - 1, 3 - 1) = C(7, 2) = 21$

## 三、二项式定理

### 1. 二项式定理公式

```
(a + b)^n = Σ_{k=0}^{n} C(n, k) a^{n-k} b^k
```

### 示例

**例7**：展开 $(a + b)^3$

**解**：

```
(a + b)^3 = C(3,0)a³ + C(3,1)a²b + C(3,2)ab² + C(3,3)b³
          = a³ + 3a²b + 3ab² + b³
```

### 2. 二项式系数性质

| 性质 | 说明 |
|-----|------|
| **对称性** | $C(n, k) = C(n, n-k)$ |
| **单行和** | $Σ C(n, k) = 2^n$ |
| **奇数项和** | $Σ C(n, 2k) = 2^{n-1}$ |
| **偶数项和** | $Σ C(n, 2k+1) = 2^{n-1}$ |

## 四、排列与组合对比

| 特征 | 排列 | 组合 |
|-----|------|------|
| **顺序** | 考虑顺序 | 不考虑顺序 |
| **公式** | $n! / (n-k)!$ | $n! / (k!(n-k)!)$ |
| **示例** | 排队 | 选代表 |
| **关系** | $P(n, k) = C(n, k) × k!$ |

## 五、应用示例

### 1. 组合优化

**组合优化问题**：从候选集中选择最优组合。

### 2. 概率计算

**概率**：有利事件数 / 总事件数。

### 示例

**例8**：从52张牌中抽5张，抽到同花顺的概率是多少？

**解**：

```
总事件数：C(52, 5) = 2598960
有利事件数：4 × 10 = 40（4种花色，10种序列）
概率：40 / 2598960 ≈ 0.000015
```

### 3. 算法分析

**算法复杂度**：计算算法执行次数。

## 六、易错点提示

> [!warning] 常见误区
> - **"排列和组合混淆"**：排列考虑顺序，组合不考虑顺序。
> - **"二项式定理展开错误"**：注意系数和指数的对应关系。
> - **"多重排列公式记错"**：分母是各重复元素阶乘的乘积。
