# 7.1 基本计数原理

> [!abstract] 核心问题
> 什么是加法原理和乘法原理？如何应用它们？

## 一、加法原理

### 1. 加法原理定义

**加法原理（Addition Principle）**：如果完成一件事情有 $n$ 类不同的方法，第 $i$ 类有 $m_i$ 种方法，则完成这件事共有：

```
m₁ + m₂ + ... + mₙ
```

种方法。

### 示例

**例1**：从北京到上海，可以坐火车（5趟）、飞机（3趟）、汽车（2趟），共有多少种方式？

**解**：$5 + 3 + 2 = 10$

### 2. 加法原理条件

| 条件 | 说明 |
|-----|------|
| **互斥性** | 各类方法互不重叠 |
| **完备性** | 所有方法都被涵盖 |

## 二、乘法原理

### 1. 乘法原理定义

**乘法原理（Multiplication Principle）**：如果完成一件事情需要 $n$ 个步骤，第 $i$ 步有 $m_i$ 种方法，则完成这件事共有：

```
m₁ × m₂ × ... × mₙ
```

种方法。

### 示例

**例2**：从北京到上海有3条路线，从上海到广州有2条路线，从北京经上海到广州共有多少种路线？

**解**：$3 × 2 = 6$

### 2. 乘法原理条件

| 条件 | 说明 |
|-----|------|
| **独立性** | 各步骤方法数相互独立 |
| **顺序性** | 步骤有先后顺序 |

## 三、加法原理与乘法原理对比

| 特征 | 加法原理 | 乘法原理 |
|-----|----------|----------|
| **问题类型** | "或"的关系 | "与"的关系 |
| **计算方式** | 求和 | 求积 |
| **条件** | 互斥、完备 | 独立、有序 |

### 示例

**例3**：一个书架有3本数学书、4本物理书、5本化学书。

1. **取一本书**：$3 + 4 + 5 = 12$（加法原理）
2. **各取一本**：$3 × 4 × 5 = 60$（乘法原理）

## 四、排列与组合基础

### 1. 排列

**排列（Permutation）**：从 $n$ 个元素中选 $k$ 个元素的有序排列数。

```
P(n, k) = n × (n-1) × ... × (n-k+1) = n! / (n-k)!
```

### 示例

**例4**：从5个人中选3个人排成一行，有多少种排法？

**解**：$P(5, 3) = 5 × 4 × 3 = 60$

### 2. 组合

**组合（Combination）**：从 $n$ 个元素中选 $k$ 个元素的无序组合数。

```
C(n, k) = P(n, k) / k! = n! / (k!(n-k)!)
```

### 示例

**例5**：从5个人中选3个人组成小组，有多少种选法？

**解**：$C(5, 3) = 5! / (3!2!) = 10$

## 五、应用示例

### 1. 密码学

**密码数量**：计算可能的密码组合数。

### 示例

**例6**：一个6位密码，每位可以是数字或字母（共36种选择），共有多少种密码？

**解**：$36^6 = 2,176,782,336$

### 2. 计算机网络

**IP地址**：计算可能的IP地址数量。

### 示例

**例7**：IPv4地址是32位二进制数，共有多少个IP地址？

**解**：$2^{32} = 4,294,967,296$

### 3. 概率论

**样本空间**：计算事件发生的可能情况数。

## 六、易错点提示

> [!warning] 常见误区
> - **"加法原理和乘法原理混淆"**："或"用加法，"与"用乘法。
> - **"排列和组合混淆"**：排列考虑顺序，组合不考虑顺序。
> - **"阶乘计算错误"**：$0! = 1$，不是0。
