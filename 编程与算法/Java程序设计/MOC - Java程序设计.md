# Java程序设计

> [!abstract] 课程定位
> 本课程是计算机专业核心课程，系统讲授Java语言的基础语法、面向对象编程、集合框架、异常处理和I/O操作等内容，培养学生的面向对象程序设计能力。

> [!info] 进阶学习路径
> 完成本课程后，可深入学习以下方向：
> - **Java进阶**：Java高级特性 → Java Web开发 → Spring框架
> - **大数据**：Hadoop → Spark → 数据仓库
> - **移动端**：Android开发 → Kotlin → Flutter

## 易混淆概念对比

| 概念对 | 区别 | 联系 |
|-------|------|------|
| **JDK vs JRE vs JVM** | JDK是开发工具包；JRE是运行环境；JVM是虚拟机 | JDK包含JRE，JRE包含JVM |
| **== vs equals** | ==比较地址；equals比较内容 | equals默认实现是== |
| **重写 vs 重载** | 重写是子类覆盖父类方法；重载是同一类中方法名相同参数不同 | 都是多态的体现 |
| **抽象类 vs 接口** | 抽象类可以有实现；接口只有声明 | 都用于抽象 |
