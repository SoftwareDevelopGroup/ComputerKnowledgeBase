# 习题-第2章-基础语法、数据类型与运算符

> [!abstract] 本章习题说明
> 本章习题涵盖Java基础语法、数据类型、运算符等核心知识点。

## 一、选择题

1. 以下哪个是合法的Java标识符（ ）
   A. 123abc
   B. abc-123
   C. _abc123
   D. class

2. Java的基本数据类型不包括（ ）
   A. byte
   B. short
   C. long
   D. String

3. 以下代码的输出结果是（ ）
   ```java
   int a = 5;
   int b = a++;
   System.out.println(a + "," + b);
   ```
   A. 5,5
   B. 5,6
   C. 6,5
   D. 6,6

4. 以下代码的输出结果是（ ）
   ```java
   int a = 10;
   int b = 3;
   System.out.println(a % b);
   ```
   A. 1
   B. 3
   C. 10
   D. 30

5. 以下哪个表达式的值为true（ ）
   A. 5 > 3 && 2 < 1
   B. 5 > 3 || 2 < 1
   C. !(5 > 3)
   D. 5 == 3

### 编程题参考代码

**第1题**

```java
public class Circle {
    public static void main(String[] args) {
        double radius = 5.0;
        double area = Math.PI * radius * radius;
        double perimeter = 2 * Math.PI * radius;
        System.out.println("面积: " + area);
        System.out.println("周长: " + perimeter);
    }
}
```

**第2题**

```java
public class Temperature {
    public static void main(String[] args) {
        double fahrenheit = 68.0;
        double celsius = (fahrenheit - 32) * 5 / 9;
        System.out.println(fahrenheit + "华氏度 = " + celsius + "摄氏度");
    }
}
```

**第3题**

```java
public class EvenCheck {
    public static void main(String[] args) {
        int num = 10;
        if (num % 2 == 0) {
            System.out.println(num + "是偶数");
        } else {
            System.out.println(num + "是奇数");
        }
    }
}
```
