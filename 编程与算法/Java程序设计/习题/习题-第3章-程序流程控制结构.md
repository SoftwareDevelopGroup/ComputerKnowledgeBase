# 习题-第3章-程序流程控制结构

> [!abstract] 本章习题说明
> 本章习题涵盖顺序结构、选择结构、循环结构等核心知识点。

## 一、选择题

1. 以下哪个不是Java的控制结构（ ）
   A. 顺序结构
   B. 选择结构
   C. 循环结构
   D. 跳转结构

2. 以下代码的输出结果是（ ）
   ```java
   int a = 10;
   if (a > 5) {
       System.out.println("大于5");
   } else {
       System.out.println("小于等于5");
   }
   ```
   A. 大于5
   B. 小于等于5
   C. 无输出
   D. 编译错误

3. switch语句的表达式不能是（ ）类型
   A. int
   B. String
   C. double
   D. char

4. while循环和do-while循环的区别是（ ）
   A. while循环先执行后判断
   B. do-while循环先执行后判断
   C. 两者完全相同
   D. do-while循环至少执行两次

5. 以下代码的输出结果是（ ）
   ```java
   for (int i = 1; i <= 3; i++) {
       if (i == 2) continue;
       System.out.println(i);
   }
   ```
   A. 1,2,3
   B. 1,3
   C. 2
   D. 无输出

### 编程题参考代码

**第1题**

```java
public class RangeCheck {
    public static void main(String[] args) {
        int num = 15;
        if (num >= 10 && num <= 20) {
            System.out.println(num + "在10到20之间");
        } else {
            System.out.println(num + "不在10到20之间");
        }
    }
}
```

**第2题**

```java
public class EvenNumbers {
    public static void main(String[] args) {
        for (int i = 1; i <= 100; i++) {
            if (i % 2 == 0) {
                System.out.println(i);
            }
        }
    }
}
```

**第3题**

```java
public class MultiplicationTable {
    public static void main(String[] args) {
        for (int i = 1; i <= 9; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print(j + "×" + i + "=" + i*j + "\t");
            }
            System.out.println();
        }
    }
}
```
