# 6.2 方法重写

> [!abstract] 核心问题
> 什么是方法重写？重写的规则是什么？重写与重载的区别是什么？

## 一、方法重写的概念

### 1. 定义

方法重写是子类对父类方法的重新实现。

### 2. 重写的目的

- 扩展父类方法的功能
- 实现多态

### 3. 示例

```java
public class Person {
    public void sayHello() {
        System.out.println("Hello from Person");
    }
}

public class Student extends Person {
    @Override
    public void sayHello() {
        System.out.println("Hello from Student");
    }
}
```

## 二、重写的规则

### 1. 方法签名必须相同

```java
public class Person {
    public void sayHello(String name) {}
}

public class Student extends Person {
    // 正确：方法签名相同
    @Override
    public void sayHello(String name) {}
    
    // 错误：参数列表不同，不是重写
    public void sayHello() {}
}
```

### 2. 返回类型

- 可以相同
- 可以是子类型（协变返回类型）

```java
public class Person {
    public Person getPerson() {
        return new Person();
    }
}

public class Student extends Person {
    @Override
    public Student getPerson() {  // 子类型
        return new Student();
    }
}
```

### 3. 访问修饰符

- 不能比父类更严格

| 父类修饰符 | 子类允许的修饰符 |
|-----------|-----------------|
| `public` | `public` |
| `protected` | `protected`、`public` |
| 默认 | 默认、`protected`、`public` |
| `private` | 不能重写 |

### 4. 异常声明

- 不能抛出比父类更广泛的异常

```java
public class Person {
    public void method() throws IOException {}
}

public class Student extends Person {
    // 正确：抛出更具体的异常
    @Override
    public void method() throws FileNotFoundException {}
    
    // 错误：抛出更广泛的异常
    // public void method() throws Exception {}
}
```

## 三、@Override注解

### 1. 作用

- 检查重写是否正确
- 提高代码可读性

### 2. 使用

```java
@Override
public void sayHello() {
    // ...
}
```

### 3. 注意事项

- @Override不是必需的，但强烈建议使用
- 如果重写不正确，编译器会报错

## 四、重写与重载的区别

### 1. 方法重载

在同一个类中，方法名相同，参数列表不同。

```java
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }
    
    public double add(double a, double b) {
        return a + b;
    }
    
    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

### 2. 区别对比

| 对比项 | 重写 | 重载 |
|-------|------|------|
| 位置 | 子类 | 同类或子类 |
| 方法名 | 相同 | 相同 |
| 参数列表 | 相同 | 不同 |
| 返回类型 | 相同或子类型 | 任意 |
| 访问修饰符 | 不能更严格 | 任意 |
| 目的 | 扩展功能 | 同一功能的不同实现 |

### 3. 示例对比

```java
// 重写
public class Person {
    public void sayHello() {
        System.out.println("Hello");
    }
}

public class Student extends Person {
    @Override
    public void sayHello() {
        System.out.println("Hello Student");
    }
}

// 重载
public class Person {
    public void sayHello() {
        System.out.println("Hello");
    }
    
    public void sayHello(String name) {
        System.out.println("Hello " + name);
    }
}
```

> [!warning] 易错点
> 重写的方法签名必须完全相同！参数列表不同的方法不是重写，而是重载。
