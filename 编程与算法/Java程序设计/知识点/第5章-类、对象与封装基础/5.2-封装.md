# 5.2 封装

> [!abstract] 核心问题
> 什么是封装？如何实现封装？访问修饰符的作用域是什么？

## 一、封装的概念

### 1. 定义

封装是将对象的属性和行为结合在一起，并对外隐藏内部实现细节。

### 2. 封装的优点

| 优点 | 说明 |
|-----|------|
| 安全性 | 防止外部直接访问和修改数据 |
| 可维护性 | 修改内部实现不影响外部使用 |
| 灵活性 | 可以控制数据的访问方式 |

### 3. 封装的示意图

```mermaid
flowchart LR
  A[外部] --> B[公共接口]
  B --> C[类内部]
  C --> D[私有成员]
```

## 二、访问修饰符

### 1. 四种访问修饰符

| 修饰符 | 同类 | 同包 | 子类 | 任意位置 |
|-------|------|------|------|---------|
| `private` | ✓ | ✗ | ✗ | ✗ |
| 默认 | ✓ | ✓ | ✗ | ✗ |
| `protected` | ✓ | ✓ | ✓ | ✗ |
| `public` | ✓ | ✓ | ✓ | ✓ |

### 2. 使用示例

```java
public class Person {
    private String name;    // 私有，只能在类内部访问
    int age;                // 默认，同包可访问
    protected String gender;  // 保护，子类可访问
    public String address;   // 公共，任意位置可访问
}
```

## 三、实现封装

### 1. 将成员变量设为私有

```java
public class Person {
    private String name;
    private int age;
}
```

### 2. 提供getter和setter方法

```java
public class Person {
    private String name;
    private int age;
    
    // getter方法：获取属性值
    public String getName() {
        return name;
    }
    
    // setter方法：设置属性值
    public void setName(String name) {
        this.name = name;
    }
    
    public int getAge() {
        return age;
    }
    
    public void setAge(int age) {
        // 可以添加验证逻辑
        if (age >= 0) {
            this.age = age;
        } else {
            System.out.println("年龄不能为负数");
        }
    }
}
```

### 3. 使用封装后的类

```java
Person p = new Person();

// 通过setter设置值
p.setName("张三");
p.setAge(18);

// 通过getter获取值
System.out.println(p.getName());  // 张三
System.out.println(p.getAge());   // 18
```

## 四、封装的应用场景

### 1. 数据验证

```java
public void setAge(int age) {
    if (age < 0 || age > 150) {
        throw new IllegalArgumentException("无效年龄");
    }
    this.age = age;
}
```

### 2. 日志记录

```java
public void setName(String name) {
    System.out.println("设置姓名：" + name);
    this.name = name;
}
```

### 3. 计算属性

```java
public class Circle {
    private double radius;
    
    public double getArea() {
        return Math.PI * radius * radius;
    }
    
    public double getCircumference() {
        return 2 * Math.PI * radius;
    }
}
```

> [!warning] 易错点
> 不要直接使用成员变量，应该通过getter和setter方法访问！这样可以保证数据的一致性和安全性。
