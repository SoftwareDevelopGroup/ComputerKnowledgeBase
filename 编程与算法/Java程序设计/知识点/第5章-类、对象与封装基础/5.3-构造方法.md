# 5.3 构造方法

> [!abstract] 核心问题
> 什么是构造方法？如何定义和使用构造方法？this关键字的作用是什么？

## 一、构造方法的概念

### 1. 定义

构造方法是用于创建对象时初始化对象的特殊方法。

### 2. 特点

| 特点 | 说明 |
|-----|------|
| 方法名与类名相同 | 包括大小写 |
| 无返回值类型 | 不需要void |
| 在创建对象时自动调用 | 使用new关键字时 |

### 3. 默认构造方法

如果类中没有定义构造方法，编译器会自动生成一个无参构造方法。

```java
public class Person {
    // 编译器自动生成的默认构造方法
    public Person() {}
}
```

## 二、定义构造方法

### 1. 无参构造方法

```java
public class Person {
    private String name;
    private int age;
    
    public Person() {
        name = "未知";
        age = 0;
    }
}
```

### 2. 有参构造方法

```java
public class Person {
    private String name;
    private int age;
    
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

### 3. 构造方法重载

```java
public class Person {
    private String name;
    private int age;
    
    public Person() {
        this("未知", 0);
    }
    
    public Person(String name) {
        this(name, 0);
    }
    
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

## 三、使用构造方法

### 1. 创建对象时调用

```java
Person p1 = new Person();           // 调用无参构造方法
Person p2 = new Person("张三");      // 调用单参构造方法
Person p3 = new Person("李四", 20);  // 调用双参构造方法
```

### 2. 构造方法链

```java
public class Person {
    public Person() {
        this("默认姓名");  // 调用另一个构造方法
    }
    
    public Person(String name) {
        this(name, 0);  // 调用第三个构造方法
    }
    
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

## 四、this关键字

### 1. 引用当前对象

```java
public class Person {
    private String name;
    
    public void setName(String name) {
        this.name = name;  // this.name是成员变量，name是参数
    }
    
    public void print() {
        System.out.println(this);  // 输出当前对象的引用
    }
}
```

### 2. 调用其他构造方法

```java
public class Person {
    public Person() {
        this("默认姓名", 0);  // 必须在第一行
    }
    
    public Person(String name, int age) {
        // ...
    }
}
```

### 3. this的作用总结

| 用途 | 示例 |
|-----|------|
| 区分成员变量和局部变量 | `this.name = name;` |
| 调用其他构造方法 | `this("参数");` |
| 返回当前对象 | `return this;` |
| 作为参数传递 | `method(this);` |

## 五、构造方法与普通方法的区别

| 对比项 | 构造方法 | 普通方法 |
|-------|---------|---------|
| 方法名 | 与类名相同 | 任意 |
| 返回值 | 无 | 有 |
| 调用时机 | 创建对象时自动调用 | 手动调用 |
| 调用方式 | new关键字 | 对象名.方法名() |

> [!warning] 易错点
> 如果定义了有参构造方法，编译器不会自动生成无参构造方法！如果需要无参构造方法，必须手动定义。
