# 第3章-程序流程控制结构

> [!abstract] 本章定位
> 本章介绍Java的三种基本程序结构：顺序结构、选择结构和循环结构。

## 学习主线

```mermaid
flowchart LR
  A[顺序结构] --> B[选择结构]
  B --> C[循环结构]
```

## 章节内容

- [[3.1-顺序结构.md]]：赋值语句、输入输出
- [[3.2-选择结构.md]]：if语句、switch语句
- [[3.3-循环结构.md]]：while循环、for循环、do-while循环

## 考点汇总

> [!important] 核心考点
> 1. if-else语句的嵌套
> 2. switch语句的使用，break的作用
> 3. while循环和do-while循环的区别
> 4. for循环的执行顺序，增强for循环
> 5. break和continue的区别
