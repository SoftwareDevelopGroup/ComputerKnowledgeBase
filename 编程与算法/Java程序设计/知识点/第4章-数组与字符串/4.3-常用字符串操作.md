# 4.3 常用字符串操作

> [!abstract] 核心问题
> String类有哪些常用方法？如何进行字符串比较、查找、替换和分割？

## 一、字符串比较

### 1. equals()

```java
String str1 = "Hello";
String str2 = "hello";
str1.equals(str2);      // false
str1.equalsIgnoreCase(str2);  // true
```

### 2. compareTo()

```java
String str1 = "apple";
String str2 = "banana";
str1.compareTo(str2);   // 负数（apple < banana）
str2.compareTo(str1);   // 正数（banana > apple）
```

### 3. startsWith()和endsWith()

```java
String str = "Hello.java";
str.startsWith("Hello");  // true
str.endsWith(".java");    // true
```

## 二、字符串查找

### 1. indexOf()

```java
String str = "Hello World";
str.indexOf('o');         // 4
str.indexOf("World");     // 6
str.indexOf('x');         // -1（未找到）
```

### 2. lastIndexOf()

```java
String str = "Hello World";
str.lastIndexOf('o');    // 7
```

### 3. charAt()

```java
String str = "Hello";
str.charAt(0);           // 'H'
str.charAt(4);           // 'o'
```

## 三、字符串截取

### 1. substring()

```java
String str = "Hello World";
str.substring(6);        // "World"
str.substring(0, 5);     // "Hello"（不包含结束索引）
```

### 2. substring()注意事项

```java
String str = "Hello";
str.substring(2, 2);     // ""（空字符串）
str.substring(2, 1);     // 抛出异常
```

## 四、字符串替换

### 1. replace()

```java
String str = "Hello World";
str.replace('o', 'x');   // "Hellx Wxrld"
str.replace("World", "Java");  // "Hello Java"
```

### 2. replaceAll()

```java
String str = "abc123def456";
str.replaceAll("[0-9]", "");  // "abcdef"
```

### 3. replaceFirst()

```java
String str = "abc123def456";
str.replaceFirst("[0-9]", "");  // "abc23def456"
```

## 五、字符串分割

### 1. split()

```java
String str = "a,b,c,d";
String[] arr = str.split(",");  // ["a", "b", "c", "d"]
```

### 2. 正则表达式分割

```java
String str = "a b\tc\nd";
String[] arr = str.split("\\s+");  // ["a", "b", "c", "d"]
```

### 3. 限制分割次数

```java
String str = "a,b,c,d";
String[] arr = str.split(",", 2);  // ["a", "b,c,d"]
```

## 六、其他常用方法

### 1. length()

```java
String str = "Hello";
str.length();  // 5
```

### 2. trim()

```java
String str = "  Hello World  ";
str.trim();    // "Hello World"
```

### 3. toUpperCase()和toLowerCase()

```java
String str = "Hello";
str.toUpperCase();   // "HELLO"
str.toLowerCase();   // "hello"
```

### 4. isEmpty()

```java
String str = "";
str.isEmpty();  // true
```

### 5. concat()

```java
String str1 = "Hello";
String str2 = "World";
str1.concat(str2);  // "HelloWorld"
```

## 七、字符串和基本类型转换

### 1. 基本类型转字符串

```java
int num = 100;
String str1 = String.valueOf(num);
String str2 = Integer.toString(num);
String str3 = "" + num;
```

### 2. 字符串转基本类型

```java
String str = "100";
int num1 = Integer.parseInt(str);
double num2 = Double.parseDouble(str);
```

> [!warning] 易错点
> 字符串索引从0开始！substring()方法不包含结束索引。split()方法的参数是正则表达式，需要注意转义。
