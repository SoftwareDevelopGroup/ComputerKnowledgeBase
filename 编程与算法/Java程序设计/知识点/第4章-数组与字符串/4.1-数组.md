# 4.1 数组

> [!abstract] 核心问题
> 什么是数组？如何声明、初始化和访问数组？

## 一、一维数组

### 1. 声明

```java
int[] arr;     // 推荐方式
int arr[];     // 兼容C/C++方式
```

### 2. 初始化

#### 静态初始化

```java
int[] arr = {1, 2, 3, 4, 5};
```

#### 动态初始化

```java
int[] arr = new int[5];
```

### 3. 访问

```java
int[] arr = {10, 20, 30, 40, 50};
System.out.println(arr[0]);  // 10
System.out.println(arr[2]);  // 30
arr[1] = 25;                 // 修改元素
```

### 4. 长度

```java
int[] arr = {1, 2, 3};
System.out.println(arr.length);  // 3
```

### 5. 遍历

```java
int[] arr = {1, 2, 3, 4, 5};

// for循环
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// 增强for循环
for (int num : arr) {
    System.out.println(num);
}
```

## 二、二维数组

### 1. 声明

```java
int[][] arr;
int arr[][];
```

### 2. 初始化

#### 静态初始化

```java
int[][] arr = {{1, 2}, {3, 4}, {5, 6}};
```

#### 动态初始化

```java
int[][] arr = new int[3][2];
```

### 3. 访问

```java
int[][] arr = {{1, 2}, {3, 4}, {5, 6}};
System.out.println(arr[0][0]);  // 1
System.out.println(arr[1][1]);  // 4
```

### 4. 遍历

```java
int[][] arr = {{1, 2}, {3, 4}, {5, 6}};

for (int i = 0; i < arr.length; i++) {
    for (int j = 0; j < arr[i].length; j++) {
        System.out.print(arr[i][j] + " ");
    }
    System.out.println();
}
```

## 三、数组常见操作

### 1. 数组排序

```java
int[] arr = {3, 1, 4, 2, 5};
Arrays.sort(arr);
System.out.println(Arrays.toString(arr));  // [1, 2, 3, 4, 5]
```

### 2. 数组查找

```java
int[] arr = {1, 3, 5, 7, 9};
int index = Arrays.binarySearch(arr, 5);
System.out.println(index);  // 2
```

### 3. 数组复制

```java
int[] arr = {1, 2, 3};
int[] copy = Arrays.copyOf(arr, arr.length);
```

## 四、数组作为方法参数

### 1. 基本用法

```java
public static void printArray(int[] arr) {
    for (int num : arr) {
        System.out.println(num);
    }
}
```

### 2. 数组作为返回值

```java
public static int[] getArray() {
    return new int[]{1, 2, 3};
}
```

## 五、Arrays工具类

### 1. 常用方法

| 方法 | 功能 |
|-----|------|
| `sort()` | 排序 |
| `binarySearch()` | 二分查找 |
| `toString()` | 转为字符串 |
| `copyOf()` | 复制数组 |
| `equals()` | 比较数组 |
| `fill()` | 填充数组 |

> [!warning] 易错点
> 数组下标从0开始！访问越界会抛出ArrayIndexOutOfBoundsException异常。
