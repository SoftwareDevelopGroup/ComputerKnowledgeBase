# 2.1 Java基础语法

> [!abstract] 核心问题
> Java的基础语法有哪些？标识符、关键字、注释的规则是什么？

## 一、标识符

### 1. 定义
标识符是用于命名变量、类、方法等的名称。

### 2. 命名规则

| 规则 | 说明 |
|-----|------|
| 必须以字母、下划线或$开头 | 不能以数字开头 |
| 可以包含字母、数字、下划线、$ | 不能包含其他字符 |
| 区分大小写 | `Name`和`name`是不同的 |
| 不能是关键字 | 不能用`int`、`class`等 |

### 3. 命名规范

```java
// 类名：大驼峰
public class MyClass {}

// 方法名：小驼峰
public void myMethod() {}

// 变量名：小驼峰
int myVariable;

// 常量名：全大写，下划线分隔
public static final int MAX_VALUE = 100;
```

## 二、关键字

### 1. 定义
关键字是Java语言保留的特殊单词。

### 2. 常见关键字

| 分类 | 关键字 |
|-----|-------|
| 数据类型 | `int`、`float`、`double`、`char`、`boolean` |
| 访问修饰符 | `public`、`private`、`protected` |
| 类相关 | `class`、`interface`、`extends`、`implements` |
| 控制结构 | `if`、`else`、`for`、`while`、`switch` |
| 其他 | `static`、`final`、`this`、`super`、`return` |

## 三、注释

### 1. 单行注释

```java
// 这是单行注释
int a = 10;
```

### 2. 多行注释

```java
/*
这是多行注释
可以跨越多行
*/
int b = 20;
```

### 3. 文档注释

```java
/**
 * 这是文档注释
 * @param a 参数说明
 * @return 返回值说明
 */
public int add(int a, int b) {
    return a + b;
}
```

## 四、语句

### 1. 表达式语句

```java
a = 10;
System.out.println("Hello");
```

### 2. 复合语句

```java
{
    int a = 10;
    int b = 20;
    System.out.println(a + b);
}
```

### 3. 空语句

```java
;  // 什么也不做
```

## 五、分号

### 1. 作用
语句的结束标志。

### 2. 示例

```java
int a = 10;  // 分号结束
System.out.println(a);  // 分号结束
```

> [!warning] 易错点
> Java是分号敏感语言！每条语句必须以分号结束。
