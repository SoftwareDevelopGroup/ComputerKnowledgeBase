# 2.2 数据类型

> [!abstract] 核心问题
> Java的数据类型有哪些？基本类型和引用类型的区别是什么？类型转换的规则是什么？

## 一、数据类型分类

### 1. 基本数据类型

| 类型 | 说明 | 大小 | 范围 |
|-----|------|------|------|
| `byte` | 字节型 | 1字节 | -128~127 |
| `short` | 短整型 | 2字节 | -32768~32767 |
| `int` | 整型 | 4字节 | -2^31~2^31-1 |
| `long` | 长整型 | 8字节 | -2^63~2^63-1 |
| `float` | 单精度浮点型 | 4字节 | 约10^-38~10^38 |
| `double` | 双精度浮点型 | 8字节 | 约10^-308~10^308 |
| `char` | 字符型 | 2字节 | '\u0000'~'\uffff' |
| `boolean` | 布尔型 | 1字节 | true/false |

### 2. 引用数据类型

- 类（class）
- 接口（interface）
- 数组（array）
- 枚举（enum）

## 二、基本类型变量

### 1. 定义和初始化

```java
int a;           // 声明
int b = 10;      // 声明并初始化
double c = 3.14;
char ch = 'A';
boolean flag = true;
```

### 2. 类型后缀

```java
long num = 100L;     // L后缀表示长整型
float pi = 3.14f;    // f后缀表示单精度浮点型
double e = 2.718;    // 默认是double
```

## 三、引用类型变量

### 1. 定义和初始化

```java
String str = "Hello";  // 字符串
int[] arr = new int[5];  // 数组
MyClass obj = new MyClass();  // 对象
```

### 2. 基本类型 vs 引用类型

| 对比项 | 基本类型 | 引用类型 |
|-------|---------|---------|
| 存储内容 | 值 | 对象的引用（地址） |
| 默认值 | 0、0.0、false、'\u0000' | null |
| 内存位置 | 栈 | 对象在堆，引用在栈 |
| 比较方式 | ==比较值 | ==比较地址，equals比较内容 |

## 四、类型转换

### 1. 隐式转换

```java
int a = 10;
double b = a;  // int自动转换为double
```

转换规则：
- 低精度 → 高精度
- byte/short/char → int → long → float → double

### 2. 显式转换

```java
double a = 3.14;
int b = (int)a;  // 强制转换，结果为3
```

### 3. 注意事项

```java
int a = 5 / 2;     // 结果为2，不是2.5
double b = 5.0 / 2;  // 结果为2.5
```

## 五、包装类

### 1. 基本类型对应的包装类

| 基本类型 | 包装类 |
|---------|-------|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

### 2. 自动装箱和拆箱

```java
// 自动装箱：基本类型→包装类
Integer num = 10;  // 等价于 Integer num = Integer.valueOf(10)

// 自动拆箱：包装类→基本类型
int value = num;   // 等价于 int value = num.intValue()
```

> [!warning] 易错点
> 基本类型和引用类型的默认值不同！基本类型默认值是0，引用类型默认值是null。包装类是引用类型，可能为null，使用时要注意空指针异常。
