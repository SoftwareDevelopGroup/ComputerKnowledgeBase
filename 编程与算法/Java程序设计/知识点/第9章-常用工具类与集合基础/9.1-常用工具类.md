# 9.1 常用工具类

> [!abstract] 核心问题
> Java有哪些常用工具类？它们的用途是什么？

## 一、Object类

### 1. 概述

Object是所有类的父类，任何类都默认继承Object。

### 2. 常用方法

| 方法 | 说明 | 默认实现 |
|-----|------|---------|
| `equals(Object obj)` | 比较两个对象是否相等 | `==`比较地址 |
| `hashCode()` | 返回对象的哈希码 | 对象地址的哈希值 |
| `toString()` | 返回对象的字符串表示 | 类名@哈希码 |
| `clone()` | 创建对象的副本 | 浅拷贝 |
| `getClass()` | 返回对象的运行时类 | 类的Class对象 |

### 3. equals和hashCode的约定

```java
// 如果两个对象equals相等，hashCode必须相等
public class Person {
    private String name;
    private int age;
    
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Person person = (Person) obj;
        return age == person.age && Objects.equals(name, person.name);
    }
    
    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }
}
```

## 二、包装类

### 1. 基本类型对应的包装类

| 基本类型 | 包装类 |
|---------|-------|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

### 2. 自动装箱和拆箱

```java
// 自动装箱
Integer num = 10;  // 等价于 Integer.valueOf(10)

// 自动拆箱
int value = num;   // 等价于 num.intValue()
```

### 3. 缓存机制

```java
Integer a = 100;
Integer b = 100;
a == b;  // true（缓存-128~127）

Integer c = 200;
Integer d = 200;
c == d;  // false（超出缓存范围）
```

### 4. 常用方法

```java
// 字符串转基本类型
int num = Integer.parseInt("100");

// 基本类型转字符串
String str = Integer.toString(100);

// 进制转换
String binary = Integer.toBinaryString(10);  // "1010"
String hex = Integer.toHexString(255);       // "ff"
```

## 三、Math类

### 1. 常用方法

| 方法 | 说明 | 示例 |
|-----|------|------|
| `abs()` | 绝对值 | `Math.abs(-5)` → 5 |
| `ceil()` | 向上取整 | `Math.ceil(3.1)` → 4.0 |
| `floor()` | 向下取整 | `Math.floor(3.9)` → 3.0 |
| `round()` | 四舍五入 | `Math.round(3.5)` → 4 |
| `max()` | 最大值 | `Math.max(3, 5)` → 5 |
| `min()` | 最小值 | `Math.min(3, 5)` → 3 |
| `pow()` | 幂运算 | `Math.pow(2, 3)` → 8.0 |
| `sqrt()` | 平方根 | `Math.sqrt(16)` → 4.0 |
| `random()` | 随机数 | `Math.random()` → 0~1 |

### 2. 示例

```java
// 生成0~100的随机整数
int random = (int) (Math.random() * 101);

// 计算圆的面积
double area = Math.PI * Math.pow(radius, 2);
```

## 四、日期时间类

### 1. Date类（旧版）

```java
Date date = new Date();
System.out.println(date);  // 当前时间
```

### 2. Calendar类

```java
Calendar calendar = Calendar.getInstance();
int year = calendar.get(Calendar.YEAR);
int month = calendar.get(Calendar.MONTH) + 1;  // 月份从0开始
int day = calendar.get(Calendar.DAY_OF_MONTH);
```

### 3. Java 8+日期时间API

```java
// LocalDate
LocalDate today = LocalDate.now();
LocalDate birthday = LocalDate.of(2000, 1, 1);

// LocalTime
LocalTime now = LocalTime.now();

// LocalDateTime
LocalDateTime dateTime = LocalDateTime.now();

// DateTimeFormatter
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String str = dateTime.format(formatter);
LocalDateTime parsed = LocalDateTime.parse(str, formatter);
```

### 4. 新旧API对比

| 旧API | 新API | 特点 |
|------|------|------|
| Date | LocalDate/LocalTime/LocalDateTime | 不可变、线程安全 |
| Calendar | DateTimeFormatter | 格式化更简单 |
| SimpleDateFormat | Duration/Period | 时间间隔计算 |

## 五、Arrays类

### 1. 常用方法

```java
int[] arr = {3, 1, 4, 2, 5};

Arrays.sort(arr);               // 排序
Arrays.binarySearch(arr, 4);    // 二分查找
Arrays.toString(arr);           // 转为字符串
Arrays.copyOf(arr, 3);          // 复制数组
Arrays.fill(arr, 0);            // 填充数组
Arrays.equals(arr1, arr2);      // 比较数组
```
