# 10.2 文件读写

> [!abstract] 核心问题
> 如何使用File类操作文件？如何使用FileInputStream和FileOutputStream读写文件？

## 一、File类

### 1. 概述

File类用于表示文件或目录的路径。

### 2. 常用方法

| 方法 | 说明 |
|-----|------|
| `exists()` | 判断文件或目录是否存在 |
| `isFile()` | 判断是否是文件 |
| `isDirectory()` | 判断是否是目录 |
| `getName()` | 返回文件名 |
| `getPath()` | 返回文件路径 |
| `getAbsolutePath()` | 返回绝对路径 |
| `length()` | 返回文件大小 |
| `createNewFile()` | 创建新文件 |
| `mkdir()` | 创建目录 |
| `mkdirs()` | 创建多级目录 |
| `delete()` | 删除文件或目录 |
| `list()` | 返回目录中的文件列表 |
| `listFiles()` | 返回目录中的文件对象数组 |

### 3. 示例

```java
File file = new File("test.txt");

// 判断文件是否存在
if (file.exists()) {
    System.out.println("文件存在");
    System.out.println("文件名: " + file.getName());
    System.out.println("文件大小: " + file.length() + " bytes");
} else {
    try {
        file.createNewFile();
        System.out.println("文件创建成功");
    } catch (IOException e) {
        e.printStackTrace();
    }
}
```

### 4. 目录操作

```java
File dir = new File("mydir/subdir");

// 创建多级目录
dir.mkdirs();

// 列出目录中的文件
File[] files = dir.listFiles();
for (File f : files) {
    System.out.println(f.getName());
}
```

## 二、FileInputStream

### 1. 概述

FileInputStream用于从文件中读取字节数据。

### 2. 读取文件

```java
try (FileInputStream fis = new FileInputStream("input.txt")) {
    int data;
    while ((data = fis.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

### 3. 批量读取

```java
try (FileInputStream fis = new FileInputStream("input.txt")) {
    byte[] buffer = new byte[1024];
    int length;
    while ((length = fis.read(buffer)) != -1) {
        System.out.print(new String(buffer, 0, length));
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

## 三、FileOutputStream

### 1. 概述

FileOutputStream用于向文件中写入字节数据。

### 2. 写入文件

```java
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    String content = "Hello, World!";
    fos.write(content.getBytes());
} catch (IOException e) {
    e.printStackTrace();
}
```

### 3. 追加写入

```java
// 设置append为true，追加写入
try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
    String content = "\n追加的内容";
    fos.write(content.getBytes());
} catch (IOException e) {
    e.printStackTrace();
}
```

### 4. 复制文件

```java
try (FileInputStream fis = new FileInputStream("input.txt");
     FileOutputStream fos = new FileOutputStream("output.txt")) {
    
    byte[] buffer = new byte[1024];
    int length;
    while ((length = fis.read(buffer)) != -1) {
        fos.write(buffer, 0, length);
    }
    
} catch (IOException e) {
    e.printStackTrace();
}
```

## 四、FileReader和FileWriter

### 1. FileReader

```java
try (FileReader reader = new FileReader("input.txt")) {
    int data;
    while ((data = reader.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

### 2. FileWriter

```java
try (FileWriter writer = new FileWriter("output.txt")) {
    writer.write("Hello, World!");
    writer.write("\n");
    writer.write("这是中文内容");
} catch (IOException e) {
    e.printStackTrace();
}
```

## 五、文件操作的注意事项

### 1. 异常处理

```java
try {
    FileInputStream fis = new FileInputStream("file.txt");
    // 读取文件
    fis.close();
} catch (FileNotFoundException e) {
    System.out.println("文件不存在");
} catch (IOException e) {
    System.out.println("读取失败");
}
```

### 2. 使用try-with-resources

```java
// 自动关闭资源，不需要手动close()
try (FileInputStream fis = new FileInputStream("input.txt");
     FileOutputStream fos = new FileOutputStream("output.txt")) {
    // 读写操作
} catch (IOException e) {
    e.printStackTrace();
}
```

### 3. 文件路径

```java
// 相对路径
File file1 = new File("test.txt");

// 绝对路径
File file2 = new File("C:/Users/test.txt");

// 使用File.separator
File file3 = new File("C:" + File.separator + "Users" + File.separator + "test.txt");
```

> [!warning] 易错点
> 使用FileOutputStream写入文件时，默认会覆盖原有内容！如果需要追加写入，需要设置append参数为true。
