# 10.3 缓冲流与字符流

> [!abstract] 核心问题
> 什么是缓冲流？如何使用BufferedReader、BufferedWriter和PrintWriter？

## 一、缓冲流的概念

### 1. 定义

缓冲流是一种处理流，通过缓冲区减少I/O操作次数，提高读写效率。

### 2. 缓冲流的优点

| 优点 | 说明 |
|-----|------|
| 提高效率 | 减少磁盘访问次数 |
| 支持行操作 | BufferedReader支持readLine() |
| 支持自动刷新 | BufferedWriter支持flush() |

### 3. 缓冲流的工作原理

```mermaid
flowchart LR
  A[数据源] --> B[缓冲区]
  B --> C[程序]
```

## 二、BufferedInputStream和BufferedOutputStream

### 1. BufferedInputStream

```java
try (BufferedInputStream bis = new BufferedInputStream(
         new FileInputStream("input.txt"))) {
    
    byte[] buffer = new byte[1024];
    int length;
    while ((length = bis.read(buffer)) != -1) {
        System.out.print(new String(buffer, 0, length));
    }
    
} catch (IOException e) {
    e.printStackTrace();
}
```

### 2. BufferedOutputStream

```java
try (BufferedOutputStream bos = new BufferedOutputStream(
         new FileOutputStream("output.txt"))) {
    
    String content = "Hello, World!";
    bos.write(content.getBytes());
    bos.flush();  // 手动刷新缓冲区
    
} catch (IOException e) {
    e.printStackTrace();
}
```

## 三、BufferedReader

### 1. 概述

BufferedReader用于高效读取文本文件，支持按行读取。

### 2. 按行读取

```java
try (BufferedReader br = new BufferedReader(
         new FileReader("input.txt"))) {
    
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
    
} catch (IOException e) {
    e.printStackTrace();
}
```

### 3. 读取所有行

```java
try (BufferedReader br = new BufferedReader(
         new FileReader("input.txt"))) {
    
    // Java 8+
    List<String> lines = br.lines().collect(Collectors.toList());
    
} catch (IOException e) {
    e.printStackTrace();
}
```

### 4. 使用InputStreamReader处理编码

```java
try (BufferedReader br = new BufferedReader(
         new InputStreamReader(
             new FileInputStream("input.txt"), "UTF-8"))) {
    
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
    
} catch (IOException e) {
    e.printStackTrace();
}
```

## 四、BufferedWriter

### 1. 概述

BufferedWriter用于高效写入文本文件，支持按行写入。

### 2. 按行写入

```java
try (BufferedWriter bw = new BufferedWriter(
         new FileWriter("output.txt"))) {
    
    bw.write("第一行");
    bw.newLine();  // 换行
    bw.write("第二行");
    bw.flush();    // 手动刷新
    
} catch (IOException e) {
    e.printStackTrace();
}
```

### 3. 追加写入

```java
try (BufferedWriter bw = new BufferedWriter(
         new FileWriter("output.txt", true))) {
    
    bw.newLine();
    bw.write("追加的内容");
    
} catch (IOException e) {
    e.printStackTrace();
}
```

### 4. 使用OutputStreamWriter处理编码

```java
try (BufferedWriter bw = new BufferedWriter(
         new OutputStreamWriter(
             new FileOutputStream("output.txt"), "UTF-8"))) {
    
    bw.write("中文内容");
    
} catch (IOException e) {
    e.printStackTrace();
}
```

## 五、PrintWriter

### 1. 概述

PrintWriter是一个方便的文本输出流，支持print和println方法。

### 2. 基本使用

```java
try (PrintWriter pw = new PrintWriter("output.txt")) {
    pw.println("Hello, World!");
    pw.println("这是中文内容");
    pw.printf("数字: %d, 浮点数: %.2f%n", 100, 3.14);
} catch (FileNotFoundException e) {
    e.printStackTrace();
}
```

### 3. 追加写入

```java
try (PrintWriter pw = new PrintWriter(
         new FileWriter("output.txt", true))) {
    
    pw.println("追加的内容");
    
} catch (IOException e) {
    e.printStackTrace();
}
```

### 4. 自动刷新

```java
// 设置autoFlush为true，println后自动刷新
try (PrintWriter pw = new PrintWriter(
         new FileOutputStream("output.txt"), true)) {
    
    pw.println("自动刷新");
    
} catch (FileNotFoundException e) {
    e.printStackTrace();
}
```

## 六、缓冲流的性能对比

### 1. 无缓冲vs有缓冲

| 操作 | 无缓冲 | 有缓冲 |
|-----|-------|-------|
| 读取1000行 | 1000次I/O | 几次I/O |
| 写入1000行 | 1000次I/O | 几次I/O |
| 效率 | 低 | 高 |

### 2. 使用建议

| 场景 | 推荐流 |
|-----|-------|
| 读取文本文件 | BufferedReader |
| 写入文本文件 | BufferedWriter |
| 格式化输出 | PrintWriter |
| 读取二进制文件 | BufferedInputStream |
| 写入二进制文件 | BufferedOutputStream |

## 七、文件操作示例

### 1. 复制文本文件

```java
try (BufferedReader br = new BufferedReader(new FileReader("input.txt"));
     BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"))) {
    
    String line;
    while ((line = br.readLine()) != null) {
        bw.write(line);
        bw.newLine();
    }
    
} catch (IOException e) {
    e.printStackTrace();
}
```

### 2. 统计文件行数

```java
try (BufferedReader br = new BufferedReader(new FileReader("input.txt"))) {
    int count = 0;
    while (br.readLine() != null) {
        count++;
    }
    System.out.println("文件行数: " + count);
} catch (IOException e) {
    e.printStackTrace();
}
```

### 3. 读取文件并转换为大写

```java
try (BufferedReader br = new BufferedReader(new FileReader("input.txt"));
     BufferedWriter bw = new BufferedWriter(new FileWriter("output.txt"))) {
    
    String line;
    while ((line = br.readLine()) != null) {
        bw.write(line.toUpperCase());
        bw.newLine();
    }
    
} catch (IOException e) {
    e.printStackTrace();
}
```

> [!warning] 易错点
> 缓冲流使用完毕后必须关闭！关闭缓冲流会自动关闭底层的节点流。
