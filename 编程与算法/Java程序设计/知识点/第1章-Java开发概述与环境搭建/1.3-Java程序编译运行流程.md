# 1.3 Java程序编译运行流程

> [!abstract] 核心问题
> Java程序的编译运行流程是什么？每个阶段做什么？

## 一、编译运行流程

### 1. 流程图

```mermaid
flowchart LR
  A[编辑源文件.java] --> B[javac编译]
  B --> C[生成字节码.class]
  C --> D[java运行]
  D --> E[JVM执行]
  E --> F[输出结果]
```

### 2. 四个阶段

| 阶段 | 输入 | 输出 | 工具 |
|-----|------|------|------|
| **编辑** | 文本编辑器 | `.java`源文件 | Notepad、IDE |
| **编译** | `.java`源文件 | `.class`字节码文件 | `javac` |
| **运行** | `.class`字节码文件 | 运行结果 | `java` |
| **执行** | 字节码 | 机器指令 | JVM |

## 二、第一个Java程序

### 1. 编写源文件

```java
// Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 2. 编译

```bash
javac Hello.java
```

生成 `Hello.class` 文件。

### 3. 运行

```bash
java Hello
```

输出：`Hello, World!`

## 三、编译过程

### 1. 词法分析
识别关键字、标识符、常量。

### 2. 语法分析
检查语法规则，构建语法树。

### 3. 语义分析
检查语义正确性。

### 4. 字节码生成
生成 `.class` 文件。

## 四、运行过程

### 1. 类加载
将 `.class` 文件加载到内存。

### 2. 字节码验证
验证字节码的安全性。

### 3. 字节码执行
JVM解释执行字节码，或JIT编译成机器码。

### 4. 垃圾回收
自动回收不再使用的对象。

## 五、main方法

### 1. 定义

```java
public static void main(String[] args) {
    // 程序入口
}
```

### 2. 参数说明

| 参数 | 说明 |
|-----|------|
| `public` | 公共访问权限 |
| `static` | 静态方法，不需要创建对象 |
| `void` | 无返回值 |
| `main` | 方法名，固定 |
| `String[] args` | 命令行参数 |

### 3. 命令行参数

```bash
java Hello 参数1 参数2
```

```java
public class Hello {
    public static void main(String[] args) {
        for (String arg : args) {
            System.out.println(arg);
        }
    }
}
```

> [!warning] 易错点
> Java源文件名必须与公共类名一致！否则编译错误。运行时不需要加 `.class` 后缀。
