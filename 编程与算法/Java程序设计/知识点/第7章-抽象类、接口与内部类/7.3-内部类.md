# 7.3 内部类

> [!abstract] 核心问题
> 什么是内部类？内部类有哪些类型？各有什么特点？

## 一、内部类的概念

### 1. 定义

内部类是定义在另一个类内部的类。

### 2. 内部类的优点

| 优点 | 说明 |
|-----|------|
| 封装性 | 可以访问外部类的私有成员 |
| 代码组织 | 相关代码放在一起 |
| 隐藏实现 | 对外隐藏实现细节 |

### 3. 内部类的分类

| 类型 | 定义位置 | 特点 |
|-----|---------|------|
| 成员内部类 | 类内部，方法外部 | 可以访问外部类所有成员 |
| 局部内部类 | 方法内部 | 只能访问方法的final变量 |
| 匿名内部类 | 方法内部 | 没有类名，一次性使用 |
| 静态内部类 | 类内部，static修饰 | 不依赖外部类实例 |

## 二、成员内部类

### 1. 定义

```java
public class Outer {
    private int outerField = 10;
    
    // 成员内部类
    public class Inner {
        private int innerField = 20;
        
        public void show() {
            System.out.println("Outer field: " + outerField);
            System.out.println("Inner field: " + innerField);
        }
    }
}
```

### 2. 使用

```java
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
inner.show();  // Outer field: 10, Inner field: 20
```

### 3. 访问外部类成员

```java
public class Outer {
    private int x = 10;
    
    public class Inner {
        private int x = 20;
        
        public void show() {
            System.out.println(this.x);      // 20（内部类）
            System.out.println(Outer.this.x); // 10（外部类）
        }
    }
}
```

## 三、局部内部类

### 1. 定义

```java
public class Outer {
    public void method() {
        final int localVar = 30;
        
        // 局部内部类
        class LocalInner {
            public void show() {
                System.out.println(localVar);  // 可以访问final变量
            }
        }
        
        LocalInner inner = new LocalInner();
        inner.show();
    }
}
```

### 2. 特点

- 定义在方法内部
- 只能在方法内部使用
- 可以访问方法的final变量（Java 8+可以访问effectively final变量）

## 四、匿名内部类

### 1. 定义

```java
public interface Flyable {
    void fly();
}

public class Test {
    public static void main(String[] args) {
        // 匿名内部类
        Flyable bird = new Flyable() {
            @Override
            public void fly() {
                System.out.println("Bird is flying");
            }
        };
        
        bird.fly();  // Bird is flying
    }
}
```

### 2. 使用场景

```java
// 作为参数传递
button.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("Button clicked");
    }
});
```

### 3. Lambda表达式替代

```java
// Java 8+
Flyable bird = () -> System.out.println("Bird is flying");
bird.fly();
```

## 五、静态内部类

### 1. 定义

```java
public class Outer {
    private static int staticField = 10;
    
    // 静态内部类
    public static class StaticInner {
        public void show() {
            System.out.println("Static field: " + staticField);
        }
    }
}
```

### 2. 使用

```java
Outer.StaticInner inner = new Outer.StaticInner();
inner.show();  // Static field: 10
```

### 3. 特点

- 使用static修饰
- 不依赖外部类实例
- 只能访问外部类的静态成员

## 六、内部类的应用场景

### 1. 适配器模式

```java
public interface Target {
    void request();
}

public class Adaptee {
    public void specificRequest() {
        System.out.println("Specific request");
    }
}

public class Adapter implements Target {
    private Adaptee adaptee;
    
    public Adapter(Adaptee adaptee) {
        this.adaptee = adaptee;
    }
    
    @Override
    public void request() {
        adaptee.specificRequest();
    }
}
```

### 2. 回调机制

```java
public interface Callback {
    void onComplete();
}

public class Worker {
    public void doWork(Callback callback) {
        // 执行工作
        callback.onComplete();
    }
}

// 使用匿名内部类
Worker worker = new Worker();
worker.doWork(new Callback() {
    @Override
    public void onComplete() {
        System.out.println("Work completed");
    }
});
```

> [!warning] 易错点
> 成员内部类不能定义静态成员！局部内部类不能有访问修饰符！
