### 简答题答案

1. 算法是对特定问题求解步骤的描述，是指令的有限序列。特性：有穷性、确定性、可行性、输入、输出。

2. 时间复杂度是算法运行时间随输入规模增长的变化趋势。分析方法：循环次数分析法、递归分析法、递推方程法。

3. O(g(n))表示上界，f(n) ≤ c·g(n)；Ω(g(n))表示下界，f(n) ≥ c·g(n)；Θ(g(n))表示精确界，c₁·g(n) ≤ f(n) ≤ c₂·g(n)。

4. 主定理用于求解T(n) = aT(n/b) + f(n)形式的递推方程。情况1：f(n) = O(n^{log_b a - ε})，T(n) = Θ(n^{log_b a})；情况2：f(n) = Θ(n^{log_b a})，T(n) = Θ(n^{log_b a} logn)；情况3：f(n) = Ω(n^{log_b a + ε})，T(n) = Θ(f(n))。

5. 递归树法步骤：展开递归树，计算每层的代价，求和得到总代价。

### 综合应用题答案

**题1答案**：
内层循环执行次数：n + (n-1) + ... + 1 = n(n+1)/2 = O(n²)
时间复杂度：O(n²)

**题2答案**：
(1) a=4, b=2, log_b a=2, f(n)=n=O(n^{2-ε})，情况1，T(n)=Θ(n²)
(2) a=2, b=2, log_b a=1, f(n)=nlogn=Ω(n^{1+ε})，情况3，T(n)=Θ(nlogn)
(3) a=1, b=2, log_b a=0, f(n)=1=Θ(n⁰)，情况2，T(n)=Θ(logn)

**题3答案**：
递归树每层代价：n + n/4 + n/2 + ... = O(n)
层数：log₄n
总代价：O(nlogn)

**题4答案**：
```python
def is_sorted(arr):
    for i in range(len(arr)-1):
        if arr[i] > arr[i+1]:
            return False
    return True
```
时间复杂度：O(n)，空间复杂度：O(1)

**题5答案**：
由f(n) = O(g(n))，存在c₁>0, n₁>0，使得f(n) ≤ c₁·g(n)（n≥n₁）
由g(n) = O(h(n))，存在c₂>0, n₂>0，使得g(n) ≤ c₂·h(n)（n≥n₂）
取c = c₁·c₂，n₀ = max(n₁, n₂)，则f(n) ≤ c·h(n)（n≥n₀）
故f(n) = O(h(n))
