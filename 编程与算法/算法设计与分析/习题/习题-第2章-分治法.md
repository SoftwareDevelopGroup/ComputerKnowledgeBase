### 简答题答案

1. 分治法是将问题分解为与原问题性质相同的子问题，递归求解后合并。适用条件：最优子结构、子问题独立、子问题规模减小、合并代价较小。

2. 二分查找：每次将搜索区间缩小一半，直到找到目标元素或区间为空。步骤：初始化low和high，循环计算mid，比较mid位置元素与目标，调整搜索区间。

3. 归并排序：将数组分成两半，分别排序后合并。步骤：分解（分成两半）、递归排序、合并（将两个有序数组合并为一个）。

4. 快速排序：选择一个基准元素，将数组分成两部分，左部分小于等于基准，右部分大于基准，递归排序。步骤：选择基准、划分、递归排序左右部分。

5. 平均情况下，每次划分将数组分成大致相等的两部分，递归深度为logn，每层比较O(n)次，总时间O(nlogn)。最坏情况下，每次划分极不均匀，递归深度为n，总时间O(n²)。

### 综合应用题答案

**题1答案**：
```python
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```
时间复杂度：O(logn)，空间复杂度：O(1)

**题2答案**：
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```
时间复杂度：O(nlogn)，空间复杂度：O(n)

**题3答案**：
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```
时间复杂度：平均O(nlogn)，最坏O(n²)，空间复杂度：O(logn)

**题4答案**：
```python
def count_inversions(arr):
    if len(arr) <= 1:
        return arr, 0
    
    mid = len(arr) // 2
    left, inv_left = count_inversions(arr[:mid])
    right, inv_right = count_inversions(arr[mid:])
    merged, inv_merge = merge_count(left, right)
    
    return merged, inv_left + inv_right + inv_merge

def merge_count(left, right):
    result = []
    inversions = 0
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
            inversions += len(left) - i
    
    result.extend(left[i:])
    result.extend(right[j:])
    return result, inversions
```
时间复杂度：O(nlogn)

**题5答案**：
最近点对算法思想：
1. 按x坐标排序
2. 分治：找到中点，分别求左右最近点对
3. 合并：检查跨越中线的点对，距离小于当前最小距离
4. 时间复杂度：O(nlogn)
