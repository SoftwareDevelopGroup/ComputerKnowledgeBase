### 填空题答案

1. 最优子结构、重叠子问题
2. 自顶向下（记忆化）、自底向上
3. c[i][j] = c[i-1][j-1]+1（x[i]=y[j]）；c[i][j] = max(c[i-1][j], c[i][j-1])（x[i]≠y[j]）
4. dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]]+v[i])
5. m[i][j] = min(m[i][k]+m[k+1][j]+p[i-1]p[k]p[j])（i≤k<j）
6. 利用数组的滚动特性，只保留当前行和上一行
7. 定义状态、状态转移方程、初始化、填表顺序、回溯求解
8. O(n²)或O(nlogn)

### 简答题答案

1. 动态规划是一种通过分解问题为子问题，利用子问题的解来构建原问题解的算法设计方法。适用条件：最优子结构、重叠子问题。

2. 分治法的子问题相互独立，动态规划的子问题重叠；分治法通常采用自顶向下的方式，动态规划通常采用自底向上的方式。

3. 贪心算法在每一步选择当前最优，不考虑后续影响；动态规划考虑所有可能的选择，通过子问题的最优解构建原问题的最优解。

4. 最优子结构：问题的最优解包含其子问题的最优解。重叠子问题：不同的子问题包含相同的子子问题。

5. 滚动数组优化：利用数组的滚动特性，只保留当前行和上一行的数据，从而节省空间。适用于状态转移只依赖于相邻行的情况，如0-1背包问题。

### 综合应用题答案

**题1答案**：
LCS长度为4，如{B,C,B,A}或{B,D,A,B}

**题2答案**：
最优顺序：((A₁×A₂)×(A₃×A₄))，总乘法次数为30×35×15 + 15×5×10 + 30×15×10 = 15750 + 750 + 4500 = 21000

**题3答案**：
最大价值为13，选择物品2（重量3，价值4）、物品3（重量4，价值5）、物品4（重量5，价值6）中的物品2和物品4，或物品1（重量2，价值3）、物品2（重量3，价值4）、物品3（重量4，价值5）。

**题4答案**：
最大价值为15，选择物品1（重量2，价值3）5次，或物品2（重量3，价值4）2次和物品1（重量2，价值3）2次。

**题5答案**：
```python
def lis(arr):
    n = len(arr)
    dp = [1] * n
    
    for i in range(1, n):
        for j in range(i):
            if arr[j] < arr[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)
```
时间复杂度：O(n²)
