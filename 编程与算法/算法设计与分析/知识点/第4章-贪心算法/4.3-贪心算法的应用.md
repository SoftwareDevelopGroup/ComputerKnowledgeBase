# 4.3 贪心算法的应用

> [!abstract] 核心问题
> 最小生成树的两种贪心算法（Prim和Kruskal）的原理是什么？如何应用贪心算法解决调度问题？

## 一、最小生成树（Minimum Spanning Tree）

### 1. 问题描述
给定带权无向连通图，找到一棵生成树，使得所有边的权值之和最小。

### 2. Prim算法

**贪心策略**：从一个顶点开始，每次选择与当前顶点集合相连的最小权边。

```python
import heapq

def prim(graph):
    start = next(iter(graph))
    visited = {start}
    edges = []
    min_heap = []
    
    for neighbor, weight in graph[start].items():
        heapq.heappush(min_heap, (weight, start, neighbor))
    
    while min_heap:
        weight, u, v = heapq.heappop(min_heap)
        if v not in visited:
            visited.add(v)
            edges.append((u, v, weight))
            for neighbor, w in graph[v].items():
                if neighbor not in visited:
                    heapq.heappush(min_heap, (w, v, neighbor))
    
    return edges
```

**时间复杂度**：O((V+E)logV)

### 3. Kruskal算法

**贪心策略**：按边权从小到大排序，依次选择不形成环的边。

```python
def kruskal(graph):
    edges = []
    for u in graph:
        for v, weight in graph[u].items():
            if u < v:
                edges.append((weight, u, v))
    
    edges.sort()
    parent = {}
    
    def find(node):
        if parent[node] != node:
            parent[node] = find(parent[node])
        return parent[node]
    
    for node in graph:
        parent[node] = node
    
    mst = []
    for weight, u, v in edges:
        root_u = find(u)
        root_v = find(v)
        if root_u != root_v:
            mst.append((u, v, weight))
            parent[root_u] = root_v
    
    return mst
```

**时间复杂度**：O(ElogE)

### 4. Prim vs Kruskal

| 对比项 | Prim算法 | Kruskal算法 |
|-------|---------|------------|
| **贪心策略** | 从顶点出发扩展 | 按边权排序选择 |
| **数据结构** | 优先队列 | 并查集 |
| **时间复杂度** | O((V+E)logV) | O(ElogE) |
| **适用场景** | 稠密图 | 稀疏图 |

## 二、调度问题

### 1. 单处理器调度

**问题描述**：给定n个作业，每个作业有处理时间tᵢ和截止时间dᵢ，求最大可调度作业数。

**贪心策略**：按截止时间排序，依次选择不超过截止时间的作业。

```python
def schedule_jobs(jobs):
    jobs.sort(key=lambda x: x[1])
    current_time = 0
    selected = []
    
    for job in jobs:
        time, deadline = job
        if current_time + time <= deadline:
            selected.append(job)
            current_time += time
    
    return selected
```

### 2. 多处理器调度

**问题描述**：用m个处理器调度n个作业，最小化完成时间。

**贪心策略**：每次将作业分配给负载最小的处理器。

```python
import heapq

def multiprocessor_scheduling(jobs, m):
    processors = [(0, i) for i in range(m)]
    heapq.heapify(processors)
    schedule = [[] for _ in range(m)]
    
    for job in jobs:
        finish_time, proc_id = heapq.heappop(processors)
        schedule[proc_id].append(job)
        heapq.heappush(processors, (finish_time + job, proc_id))
    
    return schedule
```

## 三、贪心算法应用总结

| 问题 | 贪心策略 | 时间复杂度 |
|-----|---------|-----------|
| **Prim算法** | 选择最小权边扩展顶点集 | O((V+E)logV) |
| **Kruskal算法** | 按边权排序选择不形成环的边 | O(ElogE) |
| **单处理器调度** | 按截止时间排序 | O(nlogn) |
| **多处理器调度** | 分配给负载最小的处理器 | O(nlogm) |
