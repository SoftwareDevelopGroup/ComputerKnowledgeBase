# 2.3 分治法的应用

> [!abstract] 核心问题
> 分治法如何应用于矩阵乘法和最近点对问题？Strassen算法的优化原理是什么？

## 一、矩阵乘法（Matrix Multiplication）

### 1. 问题描述
给定两个n×n矩阵A和B，计算它们的乘积C = A×B。

### 2. 普通算法

```python
def matrix_multiply(A, B):
    n = len(A)
    C = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            for k in range(n):
                C[i][j] += A[i][k] * B[k][j]
    return C
```

**时间复杂度**：O(n³)

### 3. Strassen算法（分治法优化）

**思想**：将矩阵分成4个n/2×n/2的子矩阵，用7次乘法代替8次乘法。

```
A = [A11 A12]    B = [B11 B12]
    [A21 A22]        [B21 B22]

C11 = A11×B11 + A12×B21
C12 = A11×B12 + A12×B22
C21 = A21×B11 + A22×B21
C22 = A21×B12 + A22×B22

Strassen优化：
M1 = (A11+A22)×(B11+B22)
M2 = (A21+A22)×B11
M3 = A11×(B12-B22)
M4 = A22×(B21-B11)
M5 = (A11+A12)×B22
M6 = (A21-A11)×(B11+B12)
M7 = (A12-A22)×(B21+B22)

C11 = M1+M4-M5+M7
C12 = M3+M5
C21 = M2+M4
C22 = M1-M2+M3+M6
```

**时间复杂度**：O(n^{log₂7}) ≈ O(n²·⁸⁰⁷)

## 二、最近点对问题（Closest Pair Problem）

### 1. 问题描述
给定平面上n个点，找出距离最近的两个点。

### 2. 分治法求解

**步骤**：
1. 按x坐标排序所有点
2. 递归求解左半部分和右半部分的最近点对
3. 合并：检查跨越中线的点对

```python
import math

def closest_pair(points):
    if len(points) <= 3:
        return brute_force(points)
    
    mid = len(points) // 2
    left_points = points[:mid]
    right_points = points[mid:]
    
    d1 = closest_pair(left_points)
    d2 = closest_pair(right_points)
    d = min(d1, d2)
    
    strip = [p for p in points if abs(p[0] - points[mid][0]) < d]
    strip.sort(key=lambda p: p[1])
    
    for i in range(len(strip)):
        for j in range(i+1, min(i+7, len(strip))):
            dist = math.hypot(strip[i][0]-strip[j][0], strip[i][1]-strip[j][1])
            d = min(d, dist)
    
    return d

def brute_force(points):
    min_dist = float('inf')
    for i in range(len(points)):
        for j in range(i+1, len(points)):
            dist = math.hypot(points[i][0]-points[j][0], points[i][1]-points[j][1])
            min_dist = min(min_dist, dist)
    return min_dist
```

**时间复杂度**：O(nlogn)

## 三、大整数乘法

### 1. 问题描述
计算两个大整数的乘积。

### 2. 分治法求解

**思想**：将大整数分成高位和低位两部分。

```
设X = X₁·2ⁿ/² + X₀，Y = Y₁·2ⁿ/² + Y₀
XY = X₁Y₁·2ⁿ + (X₁Y₀ + X₀Y₁)·2ⁿ/² + X₀Y₀

优化：
XY = X₁Y₁·2ⁿ + [(X₁+X₀)(Y₁+Y₀) - X₁Y₁ - X₀Y₀]·2ⁿ/² + X₀Y₀
只需3次乘法
```

**时间复杂度**：O(n^{log₂3}) ≈ O(n¹·⁵⁸⁵)

## 四、分治法应用总结

| 问题 | 普通算法复杂度 | 分治法复杂度 | 优化原理 |
|-----|-------------|------------|---------|
| **矩阵乘法** | O(n³) | O(n²·⁸⁰⁷) | 减少乘法次数 |
| **最近点对** | O(n²) | O(nlogn) | 分治+剪枝 |
| **大整数乘法** | O(n²) | O(n¹·⁵⁸⁵) | 减少乘法次数 |
