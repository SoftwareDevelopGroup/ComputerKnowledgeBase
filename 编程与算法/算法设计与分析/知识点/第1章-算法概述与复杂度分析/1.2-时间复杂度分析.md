# 1.2 时间复杂度分析

> [!abstract] 核心问题
> 如何度量算法的运行时间？渐近表示法有哪些？如何分析不同类型算法的时间复杂度？

## 一、时间复杂度的定义

**时间复杂度（Time Complexity）**是算法运行时间随输入规模增长的变化趋势。

## 二、渐近表示法

### 1. 大O表示法（O）

```
O(g(n)) = { f(n) | 存在正常数c和n₀，使得对所有n ≥ n₀，有0 ≤ f(n) ≤ c·g(n) }
```

**含义**：f(n)的增长速度不超过g(n)，表示**上界**。

### 2. 大Ω表示法（Ω）

```
Ω(g(n)) = { f(n) | 存在正常数c和n₀，使得对所有n ≥ n₀，有0 ≤ c·g(n) ≤ f(n) }
```

**含义**：f(n)的增长速度至少是g(n)，表示**下界**。

### 3. 大Θ表示法（Θ）

```
Θ(g(n)) = { f(n) | 存在正常数c₁、c₂和n₀，使得对所有n ≥ n₀，有c₁·g(n) ≤ f(n) ≤ c₂·g(n) }
```

**含义**：f(n)的增长速度与g(n)相同，表示**精确界**。

### 4. 小o表示法（o）

```
o(g(n)) = { f(n) | 对任意正常数c，存在n₀，使得对所有n ≥ n₀，有0 ≤ f(n) < c·g(n) }
```

**含义**：f(n)的增长速度严格小于g(n)。

### 5. 小ω表示法（ω）

```
ω(g(n)) = { f(n) | 对任意正常数c，存在n₀，使得对所有n ≥ n₀，有0 ≤ c·g(n) < f(n) }
```

**含义**：f(n)的增长速度严格大于g(n)。

## 三、常见时间复杂度排序

```
O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

| 复杂度 | 名称 | 典型算法 |
|-------|------|---------|
| O(1) | 常数时间 | 数组访问 |
| O(logn) | 对数时间 | 二分查找 |
| O(n) | 线性时间 | 顺序查找 |
| O(nlogn) | 线性对数时间 | 归并排序、快速排序 |
| O(n²) | 平方时间 | 冒泡排序、选择排序 |
| O(2ⁿ) | 指数时间 | 子集枚举 |

## 四、时间复杂度分析方法

### 1. 循环次数分析法

```python
# 示例：线性搜索
def linear_search(arr, target):
    for i in range(len(arr)):      # O(n)
        if arr[i] == target:       # O(1)
            return i               # O(1)
    return -1                      # O(1)
# 总复杂度：O(n)
```

### 2. 递归分析法

```python
# 示例：阶乘递归
def factorial(n):
    if n == 0:
        return 1              # O(1)
    return n * factorial(n-1) # O(1) + T(n-1)
# T(n) = T(n-1) + O(1)
# 解：T(n) = O(n)
```

## 五、空间复杂度

**空间复杂度（Space Complexity）**是算法运行所需存储空间随输入规模增长的变化趋势。

```python
# 示例：递归求阶乘的空间复杂度
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n-1)
# 递归栈深度为n，空间复杂度：O(n)
```

## 六、示例：时间复杂度分析

```python
def example(n):
    sum = 0                    # O(1)
    for i in range(n):         # O(n)
        for j in range(i, n):  # O(n-i) ≈ O(n)
            sum += i * j       # O(1)
    return sum
# 总复杂度：O(n²)
```
