# 1.3 递推方程求解

> [!abstract] 核心问题
> 什么是递推方程？如何求解递推方程？主定理的适用条件是什么？

## 一、递推方程的定义

**递推方程（Recurrence Relation）**是用自身较小规模的解来表示大规模解的方程。

## 二、递推方程的求解方法

### 1. 代入法（Substitution Method）

**步骤**：
1. 猜测解的形式
2. 用数学归纳法验证

```
示例：T(n) = 2T(n/2) + n
猜测：T(n) = O(nlogn)
验证：假设T(k) ≤ cklogk，对所有k < n
T(n) = 2T(n/2) + n ≤ 2·c(n/2)log(n/2) + n
     = cn(logn - 1) + n = cnlogn - cn + n
     ≤ cnlogn（当c ≥ 1时）
```

### 2. 递归树法（Recursion Tree Method）

**步骤**：
1. 展开递归树
2. 计算每层的代价
3. 求和

```
示例：T(n) = T(n/3) + T(2n/3) + n

          n
       /     \
    n/3     2n/3
   /  \    /    \
n/9 2n/9 2n/9 4n/9
...

每层代价：n
层数：log_{3/2}n
总代价：O(nlogn)
```

### 3. 主定理（Master Theorem）

**定理**：设a ≥ 1，b > 1是常数，f(n)是正函数，T(n) = aT(n/b) + f(n)，则：

1. **若f(n) = O(n^{log_b a - ε})**（ε > 0），则T(n) = Θ(n^{log_b a})
2. **若f(n) = Θ(n^{log_b a})**，则T(n) = Θ(n^{log_b a} logn)
3. **若f(n) = Ω(n^{log_b a + ε})**（ε > 0），且af(n/b) ≤ cf(n)（c < 1），则T(n) = Θ(f(n))

> [!warning] 易错点
> 主定理的第三项需要满足正则条件：af(n/b) ≤ cf(n)，否则不能直接应用。

### 4. 特征方程法

适用于线性齐次递推方程。

```
示例：T(n) = 2T(n-1) + 3T(n-2)
特征方程：r² - 2r - 3 = 0
解：r = 3 或 r = -1
通解：T(n) = A·3ⁿ + B·(-1)ⁿ
```

## 三、主定理应用示例

| 递推方程 | log_b a | f(n) | 情况 | 解 |
|---------|---------|------|-----|------|
| T(n) = 2T(n/2) + n | 1 | n | 情况2 | Θ(nlogn) |
| T(n) = 4T(n/2) + n | 2 | n | 情况1 | Θ(n²) |
| T(n) = T(n/2) + n | 0 | n | 情况3 | Θ(n) |
| T(n) = 2T(n/2) + n² | 1 | n² | 情况3 | Θ(n²) |

## 四、常见递推方程及其解

| 递推方程 | 解 | 典型算法 |
|---------|------|---------|
| T(n) = T(n-1) + O(1) | Θ(n) | 线性搜索 |
| T(n) = T(n-1) + O(n) | Θ(n²) | 冒泡排序 |
| T(n) = 2T(n/2) + O(n) | Θ(nlogn) | 归并排序 |
| T(n) = 2T(n/2) + O(1) | Θ(n) | 二分查找递归版 |
| T(n) = T(n/2) + O(1) | Θ(logn) | 二分查找迭代版 |

## 五、示例：快速排序的复杂度分析

```python
def quicksort(arr, low, high):
    if low < high:
        pivot = partition(arr, low, high)  # O(n)
        quicksort(arr, low, pivot-1)       # T(k)
        quicksort(arr, pivot+1, high)      # T(n-k-1)
```

**最好情况**：每次划分均匀，T(n) = 2T(n/2) + O(n) = Θ(nlogn)

**最坏情况**：每次划分极不均匀，T(n) = T(n-1) + O(n) = Θ(n²)

**平均情况**：T(n) = Θ(nlogn)
