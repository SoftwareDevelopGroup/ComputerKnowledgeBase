# 3.2 经典动态规划问题

> [!abstract] 核心问题
> 最长公共子序列、矩阵连乘、背包问题的动态规划解法是什么？状态转移方程如何建立？

## 一、最长公共子序列（LCS）

### 1. 问题描述
给定两个序列X和Y，找出它们的最长公共子序列。

### 2. 状态定义
dp[i][j]表示X[0..i-1]和Y[0..j-1]的最长公共子序列长度。

### 3. 状态转移方程

```
if X[i-1] == Y[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

### 4. 实现

```python
def lcs_length(X, Y):
    m, n = len(X), len(Y)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if X[i-1] == Y[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    
    return dp[m][n]
```

### 5. 复杂度分析
- **时间复杂度**：O(mn)
- **空间复杂度**：O(mn)

## 二、矩阵连乘问题

### 1. 问题描述
给定n个矩阵A₁×A₂×…×Aₙ，确定最优括号化方式，使得乘法次数最少。

### 2. 状态定义
dp[i][j]表示矩阵Aᵢ到Aⱼ相乘的最少乘法次数。

### 3. 状态转移方程

```
dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1]×p[k]×p[j])
其中i ≤ k < j
```

### 4. 实现

```python
def matrix_chain_order(p):
    n = len(p) - 1
    dp = [[0] * n for _ in range(n)]
    
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            for k in range(i, j):
                cost = dp[i][k] + dp[k+1][j] + p[i] * p[k+1] * p[j+1]
                if cost < dp[i][j]:
                    dp[i][j] = cost
    
    return dp[0][n-1]
```

### 5. 复杂度分析
- **时间复杂度**：O(n³)
- **空间复杂度**：O(n²)

## 三、背包问题

### 1. 0-1背包问题

**问题描述**：给定n个物品，每个物品有重量wᵢ和价值vᵢ，背包容量为C，求最大价值。

**状态定义**：dp[i][j]表示前i个物品，容量为j时的最大价值。

**状态转移方程**：
```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])  # 选或不选第i个物品
```

**实现**：
```python
def knapsack_01(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for j in range(1, capacity + 1):
            if j >= weights[i-1]:
                dp[i][j] = max(dp[i-1][j], dp[i-1][j-weights[i-1]] + values[i-1])
            else:
                dp[i][j] = dp[i-1][j]
    
    return dp[n][capacity]
```

### 2. 完全背包问题

**问题描述**：每个物品可以选多次。

**状态转移方程**：
```
dp[i][j] = max(dp[i-1][j], dp[i][j-w[i]] + v[i])  # 注意与0-1背包的区别
```

**实现**：
```python
def knapsack_unbounded(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)
    
    for j in range(1, capacity + 1):
        for i in range(n):
            if j >= weights[i]:
                dp[j] = max(dp[j], dp[j-weights[i]] + values[i])
    
    return dp[capacity]
```

## 四、三种问题对比

| 问题 | 状态定义 | 转移方程 | 时间复杂度 |
|-----|---------|---------|-----------|
| **LCS** | dp[i][j]表示X[0..i]和Y[0..j]的LCS长度 | 根据字符是否相等 | O(mn) |
| **矩阵连乘** | dp[i][j]表示Aᵢ到Aⱼ的最小乘法次数 | 枚举分割点 | O(n³) |
| **0-1背包** | dp[i][j]表示前i个物品容量j的最大价值 | 选或不选 | O(nC) |
