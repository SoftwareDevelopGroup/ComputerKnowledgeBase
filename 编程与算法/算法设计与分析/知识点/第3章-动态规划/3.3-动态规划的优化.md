# 3.3 动态规划的优化

> [!abstract] 核心问题
> 动态规划如何进行空间优化？常见的优化技巧有哪些？

## 一、滚动数组优化

### 1. 原理
当状态转移只依赖于前一行或前几行时，可以用一维数组代替二维数组。

### 2. 示例：0-1背包

**原始二维数组**：
```python
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
```

**优化为一维数组**：
```python
for i in range(n):
    for j in range(capacity, weights[i]-1, -1):
        dp[j] = max(dp[j], dp[j-weights[i]] + values[i])
```

> [!warning] 注意
> 0-1背包必须逆序遍历容量，防止同一个物品被多次选取。

### 3. 示例：最长公共子序列

**原始二维数组**：
```python
dp[i][j] = max(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]+1)
```

**优化为一维数组**：
```python
prev = 0
for i in range(m):
    for j in range(n):
        temp = dp[j]
        if X[i] == Y[j]:
            dp[j] = prev + 1
        else:
            dp[j] = max(dp[j], dp[j-1])
        prev = temp
```

## 二、状态压缩

### 1. 原理
当状态只有有限种可能时，可以用位运算或状态编码来压缩空间。

### 2. 示例：状态压缩DP

```python
# 用二进制表示状态
# dp[mask]表示状态为mask时的最优解
def state_compression_dp(n):
    dp = [0] * (1 << n)
    for mask in range(1, 1 << n):
        # 计算状态mask的最优解
        for i in range(n):
            if mask & (1 << i):
                dp[mask] = max(dp[mask], dp[mask ^ (1 << i)] + value[i])
    return dp[(1 << n) - 1]
```

## 三、单调队列优化

### 1. 原理
当状态转移方程可以表示为滑动窗口的最值问题时，使用单调队列优化。

### 2. 示例：滑动窗口最大值

```python
from collections import deque

def sliding_window_max(nums, k):
    q = deque()
    result = []
    for i in range(len(nums)):
        while q and nums[i] >= nums[q[-1]]:
            q.pop()
        q.append(i)
        while q[0] <= i - k:
            q.popleft()
        if i >= k - 1:
            result.append(nums[q[0]])
    return result
```

## 四、斜率优化

### 1. 原理
当状态转移方程可以转化为线性函数形式时，使用斜率优化。

### 2. 适用条件
状态转移方程形如：
```
dp[i] = min(dp[j] + a[i] * b[j])
```

### 3. 示例

```python
def slope_optimization():
    dp = [0] * n
    # 维护一个凸包/单调队列
    for i in range(n):
        # 在凸包上二分查找最优决策点
        j = find_best(i)
        dp[i] = dp[j] + cost(i, j)
        # 将i加入凸包
        add_to_hull(i)
    return dp[n-1]
```

## 五、优化技巧总结

| 优化技巧 | 适用场景 | 空间复杂度优化 |
|---------|---------|--------------|
| **滚动数组** | 状态只依赖前几行 | O(n) → O(1)或O(n) |
| **状态压缩** | 状态有限且可编码 | 指数级 → 线性级 |
| **单调队列** | 滑动窗口最值问题 | O(n) → O(n) |
| **斜率优化** | 线性函数形式的转移 | O(n²) → O(n) |

## 六、示例：空间优化对比

### 0-1背包空间优化

**优化前**（二维数组，O(nC)空间）：
```python
dp = [[0] * (C+1) for _ in range(n+1)]
```

**优化后**（一维数组，O(C)空间）：
```python
dp = [0] * (C+1)
```

### 完全背包空间优化

**优化前**（二维数组）：
```python
dp = [[0] * (C+1) for _ in range(n+1)]
```

**优化后**（一维数组，顺序遍历）：
```python
dp = [0] * (C+1)
for j in range(C+1):
    for i in range(n):
        if j >= w[i]:
            dp[j] = max(dp[j], dp[j-w[i]] + v[i])
```
