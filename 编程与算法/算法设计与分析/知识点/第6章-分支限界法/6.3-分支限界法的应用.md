# 6.3 分支限界法的应用

> [!abstract] 核心问题
> 旅行商问题、0-1背包问题、最大团问题的分支限界解法是什么？

## 一、旅行商问题（TSP）

### 1. 问题描述
给定n个城市和两两之间的距离，求经过所有城市一次且回到起点的最短路径。

### 2. 解空间
排列树，城市的排列。

### 3. 限界函数
当前路径长度 + 剩余城市的最小生成树代价。

### 4. 实现

```python
import heapq

class TSPSolution:
    def __init__(self, path, cost):
        self.path = path
        self.cost = cost
    
    def __lt__(self, other):
        return self.cost > other.cost

def tsp_branch_bound(graph):
    n = len(graph)
    INF = float('inf')
    
    def bound(path):
        current_cost = sum(graph[path[i]][path[i+1]] for i in range(len(path)-1))
        remaining = set(range(n)) - set(path)
        
        if not remaining:
            return current_cost + graph[path[-1]][path[0]]
        
        min_edge = INF
        for i in path:
            for j in remaining:
                min_edge = min(min_edge, graph[i][j])
        
        return current_cost + min_edge * len(remaining)
    
    heap = []
    heapq.heappush(heap, TSPSolution([0], 0))
    best_cost = INF
    best_path = []
    
    while heap:
        node = heapq.heappop(heap)
        
        if len(node.path) == n:
            total_cost = node.cost + graph[node.path[-1]][node.path[0]]
            if total_cost < best_cost:
                best_cost = total_cost
                best_path = node.path + [node.path[0]]
            continue
        
        if node.cost >= best_cost:
            continue
        
        for city in range(n):
            if city not in node.path:
                new_path = node.path + [city]
                new_cost = node.cost + graph[node.path[-1]][city]
                if new_cost < best_cost:
                    heapq.heappush(heap, TSPSolution(new_path, new_cost))
    
    return best_cost, best_path
```

### 5. 复杂度分析
- **时间复杂度**：O(n²·2ⁿ)
- **空间复杂度**：O(n)

## 二、0-1背包问题

### 1. 问题描述
给定n个物品，每个物品有重量wᵢ和价值vᵢ，背包容量为C，求最大价值。

### 2. 解空间
子集树，每个物品选或不选。

### 3. 限界函数
当前价值 + 剩余物品的最大价值估计。

### 4. 实现
见[[6.2-分支限界法的实现.md]]中的优先队列式分支限界。

### 5. 复杂度分析
- **时间复杂度**：O(n·2ⁿ)
- **空间复杂度**：O(n)

## 三、最大团问题

### 1. 问题描述
给定无向图，找到最大的完全子图（团）。

### 2. 解空间
子集树，顶点的子集。

### 3. 限界函数
当前团大小 + 剩余顶点中可能加入团的顶点数。

### 4. 实现

```python
import heapq

class CliqueSolution:
    def __init__(self, clique, candidates):
        self.clique = clique
        self.candidates = candidates
    
    def __lt__(self, other):
        return len(self.clique) + len(self.candidates) < len(other.clique) + len(other.candidates)

def max_clique(graph):
    n = len(graph)
    max_size = 0
    max_clique_set = []
    
    heap = []
    all_nodes = set(range(n))
    heapq.heappush(heap, CliqueSolution([], all_nodes))
    
    while heap:
        node = heapq.heappop(heap)
        
        if len(node.clique) > max_size:
            max_size = len(node.clique)
            max_clique_set = node.clique.copy()
        
        if len(node.clique) + len(node.candidates) <= max_size:
            continue
        
        for v in list(node.candidates):
            new_clique = node.clique + [v]
            new_candidates = node.candidates & set(i for i in range(n) if graph[v][i] == 1)
            heapq.heappush(heap, CliqueSolution(new_clique, new_candidates))
            node.candidates.remove(v)
    
    return max_clique_set
```

### 5. 复杂度分析
- **时间复杂度**：O(2ⁿ)
- **空间复杂度**：O(n)

## 四、三种问题对比

| 问题 | 解空间类型 | 限界函数 | 时间复杂度 |
|-----|----------|---------|-----------|
| **TSP问题** | 排列树 | 当前路径+剩余城市最小生成树 | O(n²·2ⁿ) |
| **0-1背包** | 子集树 | 当前价值+剩余物品最大价值 | O(n·2ⁿ) |
| **最大团** | 子集树 | 当前团大小+剩余候选顶点数 | O(2ⁿ) |
