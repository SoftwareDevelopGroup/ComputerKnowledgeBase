# 6.2 分支限界法的实现

> [!abstract] 核心问题
> 队列式分支限界和优先队列式分支限界如何实现？两者有什么区别？

## 一、队列式分支限界（FIFO）

### 1. 基本思想
使用普通队列，按照先进先出的顺序处理节点。

### 2. 实现框架

```python
from collections import deque

class Node:
    def __init__(self, level, profit, weight, items):
        self.level = level
        self.profit = profit
        self.weight = weight
        self.items = items
    
def fifo_branch_bound(weights, values, capacity):
    n = len(weights)
    queue = deque()
    queue.append(Node(-1, 0, 0, []))
    max_profit = 0
    best_items = []
    
    while queue:
        node = queue.popleft()
        
        if node.level == n - 1:
            if node.profit > max_profit:
                max_profit = node.profit
                best_items = node.items.copy()
            continue
        
        # 不选当前物品
        queue.append(Node(node.level + 1, node.profit, node.weight, node.items.copy()))
        
        # 选当前物品
        next_weight = node.weight + weights[node.level + 1]
        if next_weight <= capacity:
            next_profit = node.profit + values[node.level + 1]
            new_items = node.items.copy()
            new_items.append(node.level + 1)
            queue.append(Node(node.level + 1, next_profit, next_weight, new_items))
    
    return max_profit, best_items
```

### 3. 特点
- 实现简单
- 可能搜索大量无效节点
- 适合解空间较小的问题

## 二、优先队列式分支限界（LC）

### 1. 基本思想
使用优先队列，按照优先级（通常是限界函数值）处理节点。

### 2. 实现框架

```python
import heapq

class Node:
    def __init__(self, level, profit, weight, items):
        self.level = level
        self.profit = profit
        self.weight = weight
        self.items = items
    
    def __lt__(self, other):
        return self.bound < other.bound

def bound(node, weights, values, capacity):
    if node.weight >= capacity:
        return 0
    n = len(weights)
    bound_value = node.profit
    remaining_weight = capacity - node.weight
    j = node.level + 1
    
    while j < n and weights[j] <= remaining_weight:
        remaining_weight -= weights[j]
        bound_value += values[j]
        j += 1
    
    if j < n:
        bound_value += (remaining_weight / weights[j]) * values[j]
    
    return bound_value

def lc_branch_bound(weights, values, capacity):
    n = len(weights)
    # 按价值密度排序
    items = sorted(range(n), key=lambda i: values[i]/weights[i], reverse=True)
    sorted_weights = [weights[i] for i in items]
    sorted_values = [values[i] for i in items]
    
    heap = []
    root = Node(-1, 0, 0, [])
    root.bound = bound(root, sorted_weights, sorted_values, capacity)
    heapq.heappush(heap, root)
    
    max_profit = 0
    best_items = []
    
    while heap:
        node = heapq.heappop(heap)
        
        if node.bound <= max_profit:
            continue
        
        if node.level == n - 1:
            if node.profit > max_profit:
                max_profit = node.profit
                best_items = [items[i] for i in node.items]
            continue
        
        # 选当前物品
        next_level = node.level + 1
        next_weight = node.weight + sorted_weights[next_level]
        if next_weight <= capacity:
            next_profit = node.profit + sorted_values[next_level]
            new_items = node.items.copy()
            new_items.append(next_level)
            child = Node(next_level, next_profit, next_weight, new_items)
            child.bound = bound(child, sorted_weights, sorted_values, capacity)
            if child.bound > max_profit:
                heapq.heappush(heap, child)
        
        # 不选当前物品
        child = Node(next_level, node.profit, node.weight, node.items.copy())
        child.bound = bound(child, sorted_weights, sorted_values, capacity)
        if child.bound > max_profit:
            heapq.heappush(heap, child)
    
    return max_profit, best_items
```

### 3. 特点
- 优先搜索有希望的分支
- 通常比队列式效率高
- 需要设计限界函数

## 三、两种实现方式对比

| 对比项 | 队列式分支限界 | 优先队列式分支限界 |
|-------|------------|-----------------|
| **数据结构** | 普通队列 | 优先队列 |
| **处理顺序** | 先进先出 | 按优先级 |
| **限界函数** | 可选 | 必须 |
| **效率** | 较低 | 较高 |
| **实现复杂度** | 简单 | 较复杂 |

## 四、实现注意事项

### 1. 节点表示
定义合适的节点类，包含必要的信息。

### 2. 限界函数设计
限界函数的质量直接影响算法效率。

### 3. 剪枝条件
当节点的限界值不超过当前最优解时，剪去该分支。

### 4. 解的记录
在搜索过程中记录最优解。
