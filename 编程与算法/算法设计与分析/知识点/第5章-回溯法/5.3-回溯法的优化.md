# 5.3 回溯法的优化

> [!abstract] 核心问题
> 回溯法如何进行优化？常见的优化技巧有哪些？

## 一、约束函数优化

### 1. 提前检查约束条件
在选择之前就检查是否满足约束条件。

> [!example] 示例
> n皇后问题中，在放置皇后之前就检查该位置是否安全。

### 2. 利用对称性剪枝
如果问题具有对称性，可以只搜索一部分解空间。

> [!example] 示例
> n皇后问题中，第一行只搜索前n/2个位置，利用对称性得到另一半解。

## 二、限界函数优化

### 1. 上界估计
估计当前部分解能达到的最优值，如果小于当前最优解则剪枝。

> [!example] 示例
> 0-1背包问题中，估计剩余物品的最大价值，如果加上当前价值小于当前最优解则剪枝。

### 2. 下界估计
估计当前部分解能达到的最小值，如果大于当前最优解则剪枝。

> [!example] 示例
> TSP问题中，估计剩余路径的最小长度，如果加上当前路径长度大于当前最优解则剪枝。

## 三、排序优化

### 1. 对候选元素排序
将候选元素按某种顺序排序，优先搜索更可能得到最优解的分支。

> [!example] 示例
> 0-1背包问题中，将物品按价值密度从高到低排序，优先选择价值密度高的物品。

### 2. 对搜索顺序优化
选择合适的搜索顺序，减少无效搜索。

> [!example] 示例
> 图着色问题中，选择约束最强的顶点（度数最大的顶点）优先着色。

## 四、状态压缩优化

### 1. 用位运算表示状态
使用位运算可以高效地表示和检查状态。

> [!example] 示例
> n皇后问题中，用位运算表示列和对角线的占用情况。

```python
def n_queens_bitmask(n):
    result = 0
    
    def backtrack(cols, diag1, diag2):
        nonlocal result
        if cols == (1 << n) - 1:
            result += 1
            return
        
        available = ~(cols | diag1 | diag2) & ((1 << n) - 1)
        while available:
            pos = available & -available
            available -= pos
            backtrack(cols | pos, (diag1 | pos) << 1, (diag2 | pos) >> 1)
    
    backtrack(0, 0, 0)
    return result
```

### 2. 记忆化搜索
保存已计算的状态，避免重复搜索。

> [!example] 示例
> 子集和问题中，用记忆化保存已经计算过的状态。

## 五、分支定界优化

### 1. 优先搜索有希望的分支
使用优先队列，优先搜索可能得到最优解的分支。

> [!example] 示例
> TSP问题中，使用优先队列，优先搜索当前路径最短的分支。

### 2. 动态更新上下界
在搜索过程中动态更新上下界，提高剪枝效率。

> [!example] 示例
> 0-1背包问题中，每次选择后更新剩余物品的最大价值。

## 六、优化技巧总结

| 优化技巧 | 原理 | 适用场景 |
|---------|------|---------|
| **约束函数** | 提前检查约束条件 | 所有回溯问题 |
| **限界函数** | 估计最优值范围 | 优化问题 |
| **排序优化** | 优先搜索有希望的分支 | 组合优化问题 |
| **状态压缩** | 高效表示状态 | 状态空间较小的问题 |
| **分支定界** | 优先队列搜索 | 最优解问题 |
