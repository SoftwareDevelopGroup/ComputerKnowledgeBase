# 5.2 经典回溯问题

> [!abstract] 核心问题
> n皇后问题、子集和问题、图着色问题的回溯解法是什么？如何进行剪枝？

## 一、n皇后问题

### 1. 问题描述
在n×n的棋盘上放置n个皇后，使得任意两个皇后不在同一行、同一列、同一条对角线上。

### 2. 解空间
排列树，每个皇后在不同行，列的排列。

### 3. 约束函数
新放置的皇后与已放置的皇后不在同一列、同一对角线。

### 4. 实现

```python
def n_queens(n):
    result = []
    board = [-1] * n
    
    def is_safe(row, col):
        for prev_row in range(row):
            prev_col = board[prev_row]
            if prev_col == col or abs(row - prev_row) == abs(col - prev_col):
                return False
        return True
    
    def backtrack(row):
        if row == n:
            result.append(board.copy())
            return
        for col in range(n):
            if is_safe(row, col):
                board[row] = col
                backtrack(row + 1)
                board[row] = -1
    
    backtrack(0)
    return result
```

### 5. 复杂度分析
- **时间复杂度**：O(n!)
- **空间复杂度**：O(n)

## 二、子集和问题

### 1. 问题描述
给定n个整数和目标和S，判断是否存在子集和等于S。

### 2. 解空间
子集树，每个元素选或不选。

### 3. 约束函数
当前和不超过目标和。

### 4. 限界函数
剩余元素和+当前和 < 目标和时剪枝。

### 5. 实现

```python
def subset_sum(nums, target):
    result = []
    
    def backtrack(start, current_sum, path):
        if current_sum == target:
            result.append(path.copy())
            return
        if current_sum > target:
            return
        
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, current_sum + nums[i], path)
            path.pop()
    
    backtrack(0, 0, [])
    return result
```

### 6. 复杂度分析
- **时间复杂度**：O(2ⁿ)
- **空间复杂度**：O(n)

## 三、图着色问题

### 1. 问题描述
用k种颜色给图的顶点着色，使得相邻顶点颜色不同。

### 2. 解空间
每个顶点选择一种颜色。

### 3. 约束函数
新着色顶点与相邻顶点颜色不同。

### 4. 实现

```python
def graph_coloring(graph, k):
    n = len(graph)
    colors = [-1] * n
    
    def is_safe(node, color):
        for neighbor in range(n):
            if graph[node][neighbor] == 1 and colors[neighbor] == color:
                return False
        return True
    
    def backtrack(node):
        if node == n:
            return True
        for color in range(k):
            if is_safe(node, color):
                colors[node] = color
                if backtrack(node + 1):
                    return True
                colors[node] = -1
        return False
    
    if backtrack(0):
        return colors
    return None
```

### 5. 复杂度分析
- **时间复杂度**：O(kⁿ)
- **空间复杂度**：O(n)

## 四、三种问题对比

| 问题 | 解空间类型 | 约束函数 | 时间复杂度 |
|-----|----------|---------|-----------|
| **n皇后问题** | 排列树 | 不在同行同列同对角线 | O(n!) |
| **子集和问题** | 子集树 | 当前和不超过目标 | O(2ⁿ) |
| **图着色问题** | 多重选择树 | 相邻顶点颜色不同 | O(kⁿ) |
