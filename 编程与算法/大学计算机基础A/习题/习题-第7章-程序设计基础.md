### 简答题答案

1. 算法是解决问题的步骤集合。基本特征：有穷性（步骤有限）、确定性（步骤明确）、可行性（步骤可执行）、输入（零个或多个）、输出（至少一个）。

2. 结构化程序设计是采用顺序、选择、循环三种基本结构的编程方法。三种结构：顺序结构（按顺序执行）、选择结构（根据条件选择执行）、循环结构（重复执行）。

3. 数组是相同类型数据元素的有序集合。特点：元素类型相同、连续存储、通过下标访问、长度固定。

4. 函数是完成特定功能的代码块。作用：代码复用、模块化、便于维护和调试。

5. 面向对象编程是以对象为中心的编程方法。三大特性：封装（数据和方法捆绑）、继承（复用已有类）、多态（同一接口多种实现）。

### 综合应用题答案

**题1答案**：
(1) 自然语言：初始化和为0，循环1到100累加，输出结果。
(2) 流程图：开始→sum=0→i=1→i≤100?→是→sum=sum+i→i=i+1→循环→否→输出sum→结束。
(3) 伪代码：sum = 0; for i = 1 to 100: sum = sum + i; print sum;

**题2答案**：
```python
n = int(input("请输入一个整数："))
is_prime = True
for i in range(2, n):
    if n % i == 0:
        is_prime = False
        break
print(f"{n}是素数" if is_prime else f"{n}不是素数")
```

**题3答案**：
```python
arr = []
for i in range(10):
    arr.append(int(input(f"请输入第{i+1}个整数：")))
max_val = max(arr)
min_val = min(arr)
avg_val = sum(arr) / len(arr)
print(f"最大值：{max_val}，最小值：{min_val}，平均值：{avg_val}")
```

**题4答案**：
```python
class Student:
    def __init__(self, id, name, age):
        self.id = id
        self.name = name
        self.age = age
    
    def display(self):
        print(f"学号：{self.id}，姓名：{self.name}，年龄：{self.age}")
    
    def update_age(self, new_age):
        self.age = new_age
```
