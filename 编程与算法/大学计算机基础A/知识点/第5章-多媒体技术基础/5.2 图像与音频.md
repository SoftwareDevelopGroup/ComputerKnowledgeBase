# 5.2 图像与音频

> [!abstract] 核心问题
> 图像和音频如何数字化？常见的格式和压缩技术有哪些？

## 一、图像数字化

### 1. 图像表示

**数字图像**由像素（Pixel）组成：

| 概念 | 说明 |
|-----|------|
| **像素** | 图像的最小单位 |
| **分辨率** | 图像的像素数量（宽×高） |
| **颜色深度** | 每个像素的颜色位数 |

### 2. 色彩模型

| 模型 | 说明 | 应用 |
|-----|------|-----|
| **RGB** | 红、绿、蓝三原色 | 显示器、数码相机 |
| **CMYK** | 青、品红、黄、黑 | 印刷 |
| **HSV** | 色相、饱和度、明度 | 图像编辑 |
| **YUV** | 亮度和色度分离 | 视频压缩 |

### 3. 图像分辨率

| 类型 | 说明 | 示例 |
|-----|------|-----|
| **屏幕分辨率** | 显示器的像素数量 | 1920×1080（Full HD） |
| **图像分辨率** | 图像的像素数量 | 3000×2000 |
| **打印分辨率** | 每英寸像素数（PPI） | 300 PPI |

### 4. 图像文件大小计算

**计算公式**：文件大小 = 分辨率 × 颜色深度 / 8

**示例**：
- 分辨率：1920×1080
- 颜色深度：24位（RGB）
- 文件大小 = 1920 × 1080 × 24 / 8 = 6,220,800字节 ≈ 5.93 MB

## 二、图像格式

### 1. 位图格式

| 格式 | 特点 | 应用 |
|-----|------|-----|
| **BMP** | 无损压缩，文件大 | Windows系统 |
| **PNG** | 无损压缩，支持透明 | 网页、图标 |
| **JPEG** | 有损压缩，文件小 | 照片、网页 |
| **GIF** | 支持动画，最多256色 | 简单动画 |
| **WebP** | 高效压缩，支持透明和动画 | 现代网页 |

### 2. 矢量格式

| 格式 | 特点 | 应用 |
|-----|------|-----|
| **SVG** | 可缩放，文件小 | 网页、图标 |
| **AI** | Adobe格式，功能强大 | 专业设计 |
| **EPS** | 印刷标准格式 | 印刷出版 |

### 3. 格式选择指南

| 场景 | 推荐格式 |
|-----|---------|
| **照片** | JPEG、WebP |
| **图标/Logo** | PNG、SVG |
| **简单动画** | GIF、WebP |
| **专业设计** | AI、EPS |

## 三、图像压缩

### 1. 压缩原理

**压缩**是减少文件大小的技术：

| 类型 | 说明 |
|-----|------|
| **无损压缩** | 压缩后可完全恢复原始数据 |
| **有损压缩** | 压缩后损失部分数据，但视觉效果变化不大 |

### 2. 无损压缩技术

| 技术 | 说明 |
|-----|------|
| **行程长度编码（RLE）** | 压缩连续相同的像素 |
| **LZW编码** | 字典压缩算法 |
| **DEFLATE** | LZ77 + Huffman编码 |

### 3. 有损压缩技术

**JPEG压缩原理**：
1. 将RGB转换为YUV色彩空间
2. 分块处理（8×8像素）
3. 离散余弦变换（DCT）
4. 量化（丢弃不重要的频率）
5. Zigzag扫描和熵编码

**JPEG压缩质量**：
- 高质量：压缩率低，文件大，画质好
- 低质量：压缩率高，文件小，画质差

### 4. 压缩格式对比

| 格式 | 压缩类型 | 压缩率 | 画质 |
|-----|---------|-------|------|
| **BMP** | 无 | 1 | 无损 |
| **PNG** | 无损 | 2-4倍 | 无损 |
| **JPEG** | 有损 | 10-50倍 | 良好 |
| **WebP** | 无损/有损 | 比JPEG高25% | 良好 |

## 四、音频数字化

### 1. 音频表示

**数字音频**由采样点组成：

| 概念 | 说明 |
|-----|------|
| **采样率** | 每秒采样的次数 |
| **采样精度** | 每个采样点的位数 |
| **声道数** | 单声道、立体声、环绕声 |

### 2. 采样率

| 采样率 | 说明 | 应用 |
|-----|------|-----|
| **8 kHz** | 电话音质 | 语音 |
| **11.025 kHz** | 低质量音频 | 早期音频 |
| **22.05 kHz** | FM广播音质 | 语音、简单音乐 |
| **44.1 kHz** | CD音质 | 音乐 |
| **48 kHz** | 专业音质 | 视频、专业音频 |
| **96 kHz** | 高分辨率 | 录音棚 |

### 3. 采样精度

| 精度 | 说明 | 动态范围 |
|-----|------|---------|
| **8位** | 256个级别 | 约48 dB |
| **16位** | 65536个级别 | 约96 dB |
| **24位** | 16777216个级别 | 约144 dB |

### 4. 音频文件大小计算

**计算公式**：文件大小 = 采样率 × 采样精度 × 声道数 × 时间 / 8

**示例**：
- 采样率：44.1 kHz
- 采样精度：16位
- 声道数：2（立体声）
- 时间：1分钟 = 60秒
- 文件大小 = 44100 × 16 × 2 × 60 / 8 = 105,840,000字节 ≈ 100.9 MB

## 五、音频格式

### 1. 无损格式

| 格式 | 特点 | 应用 |
|-----|------|-----|
| **WAV** | 无压缩，文件大 | Windows系统 |
| **AIFF** | 无压缩，文件大 | macOS系统 |
| **FLAC** | 无损压缩，文件较小 | 音乐收藏 |
| **ALAC** | Apple无损压缩 | Apple设备 |

### 2. 有损格式

| 格式 | 特点 | 应用 |
|-----|------|-----|
| **MP3** | 有损压缩，流行 | 音乐播放器 |
| **AAC** | 比MP3高效 | Apple设备、流媒体 |
| **OGG** | 开源格式 | Linux、游戏 |
| **WMA** | Windows格式 | Windows Media Player |

### 3. 格式选择指南

| 场景 | 推荐格式 |
|-----|---------|
| **音乐收藏** | FLAC、ALAC |
| **在线流媒体** | MP3、AAC |
| **语音** | MP3、OGG |
| **专业录音** | WAV、AIFF |

## 六、音频压缩

### 1. 压缩原理

**心理声学原理**：人耳对某些频率不敏感，可以丢弃这些频率的信息。

### 2. MP3压缩原理

| 步骤 | 说明 |
|-----|------|
| **时域到频域转换** | 使用MDCT变换 |
| **心理声学模型** | 计算人耳掩蔽效应 |
| **量化** | 根据掩蔽阈值量化 |
| **熵编码** | Huffman编码 |

### 3. MP3比特率

| 比特率 | 音质 | 应用 |
|-----|------|-----|
| **64 kbps** | 低音质 | 语音、流媒体 |
| **128 kbps** | 中等音质 | 网络广播 |
| **192 kbps** | 较好音质 | 音乐收藏 |
| **320 kbps** | 高音质 | 高质量音乐 |

## 七、易错点提示

> [!warning] 常见误区
> - **"分辨率越高，画质越好"**：画质还受颜色深度、压缩质量等影响。
> - **"无损压缩就是不压缩"**：无损压缩会压缩数据，但可以完全恢复。
> - **"MP3音质不如WAV"**：高质量MP3和WAV在听觉上差别很小。
> - **"采样率越高越好"**：超过人耳听觉范围的采样率没有实际意义。

## 八、示例与练习

### 示例

**例1**：计算一首5分钟歌曲的WAV文件大小

**解析**：
- 采样率：44.1 kHz
- 采样精度：16位
- 声道数：2（立体声）
- 时间：5分钟 = 300秒
- 文件大小 = 44100 × 16 × 2 × 300 / 8 = 529,200,000字节 ≈ 504.7 MB

**例2**：分析JPEG和PNG的适用场景

**解析**：
- JPEG适合照片，因为照片细节丰富，少量损失不易察觉
- PNG适合图标和Logo，因为需要透明背景和无损画质
