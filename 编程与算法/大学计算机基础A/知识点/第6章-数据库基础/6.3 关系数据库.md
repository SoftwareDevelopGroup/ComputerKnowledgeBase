# 6.3 关系数据库

> [!abstract] 核心问题
> 关系数据库如何组织数据？SQL语言的基本语法是什么？

## 一、关系数据库概述

### 1. 关系数据库结构

**关系数据库**由多个表（关系）组成，表之间通过键关联：

```mermaid
erDiagram
  STUDENT ||--o{ SCORE : "拥有"
  COURSE ||--o{ SCORE : "对应"
  STUDENT {
    int student_id PK
    string name
    int age
    string gender
    int class_id FK
  }
  COURSE {
    int course_id PK
    string course_name
    int credit
  }
  SCORE {
    int student_id PK,FK
    int course_id PK,FK
    float grade
  }
  CLASS ||--o{ STUDENT : "包含"
  CLASS {
    int class_id PK
    string class_name
    string department
  }
```

### 2. 表的组成

| 组成部分 | 说明 |
|---------|------|
| **表名** | 表的唯一标识 |
| **列（字段）** | 表的属性 |
| **行（记录）** | 表的数据 |
| **主键** | 唯一标识记录的列 |
| **外键** | 关联其他表主键的列 |

## 二、SQL语言基础

### 1. SQL定义

**SQL（Structured Query Language）**是用于操作关系数据库的标准语言。

### 2. SQL分类

| 类别 | 说明 | 命令 |
|-----|------|-----|
| **DDL（数据定义语言）** | 定义数据库结构 | CREATE、DROP、ALTER |
| **DML（数据操纵语言）** | 操作数据 | SELECT、INSERT、UPDATE、DELETE |
| **DCL（数据控制语言）** | 控制数据访问 | GRANT、REVOKE |
| **TCL（事务控制语言）** | 控制事务 | COMMIT、ROLLBACK |

### 3. DDL命令

**创建表（CREATE TABLE）**：

```sql
CREATE TABLE student (
    student_id INT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    age INT,
    gender VARCHAR(10),
    class_id INT,
    FOREIGN KEY (class_id) REFERENCES class(class_id)
);
```

**修改表（ALTER TABLE）**：

```sql
ALTER TABLE student ADD email VARCHAR(100);
ALTER TABLE student MODIFY age INT DEFAULT 18;
ALTER TABLE student DROP COLUMN gender;
```

**删除表（DROP TABLE）**：

```sql
DROP TABLE student;
```

### 4. DML命令

**查询数据（SELECT）**：

```sql
-- 查询所有学生
SELECT * FROM student;

-- 查询指定列
SELECT student_id, name, age FROM student;

-- 条件查询
SELECT * FROM student WHERE age > 18;

-- 排序
SELECT * FROM student ORDER BY age DESC;

-- 分组统计
SELECT class_id, COUNT(*) FROM student GROUP BY class_id;

-- 限制结果数量
SELECT * FROM student LIMIT 10;
```

**插入数据（INSERT）**：

```sql
INSERT INTO student (student_id, name, age, gender) 
VALUES (1001, '张三', 20, '男');

INSERT INTO student (student_id, name) 
VALUES (1002, '李四');
```

**更新数据（UPDATE）**：

```sql
UPDATE student SET age = 21 WHERE student_id = 1001;
UPDATE student SET gender = '女' WHERE name = '李四';
```

**删除数据（DELETE）**：

```sql
DELETE FROM student WHERE student_id = 1001;
DELETE FROM student WHERE age < 18;
```

### 5. 连接查询

**内连接（INNER JOIN）**：

```sql
SELECT student.name, course.course_name, score.grade
FROM student
INNER JOIN score ON student.student_id = score.student_id
INNER JOIN course ON score.course_id = course.course_id;
```

**左连接（LEFT JOIN）**：

```sql
SELECT student.name, course.course_name
FROM student
LEFT JOIN score ON student.student_id = score.student_id
LEFT JOIN course ON score.course_id = course.course_id;
```

**右连接（RIGHT JOIN）**：

```sql
SELECT student.name, course.course_name
FROM student
RIGHT JOIN score ON student.student_id = score.student_id;
```

### 6. 子查询

```sql
-- 查询成绩高于平均分的学生
SELECT name FROM student 
WHERE student_id IN (
    SELECT student_id FROM score 
    WHERE grade > (SELECT AVG(grade) FROM score)
);
```

## 三、数据库设计

### 1. 设计步骤

| 步骤 | 说明 |
|-----|------|
| **需求分析** | 了解用户需求 |
| **概念设计** | 设计E-R图 |
| **逻辑设计** | 将E-R图转换为关系模型 |
| **物理设计** | 设计表结构、索引等 |
| **实施与测试** | 创建数据库并测试 |

### 2. 设计原则

| 原则 | 说明 |
|-----|------|
| **避免数据冗余** | 数据只存储一次 |
| **保证数据完整性** | 设置主键和外键约束 |
| **提高查询效率** | 创建合适的索引 |
| **考虑扩展性** | 设计灵活的结构 |

### 3. 索引

**索引（Index）**是提高查询效率的数据结构：

| 类型 | 说明 |
|-----|------|
| **主键索引** | 主键自动创建 |
| **唯一索引** | 保证列值唯一 |
| **普通索引** | 加速查询 |
| **复合索引** | 多列索引 |

**创建索引**：

```sql
CREATE INDEX idx_student_name ON student(name);
CREATE UNIQUE INDEX idx_student_email ON student(email);
```

**索引的优缺点**：

| 优点 | 说明 |
|-----|------|
| **提高查询速度** | 快速定位数据 |

| 缺点 | 说明 |
|-----|------|
| **占用存储空间** | 索引需要额外空间 |
| **降低写入速度** | 插入、更新、删除需要维护索引 |

## 四、数据库操作

### 1. 数据库创建与删除

```sql
-- 创建数据库
CREATE DATABASE school;

-- 使用数据库
USE school;

-- 删除数据库
DROP DATABASE school;
```

### 2. 视图

**视图（View）**是虚拟表，基于查询结果：

```sql
-- 创建视图
CREATE VIEW student_score AS
SELECT student.name, course.course_name, score.grade
FROM student
JOIN score ON student.student_id = score.student_id
JOIN course ON score.course_id = course.course_id;

-- 查询视图
SELECT * FROM student_score;
```

### 3. 事务

**事务（Transaction）**是一组不可分割的操作：

```sql
BEGIN TRANSACTION;
UPDATE account SET balance = balance - 100 WHERE id = 1;
UPDATE account SET balance = balance + 100 WHERE id = 2;
COMMIT; -- 提交事务
-- ROLLBACK; -- 回滚事务
```

**ACID特性**：

| 特性 | 说明 |
|-----|------|
| **原子性（Atomicity）** | 事务要么全部执行，要么全部撤销 |
| **一致性（Consistency）** | 事务执行前后数据一致 |
| **隔离性（Isolation）** | 事务之间相互隔离 |
| **持久性（Durability）** | 事务提交后数据永久保存 |

## 五、数据库安全

### 1. 用户管理

```sql
-- 创建用户
CREATE USER 'user1'@'localhost' IDENTIFIED BY 'password';

-- 授权
GRANT SELECT, INSERT ON student TO 'user1'@'localhost';

-- 撤销权限
REVOKE INSERT ON student FROM 'user1'@'localhost';

-- 删除用户
DROP USER 'user1'@'localhost';
```

| **存储加密** | 加密敏感数据存储 |

## 六、易错点提示

> [!warning] 常见误区
> - **"SELECT * 效率高"**：SELECT *会查询所有列，应只查询需要的列。
> - **"索引越多越好"**：索引会降低写入性能，应按需创建。
> - **"事务可以随便使用"**：长事务会占用资源，应尽量缩短事务时间。
> - **"外键会影响性能"**：外键保证数据完整性，对性能影响有限。

## 七、示例与练习

### 示例

**例1**：查询每个班级的学生人数和平均年龄

**解析**：

```sql
SELECT class.class_name, COUNT(student.student_id) AS count, AVG(student.age) AS avg_age
FROM class
LEFT JOIN student ON class.class_id = student.class_id
GROUP BY class.class_id;
```
