# 6.4 数据库应用

> [!abstract] 核心问题
> 如何使用Access创建数据库？数据库应用开发的流程是什么？

## 一、Access数据库概述

### 1. Access简介

**Microsoft Access**是微软公司开发的关系数据库管理系统：

| 特点 | 说明 |
|-----|------|
| **可视化操作** | 图形化界面，易于操作 |
| **集成Office** | 与Word、Excel无缝集成 |
| **适合小型应用** | 适合个人和小型企业 |
| **支持SQL** | 可以使用SQL查询 |

### 2. Access文件格式

| 格式 | 说明 |
|-----|------|
| **.mdb** | 旧版格式 |
| **.accdb** | 新版格式（Access 2007及以后） |

## 二、Access数据库创建

### 1. 创建数据库

| 步骤 | 说明 |
|-----|------|
| **打开Access** | 启动Microsoft Access |
| **选择模板** | 选择数据库模板或空白数据库 |
| **命名数据库** | 输入数据库名称和保存位置 |
| **创建数据库** | 点击"创建"按钮 |

### 2. 创建表

**使用设计视图创建表**：

| 步骤 | 说明 |
|-----|------|
| **打开设计视图** | 在"创建"选项卡中选择"表设计" |
| **添加字段** | 输入字段名称、数据类型和说明 |
| **设置主键** | 选择主键字段，点击"主键"按钮 |
| **保存表** | 点击"保存"按钮，输入表名 |

**字段数据类型**：

| 类型 | 说明 | 示例 |
|-----|------|-----|
| **文本** | 存储文本和数字 | 姓名、地址 |
| **数字** | 存储数值 | 年龄、成绩 |
| **日期/时间** | 存储日期和时间 | 出生日期 |
| **货币** | 存储货币值 | 金额 |
| **是/否** | 存储布尔值 | 状态 |
| **OLE对象** | 存储图片、文件等 | 照片、附件 |

### 3. 设置字段属性

| 属性 | 说明 |
|-----|------|
| **字段大小** | 文本类型的最大长度 |
| **格式** | 数据的显示格式 |
| **输入掩码** | 限制输入格式 |
| **默认值** | 字段的默认值 |
| **必填** | 是否必须填写 |
| **允许空字符串** | 是否允许空字符串 |

### 4. 创建关系

**设置表之间的关系**：

| 步骤 | 说明 |
|-----|------|
| **打开关系窗口** | 在"数据库工具"选项卡中选择"关系" |
| **添加表** | 添加需要建立关系的表 |
| **拖动字段** | 将主键字段拖到外键字段 |
| **设置关系选项** | 设置参照完整性、级联更新、级联删除 |

## 三、Access查询

### 1. 查询类型

| 类型 | 说明 |
|-----|------|
| **选择查询** | 从表中查询数据 |
| **参数查询** | 根据用户输入查询 |
| **交叉表查询** | 汇总数据 |
| **操作查询** | 更新、删除、追加数据 |

### 2. 创建选择查询

**使用设计视图创建查询**：

| 步骤 | 说明 |
|-----|------|
| **打开查询设计** | 在"创建"选项卡中选择"查询设计" |
| **添加表** | 添加需要查询的表 |
| **选择字段** | 选择需要显示的字段 |
| **设置条件** | 设置查询条件 |
| **运行查询** | 点击"运行"按钮查看结果 |

### 3. 使用SQL视图

**在SQL视图中编写查询**：

```sql
SELECT student.name, course.course_name, score.grade
FROM student
INNER JOIN score ON student.student_id = score.student_id
INNER JOIN course ON score.course_id = course.course_id
WHERE score.grade > 60;
```

### 4. 参数查询

**创建参数查询**：

| 步骤 | 说明 |
|-----|------|
| **打开查询设计** | 在"创建"选项卡中选择"查询设计" |
| **选择字段** | 选择需要显示的字段 |
| **设置参数** | 在条件行输入`[请输入年龄]` |
| **运行查询** | 运行时会弹出输入框 |

## 七、数据库应用示例

### 1. 学生管理系统

## 九、易错点提示

> [!warning] 常见误区
> - **"Access只能用于小型数据库"**：Access适合个人和小型企业，大型应用应使用MySQL、Oracle等。
> - **"窗体只是显示数据"**：窗体还可以进行数据验证、导航和执行操作。
> - **"报表只能打印"**：报表还可以导出为PDF、Excel等格式。
> - **"数据库不需要备份"**：数据库可能损坏或丢失，定期备份至关重要。
