# 7.4 面向对象基础

> [!abstract] 核心问题
> 面向对象的基本概念是什么？类和对象如何定义和使用？

## 一、面向对象概述

### 1. 面向对象定义

**面向对象（Object-Oriented, OO）**是一种编程范式，将数据和操作数据的方法封装在一起。

### 2. 面向对象特点

| 特点 | 说明 |
|-----|------|
| **封装** | 将数据和方法封装在对象中 |
| **继承** | 子类继承父类的属性和方法 |
| **多态** | 同一接口有不同的实现 |

### 3. 面向对象与面向过程的区别

| 对比项 | 面向过程 | 面向对象 |
|-------|---------|---------|
| **关注点** | 过程和步骤 | 对象和交互 |
| **组织方式** | 函数 | 类和对象 |
| **数据与方法** | 分离 | 封装在一起 |
| **复用方式** | 函数调用 | 继承和组合 |

## 二、类与对象

### 1. 类的定义

**类（Class）**是对象的模板，定义对象的属性和方法。

```python
class ClassName:
    """类的文档字符串"""
    
    def __init__(self, parameters):
        """构造方法"""
        self.attribute = value
    
    def method(self, parameters):
        """方法"""
        statement
```

### 2. 对象的创建

**对象（Object）**是类的实例。

```python
# 创建对象
obj = ClassName(arguments)

# 访问属性
print(obj.attribute)

# 调用方法
obj.method(arguments)
```

### 3. 示例：定义学生类

```python
class Student:
    """学生类"""
    
    def __init__(self, name, age, score):
        self.name = name
        self.age = age
        self.score = score
    
    def get_info(self):
        return f"姓名：{self.name}，年龄：{self.age}，成绩：{self.score}"
    
    def is_passed(self):
        return self.score >= 60

# 创建对象
stu = Student("张三", 20, 85)

# 访问属性
print(stu.name)  # 张三

# 调用方法
print(stu.get_info())  # 姓名：张三，年龄：20，成绩：85
print(stu.is_passed())  # True
```

## 三、封装

### 1. 封装定义

**封装（Encapsulation）**是将对象的状态和行为封装在一起，隐藏内部实现细节。

### 2. 访问控制

| 修饰符 | 说明 |
|-------|------|
| **公有（public）** | 可以被外部访问 |
| **私有（private）** | 只能被类内部访问 |
| **保护（protected）** | 可以被类和子类访问 |

### 3. Python中的封装

**使用下划线表示访问控制**：

```python
class Student:
    def __init__(self, name, age):
        self.name = name      # 公有属性
        self._age = age       # 保护属性（约定）
        self.__score = 0      # 私有属性
    
    def set_score(self, score):
        if 0 <= score <= 100:
            self.__score = score
        else:
            print("成绩无效")
    
    def get_score(self):
        return self.__score

stu = Student("张三", 20)
stu.set_score(85)
print(stu.get_score())  # 85
# print(stu.__score)  # 错误，私有属性不能直接访问
```

## 四、继承

### 1. 继承定义

**继承（Inheritance）**是子类继承父类的属性和方法。

### 2. 继承语法

```python
class ParentClass:
    """父类"""
    pass

class ChildClass(ParentClass):
    """子类"""
    pass
```

### 3. 示例：继承

```python
class Person:
    """人类"""
    
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def introduce(self):
        return f"我是{self.name}，今年{self.age}岁"

class Student(Person):
    """学生类，继承自人类"""
    
    def __init__(self, name, age, school):
        super().__init__(name, age)  # 调用父类构造方法
        self.school = school
    
    def introduce(self):
        return f"我是{self.name}，今年{self.age}岁，就读于{self.school}"

stu = Student("张三", 20, "清华大学")
print(stu.introduce())  # 我是张三，今年20岁，就读于清华大学
```

### 4. 继承类型

| 类型 | 说明 |
|-----|------|
| **单继承** | 子类只继承一个父类 |
| **多继承** | 子类继承多个父类 |
| **多层继承** | 子类继承父类，父类继承祖父类 |

### 5. 多继承示例

```python
class A:
    def method_a(self):
        print("方法A")

class B:
    def method_b(self):
        print("方法B")

class C(A, B):
    def method_c(self):
        print("方法C")

c = C()
c.method_a()  # 方法A
c.method_b()  # 方法B
c.method_c()  # 方法C
```

## 五、多态

### 1. 多态定义

**多态（Polymorphism）**是同一接口有不同的实现方式。

### 2. 多态类型

| 类型 | 说明 |
|-----|------|
| **编译时多态** | 通过方法重载实现 |
| **运行时多态** | 通过方法重写实现 |

### 3. 方法重载

**方法重载（Overloading）**是同一类中定义多个同名方法，参数不同。

> [!note] Python不支持方法重载
> Python通过默认参数和可变参数实现类似功能。

### 4. 方法重写

**方法重写（Overriding）**是子类重写父类的方法。

```python
class Animal:
    def speak(self):
        print("动物在说话")

class Dog(Animal):
    def speak(self):
        print("汪汪汪")

class Cat(Animal):
    def speak(self):
        print("喵喵喵")

def make_speak(animal):
    animal.speak()

dog = Dog()
cat = Cat()

make_speak(dog)  # 汪汪汪
make_speak(cat)  # 喵喵喵
```

## 六、类的特殊方法

### 1. 构造方法

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

### 2. 析构方法

```python
class Person:
    def __del__(self):
        print(f"{self.name}被销毁")
```

### 3. 字符串表示

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __str__(self):
        return f"Person({self.name}, {self.age})"
    
    def __repr__(self):
        return f"Person('{self.name}', {self.age})"

p = Person("张三", 20)
print(str(p))  # Person(张三, 20)
print(repr(p))  # Person('张三', 20)
```

### 4. 运算符重载

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    
    def __str__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
v3 = v1 + v2
print(v3)  # Vector(4, 6)
```

## 七、综合示例

### 1. 定义矩形类

```python
class Rectangle:
    """矩形类"""
    
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def get_area(self):
        return self.width * self.height
    
    def get_perimeter(self):
        return 2 * (self.width + self.height)

rect = Rectangle(5, 3)
print(f"面积：{rect.get_area()}")        # 面积：15
print(f"周长：{rect.get_perimeter()}")    # 周长：16
```

### 2. 定义图形继承体系

```python
class Shape:
    """图形类"""
    
    def get_area(self):
        pass
    
    def get_perimeter(self):
        pass

class Circle(Shape):
    """圆形类"""
    
    def __init__(self, radius):
        self.radius = radius
    
    def get_area(self):
        return 3.14159 * self.radius * self.radius
    
    def get_perimeter(self):
        return 2 * 3.14159 * self.radius

class Rectangle(Shape):
    """矩形类"""
    
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def get_area(self):
        return self.width * self.height
    
    def get_perimeter(self):
        return 2 * (self.width + self.height)

# 使用多态
shapes = [Circle(5), Rectangle(4, 6)]
for shape in shapes:
    print(f"面积：{shape.get_area():.2f}")
    print(f"周长：{shape.get_perimeter():.2f}")
```

## 八、易错点提示

> [!warning] 常见误区
> - **"类就是对象"**：类是对象的模板，对象是类的实例。
> - **"继承就是复制代码"**：继承不是复制，而是共享代码。
> - **"多态就是方法重写"**：多态包括方法重载和方法重写。
> - **"封装就是隐藏所有属性"**：封装是合理隐藏，不是完全隐藏。

## 九、示例与练习

### 示例

**例1**：定义一个汽车类，包含属性（品牌、型号、颜色）和方法（启动、加速、刹车）

**解析**：

```python
class Car:
    def __init__(self, brand, model, color):
        self.brand = brand
        self.model = model
        self.color = color
        self.speed = 0
    
    def start(self):
        print(f"{self.color}的{self.brand} {self.model}启动了")
    
    def accelerate(self, increment):
        self.speed += increment
        print(f"加速到{self.speed}km/h")
    
    def brake(self):
        self.speed = 0
        print("刹车，速度为0")

car = Car("宝马", "X5", "黑色")
car.start()       # 黑色的宝马 X5启动了
car.accelerate(50)  # 加速到50km/h
car.accelerate(30)  # 加速到80km/h
car.brake()       # 刹车，速度为0
```
