# 3.4 static关键字

> [!abstract] 定义
> `static`关键字用于声明静态成员（静态变量和静态方法），静态成员属于类本身，而不是类的某个实例，所有对象共享同一份静态成员。

## 静态变量

### 定义

静态变量（Static Variable）也称为类变量，属于类所有，所有对象共享同一份数据。

### 特点

| 特点 | 说明 |
|-----|------|
| **归属** | 属于类，不属于对象 |
| **内存分配** | 类加载时分配一次，所有对象共享 |
| **访问方式** | 类名.变量名 或 对象.变量名 |
| **生命周期** | 与类相同 |

> [!example] 示例：Java静态变量
> ```java
> public class Person {
>     // 实例变量：每个对象独立拥有
>     private String name;
>     
>     // 静态变量：所有对象共享
>     public static int count = 0;
>     
>     public Person(String name) {
>         this.name = name;
>         count++;  // 创建对象时计数
>     }
> }
> 
> // 使用静态变量
> Person p1 = new Person("张三");
> Person p2 = new Person("李四");
> System.out.println(Person.count);  // 输出：2
> ```

> [!example] 示例：C++静态变量
> ```cpp
> class Person {
> private:
>     std::string name;
> public:
>     static int count;  // 声明静态变量
>     
>     Person(std::string n) : name(n) {
>         count++;
>     }
> };
> 
> int Person::count = 0;  // 定义并初始化静态变量
> 
> Person p1("张三");
> Person p2("李四");
> std::cout << Person::count << std::endl;  // 输出：2
> ```

## 静态方法

### 定义

静态方法（Static Method）也称为类方法，属于类所有，可以直接通过类名调用，无需创建对象。

### 特点

| 特点 | 说明 |
|-----|------|
| **归属** | 属于类，不属于对象 |
| **调用方式** | 类名.方法名 或 对象.方法名 |
| **访问限制** | 只能访问静态成员，不能访问实例成员 |
| **this关键字** | 不能使用this |

> [!example] 示例：Java静态方法
> ```java
> public class MathUtils {
>     // 静态方法：计算两数之和
>     public static int add(int a, int b) {
>         return a + b;
>     }
>     
>     // 静态方法：计算最大值
>     public static int max(int a, int b) {
>         return a > b ? a : b;
>     }
> }
> 
> // 直接调用静态方法，无需创建对象
> int sum = MathUtils.add(1, 2);
> int max = MathUtils.max(3, 5);
> ```

> [!example] 示例：C++静态方法
> ```cpp
> class MathUtils {
> public:
>     static int add(int a, int b) {
>         return a + b;
>     }
>     
>     static int max(int a, int b) {
>         return a > b ? a : b;
>     }
> };
> 
> int sum = MathUtils::add(1, 2);
> int max = MathUtils::max(3, 5);
> ```

## 静态成员与实例成员对比

| 对比维度 | 静态成员 | 实例成员 |
|---------|---------|---------|
| **归属** | 类 | 对象 |
| **内存分配** | 类加载时一次 | 每个对象一份 |
| **访问方式** | 类名.成员名 | 对象.成员名 |
| **访问限制** | 只能访问静态成员 | 可访问静态和实例成员 |
| **this** | 不可用 | 可用 |

## 静态初始化块

### Java静态初始化块

```java
public class Person {
    public static int count;
    
    // 静态初始化块：类加载时执行
    static {
        count = 0;
        System.out.println("类已加载");
    }
}
```

### C++静态初始化

```cpp
class Person {
public:
    static int count;
};

// 静态初始化
int Person::count = 0;
```

## 静态导入

### Java静态导入

```java
import static java.lang.Math.PI;
import static java.lang.Math.sqrt;

public class Circle {
    public double getArea(double radius) {
        return PI * radius * radius;
    }
    
    public double getCircumference(double radius) {
        return 2 * PI * radius;
    }
}
```

## 应用场景

| 场景 | 使用静态成员 | 理由 |
|-----|-------------|------|
| **工具方法** | `static` | 无需创建对象，直接调用 |
| **计数器** | `static` | 所有对象共享计数 |
| **常量** | `static final` | 全局常量 |
| **工厂方法** | `static` | 返回类的实例 |
| **单例模式** | `static` | 控制对象创建 |

## 易错点

> [!warning] 常见误区
> 1. **误区**：静态方法可以访问实例成员
>    **纠正**：静态方法不能访问实例成员，因为没有this引用
>
> 2. **误区**：静态变量可以在构造方法中初始化
>    **纠正**：静态变量应该在静态初始化块或声明时初始化
>
> 3. **误区**：C++静态变量不需要定义
>    **纠正**：C++静态变量必须在类外定义并初始化

## 关键术语

| 术语 | 英文 | 定义 |
|-----|------|------|
| 静态变量 | Static Variable | 类所有，所有对象共享 |
| 静态方法 | Static Method | 类所有，无需创建对象调用 |
| 类变量 | Class Variable | 静态变量的别称 |
| 类方法 | Class Method | 静态方法的别称 |
| 静态初始化块 | Static Initializer | 类加载时执行的代码块 |
