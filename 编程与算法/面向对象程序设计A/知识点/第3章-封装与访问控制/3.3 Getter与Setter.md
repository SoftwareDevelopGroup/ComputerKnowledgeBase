# 3.3 Getter与Setter

> [!abstract] 定义
> Getter（访问器）和Setter（修改器）是封装模式的实现方式，通过公共方法访问和修改私有属性，实现数据保护和接口控制。

## Getter方法

### 定义

Getter方法用于获取私有属性的值，通常以`get`开头，后跟属性名（首字母大写）。

### 特点

| 特点 | 说明 |
|-----|------|
| **方法名** | `getXxx()` |
| **返回类型** | 属性的类型 |
| **参数** | 无参数 |
| **访问修饰符** | `public` |

> [!example] 示例：Java Getter
> ```java
> public class Person {
>     private String name;
>     private int age;
>     
>     public String getName() {
>         return name;
>     }
>     
>     public int getAge() {
>         return age;
>     }
> }
> ```

> [!example] 示例：C++ Getter
> ```cpp
> class Person {
> private:
>     std::string name;
>     int age;
> public:
>     std::string getName() const {
>         return name;
>     }
>     
>     int getAge() const {
>         return age;
>     }
> };
> ```

### 布尔类型的特殊命名

布尔类型的Getter可以使用`is`前缀。

```java
public class Person {
    private boolean isStudent;
    
    public boolean isStudent() {
        return isStudent;
    }
}
```

## Setter方法

### 定义

Setter方法用于设置私有属性的值，通常以`set`开头，后跟属性名（首字母大写）。

### 特点

| 特点 | 说明 |
|-----|------|
| **方法名** | `setXxx()` |
| **返回类型** | `void`或当前对象（链式调用） |
| **参数** | 属性的类型 |
| **访问修饰符** | `public` |

> [!example] 示例：Java Setter
> ```java
> public class Person {
>     private String name;
>     private int age;
>     
>     public void setName(String name) {
>         if (name != null && !name.isEmpty()) {
>             this.name = name;
>         }
>     }
>     
>     public void setAge(int age) {
>         if (age >= 0 && age <= 150) {
>             this.age = age;
>         }
>     }
> }
> ```

> [!example] 示例：C++ Setter
> ```cpp
> class Person {
> private:
>     std::string name;
>     int age;
> public:
>     void setName(std::string n) {
>         if (!n.empty()) {
>             name = n;
>         }
>     }
>     
>     void setAge(int a) {
>         if (a >= 0 && a <= 150) {
>             age = a;
>         }
>     }
> };
> ```

## Getter/Setter的好处

| 好处 | 说明 |
|-----|------|
| **数据校验** | 在Setter中验证输入合法性 |
| **日志记录** | 在方法中记录访问日志 |
| **触发事件** | 属性变化时触发相应事件 |
| **计算属性** | Getter可以返回计算结果 |
| **兼容性** | 修改内部实现不影响外部调用 |

## 链式调用模式

Setter返回当前对象，支持链式调用。

> [!example] 示例：Java链式调用
> ```java
> public class Person {
>     private String name;
>     private int age;
>     
>     public Person setName(String name) {
>         this.name = name;
>         return this;
>     }
>     
>     public Person setAge(int age) {
>         this.age = age;
>         return this;
>     }
> }
> 
> Person p = new Person().setName("张三").setAge(20);
> ```

> [!example] 示例：C++链式调用
> ```cpp
> class Person {
> private:
>     std::string name;
>     int age;
> public:
>     Person& setName(std::string n) {
>         name = n;
>         return *this;
>     }
>     
>     Person& setAge(int a) {
>         age = a;
>         return *this;
>     }
> };
> 
> Person p;
> p.setName("张三").setAge(20);
> ```

## 计算属性

Getter可以返回计算结果，而不是直接返回属性值。

> [!example] 示例：计算属性
> ```java
> public class Rectangle {
>     private double width;
>     private double height;
>     
>     public double getArea() {
>         return width * height;  // 计算属性
>     }
>     
>     public double getPerimeter() {
>         return 2 * (width + height);  // 计算属性
>     }
> }
> ```

## 易错点

> [!warning] 常见误区
> 1. **误区**：所有属性都需要Getter/Setter
>    **纠正**：只读属性只需Getter，只写属性只需Setter
>
> 2. **误区**：Setter不需要校验
>    **纠正**：必须在Setter中验证输入合法性
>
> 3. **误区**：Getter/Setter会影响性能
>    **纠正**：现代编译器会内联简单方法，性能影响可忽略

## 关键术语

| 术语 | 英文 | 定义 |
|-----|------|------|
| Getter | Accessor | 获取属性值的方法 |
| Setter | Mutator | 设置属性值的方法 |
| 链式调用 | Method Chaining | 连续调用多个方法 |
| 计算属性 | Computed Property | 通过计算得到的属性值 |
