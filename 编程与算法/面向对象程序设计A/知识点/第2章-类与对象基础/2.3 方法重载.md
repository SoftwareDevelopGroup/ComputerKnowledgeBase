# 2.3 方法重载

> [!abstract] 定义
> 方法重载（Method Overloading）是指在同一个类中定义多个同名方法，但参数列表不同（参数个数、类型或顺序不同），根据调用时的参数自动选择合适的方法执行。

## 2.3.1 重载规则

### 必须满足的条件

| 条件 | 说明 |
|-----|------|
| **方法名相同** | 必须完全相同 |
| **参数列表不同** | 参数个数、类型或顺序不同 |
| **返回类型** | 可以相同也可以不同（不影响重载） |
| **访问修饰符** | 可以不同 |

### 参数列表对比

| 对比项 | 是否构成重载 | 示例 |
|-------|------------|------|
| 参数个数不同 | 是 | `add(int)`, `add(int, int)` |
| 参数类型不同 | 是 | `add(int)`, `add(double)` |
| 参数顺序不同 | 是 | `add(int, double)`, `add(double, int)` |
| 返回类型不同 | 否 | `int add()`, `double add()` |
| 仅参数名不同 | 否 | `add(int a)`, `add(int b)` |

> [!example] 示例：Java方法重载
> ```java
> public class Calculator {
>     public int add(int a, int b) { return a + b; }
>     public int add(int a, int b, int c) { return a + b + c; }
>     public double add(double a, double b) { return a + b; }
> }
> ```

> [!example] 示例：C++方法重载
> ```cpp
> class Calculator {
> public:
>     int add(int a, int b) { return a + b; }
>     int add(int a, int b, int c) { return a + b + c; }
>     double add(double a, double b) { return a + b; }
> };
> ```

## 2.3.2 构造方法重载

构造方法也可以重载，提供多种初始化方式。

```java
public class Person {
    public Person() { /* ... */ }
    public Person(String name) { /* ... */ }
    public Person(String name, int age) { /* ... */ }
}
```

## 2.3.3 自动类型转换

调用重载方法时，编译器会自动进行类型转换。

```java
Calculator calc = new Calculator();
int result1 = calc.add(1, 2);      // 调用 add(int, int)
double result2 = calc.add(1, 2.5); // 调用 add(int, double)
```

## 2.3.4 重载的好处

| 好处 | 说明 |
|-----|------|
| **代码复用** | 相似功能使用同一方法名 |
| **接口简洁** | 调用者无需记忆多个方法名 |
| **灵活调用** | 根据参数自动选择合适方法 |

## 2.3.5 应用场景

| 场景 | 示例 |
|-----|------|
| **多种参数组合** | `print(int)`, `print(double)`, `print(String)` |
| **可选参数** | `draw(int x, int y)`, `draw(int x, int y, int width)` |
