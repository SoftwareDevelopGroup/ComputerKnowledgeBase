# 2.4 this关键字

> [!abstract] 定义
> `this`是一个引用变量，指向当前对象的**引用**，在方法内部使用，代表调用该方法的对象本身。

## 2.4.1 区分成员变量和局部变量

当成员变量和局部变量同名时，使用`this`区分。

> [!example] 示例：Java区分同名变量
> ```java
> public class Person {
>     private String name;
>     private int age;
>     
>     public void setName(String name) {
>         this.name = name;  // this.name是成员变量，name是参数
>     }
>     
>     public void setAge(int age) {
>         this.age = age;    // this.age是成员变量，age是参数
>     }
> }
> ```

> [!example] 示例：C++区分同名变量
> ```cpp
> class Person {
> private:
>     std::string name;
>     int age;
> public:
>     void setName(std::string name) {
>         this->name = name;
>     }
> };
> ```

## 2.4.2 调用本类的构造方法

使用`this()`在构造方法中调用另一个构造方法。

> [!example] 示例：Java调用构造方法
> ```java
> public class Person {
>     public Person() {
>         this("未知", 0);  // 调用有参构造
>     }
>     
>     public Person(String name, int age) {
>         this.name = name;
>         this.age = age;
>     }
> }
> ```

> [!warning] 注意事项
> - `this()`必须是构造方法的第一条语句
> - 不能形成递归调用

## 2.4.3 返回当前对象

使用`return this`返回当前对象，支持链式调用。

> [!example] 示例：Java链式调用
> ```java
> public class Person {
>     public Person setName(String name) {
>         this.name = name;
>         return this;
>     }
>     
>     public Person setAge(int age) {
>         this.age = age;
>         return this;
>     }
> }
> 
> Person p = new Person().setName("张三").setAge(20);
> ```

## 2.4.4 传递当前对象

将当前对象作为参数传递给其他方法。

```java
public void introduce() {
    Greeting.greet(this);
}
```

## 2.4.5 this的本质

| 特性 | 说明 |
|-----|------|
| **类型** | 当前类的引用类型 |
| **值** | 当前对象的内存地址 |
| **作用域** | 方法内部 |
| **生命周期** | 方法调用期间 |

## 2.4.6 易错点

> [!warning] 常见误区
> 1. **误区**：this可以在静态方法中使用
>    **纠正**：静态方法属于类，不属于对象，不能使用this
>
> 2. **误区**：this()可以在普通方法中使用
>    **纠正**：this()只能在构造方法中使用
