# 7.2 泛型类

> [!abstract] 定义
> 泛型类（Generic Class）是使用类型参数定义的类，允许在创建对象时指定具体类型，实现类型安全的通用编程。

## 泛型类的定义

### Java泛型类

> [!example] 示例：Java泛型类
> ```java
> public class Box<T> {
>     private T item;
>     
>     public void set(T item) {
>         this.item = item;
>     }
>     
>     public T get() {
>         return item;
>     }
> }
> ```

### 使用泛型类

```java
// 创建特定类型的对象
Box<String> stringBox = new Box<>();
stringBox.set("Hello");
String str = stringBox.get();

Box<Integer> intBox = new Box<>();
intBox.set(100);
Integer num = intBox.get();
```

### C++模板类

> [!example] 示例：C++模板类
> ```cpp
> template <typename T>
> class Box {
> private:
>     T item;
> public:
>     void set(T item) {
>         this->item = item;
>     }
>     
>     T get() const {
>         return item;
>     }
> };
> ```

### 使用模板类

```cpp
Box<std::string> stringBox;
stringBox.set("Hello");
std::string str = stringBox.get();

Box<int> intBox;
intBox.set(100);
int num = intBox.get();
```

## 多个类型参数

### Java多个类型参数

```java
public class Pair<K, V> {
    private K key;
    private V value;
    
    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }
    
    public K getKey() { return key; }
    public V getValue() { return value; }
}
```

### 使用多个类型参数

```java
Pair<String, Integer> pair = new Pair<>("年龄", 20);
String key = pair.getKey();
Integer value = pair.getValue();
```

### C++多个类型参数

```cpp
template <typename K, typename V>
class Pair {
private:
    K key;
    V value;
public:
    Pair(K k, V v) : key(k), value(v) {}
    K getKey() const { return key; }
    V getValue() const { return value; }
};
```

## 泛型类继承

### Java泛型类继承

```java
public class GenericBox<T> {
    protected T item;
}

public class StringBox extends GenericBox<String> {
    public void print() {
        System.out.println(item);
    }
}
```

### 泛型接口

```java
public interface Container<T> {
    void add(T item);
    T get(int index);
}

public class ListContainer<T> implements Container<T> {
    private List<T> list = new ArrayList<>();
    
    @Override
    public void add(T item) {
        list.add(item);
    }
    
    @Override
    public T get(int index) {
        return list.get(index);
    }
}
```

## 类型边界

### Java类型边界

```java
// 上界：T必须是Number的子类
public class NumberBox<T extends Number> {
    private T number;
    
    public double getValue() {
        return number.doubleValue();
    }
}
```

### 多个边界

```java
// T必须同时实现Comparable和Serializable
public class ComparableBox<T extends Comparable<T> & Serializable> {
    // ...
}
```

### C++类型约束

```cpp
template <typename T, typename = std::enable_if_t<std::is_arithmetic_v<T>>>
class NumberBox {
    T number;
};
```

## 泛型类的应用场景

### 集合框架

```java
List<String> list = new ArrayList<>();
Set<Integer> set = new HashSet<>();
Map<String, Object> map = new HashMap<>();
```

### 数据结构

```java
public class Stack<T> {
    private List<T> elements = new ArrayList<>();
    
    public void push(T item) { elements.add(item); }
    public T pop() { return elements.remove(elements.size() - 1); }
}
```

### 工具类

```java
public class Cache<K, V> {
    private Map<K, V> cache = new HashMap<>();
    
    public void put(K key, V value) { cache.put(key, value); }
    public V get(K key) { return cache.get(key); }
}
```

## 易错点

> [!warning] 常见误区
> 1. **误区**：泛型类可以使用基本类型
>    **纠正**：Java泛型只能使用引用类型，需要使用包装类
>
> 2. **误区**：泛型类的静态方法可以使用类型参数
>    **纠正**：静态方法不能使用类的类型参数，需要定义自己的类型参数
>
> 3. **误区**：可以创建泛型数组
>    **纠正**：Java不允许创建泛型数组

## 关键术语

| 术语 | 英文 | 定义 |
|-----|------|------|
| 泛型类 | Generic Class | 使用类型参数的类 |
| 类型参数 | Type Parameter | 泛型中的类型变量 |
| 类型边界 | Type Bound | 限制类型参数的范围 |
| 上界 | Upper Bound | 类型参数的父类约束 |
| 模板类 | Template Class | C++中的泛型类 |
