# 7.3 泛型方法

> [!abstract] 定义
> 泛型方法（Generic Method）是使用类型参数定义的方法，允许在调用时指定具体类型，实现类型安全的通用操作。

## 泛型方法的定义

### Java泛型方法

> [!example] 示例：Java泛型方法
> ```java
> public class ArrayUtils {
>     // 泛型方法：反转数组
>     public static <T> void reverse(T[] array) {
>         int left = 0;
>         int right = array.length - 1;
>         while (left < right) {
>             T temp = array[left];
>             array[left] = array[right];
>             array[right] = temp;
>             left++;
>             right--;
>         }
>     }
>     
>     // 泛型方法：查找最大值
>     public static <T extends Comparable<T>> T findMax(T[] array) {
>         T max = array[0];
>         for (T item : array) {
>             if (item.compareTo(max) > 0) {
>                 max = item;
>             }
>         }
>         return max;
>     }
> }
> ```

### 使用泛型方法

```java
String[] names = {"Alice", "Bob", "Charlie"};
ArrayUtils.reverse(names);

Integer[] numbers = {3, 1, 4, 1, 5, 9};
Integer max = ArrayUtils.findMax(numbers);
```

### C++模板函数

> [!example] 示例：C++模板函数
> ```cpp
> #include <algorithm>
> 
> template <typename T>
> void reverse(T* array, size_t size) {
>     std::reverse(array, array + size);
> }
> 
> template <typename T>
> T findMax(T* array, size_t size) {
>     T max = array[0];
>     for (size_t i = 1; i < size; ++i) {
>         if (array[i] > max) {
>             max = array[i];
>         }
>     }
>     return max;
> }
> ```

### 使用模板函数

```cpp
std::string names[] = {"Alice", "Bob", "Charlie"};
reverse(names, 3);

int numbers[] = {3, 1, 4, 1, 5, 9};
int max = findMax(numbers, 6);
```

## 泛型方法与泛型类的区别

| 对比维度 | 泛型方法 | 泛型类 |
|---------|---------|--------|
| **类型参数位置** | 方法签名 | 类名后 |
| **类型参数作用域** | 方法内部 | 整个类 |
| **静态方法** | 可以定义 | 不能使用类的类型参数 |
| **调用方式** | 方法调用时指定类型 | 创建对象时指定类型 |

## 泛型方法的类型推断

### Java类型推断

```java
// 编译器自动推断类型
ArrayUtils.reverse(names);  // 推断为String

// 显式指定类型
ArrayUtils.<String>reverse(names);
```

### C++类型推断

```cpp
// 编译器自动推断类型
reverse(names, 3);  // 推断为std::string

// 显式指定类型
reverse<std::string>(names, 3);
```

## 泛型方法的应用场景

### 工具方法

```java
public class CollectionUtils {
    public static <T> List<T> filter(List<T> list, Predicate<T> predicate) {
        List<T> result = new ArrayList<>();
        for (T item : list) {
            if (predicate.test(item)) {
                result.add(item);
            }
        }
        return result;
    }
}
```

### 转换方法

```java
public class Converter {
    public static <T, R> List<R> convert(List<T> list, Function<T, R> mapper) {
        List<R> result = new ArrayList<>();
        for (T item : list) {
            result.add(mapper.apply(item));
        }
        return result;
    }
}
```

### 工厂方法

```java
public class Factory {
    public static <T> T create(Supplier<T> supplier) {
        return supplier.get();
    }
}
```

## 递归泛型

### Java递归泛型

```java
public interface Builder<T extends Builder<T>> {
    T setName(String name);
    T setAge(int age);
    Object build();
}

public class PersonBuilder implements Builder<PersonBuilder> {
    private String name;
    private int age;
    
    @Override
    public PersonBuilder setName(String name) {
        this.name = name;
        return this;
    }
    
    @Override
    public PersonBuilder setAge(int age) {
        this.age = age;
        return this;
    }
    
    public Object build() {
        return new Object();
    }
}
```

## 易错点

> [!warning] 常见误区
> 1. **误区**：泛型方法必须在泛型类中定义
>    **纠正**：泛型方法可以在普通类中定义
>
> 2. **误区**：静态方法可以使用类的类型参数
>    **纠正**：静态方法必须定义自己的类型参数
>
> 3. **误区**：类型推断总是正确的
>    **纠正**：复杂情况下可能需要显式指定类型

| 泛型方法 | Generic Method | 使用类型参数的方法 |
