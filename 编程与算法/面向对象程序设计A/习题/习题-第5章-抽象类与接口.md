### 题1：代码分析

阅读下列Java代码，分析是否存在问题：

```java
public abstract class Animal {
    public abstract void makeSound();
    
    public void eat() {
        System.out.println("Animal eats");
    }
}

public interface Flyable {
    void fly();
}

public class Bird extends Animal implements Flyable {
    public void makeSound() {
        System.out.println("Bird chirps");
    }
    
    public void fly() {
        System.out.println("Bird flies");
    }
}

public class Test {
    public static void main(String[] args) {
        Animal a = new Bird();
        Flyable f = new Bird();
        Bird b = new Bird();
        a.makeSound();
        f.fly();
        b.eat();
    }
}
```

### 简答题答案

1. 抽象类是包含抽象方法的类，不能被实例化。特点：为继承设计、可包含抽象和非抽象方法、子类必须实现抽象方法。

2. 接口是抽象方法的集合，没有构造方法。特点：方法默认public abstract、常量默认public static final、类可实现多个接口。

3. 区别：抽象类有构造方法，接口没有；抽象类可有非抽象方法，接口不能；类只能继承一个抽象类，可实现多个接口。

4. 抽象类：需要代码复用、有默认实现、"is-a"关系；接口：需要多重继承、无默认实现、"has-a"关系。

5. Java中类可实现多个接口，用逗号分隔，必须实现所有接口的方法。

**题3答案**：
```java
public interface Shape {
    double getArea();
    double getPerimeter();
}

public interface Drawable {
    void draw();
}

public class Circle implements Shape, Drawable {
    private double radius;
    
    public Circle(double radius) {
        this.radius = radius;
    }
    
    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
    
    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }
    
    @Override
    public void draw() {
        System.out.println("Drawing a circle");
    }
}

public class Rectangle implements Shape, Drawable {
    private double length, width;
    
    public Rectangle(double length, double width) {
        this.length = length;
        this.width = width;
    }
    
    @Override
    public double getArea() {
        return length * width;
    }
    
    @Override
    public double getPerimeter() {
        return 2 * (length + width);
    }
    
    @Override
    public void draw() {
        System.out.println("Drawing a rectangle");
    }
}
```

**题4答案**：
```cpp
#include <iostream>
#include <cmath>
using namespace std;

class Shape {
public:
    virtual double getArea() const = 0;
    virtual double getPerimeter() const = 0;
};

class Drawable {
public:
    virtual void draw() const = 0;
};

class Circle : public Shape, public Drawable {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    
    double getArea() const override {
        return M_PI * radius * radius;
    }
    
    double getPerimeter() const override {
        return 2 * M_PI * radius;
    }
    
    void draw() const override {
        cout << "Drawing a circle" << endl;
    }
};
```
