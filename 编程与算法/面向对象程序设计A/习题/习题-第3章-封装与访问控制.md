### 填空题答案

1. public、private、protected、默认（包访问权限）
2. 隐藏内部实现，提供统一接口
3. get + 属性名（首字母大写）
4. set + 属性名（首字母大写）
5. 类，对象
6. this，super
7. 初始化静态成员
8. 当前类，子类

### 简答题答案

1. 封装是将对象的状态和行为绑定在一起，对外隐藏内部实现。实现：使用private修饰属性，提供public的Getter/Setter方法。

2. public：所有类；protected：当前类、同包类、子类；默认：同包类；private：仅当前类。

3. Getter/Setter提供对私有属性的受控访问，可在方法中添加验证逻辑，保证数据完整性。

4. static修饰的成员属于类，不依赖对象。区别：static成员通过类名访问，非static通过对象访问；static成员所有对象共享，非static每个对象独有。

5. 静态初始化块用于初始化静态成员，在类加载时执行，只执行一次。

**题3答案**：
```java
public class Account {
    private String accountNo;
    private double balance;
    private static int totalAccounts = 0;
    
    public Account(String accountNo, double balance) {
        this.accountNo = accountNo;
        this.balance = balance;
        totalAccounts++;
    }
    
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
    
    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
        }
    }
    
    public double getBalance() {
        return balance;
    }
    
    public static int getTotalAccounts() {
        return totalAccounts;
    }
}
```

**题4答案**：
```cpp
#include <iostream>
#include <string>
using namespace std;

class Account {
private:
    string accountNo;
    double balance;
    static int totalAccounts;
public:
    Account(string no, double bal) : accountNo(no), balance(bal) {
        totalAccounts++;
    }
    
    void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
    
    void withdraw(double amount) {
        if (amount > 0 && amount <= balance) balance -= amount;
    }
    
    double getBalance() const {
        return balance;
    }
    
    static int getTotalAccounts() {
        return totalAccounts;
    }
};

int Account::totalAccounts = 0;
```
