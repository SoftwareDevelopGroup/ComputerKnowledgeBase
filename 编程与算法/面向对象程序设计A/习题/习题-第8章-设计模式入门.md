### 填空题答案

1. 单一职责原则、开闭原则、里氏替换原则、接口隔离原则、依赖倒置原则
2. 创建型、结构型、行为型
3. 私有构造方法、私有静态实例、公共静态方法获取实例
4. 饿汉式、懒汉式（同步方法）、双重检查锁定
5. 简单工厂模式、工厂方法模式、抽象工厂模式
6. 主题（Subject），观察者（Observer）
7. 一对多依赖，状态变化时自动通知
8. Model（模型）、View（视图）、Controller（控制器）

### 简答题答案

1. SOLID原则：单一职责（SRP）、开闭（OCP）、里氏替换（LSP）、接口隔离（ISP）、依赖倒置（DIP）。

2. 设计模式是解决特定问题的通用解决方案。分类：创建型（对象创建）、结构型（对象组合）、行为型（对象交互）。

3. 单例模式确保类只有一个实例。实现：饿汉式、懒汉式、双重检查锁定、静态内部类。

4. 工厂模式封装对象创建过程。形式：简单工厂、工厂方法、抽象工厂。

5. 观察者模式定义一对多依赖，状态变化时自动通知。场景：GUI事件处理、消息推送、数据绑定。

**题4答案**：
```java
import java.util.ArrayList;
import java.util.List;

public interface Observer {
    void update(double temp, double humidity, double pressure);
}

public interface Subject {
    void registerObserver(Observer o);
    void removeObserver(Observer o);
    void notifyObservers();
}

public class WeatherData implements Subject {
    private List<Observer> observers;
    private double temperature;
    private double humidity;
    private double pressure;
    
    public WeatherData() {
        observers = new ArrayList<>();
    }
    
    @Override
    public void registerObserver(Observer o) {
        observers.add(o);
    }
    
    @Override
    public void removeObserver(Observer o) {
        observers.remove(o);
    }
    
    @Override
    public void notifyObservers() {
        for (Observer o : observers) {
            o.update(temperature, humidity, pressure);
        }
    }
    
    public void setMeasurements(double temp, double hum, double press) {
        temperature = temp;
        humidity = hum;
        pressure = press;
        notifyObservers();
    }
}

public class Display implements Observer {
    @Override
    public void update(double temp, double humidity, double pressure) {
        System.out.println("Current weather: " + temp + "C, " + humidity + "% humidity");
    }
}
```
