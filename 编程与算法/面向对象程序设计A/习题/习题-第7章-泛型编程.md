### 题2：代码补全

补全下列Java代码，实现泛型栈：

```java
public class Stack<T> {
    private List<T> elements = new ArrayList<>();
    
    // 入栈方法
    public void push(T element) {
        elements.add(element);
    }
    
    // 出栈方法
    public T pop() {
        if (elements.isEmpty()) {
            throw new EmptyStackException();
        }
        return elements.remove(elements.size() - 1);
    }
    
    // 判断栈是否为空
    public boolean isEmpty() {
        return elements.isEmpty();
    }
    
    // 获取栈大小
    public int size() {
        return elements.size();
    }
}
```

### 填空题答案

1. 参数化类型，实现类型安全的通用编程
2. class 类名<T>
3. <T> 返回类型 方法名(T 参数)
4. 任意类型
5. ?extends T，T的子类或T本身
6. ?super T，T的父类或T本身
7. 编译时类型参数被替换为Object或边界类型
8. 函数模板，类模板

### 简答题答案

1. 泛型是参数化类型，实现类型安全的通用编程。优点：类型安全、代码复用、避免类型转换。

2. 泛型类是带有类型参数的类。定义：class 类名<T>，使用时指定具体类型。

3. 泛型方法是带有类型参数的方法。定义：<T> 返回类型 方法名(T 参数)，可在普通类或泛型类中定义。

4. 通配符：?（任意类型）、?extends T（上界，T的子类）、?super T（下界，T的父类）。

5. Java泛型在编译时擦除，C++模板在编译时实例化；Java泛型不支持基本类型，C++模板支持；Java泛型类型参数有边界限制，C++模板更灵活。

**题3答案**：
```java
import java.util.Arrays;

public class GenericUtils {
    public static <T> void printArray(T[] array) {
        System.out.println(Arrays.toString(array));
    }
    
    public static <T extends Comparable<T>> T findMax(T[] array) {
        if (array == null || array.length == 0) {
            return null;
        }
        T max = array[0];
        for (T element : array) {
            if (element.compareTo(max) > 0) {
                max = element;
            }
        }
        return max;
    }
    
    public static <T> void swap(T[] array, int i, int j) {
        T temp = array[i];
        array[i] = array[j];
        array[j] = temp;
    }
}
```

**题4答案**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

template <typename T>
void printArray(const T* array, int size) {
    for (int i = 0; i < size; i++) {
        cout << array[i] << " ";
    }
    cout << endl;
}

template <typename T>
T findMax(const T* array, int size) {
    T max = array[0];
    for (int i = 1; i < size; i++) {
        if (array[i] > max) {
            max = array[i];
        }
    }
    return max;
}

template <typename T>
void swap(T* array, int i, int j) {
    T temp = array[i];
    array[i] = array[j];
    array[j] = temp;
}
```
