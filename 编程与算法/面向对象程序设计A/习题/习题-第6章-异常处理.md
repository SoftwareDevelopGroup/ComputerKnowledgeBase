
### 填空题答案

1. Throwable
2. 检查（checked），非检查（unchecked）
3. try → catch（如果异常）→ finally
4. 声明方法可能抛出的异常
5. 手动抛出异常
6. 以Exception结尾
7. 释放资源，无论是否异常都执行
8. 异常类型或引用

### 简答题答案

1. 异常是程序运行时发生的不正常情况。分类：检查异常（编译时检查）、非检查异常（运行时检查）、错误（严重问题）。

2. 执行try块代码；如果发生异常，匹配catch块处理；无论是否异常，执行finally块。

3. throws声明方法可能抛出的异常，throw手动抛出异常对象。

4. 创建类继承Exception，添加构造方法，使用throw抛出。

5. Java用try-catch-finally，C++用try-catch-throw；Java有检查异常，C++没有；Java有finally，C++没有。

**题3答案**：
```java
public class InvalidScoreException extends Exception {
    public InvalidScoreException(String message) {
        super(message);
    }
}

public class Student {
    private double score;
    
    public void setScore(double score) throws InvalidScoreException {
        if (score < 0 || score > 100) {
            throw new InvalidScoreException("Score must be between 0 and 100");
        }
        this.score = score;
    }
    
    public double getScore() {
        return score;
    }
}

public class Test {
    public static void main(String[] args) {
        Student s = new Student();
        try {
            s.setScore(90);
            System.out.println("Score: " + s.getScore());
            s.setScore(150);
        } catch (InvalidScoreException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

**题4答案**：
```cpp
#include <iostream>
#include <string>
using namespace std;

class InvalidScoreException {
private:
    string message;
public:
    InvalidScoreException(string msg) : message(msg) {}
    string getMessage() const { return message; }
};

class Student {
private:
    double score;
public:
    void setScore(double s) {
        if (s < 0 || s > 100) {
            throw InvalidScoreException("Score must be between 0 and 100");
        }
        score = s;
    }
    
    double getScore() const { return score; }
};

int main() {
    Student s;
    try {
        s.setScore(90);
        cout << "Score: " << s.getScore() << endl;
        s.setScore(150);
    } catch (InvalidScoreException e) {
        cout << "Error: " << e.getMessage() << endl;
    }
    return 0;
}
```
