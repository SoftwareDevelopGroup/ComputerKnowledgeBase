# 习题-第5章-语义分析与中间代码

> [!abstract] 本章习题概览
> 本章习题涵盖语义分析概述、属性文法、中间代码表示等核心知识点。

## 一、选择题

### 5.1 语义分析概述

**题目1**：语义分析的主要任务不包括以下哪个？（ ）
A. 类型检查
B. 语法分析
C. 作用域分析
D. 上下文相关检查

**答案**：B

**解析**：语法分析是语法分析阶段的任务，不是语义分析的任务。

**题目2**：以下哪个不是语义错误？（ ）
A. 类型不匹配
B. 未声明的变量
C. 语法错误
D. 作用域错误

**答案**：C

**解析**：语法错误是语法分析阶段检测的，不是语义错误。

### 5.2 属性文法

**题目3**：综合属性的值由什么决定？（ ）
A. 父节点的属性
B. 子节点的属性
C. 兄弟节点的属性
D. 自身的属性

**答案**：B

**解析**：综合属性的值由子节点的属性计算得到。

**题目4**：L属性文法是指？（ ）
A. 只包含综合属性的文法
B. 只包含继承属性的文法
C. 属性值可以依赖于父节点和兄弟节点的文法
D. 属性值可以依赖于任意节点的文法

**答案**：C

**解析**：L属性文法的属性值可以依赖于父节点的继承属性、兄弟节点的综合属性和自身的属性。

### 5.3 中间代码表示

**题目5**：四元式的格式是？（ ）
A. (op, arg1, arg2)
B. (op, arg1, arg2, result)
C. (op, arg1)
D. (op, arg1, arg2, result, type)

**答案**：B

**解析**：四元式包含四个字段：运算符、第一个操作数、第二个操作数和结果。

**题目1**：语义分析的主要任务包括______、______、______和______。

## 三、简答题

### 5.1 语义分析概述

**题目1**：简述语义分析的任务和方法。

**答案**：
语义分析的任务：
1. 类型检查
2. 作用域分析
3. 上下文相关检查
4. 语义信息收集

语义分析的方法：
1. 属性文法
2. 语法制导翻译
3. 语义栈

### 5.2 属性文法

**题目2**：说明综合属性和继承属性的区别。

**答案**：
**综合属性**：
- 值由子节点的属性计算得到
- 从下往上传递
- 用于表示符号的语义值

**继承属性**：
- 值由父节点或兄弟节点的属性计算得到
- 从上往下传递
- 用于表示上下文信息

### 5.3 中间代码表示

**题目3**：为什么需要中间代码？中间代码的特点是什么？

**答案**：
**需要中间代码的原因**：
1. 与目标机无关，提高编译器的可移植性
2. 便于进行代码优化
3. 简化代码生成过程

**中间代码的特点**：
1. 与目标机无关
2. 简洁、统一
3. 易于处理和优化

## 四、综合题

**题目1**：为以下表达式生成四元式。

```
a = b + c * d - e
```

**答案**：

```
(1) (*, c, d, t1)
(2) (+, b, t1, t2)
(3) (-, t2, e, t3)
(4) (:=, t3, , a)
```

**题目2**：为以下语句生成四元式。

```
if (a > b) {
    x = 1;
} else {
    x = 2;
}
```

**答案**：

```
(1) (j>, a, b, L1)
(2) (j, , , L2)
(L1) (:=, 1, , x)
(3) (j, , , L3)
(L2) (:=, 2, , x)
(L3) ...
```
