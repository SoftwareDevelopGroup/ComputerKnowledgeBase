# 习题-第3章-自上而下语法分析

> [!abstract] 本章习题概览
> 本章习题涵盖上下文无关文法、递归下降分析法、LL(1)分析法等核心知识点。

## 一、选择题

### 3.1 上下文无关文法

**题目1**：以下哪个不是上下文无关文法的组成部分？（ ）
A. 终结符集合
B. 非终结符集合
C. 产生式集合
D. 状态集合

**答案**：D

**解析**：上下文无关文法由终结符集合、非终结符集合、产生式集合和起始符号组成，状态集合属于有限自动机。

**题目2**：以下哪个产生式不是上下文无关的？（ ）
A. S → AB
B. A → a
C. B → b
D. S → aSb

**答案**：D

**解析**：所有选项都是上下文无关的产生式。上下文无关产生式的形式是A→α，其中A是非终结符，α是终结符和非终结符的任意组合。

### 3.2 递归下降分析法

**题目3**：递归下降分析法的特点是？（ ）
A. 使用栈进行分析
B. 对每个非终结符构造一个递归函数
C. 从底向上分析
D. 需要构造分析表

**答案**：B

**解析**：递归下降分析法对每个非终结符构造一个递归函数，通过函数调用来模拟推导过程。

**题目4**：递归下降分析法不能处理哪种文法？（ ）
A. 左递归文法
B. 右递归文法
C. 无递归文法
D. 二义性文法

**答案**：A

**解析**：递归下降分析法不能直接处理左递归文法，需要先消除左递归。

### 3.3 LL(1)分析法

**题目5**：LL(1)分析法中的第一个L表示？（ ）
A. 从左到右扫描输入
B. 从右到左扫描输入
C. 最左推导
D. 最右推导

**答案**：A

**解析**：LL(1)中的第一个L表示从左到右扫描输入，第二个L表示最左推导，1表示向前看一个符号。

## 二、填空题

### 3.1 上下文无关文法

**题目1**：上下文无关文法的组成包括______、______、______和______。

**答案**：终结符集合、非终结符集合、产生式集合、起始符号

**题目2**：文法的二义性是指______。

**答案**：存在句子有两个不同的最左推导或最右推导

### 3.2 递归下降分析法

**题目3**：递归下降分析法的基本思想是______。

**答案**：对每个非终结符构造一个递归函数，通过函数调用模拟推导过程

**题目4**：消除左递归的方法包括______和______。

**答案**：直接左递归消除、间接左递归消除

### 3.3 LL(1)分析法

**题目5**：LL(1)分析表的构造需要计算______和______集合。

**答案**：FIRST、FOLLOW

## 三、简答题

### 3.1 上下文无关文法

**题目1**：简述上下文无关文法的定义和组成。

**答案**：
上下文无关文法G是一个四元组(V_N, V_T, P, S)，其中：
1. V_N是非终结符集合
2. V_T是终结符集合
3. P是产生式集合，每个产生式形式为A→α
4. S是起始符号

### 3.2 递归下降分析法

**题目2**：说明递归下降分析法的优缺点。

**答案**：
**优点**：
- 直观易懂，易于实现
- 适合手工构造
- 错误处理方便

**缺点**：
- 不能处理左递归文法
- 对文法要求较高
- 递归调用开销较大

### 3.3 LL(1)分析法

**题目3**：如何构造LL(1)分析表？

**答案**：
LL(1)分析表的构造步骤：
1. 计算每个非终结符的FIRST集合
2. 计算每个非终结符的FOLLOW集合
3. 对于每个产生式A→α，计算FIRST(α)
4. 如果ε∈FIRST(α)，则将A→α填入FOLLOW(A)中的每个终结符对应的位置
5. 否则，将A→α填入FIRST(α)中的每个终结符对应的位置

## 四、综合题

**题目1**：构造以下文法的递归下降分析器。

```
E → T E'
E' → + T E' | ε
T → F T'
T' → * F T' | ε
F → ( E ) | id
```

**答案**：

```java
void E() {
    T();
    EPrime();
}

void EPrime() {
    if (lookahead == '+') {
        match('+');
        T();
        EPrime();
    }
    // else ε
}

void T() {
    F();
    TPrime();
}

void TPrime() {
    if (lookahead == '*') {
        match('*');
        F();
        TPrime();
    }
    // else ε
}

void F() {
    if (lookahead == '(') {
        match('(');
        E();
        match(')');
    } else if (lookahead == 'id') {
        match('id');
    }
}
```

**题目2**：构造以下文法的LL(1)分析表。

```
S → A B
A → a A | ε
B → b B | c
```

**答案**：

**FIRST集合**：
- FIRST(S) = {a, b, c}
- FIRST(A) = {a, ε}
- FIRST(B) = {b, c}

**FOLLOW集合**：
- FOLLOW(S) = {$}
- FOLLOW(A) = {b, c}
- FOLLOW(B) = {$}

**LL(1)分析表**：

| 非终结符 | a | b | c | $ |
|---------|---|---|---|---|
| S | S→AB | S→AB | S→AB | |
| A | A→aA | A→ε | A→ε | |
| B | | B→bB | B→c | |
