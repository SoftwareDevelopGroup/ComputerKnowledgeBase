# 习题-第7章-代码优化

> [!abstract] 本章习题概览
> 本章习题涵盖代码优化概述、局部优化、全局优化等核心知识点。

## 一、选择题

### 7.1 代码优化概述

**题目1**：代码优化的目标不包括以下哪个？（ ）
A. 提高效率
B. 减少空间
C. 改变语义
D. 降低功耗

**答案**：C

**解析**：代码优化的基本原则是保持语义不变，不能改变程序的语义。

**题目2**：以下哪个不是代码优化的分类？（ ）
A. 局部优化
B. 全局优化
C. 循环优化
D. 语法优化

**答案**：D

**解析**：语法优化不属于代码优化的分类，代码优化分为局部优化、全局优化和循环优化。

### 7.2 局部优化

**题目3**：基本块的特点是？（ ）
A. 只有一个入口和一个出口
B. 可以有多个入口和多个出口
C. 只有一个入口和多个出口
D. 可以有多个入口和一个出口

**答案**：A

**解析**：基本块是一段顺序执行的语句序列，其中只有一个入口和一个出口。

**题目4**：以下哪个不是局部优化技术？（ ）
A. 常量折叠
B. 常量传播
C. 死代码消除
D. 循环优化

**答案**：D

**解析**：循环优化属于全局优化，不是局部优化。

### 7.3 全局优化

**题目5**：循环不变式外提的目的是？（ ）
A. 将循环内不变的表达式移到循环外
B. 将循环外的表达式移到循环内
C. 消除循环
D. 展开循环

**答案**：A

**解析**：循环不变式外提是将循环内不变的表达式移到循环外，减少重复计算。

## 三、简答题

### 7.1 代码优化概述

**题目1**：简述代码优化的目标和分类。

**答案**：
代码优化的目标：
1. 提高效率
2. 减少空间
3. 降低功耗
4. 提高可靠性

代码优化的分类：
1. 局部优化：在基本块内进行的优化
2. 全局优化：跨基本块进行的优化
3. 循环优化：针对循环进行的优化

### 7.2 局部优化

**题目2**：说明基本块的定义和划分方法。

**答案**：
**基本块的定义**：基本块是一段顺序执行的语句序列，其中只有一个入口和一个出口。

**基本块的划分方法**：
1. 入口语句：程序的第一条语句或跳转语句的目标
2. 出口语句：跳转语句或程序的最后一条语句
3. 划分：将入口语句到下一个入口语句之间的语句作为一个基本块

### 7.3 全局优化

**题目3**：说明循环优化的技术和目的。

**答案**：
循环优化的技术：
1. **循环不变式外提**：将循环内不变的表达式移到循环外
2. **强度削弱**：将强度高的运算替换为强度低的运算
3. **归纳变量消除**：消除循环中的归纳变量

循环优化的目的：
1. 减少循环内的计算量
2. 提高循环执行效率
3. 优化寄存器使用

## 四、综合题

**题目1**：对以下代码进行局部优化。

```
x = 5 + 3
y = x * 2
z = x + y
```

**答案**：

**优化过程**：
1. 常量折叠：x = 8
2. 常量传播：y = 8 * 2 = 16, z = 8 + y
3. 常量折叠：y = 16
4. 常量传播：z = 8 + 16 = 24
5. 常量折叠：z = 24

**优化后**：
```
x = 8
y = 16
z = 24
```

**题目2**：对以下循环进行优化。

```
for (int i = 0; i < n; i++) {
    x = a + b;  // a和b在循环内不变
    y = x * i;
}
```

**答案**：

**优化过程**：
1. 循环不变式外提：将x = a + b移到循环外
2. 强度削弱：将乘法替换为加法（如果可能）

**优化后**：
```
x = a + b;
for (int i = 0; i < n; i++) {
    y = x * i;
}
```
