## 一、选择题

### 6.1 符号表的作用与组织

**题目1**：符号表的主要作用不包括以下哪个？（ ）
A. 存储标识符信息
B. 快速查找标识符
C. 生成目标代码
D. 管理作用域

**答案**：C

**解析**：生成目标代码是代码生成阶段的任务，不是符号表的作用。

**题目2**：以下哪种符号表组织方式的查找效率最高？（ ）
A. 线性表
B. 哈希表
C. 树结构
D. 多层符号表

**答案**：B

**解析**：哈希表的平均查找效率是O(1)，是最高的。

### 6.2 类型系统

**题目3**：结构等价和名字等价的区别在于？（ ）
A. 结构等价根据类型的结构判断，名字等价根据类型的名称判断
B. 结构等价根据类型的名称判断，名字等价根据类型的结构判断
C. 结构等价和名字等价完全相同
D. 结构等价和名字等价没有区别

**答案**：A

**解析**：结构等价根据类型的结构判断，名字等价根据类型的名称判断。

**题目4**：以下哪个不是类型系统的作用？（ ）
A. 类型检查
B. 类型推断
C. 代码优化
D. 语法分析

**答案**：D

**解析**：语法分析是语法分析阶段的任务，不是类型系统的作用。

### 6.3 类型检查算法

**题目5**：表达式类型检查的目的是？（ ）
A. 检查表达式的语法正确性
B. 检查表达式的类型正确性
C. 检查表达式的语义正确性

## 三、简答题

### 6.1 符号表的作用与组织

**题目1**：简述符号表的作用和组织方式。

**答案**：
符号表的作用：
1. 存储标识符信息
2. 快速查找标识符
3. 管理作用域
4. 支持类型检查
5. 支持代码生成

符号表的组织方式：
1. 线性表：实现简单，效率低
2. 哈希表：效率高，需要处理冲突
3. 树结构：有序遍历，效率较高
4. 多层符号表：支持作用域嵌套

### 6.2 类型系统

**题目2**：说明结构等价和名字等价的区别，并举例说明。

**答案**：
**结构等价**：两个类型等价，如果它们的结构相同。

**例子**：
```
struct Point1 { int x; int y; }
struct Point2 { int x; int y; }

Point1 和 Point2 结构等价
```

**名字等价**：两个类型等价，如果它们的名称相同。

**例子**：
```
typedef int Length;
typedef int Width;

Length 和 Width 名字不等价（虽然都是int）
```

### 6.3 类型检查算法

**题目3**：如何进行表达式的类型检查？

**答案**：
表达式类型检查的步骤：
1. 检查操作数的类型是否正确
2. 根据运算符的类型规则判断结果类型
3. 如果类型不匹配，报告错误
4. 如果类型匹配，返回结果类型

## 四、综合题

**题目1**：设计一个符号表的数据结构，支持插入、查找和作用域管理。

**答案**：

```java
class Symbol {
    private String name;
    private String type;
    private int scope;
    private int address;
    
    // 构造函数和方法
}

class MultiScopeSymbolTable {
    private List<Map<String, Symbol>> scopes = new ArrayList<>();
    
    public void enterScope() {
        scopes.add(new HashMap<>());
    }
    
    public void exitScope() {
        scopes.remove(scopes.size() - 1);
    }
    
    public void insert(Symbol symbol) {
        scopes.get(scopes.size() - 1).put(symbol.getName(), symbol);
    }
    
    public Symbol lookup(String name) {
        for (int i = scopes.size() - 1; i >= 0; i--) {
            Symbol symbol = scopes.get(i).get(name);
            if (symbol != null) {
                return symbol;
            }
        }
        return null;
    }
}
```

Type checkExpression(Expression expr) {
    if (expr instanceof Constant) {
        return expr.getType();
    } else if (expr instanceof Variable) {
        return symbolTable.lookup(expr.getName()).getType();
    } else if (expr instanceof BinaryOperation) {
        BinaryOperation op = (BinaryOperation) expr;
        Type leftType = checkExpression(op.getLeft());
        Type rightType = checkExpression(op.getRight());
        
        if (isNumericType(leftType) && isNumericType(rightType)) {

        } else {
            throw new TypeMismatchError();
        }
