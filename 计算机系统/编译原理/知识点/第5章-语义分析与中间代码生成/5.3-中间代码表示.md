# 5.3 中间代码表示

> [!abstract] 核心问题
> 中间代码的表示形式有哪些？如何生成表达式和语句的中间代码？

## 一、中间代码的概念

### 1. 基本概念

**定义**：中间代码是编译器在语法分析和目标代码生成之间生成的一种与目标机无关的代码表示。

**作用**：

| 作用 | 说明 |
|-----|------|
| **与目标机无关** | 可以生成不同目标机的代码 |
| **便于优化** | 优化算法可以在中间代码上进行 |
| **便于移植** | 只需修改代码生成器即可移植到新机器 |

### 2. 中间代码的特点

| 特点 | 说明 |
|-----|------|
| **简洁** | 比源程序更简洁 |
| **统一** | 不同源语言可以转换为相同的中间代码 |
| **易于处理** | 便于进行优化和代码生成 |

## 二、中间代码的表示形式

### 1. 四元式（Quadruple）

**定义**：四元式是一种包含四个字段的中间代码表示。

**格式**：

$$(op, arg1, arg2, result)$$

| 字段 | 说明 |
|-----|------|
| op | 运算符 |
| arg1 | 第一个操作数 |
| arg2 | 第二个操作数 |
| result | 结果存储位置 |

**示例**：

```
表达式：a = b + c * d

四元式：
(*, c, d, t1)
(+, b, t1, t2)
(:=, t2, , a)
```

### 2. 三元式（Triple）

**定义**：三元式省略了结果字段，使用三元式编号作为结果引用。

**格式**：

$$(op, arg1, arg2)$$

**示例**：

```
表达式：a = b + c * d

三元式：
(0) (*, c, d)
(1) (+, b, (0))
(2) (:=, a, (1))
```

### 3. 树形表示（Tree Representation）

**定义**：树形表示是将表达式表示为抽象语法树。

**示例**：

```
表达式：a = b + c * d

树形表示：
      :=
     /  \
    a    +
       /  \
      b    *
         /  \
        c    d
```

### 4. 三地址码（Three-Address Code）

**定义**：三地址码是一种类似汇编语言的中间表示，每条指令最多包含三个地址。

**示例**：

```
表达式：a = b + c * d

三地址码：
t1 = c * d
t2 = b + t1
a = t2
```

### 5. 表示形式对比

| 对比项 | 四元式 | 三元式 | 树形表示 | 三地址码 |
|-------|-------|-------|---------|---------|
| 可读性 | 好 | 较好 | 好 | 好 |
| 优化方便 | 方便 | 不方便 | 方便 | 方便 |
| 代码生成 | 方便 | 不方便 | 方便 | 方便 |

## 三、表达式的中间代码生成

### 1. 算术表达式

**算法**：

1. 使用属性文法计算表达式的值
2. 为每个子表达式生成四元式
3. 使用临时变量存储中间结果

**示例**：

```
表达式：a = b + c * d - e

四元式：
(1) (*, c, d, t1)
(2) (+, b, t1, t2)
(3) (-, t2, e, t3)
(4) (:=, t3, , a)
```

### 2. 布尔表达式

**算法**：

1. 使用短路求值
2. 为每个条件生成跳转指令
3. 使用标号标记跳转目标

**示例**：

```
表达式：a > b && c < d

四元式：
(1) (j>, a, b, L1)
(2) (j, , , L2)
(L1) (j<, c, d, L3)
(3) (j, , , L2)
(L3) ...
(L2) ...
```

### 3. 赋值语句

**算法**：

1. 生成表达式的中间代码
2. 生成赋值指令

**示例**：

```
语句：x = (a + b) * c

四元式：
(1) (+, a, b, t1)
(2) (*, t1, c, t2)
(3) (:=, t2, , x)
```

## 四、语句的中间代码生成

### 1. 条件语句

**算法**：

1. 生成条件表达式的中间代码
2. 生成条件跳转指令
3. 生成真假分支的中间代码

**示例**：

```
语句：if (a > b) { x = 1; } else { x = 2; }

四元式：
(1) (j>, a, b, L1)
(2) (j, , , L2)
(L1) (:=, 1, , x)
(3) (j, , , L3)
(L2) (:=, 2, , x)
(L3) ...
```

### 2. 循环语句

**算法**：

1. 生成初始化语句的中间代码
2. 生成循环条件的中间代码
3. 生成循环体的中间代码
4. 生成循环跳转指令

**示例**：

```
语句：while (i < 10) { i = i + 1; }

四元式：
(L1) (j>=, i, 10, L2)
(1) (+, i, 1, t1)
(2) (:=, t1, , i)
(3) (j, , , L1)
(L2) ...
```

### 3. 过程调用

**算法**：

1. 生成实参的中间代码
2. 生成参数传递指令
3. 生成过程调用指令
4. 生成返回值处理指令

**示例**：

```
语句：x = f(a, b)

四元式：
(1) (param, a, , )
(2) (param, b, , )
(3) (call, f, 2, t1)
(4) (:=, t1, , x)
```

## 五、中间代码生成的方法

### 1. 语法制导翻译

**方法**：在语法分析过程中生成中间代码。

**示例**：

```
产生式：E → E1 + E2
语义规则：
  E.addr = newtemp()
  emit('+', E1.addr, E2.addr, E.addr)
```

### 2. 递归下降生成

**方法**：在递归下降分析中生成中间代码。

**示例**：

```java
int E() {
    int e1 = E();
    match('+');
    int e2 = E();
    int t = newtemp();
    emit("+", e1, e2, t);
    return t;
}
```

### 3. 两遍扫描生成

**方法**：第一遍构建语法树，第二遍遍历语法树生成中间代码。

**示例**：

```mermaid
flowchart LR
    A[语法树] --> B[遍历]
    B --> C[生成中间代码]
```

## 六、中间代码的优化

### 1. 局部优化

**定义**：在基本块内进行的优化。

**优化技术**：

| 技术 | 说明 |
|-----|------|
| **常量折叠** | 编译时计算常量表达式 |
| **常量传播** | 用常量替换变量 |
| **死代码消除** | 删除永远不会执行的代码 |

### 2. 全局优化

**定义**：跨基本块的优化。

**优化技术**：

| 技术 | 说明 |
|-----|------|
| **公共子表达式消除** | 避免重复计算 |
| **循环优化** | 循环不变式外提 |
| **数据流分析** | 分析数据依赖关系 |

> [!warning] 易错点
> 中间代码是与目标机无关的！这意味着同一中间代码可以生成不同目标机的代码，提高了编译器的可移植性。
