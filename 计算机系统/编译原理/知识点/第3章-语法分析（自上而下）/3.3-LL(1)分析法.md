# 3.3 LL(1)分析法

> [!abstract] 核心问题
> 什么是LL(1)文法？如何计算FIRST集和FOLLOW集？如何构造LL(1)分析表？

## 一、LL(1)文法的定义

### 1. LL(1)的含义

**LL(1)**：

- **第一个L**：从左到右扫描输入串
- **第二个L**：最左推导
- **1**：向前看一个token

**特点**：
- 确定性：对于每个非终结符和输入token，只有一个产生式可选

### 2. LL(1)文法的判定条件

**条件**：

对于文法中的任意两个产生式 $A \to \alpha$ 和 $A \to \beta$（$\alpha \neq \beta$），必须满足：

$$\text{FIRST}(\alpha) \cap \text{FIRST}(\beta) = \emptyset$$

如果 $\alpha \Rightarrow^* \varepsilon$，则还需满足：

$$\text{FIRST}(\beta) \cap \text{FOLLOW}(A) = \emptyset$$

## 二、FIRST集和FOLLOW集

### 1. FIRST集

**定义**：对于符号串 $\alpha$，$\text{FIRST}(\alpha)$ 是 $\alpha$ 推导的第一个终结符的集合。

**计算规则**：

1. 如果 $X \in V_T$，则 $\text{FIRST}(X) = \{X\}$
2. 如果 $X \in V_N$，对于产生式 $X \to \alpha$：
   - 如果 $\alpha$ 的第一个符号是终结符 $a$，则 $a \in \text{FIRST}(X)$
   - 如果 $\alpha$ 的第一个符号是非终结符 $Y$，且 $\varepsilon \notin \text{FIRST}(Y)$，则 $\text{FIRST}(Y) \subseteq \text{FIRST}(X)$
   - 如果 $\alpha \Rightarrow^* \varepsilon$，则 $\varepsilon \in \text{FIRST}(X)$

**示例**：

```
产生式：
E → T E'
E' → + T E' | ε
T → F T'
T' → * F T' | ε
F → ( E ) | id

FIRST(E) = FIRST(T) = FIRST(F) = {(, id}
FIRST(E') = {+, ε}
FIRST(T') = {*, ε}
```

### 2. FOLLOW集

**定义**：对于非终结符 $A$，$\text{FOLLOW}(A)$ 是在某些句型中紧跟在 $A$ 后面的终结符的集合。

**计算规则**：

1. $\$ \in \text{FOLLOW}(S)$（$\$$ 是输入结束标记）
2. 如果有产生式 $B \to \alpha A \beta$，则 $\text{FIRST}(\beta) - \{\varepsilon\} \subseteq \text{FOLLOW}(A)$
3. 如果有产生式 $B \to \alpha A$ 或 $B \to \alpha A \beta$ 且 $\varepsilon \in \text{FIRST}(\beta)$，则 $\text{FOLLOW}(B) \subseteq \text{FOLLOW}(A)$

**示例**：

```
产生式：
E → T E'
E' → + T E' | ε
T → F T'
T' → * F T' | ε
F → ( E ) | id

FOLLOW(E) = {$, )}
FOLLOW(E') = FOLLOW(E) = {$, )}
FOLLOW(T) = FIRST(E') ∪ FOLLOW(E) = {+, $, )}
FOLLOW(T') = FOLLOW(T) = {+, $, )}
FOLLOW(F) = FIRST(T') ∪ FOLLOW(T) = {*, +, $, )}
```

## 三、LL(1)分析表的构造

### 1. 构造算法

**步骤**：

1. **计算FIRST集和FOLLOW集**
2. **对于每个产生式 $A \to \alpha$**：
   - 对于每个 $a \in \text{FIRST}(\alpha)$，将产生式 $A \to \alpha$ 放入分析表 $M[A, a]$
   - 如果 $\varepsilon \in \text{FIRST}(\alpha)$，对于每个 $a \in \text{FOLLOW}(A)$，将产生式 $A \to \alpha$ 放入分析表 $M[A, a]$

### 2. 示例

**分析表**：

| 非终结符 | + | * | ( | ) | id | \$ |
|---------|---|---|---|---|----|---|
| **E** | - | - | E→TE' | - | E→TE' | - |
| **E'** | E'→+TE' | - | - | E'→ε | - | E'→ε |
| **T** | - | - | T→FT' | - | T→FT' | - |
| **T'** | T'→ε | T'→*FT' | - | T'→ε | - | T'→ε |
| **F** | - | - | F→(E) | - | F→id | - |

## 四、LL(1)分析过程

### 1. 分析器的组成

**组成部分**：

| 部分 | 说明 |
|-----|------|
| **分析栈** | 存放符号序列 |
| **输入缓冲区** | 存放输入token序列 |
| **分析表** | 指导分析过程 |
| **输出** | 产生式应用序列 |

### 2. 分析步骤

**算法**：

1. 将 $\$$ 和开始符号 $S$ 压入栈
2. 令 $a$ 为输入串的第一个token
3. 重复以下步骤直到栈为空：
   - 如果栈顶符号 $X$ 是终结符或 $\$$：
     - 如果 $X = a$，弹出 $X$，读取下一个token
     - 否则，报错
   - 如果栈顶符号 $X$ 是非终结符：
     - 如果 $M[X, a]$ 有产生式 $X \to \alpha$，弹出 $X$，将 $\alpha$ 逆序压入栈
     - 否则，报错

### 3. 示例

**输入**：`id + id * id $`

**分析过程**：

| 步骤 | 栈 | 输入 | 动作 |
|-----|-----|-----|-----|
| 1 | $\$E$ | `id + id * id $` | 应用 $E \to TE'$ |
| 2 | $\$E'T$ | `id + id * id $` | 应用 $T \to FT'$ |
| 3 | $\$E'T'F$ | `id + id * id $` | 应用 $F \to id$ |
| 4 | $\$E'T'id$ | `id + id * id $` | 匹配 `id` |
| 5 | $\$E'T'$ | `+ id * id $` | 应用 $T' \to \varepsilon$ |
| 6 | $\$E'$ | `+ id * id $` | 应用 $E' \to +TE'$ |
| 7 | $\$E'T+$ | `+ id * id $` | 匹配 `+` |
| 8 | $\$E'T$ | `id * id $` | 应用 $T \to FT'$ |
| 9 | $\$E'T'F$ | `id * id $` | 应用 $F \to id$ |
| 10 | $\$E'T'id$ | `id * id $` | 匹配 `id` |
| 11 | $\$E'T'$ | `* id $` | 应用 $T' \to *FT'$ |
| 12 | $\$E'T'F*$ | `* id $` | 匹配 `*` |
| 13 | $\$E'T'F$ | `id $` | 应用 $F \to id$ |
| 14 | $\$E'T'id$ | `id $` | 匹配 `id` |
| 15 | $\$E'T'$ | `$` | 应用 $T' \to \varepsilon$ |
| 16 | $\$E'$ | `$` | 应用 $E' \to \varepsilon$ |
| 17 | $\$$ | `$` | 匹配 $\$$，分析成功 |

## 五、LL(1)分析的优缺点

### 1. 优点

| 优点 | 说明 |
|-----|------|
| **确定性** | 分析过程完全确定 |
| **效率高** | 线性时间复杂度 |
| **易于实现** | 可以自动生成分析器 |

### 2. 缺点

| 缺点 | 说明 |
|-----|------|
| **文法限制** | 要求文法是LL(1)的 |
| **需要改写文法** | 消除左递归和提取左因子 |
| **错误处理** | 错误恢复能力有限 |

> [!warning] 易错点
> FIRST集和FOLLOW集的计算是LL(1)分析的关键！计算错误会导致分析表构造错误，从而导致分析失败。
