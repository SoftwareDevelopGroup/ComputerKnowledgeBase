# 4.2 算符优先分析法

> [!abstract] 核心问题
> 什么是算符优先关系？如何计算算符优先关系？如何进行算符优先分析？

## 一、算符优先关系的定义

### 1. 基本概念

**定义**：算符优先分析是一种基于终结符之间优先级关系的自下而上分析方法。

**算符优先关系**：

| 关系 | 含义 | 示例 |
|-----|------|------|
| $a \prec b$ | $a$ 的优先级低于 $b$ | `+` $\prec$ `*` |
| $a \succ b$ | $a$ 的优先级高于 $b$ | `*` $\succ$ `+` |
| $a = b$ | $a$ 和 $b$ 的优先级相同 | `(` = `)` |

### 2. 算符文法（Operator Grammar）

**定义**：如果文法中没有两个非终结符相邻，则该文法是算符文法。

**示例**：

```
算符文法：
E → E + T | T
T → T * F | F
F → ( E ) | id

非算符文法：
E → AB
A → a
B → b
```

## 二、算符优先关系的计算

### 1. FIRSTVT集

**定义**：对于非终结符 $A$，$\text{FIRSTVT}(A)$ 是 $A$ 推导的第一个终结符的集合。

**计算规则**：

1. 如果有产生式 $A \to a \alpha$ 或 $A \to B a \alpha$，则 $a \in \text{FIRSTVT}(A)$
2. 如果 $a \in \text{FIRSTVT}(B)$ 且有产生式 $A \to B \alpha$，则 $a \in \text{FIRSTVT}(A)$

### 2. LASTVT集

**定义**：对于非终结符 $A$，$\text{LASTVT}(A)$ 是 $A$ 推导的最后一个终结符的集合。

**计算规则**：

1. 如果有产生式 $A \to \alpha a$ 或 $A \to \alpha a B$，则 $a \in \text{LASTVT}(A)$
2. 如果 $a \in \text{LASTVT}(B)$ 且有产生式 $A \to \alpha B$，则 $a \in \text{LASTVT}(A)$

### 3. 算符优先关系的确定

**规则**：

1. **$a = b$**：如果有产生式 $A \to \alpha a b \beta$ 或 $A \to \alpha a B b \beta$
2. **$a \prec b$**：如果有产生式 $A \to \alpha a B \beta$ 且 $b \in \text{FIRSTVT}(B)$
3. **$a \succ b$**：如果有产生式 $A \to \alpha B b \beta$ 且 $a \in \text{LASTVT}(B)$

### 4. 示例

**文法**：

```
E → E + T | T
T → T * F | F
F → ( E ) | id
```

**FIRSTVT集**：

| 非终结符 | FIRSTVT |
|---------|---------|
| E | {+, *, (, id} |
| T | {*, (, id} |
| F | {(, id} |

**LASTVT集**：

| 非终结符 | LASTVT |
|---------|--------|
| E | {+, *, ), id} |
| T | {*, ), id} |
| F | {), id} |

**算符优先关系**：

| | id | + | * | ( | ) | \$ |
|-----|---|---|---|---|---|---|
| **id** | - | > | > | - | > | > |
| **+** | < | > | < | < | > | > |
| **\*** | < | > | > | < | > | > |
| **(** | < | < | < | < | = | - |
| **)** | > | > | > | - | > | > |
| **\$** | < | < | < | < | - | = |

## 三、算符优先分析过程

### 1. 分析器的组成

**组成部分**：

| 部分 | 说明 |
|-----|------|
| **栈** | 存放符号（终结符和非终结符） |
| **输入缓冲区** | 存放输入token序列 |
| **优先关系表** | 指导分析过程 |

### 2. 分析步骤

**算法**：

1. 将 $\$$ 压入栈
2. 读取输入串的第一个token $a$
3. 重复以下步骤直到栈顶为 $\$$ 且输入为 $\$$：
   - 令 $\theta$ 为栈顶终结符
   - 如果 $\theta \prec a$ 或 $\theta = a$：将 $a$ 移进栈，读取下一个token
   - 如果 $\theta \succ a$：从栈中弹出符号直到找到 $\theta' \prec \theta$，将弹出的符号序列归约为某个非终结符 $N$，将 $N$ 压入栈

### 3. 示例

**输入**：`id + id * id $`

**分析过程**：

| 步骤 | 栈 | 输入 | 优先关系 | 动作 |
|-----|-----|-----|---------|------|
| 1 | `$` | `id + id * id $` | $\$ \prec id$ | 移进 |
| 2 | `$id` | `+ id * id $` | $id \succ +$ | 归约 $F \to id$ |
| 3 | `$F` | `+ id * id $` | $\$ \prec +$ | 移进 |
| 4 | `$F+` | `id * id $` | $+ \prec id$ | 移进 |
| 5 | `$F+id` | `* id $` | $id \succ *$ | 归约 $F \to id$ |
| 6 | `$F+F` | `* id $` | $+ \prec *$ | 移进 |
| 7 | `$F+F*` | `id $` | $* \prec id$ | 移进 |
| 8 | `$F+F*id` | `$` | $id \succ \$$ | 归约 $F \to id$ |
| 9 | `$F+F*F` | `$` | $* \succ \$$ | 归约 $T \to T * F$ |
| 10 | `$F+F` | `$` | $+ \succ \$$ | 归约 $E \to E + T$ |
| 11 | `$F` | `$` | $\$ \prec \$$ | 归约 $E \to T$ |
| 12 | `$E` | `$` | $\$ = \$$ | 接受 |

## 四、算符优先分析的优缺点

### 1. 优点

| 优点 | 说明 |
|-----|------|
| **实现简单** | 优先关系表易于构造 |
| **效率高** | 分析速度快 |
| **适合表达式** | 特别适合表达式文法 |

### 2. 缺点

| 缺点 | 说明 |
|-----|------|
| **文法限制** | 只能处理算符文法 |
| **能力有限** | 不能处理所有CFG |
| **错误处理** | 错误恢复能力有限 |

## 五、算符优先分析的扩展

### 1. 扩展算符优先分析

**方法**：
- 处理更复杂的表达式
- 支持不同优先级的运算符

### 2. 二义文法的处理

**方法**：
- 通过优先关系消除二义性
- 不需要改写文法

**示例**：

```
二义文法：
E → E + E | E * E | id

通过优先关系：
+ < *（*的优先级高于+）
+ > +（+左结合）
* > *（*左结合）
```

> [!warning] 易错点
> 算符优先分析只考虑终结符之间的优先关系！非终结符之间的关系不直接考虑，而是通过FIRSTVT和LASTVT间接考虑。
