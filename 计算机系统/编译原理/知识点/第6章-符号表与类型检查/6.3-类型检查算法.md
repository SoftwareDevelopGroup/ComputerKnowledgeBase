# 6.3 类型检查算法

> [!abstract] 核心问题
> 如何进行类型检查？表达式和语句的类型检查算法是什么？

## 一、类型检查的基本概念

### 1. 类型检查的定义

**定义**：类型检查是验证程序中表达式和语句的类型是否正确的过程。

**目的**：

| 目的 | 说明 |
|-----|------|
| **检测错误** | 检测类型错误 |
| **保证安全** | 保证程序运行安全 |
| **优化代码** | 支持代码优化 |

### 2. 类型检查的分类

**编译时类型检查**：

**定义**：在编译阶段进行类型检查。

**优点**：
- 错误检测及时
- 性能好

**缺点**：
- 灵活性较低

**运行时类型检查**：

**定义**：在运行阶段进行类型检查。

**优点**：
- 灵活性高
- 支持动态类型

**缺点**：
- 性能较低
- 错误检测晚

### 3. 类型检查的范围

**表达式类型检查**：

**定义**：检查表达式的类型是否正确。

**示例**：

```
int x = 5;
int y = x + 3;  // 正确
int z = x + "hello";  // 错误
```

**语句类型检查**：

**定义**：检查语句的类型是否正确。

**示例**：

```
void f() {
    int x = 5;
    return x;  // 错误：返回类型不匹配
}
```

## 二、表达式类型检查算法

### 1. 基本表达式

**算法**：

1. 如果是常量，返回常量的类型
2. 如果是变量，从符号表查找变量的类型
3. 如果是函数调用，检查参数类型是否匹配，返回函数的返回类型

**示例**：

```java
Type checkExpression(Expression expr) {
    if (expr instanceof Constant) {
        return expr.getType();
    } else if (expr instanceof Variable) {
        return symbolTable.lookup(expr.getName()).getType();
    } else if (expr instanceof FunctionCall) {
        Function func = symbolTable.lookup(expr.getFunctionName());
        List<Type> argTypes = checkArguments(expr.getArguments());
        if (argTypes.equals(func.getParameterTypes())) {
            return func.getReturnType();
        } else {
            throw new TypeMismatchError();
        }
    }
}
```

### 2. 算术表达式

**算法**：

1. 检查操作数的类型是否都是数值类型
2. 如果是，返回结果类型（通常是int或double）
3. 如果不是，报告类型错误

**示例**：

```java
Type checkArithmeticExpression(ArithmeticExpression expr) {
    Type leftType = checkExpression(expr.getLeft());
    Type rightType = checkExpression(expr.getRight());
    
    if (isNumericType(leftType) && isNumericType(rightType)) {
        return promoteTypes(leftType, rightType);
    } else {
        throw new TypeMismatchError();
    }
}
```

### 3. 关系表达式

**算法**：

1. 检查操作数的类型是否兼容
2. 如果是，返回boolean类型
3. 如果不是，报告类型错误

**示例**：

```java
Type checkRelationalExpression(RelationalExpression expr) {
    Type leftType = checkExpression(expr.getLeft());
    Type rightType = checkExpression(expr.getRight());
    
    if (areCompatible(leftType, rightType)) {
        return BooleanType.getInstance();
    } else {
        throw new TypeMismatchError();
    }
}
```

### 4. 赋值表达式

**算法**：

1. 检查左操作数的类型是否可赋值
2. 检查右操作数的类型是否与左操作数兼容
3. 如果兼容，返回void类型
4. 如果不兼容，报告类型错误

**示例**：

```java
void checkAssignment(AssignmentExpression expr) {
    Type leftType = checkExpression(expr.getLeft());
    Type rightType = checkExpression(expr.getRight());
    
    if (isAssignable(leftType, rightType)) {
        return;
    } else {
        throw new TypeMismatchError();
    }
}
```

## 三、语句类型检查算法

### 1. 条件语句

**算法**：

1. 检查条件表达式的类型是否是boolean
2. 检查真分支和假分支的类型是否正确

**示例**：

```java
void checkIfStatement(IfStatement stmt) {
    Type conditionType = checkExpression(stmt.getCondition());
    if (!conditionType.equals(BooleanType.getInstance())) {
        throw new TypeMismatchError();
    }
    checkStatement(stmt.getThenBranch());
    if (stmt.getElseBranch() != null) {
        checkStatement(stmt.getElseBranch());
    }
}
```

### 2. 循环语句

**算法**：

1. 检查条件表达式的类型是否是boolean
2. 检查循环体的类型是否正确

**示例**：

```java
void checkWhileStatement(WhileStatement stmt) {
    Type conditionType = checkExpression(stmt.getCondition());
    if (!conditionType.equals(BooleanType.getInstance())) {
        throw new TypeMismatchError();
    }
    checkStatement(stmt.getBody());
}
```

### 3. 函数声明

**算法**：

1. 检查参数类型是否正确
2. 检查返回类型是否正确
3. 检查函数体内的语句是否符合返回类型

**示例**：

```java
void checkFunctionDeclaration(FunctionDeclaration decl) {
    for (Parameter param : decl.getParameters()) {
        checkType(param.getType());
    }
    checkType(decl.getReturnType());
    checkStatement(decl.getBody());
}
```

### 4. 返回语句

**算法**：

1. 检查返回表达式的类型是否与函数返回类型兼容
2. 如果兼容，返回void类型
3. 如果不兼容，报告类型错误

**示例**：

```java
void checkReturnStatement(ReturnStatement stmt) {
    Type returnType = currentFunction.getReturnType();
    Type exprType = checkExpression(stmt.getExpression());
    
    if (isCompatible(returnType, exprType)) {
        return;
    } else {
        throw new TypeMismatchError();
    }
}
```

## 四、类型检查的实现

### 1. 属性文法方法

**方法**：使用属性文法描述类型检查规则。

**示例**：

```
产生式：E → E1 + E2
语义规则：
  E.type = if E1.type == E2.type && E1.type is numeric
           then E1.type
           else error
```

### 2. 递归下降方法

**方法**：在递归下降分析中进行类型检查。

**示例**：

```java
Type E() {
    Type e1 = E();
    match('+');
    Type e2 = E();
    
    if (isNumeric(e1) && isNumeric(e2)) {
        return promote(e1, e2);
    } else {
        throw new TypeError();
    }
}
```

### 3. 数据流分析方法

**方法**：使用数据流分析进行类型检查。

**示例**：

```mermaid

    A[数据流分析] --> B[类型推断]
    B --> C[类型检查]
```

## 五、类型检查的优化

### 1. 常量折叠

**优化**：编译时计算常量表达式。

**示例**：

```
int x = 5 + 3;  // 优化为 int x = 8;
```

### 2. 类型推断

**优化**：自动推断表达式的类型。

**示例**：

```
// Java 10+
var x = 5;  // 推断为int
var y = "hello";  // 推断为String
```

### 3. 泛型检查

**优化**：检查泛型类型的兼容性。

**示例**：

```
List<String> list = new ArrayList<>();
list.add("hello");  // 正确
list.add(5);  // 错误：类型不匹配
```

## 六、类型检查的重要性

### 1. 保证程序正确性

**作用**：
- 检测类型错误
- 防止运行时错误

### 2. 支持代码优化

**作用**：
- 常量传播
- 死代码消除
- 表达式优化

### 3. 提高代码可读性

**作用**：
- 类型信息作为文档
- 代码更清晰

> [!warning] 易错点
> 类型检查不仅检测错误，还收集类型信息！这些信息对于后续的代码优化和代码生成至关重要。
