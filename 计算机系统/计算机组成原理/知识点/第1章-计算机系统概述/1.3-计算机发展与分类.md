# 1.3 计算机发展与分类

> [!abstract] 核心问题
> 计算机经历了哪些发展阶段？计算机如何分类？各代计算机的特点是什么？

## 一、计算机发展历程

### 1. 第一代计算机（1946-1957）

**电子管时代**

**特点**：

| 特点 | 说明 |
|-----|------|
| **元器件** | 电子管 |
| **内存** | 水银延迟线、磁鼓 |
| **外存** | 纸带、卡片 |
| **语言** | 机器语言、汇编语言 |
| **速度** | 几千次/秒 |
| **代表** | ENIAC、EDVAC |

**ENIAC**：

```
诞生时间：1946年
地点：美国宾夕法尼亚大学
特点：
- 第一台电子数字计算机
- 使用18000个电子管
- 重量30吨
- 功耗150千瓦
- 运算速度：5000次/秒
```

### 2. 第二代计算机（1958-1964）

**晶体管时代**

**特点**：

| 特点 | 说明 |
|-----|------|
| **元器件** | 晶体管 |
| **内存** | 磁芯存储器 |
| **外存** | 磁盘、磁带 |
| **语言** | 高级语言（FORTRAN、COBOL） |
| **速度** | 几十万次/秒 |
| **代表** | IBM 7090 |

**优势**：

| 优势 | 说明 |
|-----|------|
| **体积小** | 比电子管小很多 |
| **功耗低** | 比电子管低很多 |
| **寿命长** | 比电子管长很多 |

### 3. 第三代计算机（1965-1970）

**集成电路时代**

**特点**：

| 特点 | 说明 |
|-----|------|
| **元器件** | 中规模集成电路（MSI） |
| **内存** | 半导体存储器（DRAM） |
| **外存** | 硬盘、软盘 |
| **语言** | 结构化程序设计语言 |
| **速度** | 几百万次/秒 |
| **代表** | IBM System/360 |

**IBM System/360**：

```
特点：
- 系列化计算机
- 兼容的指令系统
- 统一的操作系统
```

### 4. 第四代计算机（1971-至今）

**大规模集成电路时代**

**特点**：

| 特点 | 说明 |
|-----|------|
| **元器件** | 大规模集成电路（LSI）、超大规模集成电路（VLSI） |
| **内存** | 大容量DRAM、SRAM |
| **外存** | 大容量硬盘、SSD |
| **语言** | 面向对象语言（C++、Java） |
| **速度** | 几亿次/秒到几十亿次/秒 |
| **代表** | 个人计算机、工作站 |

**里程碑**：

| 里程碑 | 说明 |
|-----|------|
| **微处理器** | 1971年Intel 4004 |
| **个人计算机** | 1981年IBM PC |
| **互联网** | 1983年TCP/IP协议 |
| **智能手机** | 2007年iPhone |

## 二、计算机分类

### 1. 按用途分类

**通用计算机**：

**定义**：适用于多种应用场景的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **灵活性高** | 可以运行多种程序 |
| **适用范围广** | 适用于科学计算、数据处理、办公等 |
| **代表** | 个人计算机、服务器 |

**专用计算机**：

**定义**：专门用于特定应用场景的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **效率高** | 针对特定任务优化 |
| **功能单一** | 只执行特定任务 |
| **代表** | 嵌入式系统、工业控制计算机 |

### 2. 按规模分类

**巨型计算机**：

**定义**：性能最高、规模最大的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **性能高** | 每秒万亿次以上浮点运算 |
| **规模大** | 占地面积大、功耗高 |
| **用途** | 科学计算、天气预报、国防 |
| **代表** | 天河系列、神威系列 |

**大型计算机**：

**定义**：性能较高、规模较大的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **性能较高** | 每秒几十亿次运算 |
| **规模较大** | 适合企业级应用 |
| **用途** | 大型数据库、企业管理 |
| **代表** | IBM Z系列 |

**中型计算机**：

**定义**：性能中等、规模适中的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **性能中等** | 适合中小型企业 |
| **规模适中** | 价格相对较低 |
| **用途** | 中小型数据库、办公自动化 |

**小型计算机**：

**定义**：性能较低、规模较小的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **性能较低** | 适合个人或小型团队 |
| **规模较小** | 价格较低 |
| **用途** | 个人办公、学习 |
| **代表** | 个人计算机、笔记本电脑 |

### 3. 按处理数据类型分类

**数字计算机**：

**定义**：处理数字数据的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **精度高** | 可以精确表示数字 |
| **通用性强** | 适用于各种计算 |
| **代表** | 大多数计算机 |

**模拟计算机**：

**定义**：处理模拟数据的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **速度快** | 直接处理连续信号 |
| **精度低** | 受限于模拟电路 |
| **用途** | 连续系统仿真、过程控制 |

**混合计算机**：

**定义**：同时处理数字数据和模拟数据的计算机。

**特点**：

| 特点 | 说明 |
|-----|------|
| **兼顾精度和速度** | 结合数字和模拟的优点 |
| **用途** | 复杂系统仿真 |

## 三、计算机发展趋势

### 1. 高性能化

**方向**：

| 方向 | 说明 |
|-----|------|
| **多核处理器** | 增加CPU核心数量 |
| **并行计算** | 利用多处理器协同工作 |
| **量子计算** | 利用量子力学原理 |

### 2. 微型化

**方向**：

| 方向 | 说明 |
|-----|------|
| **移动设备** | 智能手机、平板电脑 |
| **嵌入式系统** | 物联网设备、传感器 |
| **可穿戴设备** | 智能手表、智能眼镜 |

### 3. 网络化

**方向**：

| 方向 | 说明 |
|-----|------|
| **云计算** | 通过网络提供计算服务 |
| **边缘计算** | 在网络边缘进行计算 |
| **分布式系统** | 多计算机协同工作 |

### 4. 智能化

**方向**：

| 方向 | 说明 |
|-----|------|
| **人工智能** | 机器学习、深度学习 |
| **自然语言处理** | 理解和生成自然语言 |
| **计算机视觉** | 识别和理解图像 |

> [!warning] 易错点
> 第一代计算机使用电子管，第二代使用晶体管，第三代使用集成电路，第四代使用大规模集成电路！不要混淆各代计算机的元器件。
