# 1.2 计算机性能评价指标

> [!abstract] 核心问题
> 衡量计算机性能的主要指标有哪些？如何计算和理解这些指标？

## 一、基本性能指标

### 1. 主频

**定义**：主频是CPU的时钟频率，表示CPU每秒能执行的时钟周期数。

**单位**：

| 单位 | 说明 |
|-----|------|
| **Hz** | 赫兹，每秒一个周期 |
| **MHz** | 兆赫兹，$10^6$ Hz |
| **GHz** | 吉赫兹，$10^9$ Hz |

**示例**：

```
CPU主频：3.0 GHz
含义：CPU每秒执行30亿个时钟周期
```

### 2. 时钟周期

**定义**：时钟周期是CPU完成一个基本操作所需的时间。

**计算公式**：

$$时钟周期 = \frac{1}{主频}$$

**示例**：

```
CPU主频：3.0 GHz
时钟周期 = 1 / 3.0 GHz = 0.33 ns
```

### 3. 指令周期

**定义**：指令周期是CPU执行一条指令所需的时间。

**组成**：

| 阶段 | 说明 |
|-----|------|
| **取指周期** | 从存储器中取出指令 |
| **执行周期** | 执行指令 |
| **访存周期** | 访问存储器（如果需要） |
| **中断周期** | 处理中断（如果需要） |

**示例**：

```
指令周期 = 取指周期 + 执行周期
```

## 二、运算速度指标

### 1. CPI（Clock Cycles Per Instruction）

**定义**：CPI是执行一条指令所需的平均时钟周期数。

**计算公式**：

$$CPI = \frac{总时钟周期数}{总指令数}$$

**示例**：

```
总时钟周期数：10亿
总指令数：5000万
CPI = 10亿 / 5000万 = 20
含义：平均每条指令需要20个时钟周期
```

### 2. MIPS（Millions of Instructions Per Second）

**定义**：MIPS是每秒执行的百万条指令数。

**计算公式**：

$$MIPS = \frac{主频}{CPI \times 10^6}$$

**示例**：

```
主频：3.0 GHz
CPI：20
MIPS = 3.0 GHz / (20 × 10^6) = 150
含义：每秒执行1.5亿条指令
```

### 3. FLOPS（Floating Point Operations Per Second）

**定义**：FLOPS是每秒执行的浮点运算次数。

**单位**：

| 单位 | 说明 |
|-----|------|
| **MFLOPS** | 百万次浮点运算/秒 |
| **GFLOPS** | 十亿次浮点运算/秒 |
| **TFLOPS** | 万亿次浮点运算/秒 |
| **PFLOPS** | 千万亿次浮点运算/秒 |

**示例**：

```
GPU性能：10 TFLOPS
含义：每秒执行10万亿次浮点运算
```

### 4. IPS（Instructions Per Second）

**定义**：IPS是每秒执行的指令数。

**计算公式**：

$$IPS = \frac{主频}{CPI}$$

**示例**：

```
主频：3.0 GHz
CPI：20
IPS = 3.0 GHz / 20 = 150 MIPS = 1.5亿条指令/秒
```

## 三、系统性能指标

### 1. 响应时间

**定义**：响应时间是从用户提交请求到系统返回结果的时间。

**组成**：

| 组成 | 说明 |
|-----|------|
| **CPU时间** | CPU执行程序的时间 |
| **I/O时间** | 等待I/O操作的时间 |
| **内存访问时间** | 访问内存的时间 |

**示例**：

```
程序响应时间：500 ms
其中：CPU时间 = 100 ms，I/O时间 = 300 ms，内存访问时间 = 100 ms
```

### 2. 吞吐率

**定义**：吞吐率是单位时间内系统处理的任务数。

**计算公式**：

$$吞吐率 = \frac{任务数}{时间}$$

**示例**：

```
服务器一小时处理10000个请求
吞吐率 = 10000 / 3600 ≈ 2.78 请求/秒
```

### 3. 利用率

**定义**：利用率是资源被使用的时间比例。

**计算公式**：

$$利用率 = \frac{使用时间}{总时间} \times 100\%$$

**示例**：

```
CPU一天工作8小时
利用率 = 8 / 24 × 100% ≈ 33.3%
```

## 四、存储性能指标

### 1. 存储容量

**定义**：存储容量是存储器能够存储的数据量。

**单位**：

| 单位 | 说明 |
|-----|------|
| **Byte** | 字节，8位 |
| **KB** | 千字节，$2^{10}$ Byte |
| **MB** | 兆字节，$2^{20}$ Byte |
| **GB** | 吉字节，$2^{30}$ Byte |
| **TB** | 太字节，$2^{40}$ Byte |

**示例**：

```
内存容量：16 GB = 16 × 2^30 Byte ≈ 171.8亿 Byte
```

### 2. 存储速度

**定义**：存储速度是存储器读写数据的速度。

**指标**：

| 指标 | 说明 |
|-----|------|
| **存取时间** | 从发出读写请求到完成操作的时间 |
| **存取周期** | 两次连续存取操作之间的时间 |
| **带宽** | 单位时间内传输的数据量 |

**示例**：

```
内存存取时间：10 ns
内存带宽：32 GB/s
```

## 五、性能指标的关系

### 1. 核心公式

**CPU时间计算**：

$$CPU时间 = \frac{指令数 \times CPI}{主频}$$

**性能与CPI的关系**：

| 关系 | 说明 |
|-----|------|
| **CPI越小** | 性能越好 |
| **CPI越大** | 性能越差 |

### 2. 性能对比

**示例**：

```
计算机A：主频2.0 GHz，CPI=10
计算机B：主频3.0 GHz，CPI=20

计算机A的CPU时间 = 指令数 × 10 / 2.0 GHz
计算机B的CPU时间 = 指令数 × 20 / 3.0 GHz

性能对比：计算机A的性能 / 计算机B的性能 = (20/3) / (10/2) = 4/3 ≈ 1.33
结论：计算机A的性能是计算机B的1.33倍
```

### 3. 性能误区

**误区**：

| 误区 | 纠正 |
|-----|------|
| **主频越高性能越好** | 主频只是性能指标之一，还需要考虑CPI |
| **核心越多性能越好** | 多核性能取决于程序的并行度 |
| **内存越大性能越好** | 内存容量需要与CPU和应用匹配 |

> [!warning] 易错点
> CPU时间不等于响应时间！CPU时间只是响应时间的一部分，响应时间还包括I/O时间、内存访问时间等。
