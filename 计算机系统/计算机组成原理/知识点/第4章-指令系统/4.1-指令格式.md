# 4.1 指令格式

> [!abstract] 核心问题
> 指令的格式是怎样的？操作码和地址码的作用是什么？常见的寻址方式有哪些？

## 一、指令的组成

### 1. 指令的基本格式

**定义**：指令是计算机执行的基本命令，由操作码和地址码组成。

**格式**：

```
| 操作码 | 地址码 |
```

**组成**：

| 组成 | 说明 |
|-----|------|
| **操作码** | 表示指令的操作类型 |
| **地址码** | 表示操作数的地址 |

**示例**：

```
指令格式：
| OP(6位) | A1(10位) | A2(10位) | A3(10位) |

含义：
- OP：操作码，6位，可以表示64种操作
- A1：源操作数地址
- A2：源操作数地址
- A3：目的操作数地址
```

### 2. 操作码

**定义**：操作码是指令中表示操作类型的部分。

**编码方式**：

| 方式 | 说明 |
|-----|------|
| **固定长度** | 操作码长度固定 |
| **可变长度** | 操作码长度可变 |

**固定长度编码**：

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 译码简单，速度快 |
| **缺点** | 浪费空间 |

**示例**：

```
6位操作码：
000000：ADD（加法）
000001：SUB（减法）
000010：MUL（乘法）
000011：DIV（除法）
```

**可变长度编码**：

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 节省空间 |
| **缺点** | 译码复杂，速度慢 |

**示例**：

```
可变长度操作码：
0：单地址指令
10：双地址指令
110：三地址指令
111：特殊指令
```

### 3. 地址码

**定义**：地址码是指令中表示操作数地址的部分。

**地址码格式**：

| 格式 | 说明 |
|-----|------|
| **零地址指令** | 没有地址码 |
| **一地址指令** | 一个地址码 |
| **二地址指令** | 两个地址码 |
| **三地址指令** | 三个地址码 |

**零地址指令**：

**格式**：

```
| OP |
```

**示例**：

```
NOP（空操作）：000000
HALT（停机）：000001
```

**一地址指令**：

**格式**：

```
| OP | A |
```

**示例**：

```
INC A（A加1）
DEC A（A减1）
```

**二地址指令**：

**格式**：

```
| OP | A1 | A2 |
```

**示例**：

```
ADD A1, A2（A1 = A1 + A2）
SUB A1, A2（A1 = A1 - A2）
```

**三地址指令**：

**格式**：

```
| OP | A1 | A2 | A3 |
```

**示例**：

```
ADD A1, A2, A3（A3 = A1 + A2）
MUL A1, A2, A3（A3 = A1 × A2）
```

## 二、寻址方式

### 1. 寻址方式的定义

**定义**：寻址方式是确定操作数地址的方法。

**分类**：

| 分类 | 说明 |
|-----|------|
| **立即寻址** | 操作数在指令中 |
| **直接寻址** | 操作数地址在指令中 |
| **间接寻址** | 操作数地址的地址在指令中 |
| **寄存器寻址** | 操作数在寄存器中 |
| **寄存器间接寻址** | 操作数地址在寄存器中 |
| **变址寻址** | 操作数地址 = 变址寄存器 + 位移量 |
| **相对寻址** | 操作数地址 = PC + 位移量 |
| **基址寻址** | 操作数地址 = 基址寄存器 + 位移量 |

### 2. 立即寻址

**定义**：操作数直接包含在指令中。

**格式**：

```
| OP | 立即数 |
```

**示例**：

```
ADD AX, #5（AX = AX + 5）
MOV BX, #10（BX = 10）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 不需要访问内存 |
| **缺点** | 操作数范围有限 |

### 3. 直接寻址

**定义**：操作数的地址直接包含在指令中。

**格式**：

```
| OP | 地址 |
```

**示例**：

```
ADD AX, [1000H]（AX = AX + 内存[1000H]）
MOV BX, [2000H]（BX = 内存[2000H]）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 简单直观 |
| **缺点** | 地址范围有限 |

### 4. 间接寻址

**定义**：指令中包含的是操作数地址的地址。

**格式**：

```
| OP | 地址的地址 |
```

**示例**：

```
ADD AX, [[1000H]]（AX = AX + 内存[内存[1000H]]）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 地址范围大 |
| **缺点** | 需要两次访问内存 |

### 5. 寄存器寻址

**定义**：操作数在寄存器中。

**格式**：

```
| OP | 寄存器 |
```

**示例**：

```
ADD AX, BX（AX = AX + BX）
MOV CX, DX（CX = DX）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 速度快 |
| **缺点** | 寄存器数量有限 |

### 6. 寄存器间接寻址

**定义**：操作数的地址在寄存器中。

**格式**：

```
| OP | 寄存器 |
```

**示例**：

```
ADD AX, [BX]（AX = AX + 内存[BX]）
MOV CX, [DX]（CX = 内存[DX]）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 灵活，地址范围大 |
| **缺点** | 需要访问内存 |

### 7. 变址寻址

**定义**：操作数地址 = 变址寄存器 + 位移量。

**格式**：

```
| OP | 位移量 | 变址寄存器 |
```

**示例**：

```
ADD AX, [SI + 100H]（AX = AX + 内存[SI + 100H]）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 适合数组访问 |
| **缺点** | 需要计算地址 |

### 8. 相对寻址

**定义**：操作数地址 = PC + 位移量。

**格式**：

```
| OP | 位移量 |
```

**示例**：

```
JMP +5（跳转到PC + 5的位置）
JMP -10（跳转到PC - 10的位置）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 程序可重定位 |
| **缺点** | 跳转范围有限 |

### 9. 基址寻址

**定义**：操作数地址 = 基址寄存器 + 位移量。

**格式**：

```
| OP | 位移量 | 基址寄存器 |
```

**示例**：

```
ADD AX, [BX + 100H]（AX = AX + 内存[BX + 100H]）
```

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 适合分段存储 |
| **缺点** | 需要计算地址 |

## 三、指令长度

### 1. 指令长度的定义

**定义**：指令长度是指令占用的二进制位数。

**分类**：

| 分类 | 说明 |
|-----|------|
| **固定长度** | 所有指令长度相同 |
| **可变长度** | 指令长度不同 |

**固定长度指令**：

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 结构简单，便于取指令 |
| **缺点** | 浪费空间 |

**示例**：

```
所有指令都是32位
```

**可变长度指令**：

**特点**：

| 特点 | 说明 |
|-----|------|
| **优点** | 节省空间 |
| **缺点** | 结构复杂，取指令困难 |

**示例**：

```
指令长度：16位、32位、64位
```

### 2. 指令长度的选择

**因素**：

| 因素 | 说明 |
|-----|------|
| **操作码长度** | 操作码越长，表示的操作越多 |
| **地址码长度** | 地址码越长，寻址范围越大 |
| **指令类型** | 不同类型的指令长度不同 |

**设计原则**：

| 原则 | 说明 |
|-----|------|
| **平衡** | 平衡操作码和地址码的长度 |
| **优化** | 优化常用指令的长度 |
| **兼容** | 保持与现有指令系统的兼容性 |

## 四、指令格式的设计

### 1. 设计原则

**原则**：

| 原则 | 说明 |
|-----|------|
| **完备性** | 指令系统应包含所有必要的操作 |
| **有效性** | 指令应能高效地完成操作 |
| **规整性** | 指令格式应规整统一 |
| **兼容性** | 新指令系统应兼容旧指令系统 |

### 2. 设计步骤

**步骤**：

1. 确定操作码的编码方式
2. 确定地址码的格式
3. 确定指令的长度
4. 设计寻址方式
5. 验证指令系统的完整性

> [!warning] 易错点
> 间接寻址需要两次访问内存！第一次访问获取操作数的地址，第二次访问获取操作数。
