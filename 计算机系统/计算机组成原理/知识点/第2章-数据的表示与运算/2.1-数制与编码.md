# 2.1 数制与编码

> [!abstract] 核心问题
> 什么是数制？如何进行数制转换？常见的编码有哪些？

## 一、数制的概念

### 1. 数制的定义

**定义**：数制是计数的规则，即表示数值的方法。

**基数**：

| 数制 | 基数 | 数码 |
|-----|------|------|
| **十进制** | 10 | 0-9 |
| **二进制** | 2 | 0-1 |
| **八进制** | 8 | 0-7 |
| **十六进制** | 16 | 0-9, A-F |

### 2. 位权

**定义**：位权是每个数位上的数码所代表的数值大小。

**计算公式**：

$$位权 = 基数^{位置}$$

**示例**：

```
十进制数 123.45：
- 1的位权：10^2 = 100
- 2的位权：10^1 = 10
- 3的位权：10^0 = 1
- 4的位权：10^-1 = 0.1
- 5的位权：10^-2 = 0.01

二进制数 101.1：
- 1的位权：2^2 = 4
- 0的位权：2^1 = 2
- 1的位权：2^0 = 1
- 1的位权：2^-1 = 0.5
```

## 二、数制转换

### 1. 十进制转二进制

**整数部分**：

**方法**：除2取余法

**步骤**：

1. 将十进制数除以2，取余数
2. 将商继续除以2，取余数
3. 重复步骤2，直到商为0
4. 将余数从下往上排列

**示例**：

```
十进制数 13 转二进制：
13 ÷ 2 = 6 余 1
6 ÷ 2 = 3 余 0
3 ÷ 2 = 1 余 1
1 ÷ 2 = 0 余 1

余数从下往上：1101
结果：13 = 1101B
```

**小数部分**：

**方法**：乘2取整法

**步骤**：

1. 将小数部分乘以2，取整数部分
2. 将小数部分继续乘以2，取整数部分
3. 重复步骤2，直到小数部分为0或达到精度要求
4. 将整数部分从上往下排列

**示例**：

```
十进制数 0.625 转二进制：
0.625 × 2 = 1.25 取整 1
0.25 × 2 = 0.5 取整 0
0.5 × 2 = 1.0 取整 1

整数部分从上往下：101
结果：0.625 = 0.101B
```

### 2. 二进制转十进制

**方法**：按位权展开法

**计算公式**：

$$十进制数 = \sum_{i=-n}^{m} a_i \times 2^i$$

**示例**：

```
二进制数 1101.101 转十进制：
1 × 2^3 + 1 × 2^2 + 0 × 2^1 + 1 × 2^0 + 1 × 2^-1 + 0 × 2^-2 + 1 × 2^-3
= 8 + 4 + 0 + 1 + 0.5 + 0 + 0.125
= 13.625
```

### 3. 二进制转十六进制

**方法**：四位一组法

**步骤**：

1. 将二进制数从右往左每四位一组
2. 将每组转换为对应的十六进制数
3. 将结果从左往右排列

**示例**：

```
二进制数 11010110 转十六进制：
分组：1101 0110
转换：D    6
结果：11010110B = D6H
```

### 4. 十六进制转二进制

**方法**：一位拆四位法

**步骤**：

1. 将每个十六进制数转换为对应的四位二进制数
2. 将结果从左往右排列

**示例**：

```
十六进制数 D6 转二进制：
D → 1101
6 → 0110
结果：D6H = 11010110B
```

## 三、常用编码

### 1. ASCII码

**定义**：ASCII码是美国信息交换标准代码，用于表示字符。

**编码规则**：

| 范围 | 说明 |
|-----|------|
| 0-31 | 控制字符 |
| 32 | 空格 |
| 48-57 | 数字0-9 |
| 65-90 | 大写字母A-Z |
| 97-122 | 小写字母a-z |

**示例**：

```
字符 'A' 的ASCII码：65（十进制）= 1000001B
字符 '0' 的ASCII码：48（十进制）= 0110000B
```

### 2. BCD码

**定义**：BCD码是二-十进制编码，用四位二进制表示一位十进制数。

**编码规则**：

| 十进制数 | BCD码 |
|---------|-------|
| 0 | 0000 |
| 1 | 0001 |
| 2 | 0010 |
| 3 | 0011 |
| 4 | 0100 |
| 5 | 0101 |
| 6 | 0110 |
| 7 | 0111 |
| 8 | 1000 |
| 9 | 1001 |

**示例**：

```
十进制数 123 转BCD码：
1 → 0001
2 → 0010
3 → 0011
结果：0001 0010 0011
```

### 3. Unicode

**定义**：Unicode是统一字符编码标准，支持多种语言。

**编码方式**：

| 编码 | 说明 |
|-----|------|
| **UTF-8** | 变长编码，兼容ASCII |
| **UTF-16** | 固定16位编码 |
| **UTF-32** | 固定32位编码 |

**示例**：

```
字符 '中' 的Unicode编码：U+4E2D
UTF-8编码：E4 B8 AD
```

### 4. 格雷码

**定义**：格雷码是一种无权码，相邻两个数只有一位不同。

**特点**：

| 特点 | 说明 |
|-----|------|
| **相邻性** | 相邻两个数只有一位不同 |
| **反射性** | 以中间为对称轴，上下对称 |
| **用途** | 减少数字电路中的错误 |

**示例**：

```
二进制码：0000 0001 0010 0011 0100
格雷码：  0000 0001 0011 0010 0110
```

## 四、数制与编码的应用

### 1. 计算机内部表示

**原则**：

| 原则 | 说明 |
|-----|------|
| **二进制** | 计算机内部使用二进制 |
| **编码** | 使用ASCII、Unicode等编码表示字符 |
| **BCD码** | 用于十进制计算 |

### 2. 数据存储

**示例**：

```
整数 123 在计算机中的存储：
- 二进制：1111011
- 字节表示：00000000 00000000 00000000 01111011（32位）
```

### 3. 数据传输

**示例**：

```
网络传输中的数据：
- 使用二进制表示
- 使用ASCII码表示文本
- 使用Unicode表示多语言文本
```

> [!warning] 易错点
> 二进制转十六进制时要从右往左分组！如果位数不够，要在左边补零。
