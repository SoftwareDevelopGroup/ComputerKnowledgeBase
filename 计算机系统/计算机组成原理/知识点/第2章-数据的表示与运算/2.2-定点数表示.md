# 2.2 定点数表示

> [!abstract] 核心问题
> 什么是定点数？原码、反码、补码、移码的定义和计算方法是什么？如何判断溢出？

## 一、定点数的概念

### 1. 定点数的定义

**定义**：定点数是小数点位置固定的数。

**分类**：

| 分类 | 说明 |
|-----|------|
| **定点整数** | 小数点固定在最低位之后 |
| **定点小数** | 小数点固定在最高位之前 |

**示例**：

```
定点整数：1011（表示十进制数11）
定点小数：0.1011（表示十进制数0.6875）
```

### 2. 定点数的范围

**定点整数**：

**计算公式**：

$$范围 = [-2^{n-1}, 2^{n-1} - 1]$$

**示例**：

```
n = 8位定点整数：
范围 = [-2^7, 2^7 - 1] = [-128, 127]
```

**定点小数**：

**计算公式**：

$$范围 = [-1 + 2^{-(n-1)}, 1 - 2^{-(n-1)}]$$

**示例**：

```
n = 8位定点小数：
范围 = [-1 + 2^-7, 1 - 2^-7] = [-0.9921875, 0.9921875]
```

## 二、原码表示

### 1. 原码的定义

**定义**：原码是符号位加数值位的表示方法。

**编码规则**：

| 符号 | 说明 |
|-----|------|
| **0** | 正数 |
| **1** | 负数 |

**定点整数原码**：

**计算公式**：

$$[x]_原 = \begin{cases} 
x & 0 \leq x < 2^{n-1} \\
2^{n-1} - x & -2^{n-1} < x \leq 0 
\end{cases}$$

**示例**：

```
x = +1011B（+11D）
[x]_原 = 01011B

x = -1011B（-11D）
[x]_原 = 11011B
```

**定点小数原码**：

**计算公式**：

$$[x]_原 = \begin{cases} 
x & 0 \leq x < 1 \\
1 - x & -1 < x \leq 0 
\end{cases}$$

**示例**：

```
x = +0.1011B（+0.6875D）
[x]_原 = 0.1011B

x = -0.1011B（-0.6875D）
[x]_原 = 1.1011B
```

### 2. 原码的特点

**特点**：

| 特点 | 说明 |
|-----|------|
| **简单直观** | 符号位明确表示正负 |
| **存在两个零** | +0和-0的表示不同 |
| **加减运算复杂** | 需要判断符号和大小 |

**两个零的表示**：

```
+0的原码：00000000
-0的原码：10000000
```

## 三、反码表示

### 1. 反码的定义

**定义**：反码是原码的数值位取反。

**编码规则**：

| 符号 | 说明 |
|-----|------|
| **正数** | 反码与原码相同 |
| **负数** | 反码是原码的数值位取反 |

**定点整数反码**：

**计算公式**：

$$[x]_反 = \begin{cases} 
x & 0 \leq x < 2^{n-1} \\
(2^n - 1) + x & -2^{n-1} < x \leq 0 
\end{cases}$$

**示例**：

```
x = +1011B（+11D）
[x]_反 = 01011B

x = -1011B（-11D）
[x]_反 = 10100B（原码11011的数值位取反）
```

**定点小数反码**：

**计算公式**：

$$[x]_反 = \begin{cases} 
x & 0 \leq x < 1 \\
(2 - 2^{-(n-1)}) + x & -1 < x \leq 0 
\end{cases}$$

**示例**：

```
x = +0.1011B（+0.6875D）
[x]_反 = 0.1011B

x = -0.1011B（-0.6875D）
[x]_反 = 1.0100B（原码1.1011的数值位取反）
```

### 2. 反码的特点

**特点**：

| 特点 | 说明 |
|-----|------|
| **存在两个零** | +0和-0的表示不同 |
| **加减运算** | 可以统一处理加减法 |
| **过渡码** | 通常作为原码到补码的过渡 |

**两个零的表示**：

```
+0的反码：00000000
-0的反码：11111111
```

## 四、补码表示

### 1. 补码的定义

**定义**：补码是计算机中最常用的有符号数表示方法。

**编码规则**：

| 符号 | 说明 |
|-----|------|
| **正数** | 补码与原码相同 |
| **负数** | 补码是反码加1 |

**定点整数补码**：

**计算公式**：

$$[x]_补 = \begin{cases} 
x & 0 \leq x < 2^{n-1} \\
2^n + x & -2^{n-1} \leq x < 0 
\end{cases}$$

**示例**：

```
x = +1011B（+11D）
[x]_补 = 01011B

x = -1011B（-11D）
[x]_补 = 10101B（反码10100加1）
```

**定点小数补码**：

**计算公式**：

$$[x]_补 = \begin{cases} 
x & 0 \leq x < 1 \\
2 + x & -1 \leq x < 0 
\end{cases}$$

**示例**：

```
x = +0.1011B（+0.6875D）
[x]_补 = 0.1011B

x = -0.1011B（-0.6875D）
[x]_补 = 1.0101B（反码1.0100加1）
```

### 2. 补码的特点

**特点**：

| 特点 | 说明 |
|-----|------|
| **唯一零** | 只有一个零的表示 |
| **加减法统一** | 减法可以转换为加法 |
| **溢出判断** | 可以通过符号位判断溢出 |

**唯一零的表示**：

```
0的补码：00000000
```

### 3. 补码的溢出判断

**溢出条件**：

| 条件 | 说明 |
|-----|------|
| **正+正=负** | 正数相加结果为负数，溢出 |
| **负+负=正** | 负数相加结果为正数，溢出 |

**溢出判断方法**：

**方法一**：符号位判断

```
符号位进位C1，最高数值位进位C2
溢出 = C1 XOR C2
```

**方法二**：双符号位判断

```
使用两位符号位：
00：正数
11：负数
01：正溢出
10：负溢出
```

## 五、移码表示

### 1. 移码的定义

**定义**：移码是将补码的符号位取反。

**计算公式**：

$$[x]_移 = 2^{n-1} + x$$

**示例**：

```
x = +1011B（+11D）
[x]_移 = 11011B（补码01011的符号位取反）

x = -1011B（-11D）
[x]_移 = 00101B（补码10101的符号位取反）
```

### 2. 移码的特点

**特点**：

| 特点 | 说明 |
|-----|------|
| **便于比较** | 移码的大小顺序与真值一致 |
| **用于浮点数** | 浮点数的阶码使用移码表示 |
| **唯一零** | 只有一个零的表示 |

**移码的比较**：

```
x1 = +1011B，[x1]_移 = 11011B
x2 = -1011B，[x2]_移 = 00101B

比较移码：11011B > 00101B
结论：x1 > x2
```

## 六、四种编码的对比

### 1. 编码对比表

| 数值 | 原码 | 反码 | 补码 | 移码 |
|-----|-----|-----|-----|-----|
| +1011 | 01011 | 01011 | 01011 | 11011 |
| -1011 | 11011 | 10100 | 10101 | 00101 |
| +0 | 00000 | 00000 | 00000 | 10000 |
| -0 | 10000 | 11111 | 00000 | 10000 |

### 2. 特点对比

| 编码 | 优点 | 缺点 |
|-----|------|------|
| **原码** | 简单直观 | 存在两个零，加减运算复杂 |
| **反码** | 可以统一加减法 | 存在两个零，不常用 |
| **补码** | 唯一零，加减法统一 | 不够直观 |
| **移码** | 便于比较，用于阶码 | 不常用作一般数值表示 |

> [!warning] 易错点
> 补码的负数表示是反码加1！不要忘记加1，这是补码计算的关键。
