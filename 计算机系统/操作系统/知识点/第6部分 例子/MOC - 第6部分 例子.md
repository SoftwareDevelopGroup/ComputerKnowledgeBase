# MOC - 第6部分 例子

本部分以 UNIX/POSIX 与 Windows 两条整机案例回看进程、内存、文件、I/O、保护和安全机制在真实系统架构中的组合方式。

> 课程总入口：[[MOC - 操作系统]]

## 案例入口

| 章节级案例 | 观察重点 |
| --- | --- |
| [[例子 - UNIX 操作系统]] | Shell、进程、VFS、文件描述符、I/O 与受控提权 |
| [[例子 - Windows 操作系统]] | 对象、令牌、线程、虚拟内存、I/O 管理器与文件系统 |
