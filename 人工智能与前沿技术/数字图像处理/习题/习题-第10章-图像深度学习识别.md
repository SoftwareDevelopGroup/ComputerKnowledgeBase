## 一、单选题

### 1.1 Bayes 分类器的判别函数公式为？

A. $g_i(\mathbf{x}) = p(\mathbf{x} | \omega_i) P(\omega_i)$
B. $g_i(\mathbf{x}) = \ln p(\mathbf{x} | \omega_i) + \ln P(\omega_i)$
C. $g_i(\mathbf{x}) = P(\omega_i) / p(\mathbf{x})$
D. $g_i(\mathbf{x}) = p(\mathbf{x} | \omega_i) / P(\omega_i)$

<details><summary>答案与解析</summary>

**答案：B**

Bayes 判别函数取对数形式：$g_i(\mathbf{x}) = \ln p(\mathbf{x} | \omega_i) + \ln P(\omega_i)$。分类时选择 $g_i(\mathbf{x})$ 最大的类别。取对数将乘法运算转化为加法，便于计算。

</details>

### 1.2 下列关于 SVM（支持向量机）的说法，正确的是？

A. SVM 只能处理线性可分问题
B. SVM 通过最大化分类间隔实现分类
C. SVM 不需要核函数
D. SVM 的决策边界由所有训练样本共同决定

<details><summary>答案与解析</summary>

**答案：B**

SVM 通过最大化分类间隔（最大间隔原则）寻找最优分类超平面。即使原问题线性不可分，通过核函数映射到高维空间后可以线性可分。SVM 的决策边界只由支持向量（少数关键样本）决定。

</details>

### 1.3 R-CNN 中使用的区域提议方法是？

A. Selective Search
B. Region Proposal Network (RPN)
C. Sliding Window
D. Edge Boxes

<details><summary>答案与解析</summary>

**答案：A**

R-CNN 使用 Selective Search 生成约 2000 个候选区域，然后对每个区域用 CNN 提取特征并分类。Faster R-CNN 才引入了 RPN（区域提议网络）。

</details>

### 1.4 下列关于 YOLO 算法的说法，正确的是？

A. YOLO 是 Two-Stage 检测算法
B. YOLO 将检测问题转化为回归问题
C. YOLO 不使用边界框
D. YOLO 检测精度始终高于 Faster R-CNN

<details><summary>答案与解析</summary>

**答案：B**

YOLO（You Only Look Once）是 One-Stage 检测算法，将目标检测问题直接转化为边界框和类别概率的回归问题，速度快但精度（尤其是小目标）通常不如 Faster R-CNN。

</details>

### 1.5 U-Net 架构中，跳跃连接（Skip Connection）的作用是？

A. 加速训练
B. 将编码器的低层特征传递给解码器，保留细节信息
C. 减少参数量
D. 防止过拟合

<details><summary>答案与解析</summary>

**答案：B**

U-Net 的跳跃连接将编码器（下采样路径）的特征图直接传递给解码器（上采样路径），使解码器能够利用低层的细节信息（如边缘、纹理），从而获得更精确的分割结果。

</details>

### 1.6 下列关于迁移学习的说法，正确的是？

A. 迁移学习只能用于相同任务
B. 冻结特征提取层，只训练分类头是常见的迁移学习策略
C. 迁移学习一定比从头训练效果好
D. 迁移学习不需要任何目标域数据

<details><summary>答案与解析</summary>

**答案：B**

迁移学习中，冻结在大数据集上预训练的特征提取层（如 ImageNet），只训练自定义的分类头是最常见的策略。迁移学习适合目标域数据少的情况，但如果源域和目标域差异很大，效果可能不好。

</details>

## 二、多选题

### 2.1 下列关于 CNN 卷积层的说法，正确的是？

A. 卷积层通过局部连接提取特征
B. 卷积层使用权值共享减少参数量
C. 卷积层可以提取边缘、纹理等特征
D. 卷积层输出的特征图数量等于输入通道数
E. 卷积层后通常接激活函数

<details><summary>答案与解析</summary>

**答案：A、B、C、E**

D 错误：卷积层输出的特征图数量由卷积核数量决定，不一定等于输入通道数。每个卷积核（一组权重）产生一个输出特征图。

</details>

### 2.2 下列关于池化层的说法，正确的是？

A. 最大池化取窗口内最大值
B. 平均池化取窗口内平均值
C. 池化层可以减少特征图尺寸
D. 池化层增加了平移不变性
E. 池化层可以替代卷积层

<details><summary>答案与解析</summary>

**答案：A、B、C、D**

E 错误：池化层和卷积层功能不同。池化层用于降采样和增加不变性，不能替代卷积层的特征提取功能。现代 CNN 中有时使用步长卷积替代池化。

</details>

### 2.3 下列关于目标检测算法的说法，正确的是？

A. R-CNN 是 Two-Stage 算法
B. Faster R-CNN 引入了 RPN 网络
C. YOLO 是 One-Stage 算法
D. SSD 使用多尺度检测

**答案：A、B、C、D**

E 错误：YOLOv5 使用锚框（anchor-based）。YOLOv5 使用三种不同尺度的特征图和预设锚框进行检测。Anchor-Free 方法如 CornerNet、CenterNet 才不使用锚框。

### 2.4 下列关于语义分割和实例分割的说法，正确的是？

A. 语义分割标注每个像素的类别
B. 实例分割不仅区分类别，还要区分不同实例
C. U-Net 可用于语义分割
D. Mask R-CNN 可用于实例分割
E. 语义分割比实例分割更简单

<details><summary>答案与解析</summary>

**答案：A、B、C、D、E**

语义分割只需要为每个像素分配类别标签，不区分同一类的不同实例。实例分割需要同时区分类别和不同实例（如同类的不同人），因此更复杂。

## 三、判断题

### 3.1 Bayes 分类器在所有分类器中理论错误率最低。

<details><summary>答案与解析</summary>

**正确**

在给定的类条件概率密度和先验概率下，Bayes 分类器具有最小的平均分类错误率，是理论最优分类器。其他分类器都是对 Bayes 分类器的近似实现。

</details>

---

### 3.2 SVM 的核函数 $K(\mathbf{x}_i, \mathbf{x}_j) = (\mathbf{x}_i \cdot \mathbf{x}_j)^d$ 是多项式核。

<details><summary>答案与解析</summary>

**正确**

这是 $d$ 阶多项式核。当 $d=1$ 时退化为线性核 $K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i \cdot \mathbf{x}_j$。多项式核将输入映射到 $d$ 次多项式特征空间。

</details>

---

### 3.3 R-CNN、Fast R-CNN、Faster R-CNN 在检测流程上的主要区别是区域提议方法。

<details><summary>答案与解析</summary>

**正确**

- R-CNN：Selective Search 生成 2000 个提议区域，每个区域独立用 CNN 提取特征
- Fast R-CNN：Selective Search 生成提议区域，但特征提取在整图上一次完成（ROI Pooling）
- Faster R-CNN：引入 RPN 网络替代 Selective Search，实现端到端训练

</details>

---

### 3.4 YOLO 算法的检测速度比 Faster R-CNN 快，但小目标检测精度较低。

<details><summary>答案与解析</summary>

**正确**

YOLO 是 One-Stage 检测器，直接在特征图上回归边界框，速度快。Faster R-CNN 是 Two-Stage 检测器，先生成区域提议再分类，精度高但速度慢。YOLO 由于在低分辨率特征图上检测，小目标容易丢失。

</details>

---

### 3.5 U-Net 中编码器（下采样）和解码器（上采样）的特征图通过跳跃连接相加。

<details><summary>答案与解析</summary>

**错误**

U-Net 的跳跃连接是**拼接（concatenation）**，而不是相加。编码器的特征图和解码器的特征图在通道维度上拼接，保留了更多的信息。相加操作会混合信息，而拼接保留了原始信息。

</details>

---

### 3.6 迁移学习中，预训练模型的所有层都可以用于目标任务。

<details><summary>答案与解析</summary>

**正确**

迁移学习中，可以冻结前面的特征提取层，只训练后面的分类头；也可以使用预训练权重作为初始化，对整个网络进行微调。选择取决于目标域数据量和源域与目标域的相似度。

</details>

## 四、简答题

### 4.1 描述传统模式识别的完整管线，并说明每个阶段的作用和典型方法。

<details><summary>参考答案</summary>

**传统模式识别管线：**

```
数据获取 → 预处理 → 特征提取 → 特征选择 → 分类器设计 → 分类决策
```

**各阶段说明：**

1. **数据获取**：获取原始数据（图像、信号等）
   - 典型方法：传感器采集、数据集收集
   - 输出：原始数据

2. **预处理**：消除噪声、标准化数据
   - 典型方法：滤波、二值化、归一化
   - 输出：干净数据

3. **特征提取**：从原始数据中提取判别性特征
   - 典型方法：HOG、SIFT、LBP、颜色直方图、矩不变量
   - 输出：特征向量

4. **特征选择**：从提取的特征中选择最有判别力的子集
   - 典型方法：PCA、LDA、信息增益、特征重要性
   - 输出：降维特征向量

5. **分类器设计**：基于特征训练分类模型
   - 典型方法：Bayes、k-NN、SVM、决策树、随机森林
   - 输出：分类模型

6. **分类决策**：对新数据进行分类
   - 典型方法：基于模型的预测
   - 输出：分类结果

**传统方法 vs 深度学习：** 深度学习将特征提取、特征选择和分类器设计整合为端到端的学习过程。

</details>

### 4.2 描述 Bayes 分类器的基本原理。对两类问题，若先验概率相等且类条件概率为高斯分布，写出简化后的 Bayes 判别函数。

<details><summary>参考答案</summary>

**基本原理：**

Bayes 分类器基于后验概率进行决策：

$$P(\omega_i | \mathbf{x}) = \frac{p(\mathbf{x} | \omega_i) P(\omega_i)}{p(\mathbf{x})}$$

选择 $P(\omega_i | \mathbf{x})$ 最大的类别。判别函数为：

$$g_i(\mathbf{x}) = \ln p(\mathbf{x} | \omega_i) + \ln P(\omega_i)$$

**两类问题 + 高斯分布 + 等先验（$P(\omega_1) = P(\omega_2) = 0.5$）：**

设 $\mathbf{x} | \omega_i \sim \mathcal{N}(\boldsymbol{\mu}_i, \Sigma_i)$，则：

$$p(\mathbf{x} | \omega_i) = \frac{1}{(2\pi)^{d/2}|\Sigma_i|^{1/2}} e^{-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_i)^T \Sigma_i^{-1} (\mathbf{x}-\boldsymbol{\mu}_i)}$$

取对数后：

$$g_i(\mathbf{x}) = -\frac{1}{2}\ln|\Sigma_i| - \frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_i)^T \Sigma_i^{-1} (\mathbf{x}-\boldsymbol{\mu}_i) + \text{const}$$

若 $\Sigma_1 = \Sigma_2 = \Sigma$（协方差相同），则：

$$g_i(\mathbf{x}) = -\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_i)^T \Sigma^{-1} (\mathbf{x}-\boldsymbol{\mu}_i) + \text{const}'$$

**线性判别函数：** 展开上式，$\mathbf{x}^T \Sigma^{-1} \mathbf{x}$ 对所有类别相同（忽略），得到：

$$g_i(\mathbf{x}) = \mathbf{w}_i^T \mathbf{x} + w_{i0}$$

其中 $\mathbf{w}_i = \Sigma^{-1} \boldsymbol{\mu}_i$，$w_{i0} = -\frac{1}{2}\boldsymbol{\mu}_i^T \Sigma^{-1} \boldsymbol{\mu}_i$。

这是一个线性判别函数，分类边界为超平面。

</details>

### 4.3 比较 R-CNN、Fast R-CNN、Faster R-CNN 的架构差异，说明 Faster R-CNN 中 RPN 的作用。

<details><summary>参考答案</summary>

**架构对比：**

| 方面 | R-CNN | Fast R-CNN | Faster R-CNN |
|------|-------|------------|-------------|
| 区域提议 | Selective Search (CPU) | Selective Search (CPU) | RPN (GPU,端到端) |
| 特征提取 | 每个 ROI 独立 CNN | 整图特征 + ROI Pooling | 整图特征 + ROI Pooling |
| 训练方式 | 多阶段（SVM+边界框回归） | 多任务损失（分类+回归） | 多任务损失（RPN+Fast R-CNN） |
| 检测速度 | ~0.5 FPS | ~7 FPS | ~17 FPS |

**RPN 的作用：**

Region Proposal Network（区域提议网络）是 Faster R-CNN 的核心创新，用于替代耗时的 Selective Search：

1. **输入**：整幅图像的特征图
2. **输出**：一组矩形候选区域（区域提议）及其前景分数
3. **工作原理**：
   - 在特征图的每个位置预测 9 个锚框（3 种尺度 × 3 种长宽比）
   - 对每个锚框预测：前景/背景分类概率 + 边界框偏移量
   - 使用 NMS（非极大值抑制）去除重叠区域
4. **优势**：
   - 端到端训练，所有模块共享特征
   - GPU 实现，速度快
   - 区域提议质量高，召回率高

</details>

### 4.4 描述 CNN 中卷积层、池化层、BatchNorm、Dropout 的作用。

<details><summary>参考答案</summary>

**卷积层（Convolutional Layer）：**

作用：通过局部连接和权值共享提取图像的局部特征
- 权值共享：同一个卷积核在不同位置滑动，大幅减少参数量
- 多层卷积：低层提取边缘/纹理，高层提取语义/概念
- 公式：$y_j^l = f\left(\sum_{i \in M_j} x_i^{l-1} * k_{ij}^l + b_j^l\right)$

**池化层（Pooling Layer）：**

作用：降采样，增加特征的平移不变性
- 最大池化：取窗口内最大值，保留最显著特征
- 平均池化：取窗口内平均值，保留整体信息
- 现代趋势：部分网络使用步长卷积替代池化

**BatchNorm（批归一化）：**

作用：加速训练，缓解内部协变量偏移
$$\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y = \gamma \hat{x} + \beta$$
- 对每个 mini-batch 的特征进行归一化
- $\gamma$ 和 $\beta$ 是可学习的参数
- 允许更大的学习率，加速收敛

**Dropout：**

作用：防止过拟合，实现近似集成
- 训练时随机"丢弃"一部分神经元（概率 $p$）
- 推理时所有神经元参与，权重乘以 $(1-p)$
- 类似于在多个网络间进行平均

</details>

### 4.5 说明迁移学习的两种主要策略（冻结特征层 vs 微调）及其适用场景。

<details><summary>参考答案</summary>

**策略 1：冻结特征提取层 + 训练分类头**

$$\text{Feature Extractor（冻结）} \rightarrow \text{Classifier Head（训练）}$$

- 将预训练模型（如 ResNet-50）作为固定的特征提取器
- 移除原有的分类头，添加自定义分类头
- 只训练分类头的参数
- **适用场景：**
  - 目标域数据量少（< 1000 张）
  - 源域和目标域特征相似
  - 计算资源有限
  - 分类任务简单

**策略 2：微调（Fine-tuning）**

$$\text{预训练模型（部分/全部微调）} \rightarrow \text{Classifier Head（训练）}$$

- 使用预训练权重作为初始化
- 较小学习率微调所有层，或先冻结再解冻部分层
- **适用场景：**
  - 目标域数据量较多（> 1000 张）
  - 源域和目标域差异较大
  - 任务复杂（如检测、分割）
  - 需要更高性能

**选择策略：**

| 因素 | 冻结特征层 | 微调 |
|------|-----------|------|
| 目标数据量 | 少 | 多 |
| 源-目标差异 | 小 | 大 |
| 计算资源 | 少 | 多 |
| 性能需求 | 中等 | 高 |

</details>

## 五、计算题

### 5.1 对两类分类问题，使用 Bayes 分类器进行分类。给定：

- $\omega_1$ 类：$\boldsymbol{\mu}_1 = [1, 1]^T$，$\Sigma_1 = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$
- $\omega_2$ 类：$\boldsymbol{\mu}_2 = [3, 3]^T$，$\Sigma_2 = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$
- 先验概率 $P(\omega_1) = 0.6$，$P(\omega_2) = 0.4$
- 待分类样本 $\mathbf{x} = [2, 2]^T$

计算判别函数值并给出分类结果。

<details><summary>参考答案</summary>

**Bayes 判别函数（高斯分布，等协方差）：**

$$g_i(\mathbf{x}) = -\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_i)^T \Sigma^{-1} (\mathbf{x}-\boldsymbol{\mu}_i) + \ln P(\omega_i) + \text{const}$$

由于 $\Sigma_1 = \Sigma_2 = I$（单位矩阵），$\Sigma^{-1} = I$。

**对 $\omega_1$：**

$$(\mathbf{x}-\boldsymbol{\mu}_1)^T \Sigma^{-1} (\mathbf{x}-\boldsymbol{\mu}_1) = [2-1, 2-1] \begin{bmatrix} 1 \\ 1 \end{bmatrix} = 1^2 + 1^2 = 2$$

$$g_1(\mathbf{x}) = -\frac{1}{2} \times 2 + \ln(0.6) = -1 + (-0.5108) = -1.5108$$

**对 $\omega_2$：**

$$(\mathbf{x}-\boldsymbol{\mu}_2)^T \Sigma^{-1} (\mathbf{x}-\boldsymbol{\mu}_2) = [2-3, 2-3] \begin{bmatrix} -1 \\ -1 \end{bmatrix} = (-1)^2 + (-1)^2 = 2$$

$$g_2(\mathbf{x}) = -\frac{1}{2} \times 2 + \ln(0.4) = -1 + (-0.9163) = -1.9163$$

**分类结果：** $g_1(\mathbf{x}) = -1.5108 > g_2(\mathbf{x}) = -1.9163$，因此 $\mathbf{x}$ 属于 $\omega_1$ 类。

</details>

### 5.2 计算一维卷积的输出。给定输入特征图和卷积核：

$$\text{输入 } X = [1, 2, 3, 4, 5], \quad \text{核 } K = [1, 0, -1], \quad \text{步长 } s=1, \text{填充 } p=0$$

<details><summary>参考答案</summary>

**卷积计算（有效填充）：**

输出长度 $L = \lfloor \frac{5 - 3}{1} \rfloor + 1 = 3$

**位置 0：** $Y[0] = 1 \times 1 + 2 \times 0 + 3 \times (-1) = 1 + 0 - 3 = -2$

**位置 1：** $Y[1] = 2 \times 1 + 3 \times 0 + 4 \times (-1) = 2 + 0 - 4 = -2$

**位置 2：** $Y[2] = 3 \times 1 + 4 \times 0 + 5 \times (-1) = 3 + 0 - 5 = -2$

**输出：** $Y = [-2, -2, -2]$

注意：卷积计算中，通常卷积核是翻转的（相关运算 vs 真正的卷积）。在深度学习中通常使用相关运算：

$$Y[n] = \sum_{k=0}^{K-1} X[n+k] \cdot K[k]$$

如果使用真正的卷积（翻转核），结果会不同。

### 5.3 计算两个边界框的 IoU（交并比）。

$$\text{框 A: } (x_1=10, y_1=10, x_2=50, y_2=50)$$
$$\text{框 B: } (x_1=30, y_1=20, x_2=70, y_2=60)$$

<details><summary>参考答案</summary>

**交集计算：**

$$x_1^{\text{int}} = \max(10, 30) = 30$$
$$y_1^{\text{int}} = \max(10, 20) = 20$$
$$x_2^{\text{int}} = \min(50, 70) = 50$$
$$y_2^{\text{int}} = \min(50, 60) = 50$$

$$\text{Intersection Area} = (50-30) \times (50-20) = 20 \times 30 = 600$$

**并集计算：**

$$\text{Area}_A = (50-10) \times (50-10) = 40 \times 40 = 1600$$
$$\text{Area}_B = (70-30) \times (60-20) = 40 \times 40 = 1600$$

$$\text{Union Area} = 1600 + 1600 - 600 = 2600$$

**IoU：**

$$\text{IoU} = \frac{600}{2600} \approx 0.2308 = 23.08\%$$

</details>

### 5.4 计算卷积层的输出尺寸。给定输入特征图尺寸 $32 \times 32 \times 3$（高×宽×通道数），使用 3×3 卷积核，步长为 2，填充为 1。

<details><summary>参考答案</summary>

**输出尺寸公式：**

$$\text{Output} = \left\lfloor \frac{\text{Input} + 2 \times \text{padding} - \text{kernel}}{\text{stride}} \right\rfloor + 1$$

**高度：** $\lfloor (32 + 2 \times 1 - 3) / 2 \rfloor + 1 = \lfloor 31/2 \rfloor + 1 = 15 + 1 = 16$

**宽度：** $\lfloor (32 + 2 \times 1 - 3) / 2 \rfloor + 1 = 15 + 1 = 16$

**通道数** = 卷积核数量（假设为 16），则输出为 $16 \times 16 \times 16$。

**参数量计算：**
每个卷积核的参数量 = $3 \times 3 \times 3 + 1 = 28$（权重 + 偏置）
16 个卷积核的总参数量 = $16 \times 28 = 448$

### 6.1 使用 PyTorch 实现一个简单的 CNN 图像分类器（类似 LeNet 架构）。

<details><summary>参考答案</summary>

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
import torchvision
import torchvision.transforms as transforms
import matplotlib.pyplot as plt

class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(SimpleCNN, self).__init__()
        self.conv1 = nn.Conv2d(3, 6, kernel_size=5, padding=2)
        self.conv2 = nn.Conv2d(6, 16, kernel_size=5)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc1 = nn.Linear(16 * 6 * 6, 120)
        self.fc2 = nn.Linear(120, 84)
        self.fc3 = nn.Linear(84, num_classes)
        self.relu = nn.ReLU()
    
    def forward(self, x):
        x = self.pool(self.relu(self.conv1(x)))
        x = self.pool(self.relu(self.conv2(x)))
        x = x.view(x.size(0), -1)
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.fc3(x)
        return x

transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))
])

trainset = torchvision.datasets.CIFAR10(root='./data', train=True, download=True, transform=transform)
trainloader = DataLoader(trainset, batch_size=64, shuffle=True)

model = SimpleCNN(num_classes=10)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

for epoch in range(5):
    running_loss = 0.0
    for i, (inputs, labels) in enumerate(trainloader):
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        running_loss += loss.item()
    print(f'Epoch {epoch+1}, Loss: {running_loss/len(trainloader):.4f}')

print('Training completed!')
```

### 6.2 使用 PyTorch 实现迁移学习：加载预训练 ResNet-50，微调用于自定义分类任务。

```python
import torch

from torch.utils.data import DataLoader

import torchvision.transforms as transforms
import matplotlib.pyplot as plt

model = torchvision.models.resnet50(pretrained=True)

    transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
])

valset = torchvision.datasets.ImageFolder(root='./data/val', transform=transform_val)

valloader = DataLoader(valset, batch_size=32, shuffle=False)

    train_loss = 0
    for inputs, labels in trainloader:
        inputs, labels = inputs.to(device), labels.to(device)
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        train_loss += loss.item()
    
    model.eval()
    correct = total = 0
    with torch.no_grad():
        for inputs, labels in valloader:
            inputs, labels = inputs.to(device), labels.to(device)
            outputs = model(inputs)
            _, predicted = torch.max(outputs, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()
    
    print(f'Epoch {epoch+1}: Loss={train_loss/len(trainloader):.4f}, Acc={100*correct/total:.1f}%')
```

### 6.3 使用 PyTorch 实现 U-Net 用于图像分割，计算 Dice 系数和 IoU。

<details><summary>参考答案</summary>

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, Dataset
import torchvision.transforms as transforms
from PIL import Image
import numpy as np

class DoubleConv(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True)
        )
    def forward(self, x):
        return self.conv(x)

class UNet(nn.Module):
    def __init__(self, n_channels, n_classes):
        super().__init__()
        self.enc1 = DoubleConv(n_channels, 64)
        self.enc2 = DoubleConv(64, 128)
        self.enc3 = DoubleConv(128, 256)
        self.enc4 = DoubleConv(256, 512)
        self.bottleneck = DoubleConv(512, 1024)
        self.pool = nn.MaxPool2d(2, 2)
        self.up4 = nn.ConvTranspose2d(1024, 512, 2, stride=2)
        self.dec4 = DoubleConv(1024, 512)
        self.up3 = nn.ConvTranspose2d(512, 256, 2, stride=2)
        self.dec3 = DoubleConv(512, 256)
        self.up2 = nn.ConvTranspose2d(256, 128, 2, stride=2)
        self.dec2 = DoubleConv(256, 128)
        self.up1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.dec1 = DoubleConv(128, 64)
        self.final = nn.Conv2d(64, n_classes, 1)
    
    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        e4 = self.enc4(self.pool(e3))
        b = self.bottleneck(self.pool(e4))
        d4 = self.up4(b)
        d4 = self.dec4(torch.cat([d4, e4], dim=1))
        d3 = self.up3(d4)
        d3 = self.dec3(torch.cat([d3, e3], dim=1))
        d2 = self.up2(d3)
        d2 = self.dec2(torch.cat([d2, e2], dim=1))
        d1 = self.up1(d2)
        d1 = self.dec1(torch.cat([d1, e1], dim=1))
        return self.final(d1)

def dice_coeff(pred, target, smooth=1e-6):
    pred = (pred > 0.5).float()
    intersection = (pred * target).sum(dim=(1,2,3))
    return (2.0 * intersection + smooth) / (pred.sum(dim=(1,2,3)) + target.sum(dim=(1,2,3)) + smooth)

def iou_coeff(pred, target, smooth=1e-6):
    pred = (pred > 0.5).float()
    intersection = (pred * target).sum(dim=(1,2,3))
    union = pred.sum(dim=(1,2,3)) + target.sum(dim=(1,2,3)) - intersection
    return (intersection + smooth) / (union + smooth)

model = UNet(n_channels=3, n_classes=1)
criterion = nn.BCEWithLogitsLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)
```

> [!tip] 复习要点
> 1. 传统识别管线：数据→预处理→特征提取→特征选择→分类器→决策
> 2. Bayes 分类器：$g_i(\mathbf{x}) = \ln p(\mathbf{x}|\omega_i) + \ln P(\omega_i)$，理论最优
> 3. SVM：最大间隔原则 + 核技巧，HOG+SVM 是经典组合
> 4. CNN 核心组件：卷积（特征提取）→池化（降采样）→激活（非线性）→BN（归一化）→Dropout（正则化）
> 5. 检测算法演进：R-CNN → Fast R-CNN → Faster R-CNN（RPN）→ YOLO/SSD（One-Stage）
> 6. 分割算法：FCN → U-Net（编码器-解码器+跳跃连接）→ DeepLab
> 7. 迁移学习策略：冻结特征层（数据少）vs 微调（数据多）
> 8. 评价指标：IoU、Dice（分割）、mAP（检测）、Top-K Accuracy（分类）
> 9. 数据增强是提升泛化能力的有效手段
