## 一、单选题

### 1.1 SIFT 算法中 DoG（Difference of Gaussian）检测相比 LoG 检测的主要优势是？

A. DoG 检测更精确
B. DoG 计算量更小，是 LoG 的近似
C. DoG 不需要高斯滤波
D. DoG 能检测更多关键点

<details><summary>答案与解析</summary>

**答案：B**

DoG 是 LoG 的近似：$D(x,y,\sigma) = G(x,y,k\sigma) * I - G(x,y,\sigma) * I$。由于高斯函数的线性组合近似满足 LoG 算子（当 $k$ 接近 1 时），DoG 可以用减法代替 LoG 的二阶导数计算，效率更高。

</details>

---

### 1.2 下列关于 Hu 矩不变量的说法，正确的是？

A. Hu 矩只有 5 个
B. $\phi_1 = \eta_{20} + \eta_{02}$ 具有平移、旋转和缩放不变性
C. Hu 矩对所有仿射变换都具有不变性
D. Hu 矩只能用于二值图像

<details><summary>答案与解析</summary>

**答案：B**

Hu 矩共 7 个，$\phi_1$ 是二阶中心矩的组合，具有平移、旋转和缩放不变性。Hu 矩对刚体变换（平移+旋转+缩放）具有不变性，但不支持 shear 变换。

</details>

### 1.3 HOG 特征的计算步骤中，cell 和 block 的关系是？

A. block 是 cell 的组成单位
B. cell 是 block 的组成单位，block 由 2×2 个 cell 组成
C. cell 和 block 是相同的概念
D. cell 的大小必须大于 block

<details><summary>答案与解析</summary>

**答案：B**

HOG 中，图像被划分为小的 cell（通常 8×8 像素），每个 cell 计算一个梯度直方图。相邻的 2×2 个 cell 组成一个 block（因此 block 通常为 16×16 像素），对 block 内的特征进行归一化。

</details>

### 1.4 下列关于 LBP（局部二值模式）的说法，正确的是？

A. LBP 只能取 8 个值
B. LBP 编码的是中心像素与邻域像素的灰度关系
C. LBP 不具有旋转不变性
D. LBP 只能用于二值图像

<details><summary>答案与解析</summary>

**答案：B**

LBP 编码规则为：对中心像素 $g_c$ 及其 $P$ 个邻域像素 $g_p$，若 $g_p \geq g_c$ 则编码为 1，否则为 0，形成二进制编码。通过旋转不变模式可以实现旋转不变性。

</details>

### 1.5 SIFT 描述子的维度是？

A. 64 维
B. 128 维
C. 256 维
D. 32 维

<details><summary>答案与解析</summary>

**答案：B**

SIFT 描述子将关键点周围 16×16 区域划分为 4×4 个 block，每个 block 计算 8 个方向的梯度直方图（0°, 45°, 90°, ..., 315°），总维度为 $4 \times 4 \times 8 = 128$ 维。

</details>

### 1.6 下列关于 ORB 算法的说法，正确的是？

A. ORB 不具有旋转不变性
B. ORB 使用 BRIEF 描述子替代 SIFT 的描述子
C. ORB 计算速度比 SIFT 慢
D. ORB 不使用高斯金字塔

<details><summary>答案与解析</summary>

**答案：B**

ORB（Oriented FAST and Rotated BRIEF）结合了 FAST 角点检测和改进的 BRIEF 描述子，通过计算关键点方向实现旋转不变性。相比 SIFT/SURF，ORB 速度更快，但不具有尺度不变性。

</details>

### 2.1 下列关于 SIFT 算法的说法，正确的是？

A. SIFT 具有尺度不变性
B. SIFT 具有旋转不变性
C. SIFT 使用 DoG 检测关键点
D. SIFT 描述子为 128 维

A. SURF 比 SIFT 更快

C. SURF 使用 FAST 角点检测

## 三、判断题

### 3.1 SIFT 算法中，DoG 的相邻尺度因子 $k$ 通常取 $k = 2^{1/S}$，$S$ 为每组尺度数。

<details><summary>答案与解析</summary>

**正确**

SIFT 通常取 $S=3$，$k = 2^{1/3} \approx 1.26$。DoG 近似 LoG 时，$k$ 越接近 1，近似越好。

</details>

---

### 3.2 SIFT 描述子需要进行归一化以消除光照影响。

<details><summary>答案与解析</summary>

**正确**

SIFT 描述子生成后，会将 128 维向量进行 L2 归一化：$\mathbf{d} = \mathbf{d} / ||\mathbf{d}||_2$。这消除了光照强度的影响，因为梯度幅值随光照线性变化。

</details>

---

### 3.3 Hu 矩中的 $\phi_1 = \eta_{20} + \eta_{02}$ 可以区分正方形和圆形。

<details><summary>答案与解析</summary>

**错误**

$\phi_1$ 描述的是物体的"偏心率"或"拉伸程度"，但它是二阶矩的线性组合，对于正方形和圆形可能产生相同的值。区分度有限，通常需要结合 $\phi_2$ 等更高阶矩。

</details>

---

### 3.4 HOG 特征中的 block 归一化使用了 L1-norm、L2-norm 等方法。

<details><summary>答案与解析</summary>

**正确**

HOG 中 block 归一化的常见形式有：
- L2-norm: $\mathbf{v} / \sqrt{||\mathbf{v}||_2^2 + \epsilon^2}$
- L1-norm: $\mathbf{v} / (||\mathbf{v}||_1 + \epsilon)$
- L2-HYS: 先 L2 归一化，再截断最大值 0.2，再 L2 归一化

</details>

---

### 3.5 ORB 算法的描述子是二进制的，因此可以使用汉明距离快速匹配。

<details><summary>答案与解析</summary>

**正确**

ORB 使用 BRIEF 描述子，输出为二进制串（通常 256 位）。两个二进制串的汉明距离可通过异或和位计数高效计算，极大提升了匹配速度。

</details>

---

### 3.6 链码表示不具有旋转不变性。

<details><summary>答案与解析</summary>

**正确**

链码（Freeman Chain Code）通过编码边界点的方向来表示形状，但方向编码依赖于起始点和物体的旋转方向。通常需要通过归一化（如固定起始点、使用差分链码）来实现旋转不变性。

</details>

## 四、简答题

### 4.1 描述 SIFT 算法的完整流程（四步法），并说明每一步的关键设计。

<details><summary>参考答案</summary>

**第一步：尺度空间极值检测**

1. 构建高斯金字塔：对图像进行多次高斯模糊，每组有 $S$ 个尺度，相邻尺度因子 $k = 2^{1/S}$
2. 计算 DoG：相邻尺度高斯模糊图像相减
3. 极值检测：在尺度空间中，每个像素与其 26 个邻域像素（同尺度 8 邻域 + 上下相邻尺度各 9 个）比较，检测局部极值
4. 精确定位：对 DoG 函数进行泰勒展开，亚像素级精确定位极值点位置和尺度

**第二步：关键点定位**

剔除低对比度（$|D(\hat{x})| < 0.03$）和边缘响应（$H$ 矩阵的比值 $\frac{\text{Tr}(H)^2}{\text{Det}(H)} > \frac{(r+1)^2}{r}$，$r=10$）的关键点。

**第三步：方向分配**

1. 在关键点邻域内计算梯度幅值和方向
2. 构建梯度方向直方图（36 个 bin）
3. 取主方向（直方图峰值）作为关键点方向
4. 若存在多个主方向，创建多个描述子（通常 2 个）

**第四步：描述子生成**

1. 将关键点邻域旋转至主方向
2. 划分为 4×4 个子区域
3. 每个子区域计算 8 方向梯度直方图
4. 归一化得到 128 维描述子

</details>

### 4.2 说明 Hu 矩不变量的推导思路，写出前三个 Hu 矩的表达式。

<details><summary>参考答案</summary>

**推导思路：**

**步骤 1：原始矩**

$$m_{pq} = \sum_{x}\sum_{y} x^p y^q f(x,y)$$

**步骤 2：中心矩**

$$\mu_{pq} = \sum_{x}\sum_{y} (x - \bar{x})^p (y - \bar{y})^q f(x,y)$$

其中 $\bar{x} = m_{10}/m_{00}$，$\bar{y} = m_{01}/m_{00}$。中心矩具有平移不变性。

**步骤 3：归一化中心矩**

$$\eta_{pq} = \frac{\mu_{pq}}{m_{00}^{(p+q)/2 + 1}}$$

归一化后具有缩放不变性。

**步骤 4：Hu 矩（旋转不变性组合）**

$$\phi_1 = \eta_{20} + \eta_{02}$$

$$\phi_2 = (\eta_{20} - \eta_{02})^2 + 4\eta_{11}^2$$

$$\phi_3 = (\eta_{30} - 3\eta_{12})^2 + (3\eta_{21} - \eta_{03})^2$$

**物理含义：**
- $\phi_1$：物体的紧凑度/偏心率
- $\phi_2$：物体的方向性
- $\phi_3$：物体的对称性

</details>

### 4.3 描述 HOG 特征的计算流程，并说明它为什么适合行人检测。

<details><summary>参考答案</summary>

**计算流程：**

1. **图像预处理**：将输入图像归一化到固定大小（如 64×128）
2. **梯度计算**：对每个像素计算水平梯度 $G_x$ 和垂直梯度 $G_y$，得到幅值 $G$ 和方向 $\theta$
3. **Cell 直方图统计**：将图像划分为 8×8 的 cell，每个 cell 内统计 9 个方向 bin（0°~180°，每 20° 一个 bin）的梯度幅值加权直方图
4. **Block 归一化**：2×2 个 cell 组成一个 block（16×16 像素），对 block 内的 36 维特征（2×2×9）进行 L2-HYS 归一化
5. **特征向量拼接**：将所有 block 的特征拼接，得到最终的 HOG 特征向量

**适合行人检测的原因：**
1. **边缘/形状描述**：HOG 捕捉物体的边缘和梯度方向分布，适合描述行人的轮廓形状
2. **局部归一化**：block 级归一化消除光照和阴影的影响
3. **方向直方图**：行人的形状有稳定的梯度方向分布（头肩、躯干轮廓）
4. **尺度鲁棒**：cell 和 block 的多尺度设计应对不同大小的行人
5. **计算高效**：相比 SIFT 等特征，HOG 计算更简洁，配合 SVM 可实时检测

</details>

### 4.4 描述 LBP 特征的计算过程，并说明其旋转不变性的实现方法。

<details><summary>参考答案</summary>

**计算过程（以 $P=8, R=1$ 为例）：**

1. 对每个中心像素 $g_c$，取其 $P=8$ 个邻域像素（半径 $R=1$）
2. 比较每个邻域像素与中心像素的灰度：
   - 若 $g_p \geq g_c$，编码为 1
   - 若 $g_p < g_c$，编码为 0
3. 从某个起始位置（如正上方）开始，顺时针编码形成 8 位二进制数
4. 将二进制数转换为十进制 LBP 值（0~255）

$$LBP_{P,R} = \sum_{p=0}^{P-1} s(g_p - g_c) \cdot 2^p, \quad s(x) = \begin{cases} 1, & x \geq 0 \\ 0, & x < 0 \end{cases}$$

**旋转不变性实现：**

将 LBP 编码循环右移，取最小值作为旋转不变的 LBP 值：

$$LBP_{P,R}^{ri} = \min_{i=0}^{P-1} \text{Rotate}(\text{LBP}_{P,R}, i)$$

即将二进制编码进行 $i$ 位循环旋转（$i=0,1,...,P-1$），取最小值作为旋转不变编码。

**统一模式（Uniform Pattern）：**

当 LBP 二进制编码中 0→1 的跳变次数不超过 2 时，称为统一模式。$P=8$ 时，统一模式共 58 种，加上 2 种非统一模式的标签，共 60 类，显著降低了特征维度。

</details>

### 4.5 描述特征匹配中的 Lowe's Ratio Test 原理和作用。

<details><summary>参考答案</summary>

**原理：**

对每个查询图像的特征点，在目标图像中找到最近邻和次近邻的描述子。如果最近邻距离 $d_1$ 明显小于次近邻距离 $d_2$，则认为匹配可靠。

$$\frac{d_1}{d_2} < \tau$$

其中 $\tau$ 为阈值，通常取 $0.75 \sim 0.8$。

**作用：**

1. **去除歧义匹配**：当一个特征点的最近邻和次近邻距离接近时（$d_1 \approx d_2$），说明存在多个候选匹配，该匹配不可靠
2. **提高匹配精度**：仅保留比值小于阈值的匹配对，有效过滤错误匹配
3. **阈值选择**：$\tau$ 越小，匹配越严格，正确匹配率越高，但匹配数量减少；$\tau$ 越大，匹配越多，但可能引入更多错误

**示例：**

若 $d_1 = 0.4$，$d_2 = 0.6$，比值 $0.4/0.6 = 0.67 < 0.8$，匹配保留。
若 $d_1 = 0.5$，$d_2 = 0.55$，比值 $0.5/0.55 = 0.91 > 0.8$，匹配丢弃。

</details>

## 五、计算题

### 5.1 对下列 3×3 二值图像计算原始矩 $m_{10}$、$m_{01}$ 和中心矩 $\mu_{20}$、$\mu_{02}$，并判断物体是否对称。

$$I = \begin{bmatrix} 0 & 0 & 0 \\ 0 & 1 & 0 \\ 1 & 1 & 1 \end{bmatrix}$$

<details><summary>参考答案</summary>

**原始矩计算：**

$$m_{pq} = \sum_{x}\sum_{y} x^p y^q f(x,y)$$

$$m_{10} = \sum x \cdot f(x,y) = 0 \times 0 + 1 \times 1 + 2 \times 0 + 0 \times 1 + 1 \times 1 + 2 \times 1 = 1 + 1 + 2 = 4$$

$$m_{01} = \sum y \cdot f(x,y) = 0 \times 0 + 0 \times 1 + 0 \times 0 + 1 \times 1 + 1 \times 1 + 1 \times 1 = 0 + 1 + 1 + 1 = 3$$

$$m_{00} = \sum f(x,y) = 4$$

**重心：** $\bar{x} = m_{10}/m_{00} = 4/4 = 1$，$\bar{y} = m_{01}/m_{00} = 3/4 = 0.75$

**中心矩：**

$$\mu_{20} = \sum (x - \bar{x})^2 f(x,y) = (0-1)^2 \times 0 + (1-1)^2 \times 1 + (2-1)^2 \times 0 + (0-1)^2 \times 1 + (1-1)^2 \times 1 + (2-1)^2 \times 1$$
$$= 0 + 0 + 0 + 1 + 0 + 1 = 2$$

$$\mu_{02} = \sum (y - \bar{y})^2 f(x,y) = (0-0.75)^2 \times 0 + (0-0.75)^2 \times 1 + (0-0.75)^2 \times 0 + (1-0.75)^2 \times 1 + (1-0.75)^2 \times 1 + (1-0.75)^2 \times 1$$
$$= 0 + 0.5625 + 0 + 0.0625 + 0.0625 + 0.0625 = 0.75$$

**判断对称性：**

由于 $\mu_{20} = 2 \neq \mu_{02} = 0.75$，物体在水平和垂直方向上的分布不同，不是对称的。$\mu_{20} > \mu_{02}$ 说明物体在水平方向上的展布更大。

</details>

### 5.2 计算一个 8×8 图像块的梯度方向直方图（HOG cell）。给定每个像素的梯度幅值和方向：

| 像素位置 | 幅值 | 方向（°） |
|---------|------|-----------|
| (0,0)   | 10   | 0         |
| (0,1)   | 20   | 90        |
| (0,2)   | 15   | 45        |

### 5.4 对 4×4 图像块的梯度方向进行 HOG cell 直方图统计（9 个方向 bin），并对 2×2 个 cell 的 block 进行 L2-HYS 归一化。

$$||\mathbf{v}||_2 = \sqrt{30^2 + 10^2 + 5^2 + \cdots + 12^2 + 18^2}$$

### 6.3 使用 Python/OpenCV 实现 ORB 基于图像拼接（Panorama Stitching）。

<details><summary>参考答案</summary>

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def stitch_images(img1, img2):
    orb = cv2.ORB_create(nfeatures=2000)
    
    kp1, des1 = orb.detectAndCompute(img1, None)
    kp2, des2 = orb.detectAndCompute(img2, None)
    
    bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=False)
    matches = bf.knnMatch(des1, des2, k=2)
    
    good = []
    for m, n in matches:
        if m.distance < 0.75 * n.distance:
            good.append(m)
    
    if len(good) < 10:
        return None
    
    src_pts = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
    dst_pts = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
    
    H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
    
    h, w = img2.shape[:2]
    img1_warp = cv2.warpPerspective(img1, H, (w + img1.shape[1], h))
    
    img1_warp[0:img2.shape[0], 0:img2.shape[1]] = img2
    
    return img1_warp

img1 = cv2.imread('left.jpg')
img2 = cv2.imread('right.jpg')
result = stitch_images(img1, img2)

if result is not None:
    plt.figure(figsize=(18, 6))
    plt.imshow(cv2.cvtColor(result, cv2.COLOR_BGR2RGB))
    plt.title('Panorama Stitching Result')
    plt.axis('off')
    plt.show()
```

</details>

> [!tip] 复习要点
> 1. SIFT 四步法：DoG 极值检测 → 关键点定位 → 方向分配 → 描述子生成
> 2. SURF 使用 Box Filter 近似 LoG，速度比 SIFT 更快
> 3. ORB = FAST 角点 + 改进 BRIEF 描述子，二进制描述子可使用汉明距离快速匹配
> 4. Hu 矩共 7 个，由归一化中心矩组合，具有平移/旋转/缩放不变性
> 5. HOG = 梯度方向直方图 + block 归一化，经典行人检测特征
> 6. LBP 是高效的纹理描述子，统一模式 + 旋转不变编码
> 7. Lowe's Ratio Test 是特征匹配后处理的标准方法
> 8. 特征选择依据：不变性需求、计算效率、描述维度、匹配方法
