## 一、单选题

### 1.1 RGB 空间中，R=G=B 时表示的颜色是？

A. 红色
B. 绿色
C. 蓝色
D. 灰色/白色

<details><summary>答案与解析</summary>

**答案：D**

当 R=G=B 时，三个通道亮度相同，表示灰色（当值为 0 时是黑色，255 时是白色，中间值为不同灰度的灰色）。这是灰度图可以从 RGB 图转换得到的基础。

</details>

### 1.2 HSI 空间中，H（Hue）分量的取值范围是？

A. $[0, 255]$
B. $[0, 1]$
C. $[0°, 360°]$
D. $[-180°, 180°]$

<details><summary>答案与解析</summary>

**答案：C**

H（色调）表示颜色的纯度/种类，用角度表示，范围为 $0°$ 到 $360°$，对应色轮上的位置。$0°$ 为红色，$120°$ 为绿色，$240°$ 为蓝色。

</details>

### 1.3 下列关于 RGB 与 CMY 转换的说法，正确的是？

A. CMY = 1 - RGB（逐通道）
B. CMY = RGB / 255
C. CMY = RGB + 128
D. CMY = RGB × 2

<details><summary>答案与解析</summary>

**答案：A**

RGB 和 CMY 是互补的颜色空间，转换关系为：$C = 1 - R$，$M = 1 - G$，$Y = 1 - B$（归一化到 $[0,1]$）。CMY 用于印刷，因为它是减色混合（从白色中减去颜色）。

</details>

---

### 1.4 Retinex 理论的核心公式是？

A. $\log R = \log I - \log L$
B. $R = I \times L$
C. $\log R = \log I + \log L$
D. $R = I / L^2$

<details><summary>答案与解析</summary>

**答案：A**

Retinex 理论认为图像 $I(x,y)$ 是照度 $L(x,y)$ 和反射率 $R(x,y)$ 的乘积：$I = L \times R$。取对数后：$\log I = \log L + \log R$，分离出反射率：$\log R = \log I - \log L$。反射率 $R$ 即为照度归一化后的图像。

</details>

### 1.5 暗通道先验（DCP）去雾算法中，暗通道的定义为？

A. 图像中每个像素 RGB 三通道的最小值
B. 图像局部区域中 RGB 三通道最小值中的最小值
C. 图像的灰度值
D. 图像的低频成分

<details><summary>答案与解析</summary>

**答案：B**

暗通道定义为：对图像中每个像素，在一个局部邻域 $\Omega(x)$ 内，取 RGB 三通道的最小值：

$$J_{\text{dark}}(x) = \min_{y \in \Omega(x)}\left(\min_{c \in \{r,g,b\}} J^c(y)\right)$$

</details>

### 1.6 下列关于直方图均衡化在彩色图像上的应用，正确的是？

A. 可以直接对 RGB 三个通道分别均衡
B. 应在 HSI 空间中对 I 分量进行均衡
C. 应在 HSI 空间中对 H 分量进行均衡
D. 只需要均衡 S 分量

<details><summary>答案与解析</summary>

**答案：B**

直接对 RGB 三通道分别均衡会破坏颜色的色度关系，导致偏色。正确做法是转换到 HSI/HSV 空间，仅对亮度分量（I 或 V）进行均衡，保持色调和饱和度不变。

</details>

## 三、判断题

### 3.1 HSI 空间中，H 通道对光照变化最不敏感。

<details><summary>答案与解析</summary>

**正确**

H（色调）描述的是颜色的种类（如红、绿、蓝），主要由光谱分布决定，对光照强度变化不敏感。而 I（亮度）直接反映光照强度，S（饱和度）也会受光照影响。

</details>

---

### 3.2 直接对 RGB 三个通道分别进行直方图均衡化不会改变图像颜色。

<details><summary>答案与解析</summary>

**错误**

分别对 RGB 通道均衡化会破坏三个通道之间的比例关系，导致颜色失真（偏色）。正确做法是在 HSI/HSV 空间均衡化亮度分量。

</details>

---

### 3.3 CMYK 空间中的 K 通道代表黑色，是为了印刷中更好地控制黑色。

<details><summary>答案与解析</summary>

**正确**

CMY 三个通道混合可以产生黑色，但实际印刷中使用 K（黑色）通道可以更经济地获得高质量的黑色，避免三原色油墨混合产生的不理想的黑色。

</details>

---

### 3.4 Retinex 理论中，照度 $L$ 通常采用大尺度高斯滤波估计。

<details><summary>答案与解析</summary>

**正确**

Retinex 假设照度是图像的低频成分（变化缓慢），因此用大尺度高斯滤波（大 $\sigma$）估计照度 $L(x,y) = G_{\sigma} * I(x,y)$。

</details>

---

### 3.5 暗通道先验中，透射率 $t(x)$ 越小表示该位置越远离相机。

<details><summary>答案与解析</summary>

**正确**

透射率 $t(x) = e^{-\beta d(x)}$，其中 $d(x)$ 是场景点到相机的距离。距离越远，$t(x)$ 越小，雾气越浓。当 $t(x) \to 0$ 时，图像趋近于大气光 $A$。

</details>

---

### 3.6 YCbCr 空间中，Y 分量表示亮度，Cb 和 Cr 表示色度。

<details><summary>答案与解析</summary>

**正确**

YCbCr 将亮度（Y）和色度（Cb、Cr）分离，广泛用于视频压缩标准（MPEG、H.264 等）。Cb 是蓝色色差，Cr 是红色色差。

</details>

## 四、简答题

### 4.1 写出 RGB 到 HSI 的完整转换公式，并对 $(R=200, G=100, B=50)$ 计算 HSI 值。

<details><summary>参考答案</summary>

**转换公式：**

设归一化 $R, G, B \in [0,1]$，令 $M = \max(R,G,B)$，$m = \min(R,G,B)$，$C = M - m$。

**色相 H：**

$$H = \begin{cases} 0°, & \text{if } C = 0 \\ 60° \times \left(\frac{G-B}{C} \mod 6\right), & \text{if } M = R \\ 60° \times \left(\frac{B-R}{C} + 2\right), & \text{if } M = G \\ 60° \times \left(\frac{R-G}{C} + 4\right), & \text{if } M = B \end{cases}$$

**饱和度 S：**

$$S = \begin{cases} 0, & \text{if } I = 0 \\ \frac{C}{I} = 1 - \frac{m}{I}, & \text{otherwise} \end{cases}$$

**亮度 I：**

$$I = \frac{R + G + B}{3}$$

**计算 $(R=200, G=100, B=50)$：**

归一化：$R = 200/255 \approx 0.784$，$G = 100/255 \approx 0.392$，$B = 50/255 \approx 0.196$

$M = 0.784$（R），$m = 0.196$（B），$C = 0.784 - 0.196 = 0.588$

**H：** 因为 $M = R$，$H = 60° \times \frac{0.392 - 0.196}{0.588} = 60° \times \frac{0.196}{0.588} \approx 60° \times 0.333 = 20°$

**S：** $I = (0.784 + 0.392 + 0.196)/3 = 0.457$，$S = 0.588/0.457$，但此值大于1，需要重新计算：

$$S = 1 - \frac{m}{I} = 1 - \frac{0.196}{0.457} \approx 0.571$$

**I：** $I = 0.457$（或 $I \times 255 \approx 116$）

**结果：** $H \approx 20°$，$S \approx 0.571$，$I \approx 0.457$

</details>

### 4.2 描述 SSR（单尺度 Retinex）和 MSR（多尺度 Retinex）的算法流程，并说明它们的区别。

<details><summary>参考答案</summary>

**SSR 流程：**

1. 输入图像 $I(x,y)$（对数域）
2. 用高斯函数估计照度：$\log L(x,y) = G_{\sigma}(x,y) * \log I(x,y)$
3. 计算反射率（输出）：$\log R(x,y) = \log I(x,y) - \log L(x,y)$
4. 指数变换回线性域：$R(x,y) = \exp(\log R(x,y))$

**MSR 流程：**

使用多个尺度的 $\sigma$，对每个尺度分别计算反射率，然后加权融合：

$$\log R_{\text{MSR}}(x,y) = \sum_{i=1}^{N} w_i \cdot [\log I(x,y) - G_{\sigma_i}(x,y) * \log I(x,y)]$$

其中 $\sum w_i = 1$，通常取等权重。

**区别：**

| 方面 | SSR | MSR |
|------|-----|-----|
| 尺度 | 单一 $\sigma$ | 多个 $\sigma$ |
| 细节保留 | $\sigma$ 小时保留细节但光照估计差 | 多尺度融合兼顾细节和光照 |
| 适用场景 | 简单光照不均 | 复杂光照变化 |
| 计算量 | 较小 | 较大 |

</details>

### 4.3 描述 DCP（暗通道先验）去雾算法的完整流程。

<details><summary>参考答案</summary>

**步骤 1：计算暗通道**

$$J_{\text{dark}}(x) = \min_{y \in \Omega(x)}\left(\min_{c \in \{r,g,b\}} J^c(y)\right)$$

**步骤 2：估计大气光 $A$**

取暗通道中亮度最大的前 $0.1\%$ 像素位置，对应原图中亮度最高的值作为 $A$。

**步骤 3：估计透射率**

$$\tilde{t}(x) = 1 - \omega \cdot \min_{y \in \Omega(x)}\left(\min_{c \in \{r,g,b\}} \frac{I^c(y)}{A^c}\right)$$

其中 $\omega \in (0,1]$ 为去雾强度参数，通常取 $\omega = 0.95$。

**步骤 4：透射率细化（导向滤波）**

对初始透射率图使用导向滤波进行细化，使其与原图边缘对齐。

**步骤 5：恢复无雾图像**

$$J(x) = \frac{I(x) - A}{\max(t(x), t_0)} + A$$

其中 $t_0$ 为透射率下限（通常取 0.1），避免分母过小导致噪声放大。

</details>

### 4.4 说明为什么直方图均衡化在 HSI 空间中对 I 分量有效，而在 RGB 空间中直接对三个通道均衡化会产生颜色失真。

<details><summary>参考答案</summary>

**HSI 空间的优势：**

HSI 将颜色分解为三个独立分量：
- H（色调）：颜色种类
- S（饱和度）：颜色纯度
- I（亮度）：光照强度

对 I 分量均衡化只改变亮度分布，不改变 H 和 S，因此保持了图像的颜色外观。

**RGB 空间的问题：**

RGB 空间中三个通道是高度相关的。假设一个像素的 RGB 值为 $(200, 100, 50)$：
- R 通道均衡化后可能变为 220
- G 通道均衡化后可能变为 80
- B 通道均衡化后可能变为 30

新值 $(220, 80, 30)$ 的色调与原值 $(200, 100, 50)$ 完全不同，导致颜色失真。

**正确做法：**
1. RGB → HSI
2. 对 I 通道进行直方图均衡化
3. 保持 H 和 S 通道不变
4. HSI → RGB

</details>

### 4.5 设计一个基于 Lab 空间的肤色检测算法，说明各步骤的设计理由。

<details><summary>参考答案</summary>

**算法流程：**

1. **RGB → Lab 转换**
   - Lab 空间具有感知均匀性，欧氏距离与人眼感知差异一致
   - L 通道表示亮度，a 和 b 通道表示色度
   - 肤色在 Lab 空间中分布集中，便于建模

2. **提取 a 和 b 通道**
   - 忽略 L 通道（亮度信息），只用 a 和 b 色度信息
   - 肤色的色度分布相对独立于亮度

3. **建立肤色模型**
   - 收集大量肤色样本，在 ab 空间中建模
   - 常用高斯模型或直方图模型
   - 肤色在 ab 空间中通常分布在椭圆区域：$a \in [100, 150]$，$b \in [120, 170]$（近似范围）

4. **计算肤色概率**
   - 对每个像素计算其色度向量在肤色模型下的概率
   - 概率高于阈值的像素标记为肤色

5. **后处理**
   - 形态学操作去除孤立噪声
   - 连通域分析提取人脸区域

**设计理由：**
- Lab 空间分离亮度和色度，光照变化影响 L 通道但不影响 ab 通道
- 感知均匀性使肤色聚类更紧凑
- 模型简单，实时性好

</details>

## 五、计算题

### 5.1 将 RGB 值 $(R=180, G=120, B=60)$ 转换为 HSI 值（保留两位小数）。

<details><summary>参考答案</summary>

**步骤 1：归一化**

$$R = \frac{180}{255} \approx 0.706, \quad G = \frac{120}{255} \approx 0.471, \quad B = \frac{60}{255} \approx 0.235$$

**步骤 2：计算 I**

$$I = \frac{R + G + B}{3} = \frac{0.706 + 0.471 + 0.235}{3} \approx 0.471$$

**步骤 3：计算 S**

$$M = \max(0.706, 0.471, 0.235) = 0.706 \quad (\text{即 } R)$$
$$m = \min(0.706, 0.471, 0.235) = 0.235 \quad (\text{即 } B)$$
$$S = 1 - \frac{m}{I} = 1 - \frac{0.235}{0.471} \approx 1 - 0.499 = 0.501$$

**步骤 4：计算 H**

因为 $M = R$：

$$H = 60° \times \frac{G - B}{M - m} = 60° \times \frac{0.471 - 0.235}{0.706 - 0.235} = 60° \times \frac{0.236}{0.471} \approx 60° \times 0.501 = 30.06°$$

**结果：** $H \approx 30.06°$，$S \approx 0.50$，$I \approx 0.47$

这对应橙色（H≈30°），饱和度中等，亮度中等。

</details>

### 5.2 对像素 $(R=255, G=128, B=0)$，计算其在 HSV 空间中的 H、S、V 值。

<details><summary>参考答案</summary>

**归一化：** $R = 1.0$，$G = 0.502$，$B = 0.0$

**$V$（Value）：** $V = \max(R,G,B) = 1.0$

**$S$（Saturation）：** 令 $M = 1.0$，$m = 0.0$，$C = 1.0 - 0.0 = 1.0$

$$S = \frac{C}{V} = \frac{1.0}{1.0} = 1.0$$

**$H$（Hue）：** 因为 $M = R$：

$$H = 60° \times \frac{G - B}{C} = 60° \times \frac{0.502 - 0}{1.0} = 60° \times 0.502 \approx 30.12°$$

**结果：** $H \approx 30.12°$，$S = 1.0$，$V = 1.0$

这是纯橙色（色相 30°，完全饱和，最亮）。

</details>

### 5.3 对 RGB 图像像素 $(R=100, G=150, B=50)$，使用 RGB→YCbCr 转换矩阵计算 Y、Cb、Cr 值。

转换矩阵为：

$$\begin{bmatrix} Y \\ Cb \\ Cr \end{bmatrix} = \begin{bmatrix} 0.299 & 0.587 & 0.114 \\ -0.169 & -0.331 & 0.500 \\ 0.500 & -0.419 & -0.081 \end{bmatrix} \begin{bmatrix} R \\ G \\ B \end{bmatrix}$$

<details><summary>参考答案</summary>

$$Y = 0.299 \times 100 + 0.587 \times 150 + 0.114 \times 50 = 29.9 + 88.05 + 5.7 = 123.65$$

$$Cb = -0.169 \times 100 - 0.331 \times 150 + 0.500 \times 50 = -16.9 - 49.65 + 25.0 = -41.55$$

$$Cr = 0.500 \times 100 - 0.419 \times 150 - 0.081 \times 50 = 50.0 - 62.85 - 4.05 = -16.90$$

**结果：** $Y = 123.65$，$Cb = -41.55$，$Cr = -16.90$

Cb 和 Cr 为负值说明该像素偏绿（因为 G 通道最大）。在实际视频编码中，Cb 和 Cr 通常偏移 128 转为无符号整数。

</details>

### 5.4 给定一幅有雾图像的透射率估计 $\tilde{t}(x) = 0.6$，大气光 $A = [250, 240, 230]$，原图像像素 $I(x) = [180, 170, 160]$，求去雾后的像素值。

<details><summary>参考答案</summary>

**DCP 去雾公式：**

$$J(x) = \frac{I(x) - A}{\max(t(x), t_0)} + A$$

取 $t_0 = 0.1$，$t(x) = 0.6 > t_0$，所以 $\max(t(x), t_0) = 0.6$。

**R 通道：**

$$J_R = \frac{180 - 250}{0.6} + 250 = \frac{-70}{0.6} + 250 = -116.67 + 250 = 133.33$$

**G 通道：**

$$J_G = \frac{170 - 240}{0.6} + 240 = \frac{-70}{0.6} + 240 = -116.67 + 240 = 123.33$$

**B 通道：**

$$J_B = \frac{160 - 230}{0.6} + 230 = \frac{-70}{0.6} + 230 = -116.67 + 230 = 113.33$$

**结果：** $J(x) = [133.33, 123.33, 113.33]$

去雾后像素值变小（变暗），说明原图像的"雾气"增加了亮度（因为透射率低时，图像值趋近于大气光 A）。

</details>

### 6.2 使用 Python/OpenCV 实现 SSR Retinex 图像增强算法。

<details><summary>参考答案</summary>

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def ssr_retinex(image, sigma=25):
    img_float = np.float64(image) + 1.0
    
    log_img = np.log(img_float)
    gaussian = cv2.GaussianBlur(log_img, (0, 0), sigma)
    
    log_r = log_img - gaussian
    r = np.exp(log_r)
    
    r_normalized = cv2.normalize(r, None, 0, 255, cv2.NORM_MINMAX)
    return np.uint8(r_normalized)

img = cv2.imread('low_light.jpg', cv2.IMREAD_GRAYSCALE)
result = ssr_retinex(img, sigma=25)

fig, axes = plt.subplots(1, 2, figsize=(14, 6))
axes[0].imshow(img, cmap='gray')
axes[0].set_title('Original')
axes[1].imshow(result, cmap='gray')
axes[1].set_title('SSR Retinex')
for ax in axes:
    ax.axis('off')
plt.tight_layout()
plt.show()
```

</details>

### 6.3 使用 Python/OpenCV 实现基于 HSV 的颜色分割。

<details><summary>参考答案</summary>

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

img = cv2.imread('peppers.jpg')
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

lower_red = np.array([0, 100, 100])
upper_red = np.array([10, 255, 255])
mask1 = cv2.inRange(hsv, lower_red, upper_red)

lower_red2 = np.array([160, 100, 100])
upper_red2 = np.array([180, 255, 255])
mask2 = cv2.inRange(hsv, lower_red2, upper_red2)

red_mask = cv2.bitwise_or(mask1, mask2)

kernel = np.ones((5, 5), np.uint8)
red_mask = cv2.morphologyEx(red_mask, cv2.MORPH_OPEN, kernel)
red_mask = cv2.morphologyEx(red_mask, cv2.MORPH_CLOSE, kernel)

result = cv2.bitwise_and(img, img, mask=red_mask)

fig, axes = plt.subplots(1, 3, figsize=(16, 5))
axes[0].imshow(cv2.cvtColor(img, cv2.COLOR_BGR2RGB))
axes[0].set_title('Original')
axes[1].imshow(red_mask, cmap='gray')
axes[1].set_title('Red Mask')
axes[2].imshow(cv2.cvtColor(result, cv2.COLOR_BGR2RGB))
axes[2].set_title('Red Peppers')
for ax in axes:
    ax.axis('off')
plt.tight_layout()
plt.show()
```

> [!tip] 复习要点
> 1. RGB 适合显示，HSI/HSV 适合处理——颜色空间的选择依赖于任务
> 2. 直方图均衡化应在 HSI/HSV 空间的亮度分量上进行，避免颜色失真
> 3. Retinex 理论：$\log R = \log I - \log L$，SSR 单尺度 vs MSR 多尺度
> 4. DCP 去雾五步：暗通道 → 大气光 → 透射率 → 导向滤波 → 去雾恢复
> 5. RGB↔HSI 转换公式是考研计算题高频考点
> 6. 白平衡方法：灰度世界、完美反射、直方图均衡
> 7. 彩色直方图具有旋转/尺度不变性，但缺乏空间信息
> 8. Lab 空间的感知均匀性在肤色检测等应用中很重要
