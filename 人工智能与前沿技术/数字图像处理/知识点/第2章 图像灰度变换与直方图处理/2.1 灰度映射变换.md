# 2.1 灰度映射变换

## 📖 基本概念

灰度映射变换（Intensity Transformation）是最简单的图像处理技术之一，其数学本质是对图像中每个像素的灰度值 $r$ 施加一个映射函数 $T$，得到新的灰度值 $s$：

$$s = T(r)$$

变换仅依赖于像素自身的灰度值，与像素的空间位置无关，因此属于**点运算（Point Operation）**，也称为**灰度级变换（Gray-Level Transformation）**。

### 变换分类体系

```mermaid
flowchart LR
    A[灰度映射变换] --> B[线性变换]
    A --> C[非线性变换]
    A --> D[分段线性变换]
    B --> B1[正比变换<br/>s = k·r + b]
    B --> B2[反比变换<br/>s = L-1-r]
    C --> C1[对数变换<br/>s = c·log(1+r)]
    C --> C2[幂次变换<br/>s = c·r^γ]
    D --> D1[对比度拉伸]
    D --> D2[阈值化]
    D --> D3[灰度切片]
```

## 🔬 线性变换

### 一般形式

$$s = a \cdot r + b$$

其中 $a$ 为斜率（增益），$b$ 为截距（偏置）。

### 特殊情形

| 类型 | 公式 | 效果 | 应用场景 |
|------|------|------|----------|
| 正比变换 | $s = k \cdot r$ ($k>1$) | 对比度增强 | 整体灰度拉伸 |
| 反比变换（底片） | $s = L-1-r$ | 反色显示 | X 光片反转 |
| 恒等变换 | $s = r$ | 无变化 | 对照参考 |
| 压缩变换 | $s = k \cdot r$ ($0<k<1$) | 对比度降低 | 动态范围压缩 |

### 反色变换示例

$$s = 255 - r$$

对于 8-bit 图像（$L=256$），将亮变暗、暗变亮，类似照相底片效果。

## 📈 非线性变换

### 对数变换

$$s = c \cdot \log(1 + r)$$

**特点**：将输入图像中范围较宽的低灰度值映射为输出较宽的灰度级，同时压缩高灰度值范围。

**典型应用**：
- 显示动态范围极大的图像（如 X 光片、天文图像）
- 频谱图像的显示（傅里叶谱动态范围可达 $10^6$）

**参数说明**：
- $c$ 为缩放常数，通常取 $c = \frac{L-1}{\log(1+r_{\max})}$
- 保证输出范围在 $[0, L-1]$ 内

### 幂次变换（伽马校正）

$$s = c \cdot r^\gamma$$

**特点**：变换曲线随 $\gamma$ 值变化：

```mermaid
graph LR
    subimage 幂次变换曲线
    A[γ < 1<br/>暗部增强] --> B["s = c·r^γ"]
    B --> C[γ = 1<br/>线性变换]
    C --> D[γ > 1<br/>亮部增强]
```

| γ 取值 | 效果 | 应用 |
|--------|------|------|
| $\gamma < 1$ | 提升暗部灰度值 | 显示器 gamma 校正、暗部细节增强 |
| $\gamma = 1$ | 线性变换 | 无效果 |
| $\gamma > 1$ | 压缩暗部，增强亮部 | 高光细节增强 |

**伽马校正公式**：

$$s = \left(\frac{r}{r_{\max}}\right)^\gamma \cdot (L-1)$$

### 对数变换 vs 幂次变换

| 对比项 | 对数变换 | 幂次变换 |
|--------|----------|----------|
| 曲线形状 | 凹函数，上凸 | 可变（依赖 γ） |
| 动态范围压缩 | 强（压缩高值） | 可调节 |
| 灵活性 | 低 | 高（γ 控制） |
| 典型用途 | X 光、频谱显示 | 显示器校正、通用增强 |

## 📐 分段线性变换

分段线性变换通过多个线性函数分段映射灰度值，可实现更灵活的灰度调整。

### 对比度拉伸（Contrast Stretching）

将原始灰度范围 $[r_{\min}, r_{\max}]$ 线性映射到 $[s_{\min}, s_{\max}]$：

$$s = s_{\min} + \frac{s_{\max} - s_{\min}}{r_{\max} - r_{\min}} \cdot (r - r_{\min})$$

**改进版**：基于直方图分位数，用 $r_{5\%}$ 和 $r_{95\%}$ 替代 $r_{\min}$ 和 $r_{\max}$，避免极端值影响。

### 阈值化（Thresholding）

最简单的分段变换，产生二值图像：

$$s = \begin{cases} L-1 & \text{if } r > T \\ 0 & \text{if } r \leq T \end{cases}$$

### 灰度切片（Gray Level Slicing）

将某一灰度范围的像素高亮显示，用于特定灰度区域的视觉检测：

$$s = \begin{cases} L-1 & \text{if } r_1 \leq r \leq r_2 \\ 0 & \text{otherwise} \end{cases}$$

## 💻 Python / OpenCV 代码实现

### 基本灰度变换

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

img = cv2.imread('input.jpg', cv2.IMREAD_GRAYSCALE)

# 1. 反色变换
negative = cv2.bitwise_not(img)

# 2. 对数变换
c = 255 / np.log(1 + np.max(img.astype(np.float64)))
log_transformed = c * np.log(1 + img.astype(np.float64))
log_transformed = np.uint8(log_transformed)

# 3. 幂次变换（伽马校正）
gamma = 0.5
lookup_table = np.array([((i / 255.0) ** gamma) * 255
                         for i in range(256)]).astype(np.uint8)
gamma_corrected = cv2.LUT(img, lookup_table)

# 4. 使用 convertScaleAbs 对比度调整
alpha = 1.5  # 对比度增益
beta = 20    # 亮度偏置
adjusted = cv2.convertScaleAbs(img, alpha=alpha, beta=beta)
```

### 对比度拉伸

```python
def contrast_stretch(image, low=2, high=98):
    p2, p98 = np.percentile(image, (low, high))
    stretched = np.clip((image - p2) / (p98 - p2) * 255.0, 0, 255)
    return np.uint8(stretched)

stretched = contrast_stretch(img)
```

### 分段线性变换

```python
def piecewise_linear(image):
    result = np.zeros_like(image, dtype=np.float64)
    r = image.astype(np.float64)

    # 第一段: 0~50 保持不变
    mask1 = r < 50
    result[mask1] = r[mask1]

    # 第二段: 50~150 映射到 50~200
    mask2 = (r >= 50) & (r < 150)
    result[mask2] = 50 + (200 - 50) / (150 - 50) * (r[mask2] - 50)

    # 第三段: 150~255 映射到 200~255
    mask3 = r >= 150
    result[mask3] = 200 + (255 - 200) / (255 - 150) * (r[mask3] - 150)

    return np.uint8(np.clip(result, 0, 255))

piecewise_result = piecewise_linear(img)
```

### 效果对比可视化

```python
fig, axes = plt.subplots(2, 3, figsize=(15, 10))
titles = ['Original', 'Negative', 'Log Transform',

images = [img, negative, log_transformed, gamma_corrected,

for ax, title, im in zip(axes.flat, titles, images):
```

## ❓ 常见问题

### Q1：为什么对数变换后需要归一化？

原始图像的灰度值范围为 $[0, 255]$，经过 $\log(1+r)$ 变换后值域为 $[0, \log(256)] \approx [0, 5.54]$，超出了 8-bit 显示范围，必须乘以缩放常数 $c$ 将值映射回 $[0, 255]$。

### Q2：伽马校正中 γ 的物理意义？

$\gamma$ 反映了显示设备的响应特性。传统 CRT 显示器的电压-亮度关系为非线性（约 2.5 次幂），因此需要对输入信号进行 $\gamma$ 预校正。现在的 LCD/OLED 也遵循类似的色彩管理标准（sRGB 使用 $\gamma \approx 2.2$）。

### Q3：`cv2.convertScaleAbs` 与 `cv2.LUT` 的区别？

- `convertScaleAbs`：在线性变换基础上叠加偏置，内部自动做饱和运算，适合简单的亮度/对比度调整。
- `LUT`（Look-Up Table）：通过预计算的查找表实现任意映射，效率高但需预先构造表。

> 📌 **关键总结**：灰度变换是图像处理中最基础也是最重要的技术。理解各变换的数学本质和适用场景，是掌握后续直方图处理和空间域滤波的基础。在实际工程中，对数变换适合动态范围压缩，幂次变换适合显示校正，分段线性变换适合特定灰度范围的精细控制。
