# 4.3 Spark SQL与DataFrame

> [!abstract] 核心问题
> Spark SQL是什么？DataFrame和Dataset有什么区别？

## 一、Spark SQL概述

### 1. Spark SQL的定义

**定义**：Spark SQL是Spark的SQL查询模块，用于处理结构化数据。

**设计目标**：

| 目标 | 说明 |
|-----|------|
| **SQL支持** | 支持标准SQL查询 |
| **统一接口** | 提供统一的数据访问接口 |
| **高性能** | 基于Spark引擎，高性能 |
| **兼容Hive** | 兼容Hive SQL |

**适用场景**：

| 场景 | 说明 |
|-----|------|
| **交互式查询** | 交互式数据分析 |
| **数据探索** | 数据探索和分析 |
| **报表生成** | 生成数据报表 |
| **ETL** | 数据抽取、转换和加载 |

### 2. Spark SQL与Hive的对比

**对比表**：

| 对比项 | Hive | Spark SQL |
|-------|------|-----------|
| **计算引擎** | MapReduce | Spark |
| **速度** | 慢 | 快 |
| **内存计算** | 不支持 | 支持 |
| **API** | HQL | SQL/DataFrame/Dataset |
| **数据源** | HDFS | 多种数据源 |

## 二、DataFrame

### 1. DataFrame的定义

**定义**：DataFrame是一种分布式的数据集合，类似于关系型数据库的表。

**特点**：

| 特点 | 说明 |
|-----|------|
| **结构化数据** | 有固定的schema |
| **分布式** | 数据分散存储在多个节点 |
| **不可变** | 数据不可修改 |
| **类型安全** | 编译时类型检查 |

**与RDD的对比**：

| 对比项 | RDD | DataFrame |
|-------|-----|-----------|
| **数据结构** | 无schema | 有schema |
| **性能优化** | 手动优化 | Catalyst优化器 |
| **API** | 函数式 | SQL/DSL |
| **类型安全** | Python无类型检查 | 编译时类型检查 |

### 2. 创建DataFrame

**从RDD创建**：

```python
from pyspark.sql import SparkSession

# 创建SparkSession
spark = SparkSession.builder.appName("DataFrameExample").getOrCreate()

# 从RDD创建DataFrame
rdd = sc.parallelize([(1, "Alice", 25), (2, "Bob", 30), (3, "Charlie", 35)])
df = rdd.toDF(["id", "name", "age"])

# 显示DataFrame
df.show()
```

**从文件创建**：

```python
# 从CSV文件创建
df = spark.read.csv("data.csv", header=True, inferSchema=True)

# 从JSON文件创建
df = spark.read.json("data.json")

# 从Parquet文件创建
df = spark.read.parquet("data.parquet")
```

**从数据库创建**：

```python
# 从JDBC数据源创建
df = spark.read.format("jdbc") \
    .option("url", "jdbc:mysql://localhost:3306/test") \
    .option("dbtable", "users") \
    .option("user", "root") \
    .option("password", "password") \
    .load()
```

### 3. DataFrame操作

**查看DataFrame信息**：

```python
# 显示DataFrame
df.show()

# 查看schema
df.printSchema()

# 查看前n行
df.head(5)

# 查看行数
df.count()

# 查看列名
df.columns
```

**数据选择和过滤**：

```python
# 选择列
df.select("name", "age").show()

# 过滤数据
df.filter(df.age > 30).show()

# 条件查询
df.where(df.name == "Alice").show()
```

**数据聚合**：

```python
# 分组聚合
df.groupBy("age").count().show()

# 统计汇总
df.describe().show()

# 聚合函数
from pyspark.sql.functions import sum, avg, max, min
df.select(sum("age"), avg("age"), max("age"), min("age")).show()
```

**数据排序**：

```python
# 按列排序
df.orderBy("age").show()

# 降序排序
df.orderBy(df.age.desc()).show()
```

**数据操作**：

```python
# 添加列
df = df.withColumn("age_plus_10", df.age + 10)

# 修改列名
df = df.withColumnRenamed("age", "age_old")

# 删除列
df = df.drop("age_plus_10")
```

## 三、Spark SQL查询

### 1. SQL查询基础

**创建临时视图**：

```python
# 创建临时视图
df.createOrReplaceTempView("users")

# 创建全局临时视图
df.createGlobalTempView("users_global")
```

**执行SQL查询**：

```python
# 执行SQL查询
result = spark.sql("SELECT * FROM users WHERE age > 30")
result.show()

# 聚合查询
result = spark.sql("SELECT age, COUNT(*) as count FROM users GROUP BY age")
result.show()

# 连接查询
result = spark.sql("SELECT * FROM users JOIN orders ON users.id = orders.user_id")
result.show()
```

### 2. SQL函数

**内置函数**：

```python
# 使用内置函数
from pyspark.sql.functions import upper, lower, length, concat

# 字符串函数
df.select(upper(df.name), lower(df.name), length(df.name)).show()

# 日期函数
from pyspark.sql.functions import current_date, current_timestamp
df.select(current_date(), current_timestamp()).show()

# 数学函数
from pyspark.sql.functions import sqrt, pow, abs
df.select(sqrt(df.age), pow(df.age, 2), abs(df.age - 30)).show()
```

**自定义函数**：

```python
# 创建自定义函数
from pyspark.sql.functions import udf
from pyspark.sql.types import StringType

def greet(name):
    return "Hello, " + name

greet_udf = udf(greet, StringType())

# 使用自定义函数
df.select(greet_udf(df.name)).show()
```

## 四、Dataset

### 1. Dataset的定义

**定义**：Dataset是一种强类型的数据集合，结合了RDD的类型安全和DataFrame的优化。

**特点**：

| 特点 | 说明 |
|-----|------|
| **强类型** | 编译时类型检查 |
| **优化执行** | Catalyst优化器 |
| **类型安全** | Scala/Java支持，Python不支持 |

**与DataFrame的对比**：

| 对比项 | DataFrame | Dataset |
|-------|-----------|---------|
| **类型安全** | 运行时类型检查 | 编译时类型检查 |
| **语言支持** | Scala/Java/Python | Scala/Java |
| **API** | SQL/DSL | SQL/DSL/函数式 |
| **性能** | 优化 | 优化 |

### 2. 创建Dataset

**从DataFrame创建**：

```scala
// 创建Dataset
case class Person(id: Int, name: String, age: Int)
val ds = df.as[Person]

// 显示Dataset
ds.show()
```

**从序列创建**：

```scala
// 从序列创建Dataset
val ds = spark.createDataset(Seq(
    Person(1, "Alice", 25),
    Person(2, "Bob", 30),
    Person(3, "Charlie", 35)
))

// 显示Dataset
ds.show()
```

### 3. Dataset操作

**基本操作**：

```scala
// 过滤数据
ds.filter(_.age > 30).show()

// 选择数据
ds.select(_.name, _.age).show()

// 排序
ds.sort(_.age).show()

// 聚合
ds.groupBy(_.age).count().show()
```

**函数式操作**：

```scala
// map操作
ds.map(person => (person.name, person.age * 2)).show()

// flatMap操作
ds.flatMap(person => person.name.toCharArray).show()

// reduce操作
val totalAge = ds.map(_.age).reduce(_ + _)
println(totalAge)
```

## 六、性能优化

### 1. 查询优化

**优化策略**：

| 策略 | 说明 |
|-----|------|
| **使用DataFrame/Dataset** | 自动优化 |
| **避免全表扫描** | 使用索引 |
| **减少数据传输** | 过滤和聚合后再传输 |
| **使用缓存** | 缓存需要重复使用的数据 |

**示例**：

```python
# 缓存DataFrame
df.cache()

# 过滤后再聚合
df.filter(df.age > 30).groupBy("age").count().show()

# 使用广播变量
from pyspark.sql.functions import broadcast
small_df = spark.read.csv("small.csv")
large_df = spark.read.csv("large.csv")
result = large_df.join(broadcast(small_df), "id")
```

### 2. 执行计划

**查看执行计划**：

```python
# 查看逻辑执行计划
df.explain()

# 查看物理执行计划
df.explain(True)
```

**执行计划示例**：

```

*(1) HashAggregate(keys=[age#0], functions=[count(1)])
+- *(1) HashAggregate(keys=[age#0], functions=[partial_count(1)])
   +- *(1) Filter (age#0 > 30)
      +- *(1) Scan csv [id#1, name#2, age#0] Batched: false, Format: CSV, Location: InMemoryFileIndex[file:/data.csv], PartitionFilters: [], PushedFilters: [IsNotNull(age), GreaterThan(age,30)], ReadSchema: struct<id:string,name:string,age:int>
```

> [!warning] 易错点
> DataFrame有schema，RDD没有schema！DataFrame是结构化数据，RDD是通用数据集合。
