# 4.2 RDD编程模型

> [!abstract] 核心问题
> RDD的Transformation和Action操作有什么区别？如何持久化RDD？

## 一、RDD操作概述

### 1. 操作类型

**定义**：RDD的操作分为Transformation和Action两种类型。

**操作类型对比**：

| 操作类型 | 说明 | 是否触发执行 |
|---------|------|------------|
| **Transformation** | 转换操作，创建新RDD | 否（懒执行） |
| **Action** | 动作操作，返回结果 | 是（触发执行） |

**示例**：

```python
# Transformation操作（懒执行）
rdd = sc.textFile("input.txt")
words = rdd.flatMap(lambda line: line.split(" "))

# Action操作（触发执行）
count = words.count()
print(count)
```

### 2. 懒执行机制

**定义**：懒执行是指Transformation操作不会立即执行，而是等到Action操作触发时才执行。

**原理**：

| 原理 | 说明 |
|-----|------|
| **构建DAG** | Transformation操作构建有向无环图 |
| **优化执行** | Spark根据DAG优化执行计划 |
| **延迟计算** | 只计算需要的数据 |

**优势**：

| 优势 | 说明 |
|-----|------|
| **性能优化** | 可以优化执行计划 |
| **减少计算** | 只计算需要的数据 |
| **容错性** | 可以重新计算丢失的数据 |

## 二、Transformation操作

### 1. 基本Transformation操作

**常用操作**：

| 操作 | 说明 | 示例 |
|-----|------|------|
| **map** | 对每个元素应用函数 | `rdd.map(lambda x: x * 2)` |
| **flatMap** | 对每个元素应用函数并展开 | `rdd.flatMap(lambda x: x.split(" "))` |
| **filter** | 过滤满足条件的元素 | `rdd.filter(lambda x: x > 0)` |
| **distinct** | 去重 | `rdd.distinct()` |
| **sample** | 抽样 | `rdd.sample(False, 0.1)` |

**示例**：

```python
# 创建RDD
rdd = sc.parallelize([1, 2, 3, 4, 5])

# map操作：每个元素乘以2
result = rdd.map(lambda x: x * 2)
print(result.collect())  # 输出: [2, 4, 6, 8, 10]

# filter操作：过滤大于2的元素
result = rdd.filter(lambda x: x > 2)
print(result.collect())  # 输出: [3, 4, 5]

# distinct操作：去重
rdd = sc.parallelize([1, 2, 2, 3, 3, 3])
result = rdd.distinct()
print(result.collect())  # 输出: [1, 2, 3]
```

### 2. 键值对Transformation操作

**常用操作**：

| 操作 | 说明 | 示例 |
|-----|------|------|
| **mapValues** | 对键值对的值应用函数 | `rdd.mapValues(lambda x: x * 2)` |
| **reduceByKey** | 按键归约 | `rdd.reduceByKey(lambda a, b: a + b)` |
| **groupByKey** | 按键分组 | `rdd.groupByKey()` |
| **sortByKey** | 按键排序 | `rdd.sortByKey()` |
| **join** | 连接两个RDD | `rdd1.join(rdd2)` |

**示例**：

```python
# 创建键值对RDD
rdd = sc.parallelize([("a", 1), ("b", 2), ("a", 3), ("b", 4)])

# reduceByKey操作：按键求和
result = rdd.reduceByKey(lambda a, b: a + b)
print(result.collect())  # 输出: [("a", 4), ("b", 6)]

# groupByKey操作：按键分组
result = rdd.groupByKey()
print(result.collect())  # 输出: [("a", [1, 3]), ("b", [2, 4])]

# sortByKey操作：按键排序
result = rdd.sortByKey()
print(result.collect())  # 输出: [("a", 1), ("a", 3), ("b", 2), ("b", 4)]
```

### 3. 双RDD Transformation操作

**常用操作**：

| 操作 | 说明 | 示例 |
|-----|------|------|
| **union** | 合并两个RDD | `rdd1.union(rdd2)` |
| **intersection** | 求交集 | `rdd1.intersection(rdd2)` |
| **subtract** | 求差集 | `rdd1.subtract(rdd2)` |
| **cartesian** | 求笛卡尔积 | `rdd1.cartesian(rdd2)` |
| **join** | 连接两个RDD | `rdd1.join(rdd2)` |

**示例**：

```python
# 创建两个RDD
rdd1 = sc.parallelize([1, 2, 3])
rdd2 = sc.parallelize([3, 4, 5])

# union操作：合并两个RDD
result = rdd1.union(rdd2)
print(result.collect())  # 输出: [1, 2, 3, 3, 4, 5]

# intersection操作：求交集
result = rdd1.intersection(rdd2)
print(result.collect())  # 输出: [3]

# subtract操作：求差集
result = rdd1.subtract(rdd2)
print(result.collect())  # 输出: [1, 2]
```

## 三、Action操作

### 1. 基本Action操作

**常用操作**：

| 操作 | 说明 | 示例 |
|-----|------|------|
| **collect** | 返回所有元素 | `rdd.collect()` |
| **count** | 返回元素数量 | `rdd.count()` |
| **first** | 返回第一个元素 | `rdd.first()` |
| **take** | 返回前n个元素 | `rdd.take(3)` |
| **top** | 返回最大的n个元素 | `rdd.top(3)` |

**示例**：

```python
# 创建RDD
rdd = sc.parallelize([1, 2, 3, 4, 5])

# collect操作：返回所有元素
print(rdd.collect())  # 输出: [1, 2, 3, 4, 5]

# count操作：返回元素数量
print(rdd.count())  # 输出: 5

# first操作：返回第一个元素
print(rdd.first())  # 输出: 1

# take操作：返回前3个元素
print(rdd.take(3))  # 输出: [1, 2, 3]
```

### 2. 聚合Action操作

**常用操作**：

| 操作 | 说明 | 示例 |
|-----|------|------|
| **reduce** | 归约所有元素 | `rdd.reduce(lambda a, b: a + b)` |
| **fold** | 归约所有元素（带初始值） | `rdd.fold(0, lambda a, b: a + b)` |
| **aggregate** | 聚合所有元素（带初始值） | `rdd.aggregate((0, 0), ...)` |

**示例**：

```python
# 创建RDD
rdd = sc.parallelize([1, 2, 3, 4, 5])

# reduce操作：求和
print(rdd.reduce(lambda a, b: a + b))  # 输出: 15

# fold操作：求和（带初始值）
print(rdd.fold(0, lambda a, b: a + b))  # 输出: 15

# aggregate操作：求总和和元素数量
sumCount = rdd.aggregate((0, 0),
    lambda acc, val: (acc[0] + val, acc[1] + 1),
    lambda acc1, acc2: (acc1[0] + acc2[0], acc1[1] + acc2[1]))
print(sumCount)  # 输出: (15, 5)
```

### 3. 键值对Action操作

**常用操作**：

| 操作 | 说明 | 示例 |
|-----|------|------|
| **countByKey** | 按键计数 | `rdd.countByKey()` |
| **collectAsMap** | 返回键值对Map | `rdd.collectAsMap()` |
| **lookup** | 根据键查找值 | `rdd.lookup("a")` |

**示例**：

```python
# 创建键值对RDD
rdd = sc.parallelize([("a", 1), ("b", 2), ("a", 3), ("b", 4)])

# countByKey操作：按键计数
print(rdd.countByKey())  # 输出: {"a": 2, "b": 2}

# collectAsMap操作：返回键值对Map
print(rdd.collectAsMap())  # 输出: {"a": 3, "b": 4}

# lookup操作：根据键查找值
print(rdd.lookup("a"))  # 输出: [1, 3]
```

### 4. 输出Action操作

**常用操作**：

| 操作 | 说明 | 示例 |
|-----|------|------|
| **saveAsTextFile** | 保存为文本文件 | `rdd.saveAsTextFile("output")` |
| **saveAsSequenceFile** | 保存为SequenceFile | `rdd.saveAsSequenceFile("output")` |
| **saveAsObjectFile** | 保存为对象文件 | `rdd.saveAsObjectFile("output")` |

**示例**：

```python
# 创建RDD
rdd = sc.parallelize([("a", 1), ("b", 2), ("a", 3), ("b", 4)])

# 保存为文本文件
rdd.saveAsTextFile("output")
```

## 四、RDD持久化

### 1. 持久化概述

**定义**：RDD持久化是指将RDD的数据缓存到内存或磁盘中，以便重复使用。

**作用**：

| 作用 | 说明 |
|-----|------|
| **提高性能** | 避免重复计算 |
| **减少计算时间** | 缓存后直接读取 |
| **适合迭代计算** | 机器学习算法需要多次迭代 |

**持久化级别**：

| 级别 | 说明 |
|-----|------|
| **MEMORY_ONLY** | 存储在内存中（默认） |
| **MEMORY_AND_DISK** | 存储在内存和磁盘中 |
| **DISK_ONLY** | 存储在磁盘中 |
| **MEMORY_ONLY_SER** | 存储在内存中（序列化） |
| **MEMORY_AND_DISK_SER** | 存储在内存和磁盘中（序列化） |

### 2. cache和persist

**cache**：

```python
# 使用cache缓存RDD（默认MEMORY_ONLY）
rdd.cache()
```

**persist**：

```python
# 使用persist缓存RDD（指定持久化级别）
from pyspark.storagelevel import StorageLevel
rdd.persist(StorageLevel.MEMORY_AND_DISK)
```

**区别**：

| 区别 | cache | persist |
|-----|-------|---------|
| **持久化级别** | 默认MEMORY_ONLY | 用户指定 |
| **灵活性** | 低 | 高 |

### 3. 缓存管理

**查看缓存状态**：

```python
# 查看RDD是否被缓存
print(rdd.is_cached)  # 输出: True

# 查看缓存大小
print(rdd.getStorageLevel())  # 输出: StorageLevel(True, False, False, False)
```

**清除缓存**：

```python
# 清除单个RDD的缓存
rdd.unpersist()

# 清除所有RDD的缓存
sc.clearCache()
```

## 五、RDD分区管理

### 1. 分区数量调整

**调整分区数量**：

```python
# 创建RDD时指定分区数量
rdd = sc.parallelize([1, 2, 3, 4, 5], numSlices=3)

# 重新分区
rdd = rdd.repartition(5)

# 合并分区
rdd = rdd.coalesce(2)
```

**repartition vs coalesce**：

| 区别 | repartition | coalesce |
|-----|-------------|----------|
| **是否洗牌** | 是 | 否（减少分区时） |
| **性能** | 慢 | 快 |
| **适用场景** | 增加分区 | 减少分区 |

### 2. 分区器

**设置分区器**：

```python
from pyspark import HashPartitioner, RangePartitioner

# 使用哈希分区器
rdd = rdd.partitionBy(HashPartitioner(3))

# 使用范围分区器
rdd = rdd.partitionBy(RangePartitioner(3))
```

**自定义分区器**：

```python
from pyspark import Partitioner

class CustomPartitioner(Partitioner):
    def __init__(self, numPartitions):
        self.numPartitions = numPartitions
    
    def numPartitions(self):
        return self.numPartitions
    
    def getPartition(self, key):
        # 自定义分区逻辑
        if key < 10:
            return 0
        elif key < 20:
            return 1
        else:
            return 2

# 使用自定义分区器
rdd = rdd.partitionBy(CustomPartitioner(3))
```

> [!warning] 易错点
> Transformation操作是懒执行的，Action操作才会触发执行！不要忘记只有Action操作才会真正执行计算。
