# 5.2 HQL查询语言

> [!abstract] 核心问题
> HQL和SQL有什么区别？如何编写HQL查询？

## 一、HQL概述

### 1. HQL的定义

**定义**：HQL（Hive Query Language）是Hive的查询语言，类似于SQL。

**特点**：

| 特点 | 说明 |
|-----|------|
| **类SQL** | 语法类似于SQL |
| **扩展性** | 支持用户自定义函数 |
| **分布式** | 基于分布式计算 |
| **批处理** | 批处理查询 |

**与SQL的区别**：

| 区别 | SQL | HQL |
|-----|-----|-----|
| **执行引擎** | 自身引擎 | MapReduce/Spark |
| **数据存储** | 本地存储 | HDFS |
| **事务支持** | 支持 | 有限支持 |
| **数据类型** | 标准类型 | 扩展类型 |
| **分区表** | 不支持 | 支持 |

### 2. HQL数据类型

**基本数据类型**：

| 类型 | 说明 | 示例 |
|-----|------|------|
| **TINYINT** | 1字节整数 | 1 |
| **SMALLINT** | 2字节整数 | 100 |
| **INT** | 4字节整数 | 10000 |
| **BIGINT** | 8字节整数 | 1000000000 |
| **FLOAT** | 单精度浮点 | 1.5 |
| **DOUBLE** | 双精度浮点 | 1.5 |
| **STRING** | 字符串 | "hello" |
| **BOOLEAN** | 布尔值 | true |
| **TIMESTAMP** | 时间戳 | "2023-01-01 00:00:00" |
| **DATE** | 日期 | "2023-01-01" |

**复杂数据类型**：

| 类型 | 说明 | 示例 |
|-----|------|------|
| **ARRAY** | 数组 | array(1, 2, 3) |
| **MAP** | 键值对 | map("a", 1, "b", 2) |
| **STRUCT** | 结构体 | struct("Alice", 25) |
| **UNION** | 联合类型 | create_union(0, "hello", 1) |

## 二、DDL语句

### 1. 数据库操作

**创建数据库**：

```sql
CREATE DATABASE IF NOT EXISTS mydb;
```

**使用数据库**：

```sql
USE mydb;
```

**查看数据库**：

```sql
SHOW DATABASES;
```

**删除数据库**：

```sql
DROP DATABASE IF EXISTS mydb;
```

### 2. 表操作

**创建表**：

```sql
CREATE TABLE IF NOT EXISTS users (
    id INT,
    name STRING,
    age INT
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
LINES TERMINATED BY '\n';
```

**查看表**：

```sql
SHOW TABLES;
```

**查看表结构**：

```sql
DESCRIBE users;
DESCRIBE EXTENDED users;
```

**修改表**：

```sql
-- 添加列
ALTER TABLE users ADD COLUMNS (email STRING);

-- 修改列类型
ALTER TABLE users CHANGE COLUMN age age_new INT;

-- 修改表名
ALTER TABLE users RENAME TO users_new;
```

**删除表**：

```sql
DROP TABLE IF EXISTS users;
```

### 3. 分区操作

**添加分区**：

```sql
ALTER TABLE users_part ADD PARTITION (country='US');
```

**删除分区**：

```sql
ALTER TABLE users_part DROP PARTITION (country='US');
```

**查看分区**：

```sql
SHOW PARTITIONS users_part;
```

## 三、DML语句

### 1. 数据加载

**加载数据**：

```sql
-- 从本地加载数据
LOAD DATA LOCAL INPATH '/data/users.txt' INTO TABLE users;

-- 从HDFS加载数据
LOAD DATA INPATH '/user/hadoop/users.txt' INTO TABLE users;

-- 覆盖加载数据
LOAD DATA LOCAL INPATH '/data/users.txt' OVERWRITE INTO TABLE users;
```

**插入数据**：

```sql
-- 插入单行数据
INSERT INTO TABLE users VALUES (1, 'Alice', 25);

-- 插入查询结果
INSERT INTO TABLE users_new
SELECT id, name, age FROM users WHERE age > 30;

-- 多表插入
FROM users
INSERT INTO TABLE users_us SELECT * WHERE country='US'
INSERT INTO TABLE users_cn SELECT * WHERE country='CN';
```

### 2. 数据导出

**导出数据**：

```sql
-- 导出到本地
INSERT OVERWRITE LOCAL DIRECTORY '/data/output'
SELECT * FROM users;

-- 导出到HDFS
INSERT OVERWRITE DIRECTORY '/user/hadoop/output'
SELECT * FROM users;
```

### 3. 数据删除

**删除数据**：

```sql
-- 删除表中所有数据
TRUNCATE TABLE users;

-- 删除分区数据
ALTER TABLE users_part DROP PARTITION (country='US');
```

## 四、查询语句

### 1. 基本查询

**查询所有数据**：

```sql
SELECT * FROM users;
```

**查询指定列**：

```sql
SELECT id, name FROM users;
```

**条件查询**：

```sql
SELECT * FROM users WHERE age > 30;
```

**排序查询**：

```sql
SELECT * FROM users ORDER BY age DESC;
```

**限制查询**：

```sql
SELECT * FROM users LIMIT 10;
```

### 2. 聚合查询

**聚合函数**：

| 函数 | 说明 |
|-----|------|
| **COUNT** | 计数 |
| **SUM** | 求和 |
| **AVG** | 求平均 |
| **MAX** | 求最大 |
| **MIN** | 求最小 |

**示例**：

```sql
-- 计数
SELECT COUNT(*) FROM users;

-- 求和
SELECT SUM(age) FROM users;

-- 求平均
SELECT AVG(age) FROM users;

-- 分组聚合
SELECT country, COUNT(*) as count FROM users GROUP BY country;

-- 分组筛选
SELECT country, COUNT(*) as count FROM users GROUP BY country HAVING count > 100;
```

### 3. 连接查询

**连接类型**：

| 类型 | 说明 |
|-----|------|
| **INNER JOIN** | 内连接 |
| **LEFT JOIN** | 左连接 |
| **RIGHT JOIN** | 右连接 |
| **FULL JOIN** | 全连接 |
| **CROSS JOIN** | 笛卡尔积 |

**示例**：

```sql
-- 内连接
SELECT u.id, u.name, o.order_id
FROM users u
INNER JOIN orders o ON u.id = o.user_id;

-- 左连接
SELECT u.id, u.name, o.order_id
FROM users u
LEFT JOIN orders o ON u.id = o.user_id;

-- 右连接
SELECT u.id, u.name, o.order_id
FROM users u
RIGHT JOIN orders o ON u.id = o.user_id;
```

### 4. 子查询

**子查询示例**：

```sql
-- 标量子查询
SELECT * FROM users WHERE age > (SELECT AVG(age) FROM users);

-- 行子查询
SELECT * FROM users WHERE (id, age) IN (SELECT id, age FROM users_new);

-- 相关子查询
SELECT * FROM users u WHERE EXISTS (SELECT * FROM orders o WHERE o.user_id = u.id);
```

### 5. 窗口函数

**窗口函数概述**：

**定义**：窗口函数是对一组数据进行计算，但不改变数据的行数。

**常用窗口函数**：

| 函数 | 说明 |
|-----|------|
| **ROW_NUMBER** | 行号 |
| **RANK** | 排名（有间隙） |
| **DENSE_RANK** | 排名（无间隙） |
| **LAG** | 前n行数据 |
| **LEAD** | 后n行数据 |
| **SUM OVER** | 累计求和 |

**示例**：

```sql
-- 行号
SELECT id, name, age, ROW_NUMBER() OVER (ORDER BY age) as row_num FROM users;

-- 排名
SELECT id, name, age, RANK() OVER (ORDER BY age) as rank FROM users;

-- 累计求和
SELECT id, name, age, SUM(age) OVER (ORDER BY id) as cumulative_sum FROM users;

-- 分组排名
SELECT id, name, age, country, ROW_NUMBER() OVER (PARTITION BY country ORDER BY age) as row_num FROM users;
```

## 五、用户自定义函数

### 1. UDF

**定义**：UDF（User Defined Function）是用户自定义的函数。

**创建UDF**：

```java
public class MyUDF extends UDF {
    public Text evaluate(Text input) {
        if (input == null) {
            return null;
        }
        return new Text(input.toString().toUpperCase());
    }
}
```

**注册UDF**：

```sql
-- 注册UDF
ADD JAR /path/to/myudf.jar;
CREATE TEMPORARY FUNCTION to_upper AS 'com.example.MyUDF';

-- 使用UDF
SELECT to_upper(name) FROM users;
```

### 2. UDAF

**定义**：UDAF（User Defined Aggregate Function）是用户自定义的聚合函数。

**创建UDAF**：

```java
public class MyUDAF extends AbstractGenericUDAFResolver {
    @Override
    public GenericUDAFEvaluator getEvaluator(TypeInfo[] parameters) {
        return new MyUDAFEvaluator();
    }
    
    public static class MyUDAFEvaluator extends GenericUDAFEvaluator {
        // 聚合逻辑
    }
}
```

### 3. UDTF

**定义**：UDTF（User Defined Table Generating Function）是用户自定义的表生成函数。

**创建UDTF**：

```java
public class MyUDTF extends GenericUDTF {
    @Override
    public void process(Object[] args) throws HiveException {
        // 生成多行数据
    }
    
    @Override
    public void close() throws HiveException {
        // 清理资源
    }
}
```

> [!warning] 易错点
> HQL支持窗口函数，但传统SQL的某些特性在HQL中不支持！例如，HQL不支持UPDATE和DELETE语句（除非启用事务）。
