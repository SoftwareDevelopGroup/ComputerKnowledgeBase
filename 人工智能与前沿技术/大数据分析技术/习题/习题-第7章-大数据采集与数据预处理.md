## 三、简答题

### 7.1 大数据采集工具Flume

**题目1**：请简述Flume的架构设计。

**参考答案**：

Flume的架构包括三个核心组件：

1. **Source**：数据源，负责收集数据。
2. **Channel**：通道，负责缓冲数据。
3. **Sink**：接收器，负责输出数据。

数据从Source流入Channel，然后从Channel流出到Sink。Flume支持多种Source、Channel和Sink类型，可以灵活配置。

---

**题目2**：请编写一个Flume配置文件，将日志文件收集到HDFS。

**参考答案**：

```properties
# 定义Agent
agent.sources = source1
agent.channels = channel1
agent.sinks = sink1

# 配置Source（Spooling Directory Source）
agent.sources.source1.type = spooldir
agent.sources.source1.spoolDir = /data/logs
agent.sources.source1.fileSuffix = .log
agent.sources.source1.deletePolicy = immediate

# 配置Channel（Memory Channel）
agent.channels.channel1.type = memory
agent.channels.channel1.capacity = 10000
agent.channels.channel1.transactionCapacity = 100

# 配置Sink（HDFS Sink）
agent.sinks.sink1.type = hdfs
agent.sinks.sink1.hdfs.path = hdfs://localhost:9000/flume/logs
agent.sinks.sink1.hdfs.filePrefix = logs
agent.sinks.sink1.hdfs.fileSuffix = .log
agent.sinks.sink1.hdfs.rollInterval = 30
agent.sinks.sink1.hdfs.rollSize = 134217728
agent.sinks.sink1.hdfs.rollCount = 0

# 连接Source、Channel、Sink
agent.sources.source1.channels = channel1
agent.sinks.sink1.channel = channel1
```

### 7.2 消息队列Kafka

**题目3**：请简述Kafka的架构设计。

**参考答案**：

Kafka的架构包括：

1. **Producer**：生产者，负责发送消息到Kafka。
2. **Consumer**：消费者，负责从Kafka读取消息。
3. **Broker**：代理，负责存储消息。
4. **Topic**：主题，消息的分类。
5. **Partition**：分区，Topic的分片。
6. **Consumer Group**：消费者组，多个消费者协同消费一个Topic。

Kafka将消息存储在磁盘上，支持多副本，保证数据可靠性。

---

**题目4**：请编写一个Kafka Producer和Consumer的示例。

**参考答案**：

**Producer**：

```java
Properties props = new Properties();
props.put("bootstrap.servers", "localhost:9092");
props.put("key.serializer", "org.apache.kafka.common.serialization.StringSerializer");
props.put("value.serializer", "org.apache.kafka.common.serialization.StringSerializer");

KafkaProducer<String, String> producer = new KafkaProducer<>(props);
ProducerRecord<String, String> record = new ProducerRecord<>("mytopic", "key", "value");
producer.send(record);
producer.close();
```

**Consumer**：

```java
Properties props = new Properties();
props.put("bootstrap.servers", "localhost:9092");
props.put("key.deserializer", "org.apache.kafka.common.serialization.StringDeserializer");
props.put("value.deserializer", "org.apache.kafka.common.serialization.StringDeserializer");
props.put("group.id", "mygroup");

KafkaConsumer<String, String> consumer = new KafkaConsumer<>(props);
consumer.subscribe(Arrays.asList("mytopic"));

while (true) {
    ConsumerRecords<String, String> records = consumer.poll(Duration.ofMillis(100));
    for (ConsumerRecord<String, String> record : records) {
        System.out.println(record.value());
    }
}
```

### 7.3 数据预处理与ETL流程

**题目5**：请简述ETL流程。

**参考答案**：

ETL流程包括：

1. **数据抽取**：从各种数据源抽取数据（数据库、文件、日志、API等）。
2. **数据转换**：对抽取的数据进行清洗、转换和集成。
   - 数据清洗：去重、补全缺失值、修正错误值、过滤无效数据。
   - 数据转换：类型转换、格式转换、字段映射、数据派生。
   - 数据集成：连接、合并、关联多个数据源。
3. **数据加载**：将转换后的数据加载到目标系统（数据仓库、数据库、数据湖等）。

---

**题目6**：请编写一个Spark数据预处理的示例。

**参考答案**：

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, when

# 创建SparkSession
spark = SparkSession.builder \
    .appName("Data Preprocessing") \
    .getOrCreate()

# 加载数据
df = spark.read.csv("data.csv", header=True, inferSchema=True)

# 数据清洗
df_clean = df.na.drop()  # 删除缺失值
df_dedup = df_clean.dropDuplicates()  # 删除重复值
df_filtered = df_dedup.filter(col("age") > 0)  # 过滤无效数据

# 数据转换
df_cast = df_filtered.withColumn("age", col("age").cast("int"))  # 类型转换
df_mapped = df_cast.withColumn("gender", when(col("sex") == "M", "男").otherwise("女"))  # 字段映射

# 数据集成
df_joined = df_mapped.join(other_df, "id", "left")  # 左连接

# 保存数据
df_joined.write.csv("output.csv", header=True)

# 关闭SparkSession
spark.stop()
```

**题目2**：请说明ETL和ELT的区别。

**参考答案**：

ETL和ELT的区别：

1. **处理顺序**：
   - ETL：抽取→转换→加载
   - ELT：抽取→加载→转换

2. **转换位置**：
   - ETL：在中间层进行转换
   - ELT：在目标系统进行转换

3. **适用场景**：
   - ETL：传统数据仓库
   - ELT：大数据（数据量较大）

4. **灵活性**：
   - ETL：灵活性较低
   - ELT：灵活性较高

5. **性能**：
   - ETL：性能较低
   - ELT：性能较高（利用目标系统的计算能力）

## 五、面试真题

**题目1**：Flume和Kafka有什么区别？

**参考答案**：

1. **定位**：Flume是日志收集系统，Kafka是消息队列系统。
2. **数据源**：Flume支持多种数据源，Kafka的数据源是Producer。
3. **目的地**：Flume支持多种目的地，Kafka的目的地是Consumer。
4. **可靠性**：Flume的可靠性取决于Channel类型，Kafka的可靠性较高。
5. **吞吐量**：Flume的吞吐量中等，Kafka的吞吐量较高。

---

**题目2**：Kafka的数据保留策略是什么？

**参考答案**：

Kafka的数据保留策略包括：

1. **时间保留**：按时间保留消息，默认保留7天。
2. **大小保留**：按大小保留消息，默认保留1GB。

可以通过以下配置设置：

```properties
log.retention.hours=168  # 时间保留（7天）
log.retention.bytes=1073741824  # 大小保留（1GB）
log.segment.bytes=1073741824  # 日志段大小（1GB）
```

---

**题目3**：数据预处理的重要性是什么？

**参考答案**：

数据预处理的重要性包括：

1. **提高数据质量**：清洗脏数据，提高数据准确性和完整性。
2. **提高分析效率**：预处理后的数据更容易分析。
3. **减少错误**：减少分析过程中的错误。
4. **提高模型性能**：高质量的数据可以提高模型的准确性。
5. **符合业务需求**：将数据转换为业务需要的格式。
