# 1.1 嵌入式定义、特征与应用场景

## 一、嵌入式系统的定义

### 1. 经典定义

> [!quote] 定义
> 嵌入式系统是以应用为中心、以计算机技术为基础、软硬件可裁剪，适用于对功能、可靠性、成本、体积、功耗等严格要求的专用计算机系统。

**解读**：

| 关键词 | 含义 |
|-------|------|
| 以应用为中心 | 为特定应用而设计，不是通用计算机 |
| 以计算机技术为基础 | 基于微处理器、存储器等计算机技术 |
| 软硬件可裁剪 | 根据需求裁剪硬件和软件 |
| 专用性 | 针对特定任务，功能有限但高效 |

### 2. 与通用计算机的对比

| 对比项 | 嵌入式系统 | 通用计算机 |
|-------|----------|-----------|
| 设计目标 | 专用、特定功能 | 通用、多用途 |
| 资源 | 有限（低功耗、小体积） | 丰富 |
| 功耗 | 严格控制 | 相对宽松 |
| 可靠性 | 高（长期运行） | 中等 |
| 实时性 | 常要求实时响应 | 通常无此要求 |
| 操作系统 | RTOS或无OS | Linux/Windows/macOS |
| 成本 | 敏感（批量） | 相对不敏感 |

## 二、嵌入式系统的典型特征

### 1. 专用性

- 面向特定应用场景（如电机控制、传感器采集）
- 功能定制，不追求通用性
- 硬件软件协同设计

### 2. 资源受限

| 资源 | 约束 |
|-----|------|
| 存储空间 | Flash/SRAM容量有限 |
| 处理能力 | MCU主频通常10MHz~1GHz |
| 功耗 | 需要低功耗设计（电池供电） |
| 体积 | 小型化、微型化 |
| 成本 | 对BOM成本敏感 |

### 3. 高可靠性

- 长期稳定运行（7×24小时）
- 工作环境恶劣（温度、震动、电磁干扰）
- 需要故障恢复机制（看门狗、冗余设计）

### 4. 实时性

- 必须在规定时间内响应外部事件
- 硬实时：超deadline即失效（如刹车控制）
- 软实时：偶尔可超deadline（如音视频播放）

## 三、嵌入式系统的分类

### 按复杂度分类

| 类别 | MCU位数 | 主频 | 代表产品 | 应用 |
|-----|--------|------|---------|-----|
| 低端 | 4/8位 | <10MHz | 51系列、PIC | 家电、仪表 |
| 中端 | 16/32位 | 10~100MHz | STM32 F1/F0、MSP430 | 工业控制、物联网 |
| 高端 | 32/64位 | >100MHz | STM32H7、i.MX6、RK3288 | 网关、机器人、边缘AI |

### 按指令集分类

| 架构 | 特点 | 代表产品 |
|-----|------|---------|
| CISC（x86） | 指令复杂、功耗高 | PC处理器 |
| RISC（ARM） | 指令简单、功耗低 | STM32、i.MX、RK |
| RISC-V | 开源免费 | 生态迅速发展 |

### 按软件架构分类

| 类型 | 说明 |
|-----|------|
| 裸机系统 | 无OS，直接操作硬件 |
| 前后台系统 | 主循环+中断，简单调度 |
| RTOS系统 | 实时多任务操作系统 |
| Linux系统 | 通用嵌入式Linux |

## 四、嵌入式系统的典型应用场景

### 1. 工业控制

- PLC（可编程逻辑控制器）
- 电机驱动与变频控制
- 工业机器人（机械臂、AGV）
- 智能传感器（温度、压力、振动）

### 2. 消费电子

- 智能手机、平板电脑
- 智能手表、运动手环
- 智能音箱、家庭网关
- 电子书阅读器

### 3. 汽车电子

- ECU（电子控制单元）
- ADAS（高级驾驶辅助系统）
- 车载T-BOX（远程信息处理）
- 智能仪表盘

### 4. 医疗设备

- 电子血压计、血糖仪
- 心电监护仪、呼吸机
- 便携式B超、心电图机
- 植入式设备（心脏起搏器）

### 5. 物联网

- 智能传感器节点
- 无线网关、边缘网关
- RFID读写器
- 智能家居控制器

### 6. 典型产品拆解

> [!example] 智能音箱的嵌入式系统
> 
> - **核心芯片**：全志R16（四核Cortex-A7 + 语音加速器）
> - **存储**：512MB DDR3 + 8GB eMMC
> - **外设**：麦克风阵列、扬声器、触摸按键、Wi-Fi/蓝牙模块
> - **软件**：运行定制Linux，集成语音唤醒、云端交互

## 五、嵌入式系统的发展趋势

### 1. 智能化

- AI推理在边缘端运行（TFLite、ONNX Runtime）
- 本地语音识别、图像处理
- 自适应控制算法

### 2. 网络化

- 5G/Cat.1/Cat.4通信
- OTA（空中升级）
- 云边协同

### 3. 低功耗

- 能量收集（太阳能、温差发电）
- 休眠/唤醒策略
- 低功耗通信协议（BLE、LoRa、NB-IoT）

### 4. 小型化

- System-in-Package（SiP）
- Chiplet（芯粒）技术
- 柔性、可穿戴
