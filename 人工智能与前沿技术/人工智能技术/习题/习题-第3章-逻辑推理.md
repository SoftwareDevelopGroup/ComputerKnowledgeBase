## 一、单选题

**1. 在命题逻辑中，下列哪一个是永真式（重言式，tautology）？**

A. P ∧ ¬P
B. P ∨ ¬P
C. P → ¬P
D. (P ∨ Q) ∧ (¬P ∧ ¬Q)

**2. 下列关于谓词逻辑的说法，错误的是？**

A. 谓词逻辑可以表示对象之间的关系
B. 全称量词 ∀ 表示"对于所有"
C. 存在量词 ∃ 表示"存在一个"
D. 谓词逻辑不能表达"所有鸟都会飞"这样的陈述

**3. 归结推理（Resolution）的核心规则是？**

A. 从 P 和 P → Q 推出 Q
B. 从 P ∨ Q 和 ¬P ∨ R 推出 Q ∨ R
C. 从 P 和 ¬P 推出任意结论
D. 从 P → Q 和 Q → R 推出 P → R

**4. 在 Horn 子句中，最多包含几个正文字？**

A. 0 个
B. 1 个
C. 2 个
D. 任意多个

**5. 下列关于前束范式（prenex normal form）的说法，正确的是？**

A. 量词全部放在公式最前面
B. 所有量词都被消去
C. 只存在全称量词
D. 只存在存在量词

**6. 设论域为所有实数，谓词 P(x) 表示"x > 0"，则 ∀x ∃y (P(x) ∧ P(y) ∧ (x + y = 0)) 的真值为？**

A. 真
B. 假
C. 无法判定
D. 取决于具体的 x 和 y

## 五、计算题

**1. 【命题逻辑推理】使用真值表法判断下列公式是否为永真式：**
$$(P \rightarrow Q) \wedge (Q \rightarrow R) \rightarrow (P \rightarrow R)$$

**2. 【归结证明】使用归结推理证明以下推理的正确性：**
- 前提：① 所有的人都会死 ② 苏格拉底是人
- 结论：苏格拉底会死
- 要求：将前提和结论否定转化为子句，然后进行归结，推出空子句。

**3. 【谓词逻辑翻译】设谓词如下：**
- $Bird(x)$：$x$ 是鸟
- $Fly(x)$：$x$ 会飞
- $Penguin(x)$：$x$ 是企鹅
- $Swim(x)$：$x$ 会游泳

请将下列语句翻译为一阶谓词逻辑公式：
- (1) 所有的鸟都会飞，但企鹅是鸟却不会飞；
- (2) 有些鸟会游泳；
- (3) 如果所有的鸟都会飞，那么企鹅不是鸟。

**4. 【子句化与归结】将下列谓词公式转化为子句集，并使用归结推理判断其是否可满足：**
$$\exists x \forall y (P(x, y) \rightarrow \forall z Q(z))$$

## 六、编程题

**1. 【命题逻辑求值】使用 Python 实现一个简单的命题逻辑求值器：**
- 支持 ¬（否定）、∧（合取）、∨（析取）、→（蕴含）、↔（等值）五种连接词；
- 输入一个命题公式（以字符串形式）和一个真值赋值字典，输出公式的真值；
- 测试用例：`(P → Q) ∧ (Q → R) → (P → R)`，其中 P=True, Q=False, R=True。

**2. 【简单归结引擎】使用 Python 实现一个命题逻辑的归结推理引擎：**
- 支持将命题公式转化为子句集；
- 实现二元归结规则；
- 输入一组前提子句和一个目标子句（取反），判断是否能归结出空子句；
- 测试：前提为 `{P, P→Q, Q→R}`，目标为 `R`。
