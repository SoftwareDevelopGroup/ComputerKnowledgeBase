## 三、判断题

**1. 大模型的涌现能力（Emergent Abilities）指的是当模型规模达到一定阈值后，在某些任务上表现出出乎意料的能力。**

**2. LoRA 通过低秩矩阵近似权重更新，使得微调 7B 模型只需数 GB 显存。**

**3. RLHF 中的奖励模型需要人类对模型输出进行排序标注来训练。**

**4. Diffusion Model 的反向去噪过程是一个马尔可夫链，每一步只依赖当前的噪声状态。**

**5. RAG 的核心优势是可以引入私有知识库，并且能减少幻觉，不需要重新训练模型。**

**6. 量化（Quantization）技术会导致模型性能严重下降，因此在实际部署中很少使用。**

## 五、计算题

**1. 【Self-Attention 计算】给定输入序列长度 $n = 4$，嵌入维度 $d_{model} = 512$，注意力头数 $h = 8$：**
- (1) 计算每个注意力头的维度 $d_k$；
- (2) 计算 Self-Attention 中 $Q$、$K$、$V$ 投影矩阵的总参数量；
- (3) 计算单层 Self-Attention 的计算量（FLOPs）。

**2. 【LoRA 参数量】假设对一个 7B 参数的大模型应用 LoRA：**
- 原始模型参数量：$7 \times 10^9$
- LoRA 秩 $r = 8$，目标模块为 Query 和 Value 投影
- 原始 $W_q$ 和 $W_v$ 的形状均为 $[512, 512]$
计算 LoRA 新增的参数量。

**3. 【KV Cache 显存估算】假设 LLM 有 32 层，隐藏维度 4096，序列长度 2048，数据类型为 FP16（2 字节）：**
- 计算单 token 的 KV Cache 显存占用；
- 当生成长度为 1024 的序列时，计算总 KV Cache 显存。

**4. 【参数量估算】估算一个 LLaMA-7B 模型的参数量（已知 Transformer 层数 $L=32$，隐藏维度 $d=4096$，注意力头数 $h=32$，FFN 中间维度 $d_{ff}=11008$，词表大小 $V=32000$）。**
