# 8.1 文本预处理与词嵌入

## 一、文本预处理

### 1.1 分词（Tokenization）

**定义：** 将连续的文本序列按照一定规则切分为有意义的最小单元（Token）的过程。

#### 常用分词方法

| 方法 | 描述 | 示例 |
|------|------|------|
| 规则分词 | 基于词典和语法规则 | 正向最大匹配、逆向最大匹配 |
| 统计分词 | 基于统计模型 | N-最短路径、HMM、CRF |
| 深度学习分词 | 基于神经网络 | BiLSTM-CRF、BERT分词 |

#### 中英文分词差异

- **中文分词**：没有天然分隔符，需要算法识别词边界
- **英文分词**：天然以空格分隔，需处理缩写、标点等

### 1.2 词性标注（POS Tagging）

**定义：** 为每个分词标注其语法词性的过程。

常用标签集：Penn Treebank（45个标签）、ICTB（33个标签）

### 1.3 词干提取（Stemming）与词形还原（Lemmatization）

#### 词干提取（Stemming）

将词还原为词干形式的过程，基于规则。

```python
# 常用算法
# Porter Stemmer：基于规则的词干提取
# Lancaster Stemmer：更激进的词干提取
# Snowball Stemmer：多语言支持
```

| 原词 | Porter Stemmer | Lancaster Stemmer |
|------|----------------|-------------------|
| running | run | run |
| faster | faster | faster |
| national | nation | nat |
| international | intern | intern |

#### 词形还原（Lemmatization）

将词还原为词典中的原形（lemma），基于词典和词性。

| 原词 | 词形还原 | 词干提取 |
|------|----------|----------|
| better | good | better |
| feet | foot | feet |
| running | run | run |
| went | go | went |

#### 对比

| 维度 | 词干提取 | 词形还原 |
|------|----------|----------|
| 方法 | 基于规则 | 基于词典+词性 |
| 还原精度 | 较低（可能产生非词） | 高（产生真实词） |
| 速度 | 快 | 较慢 |
| 适用场景 | 信息检索、搜索引擎 | 需要精确语义的NLP任务 |

### 1.4 停用词去除

**定义：** 去除在文本中出现频率高但对语义贡献小的词汇（如"的"、"是"、"the"、"is"等）。

## 二、传统文本表示方法

### 2.1 独热编码（One-Hot Encoding）

**定义：** 将每个词表示为词表大小的向量，只有对应词的位置为1，其余为0。

#### 数学表示

$$\text{OneHot}(w) = [0, 0, \ldots, 1, \ldots, 0] \in \mathbb{R}^{|V|}$$

其中 $|V|$ 为词表大小。

#### 优缺点

| 优点 | 缺点 |
|------|------|
| 简单直观 | 维度灾难（词表越大维度越高） |
| 稀疏存储高效 | 无语义相似度信息 |
| 适用于小规模词表 | 泛化能力差 |

### 2.2 词袋模型（Bag of Words, BoW）

**定义：** 基于词频统计的文本表示方法，忽略词序和语法。

#### 数学表示

$$\text{BoW}(\text{doc}) = [\text{count}(w_1), \text{count}(w_2), \ldots, \text{count}(w_{|V|})]$$

### 2.3 TF-IDF

**定义：** 基于词频和逆文档频率的加权统计方法，评估词对文档的重要性。

#### TF（Term Frequency，词频）

$$\text{TF}(t, d) = \frac{\text{count}(t, d)}{\text{total\_terms}(d)}$$

#### IDF（Inverse Document Frequency，逆文档频率）

$$\text{IDF}(t) = \log \frac{|D|}{1 + \text{DF}(t)}$$

其中：
- $|D|$：文档总数
- $\text{DF}(t)$：包含词 $t$ 的文档数
- 分母加1防止除零

#### TF-IDF 计算公式

$$\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \text{IDF}(t)$$

#### TF-IDF 变体

| 变体 | TF计算方式 | 特点 |
|------|-----------|------|
| 标准TF-IDF | $\frac{f_{t,d}}{\sum f_{w,d}}$ | 归一化词频 |
| 对数TF-IDF | $1 + \log(f_{t,d})$ | 压缩高频词的影响 |
| 亚线性TF-IDF | $1 + 0.5 \cdot \log(f_{t,d})$ | 进一步压缩高频词 |
| 双重归一化 | $0.5 + 0.5 \cdot \frac{f_{t,d}}{\max f_{w,d}}$ | 基准频率归一化 |

#### TF-IDF 计算示例

**文档集：**
- $D_1$: "the cat sat on the mat"
- $D_2$: "the dog sat on the log"
- $D_3$: "the cat and the dog played"

**计算词 "cat" 在 $D_1$ 中的 TF-IDF：**

$$\text{TF}(\text{cat}, D_1) = \frac{1}{6} \approx 0.167$$

$$\text{IDF}(\text{cat}) = \log \frac{3}{1 + 2} = \log 1 = 0$$

$$\text{TF-IDF}(\text{cat}, D_1) = 0.167 \times 0 = 0$$

**计算词 "mat" 在 $D_1$ 中的 TF-IDF：**

$$\text{TF}(\text{mat}, D_1) = \frac{1}{6} \approx 0.167$$

$$\text{IDF}(\text{mat}) = \log \frac{3}{1 + 1} = \log 1.5 \approx 0.176$$

$$\text{TF-IDF}(\text{mat}, D_1) = 0.167 \times 0.176 \approx 0.0294$$

#### PyTorch实现

```python
import torch
import torch.nn as nn

class TFIDFEncoder(nn.Module):
    def __init__(self, vocab_size, idf_weights):
        super().__init__()
        self.vocab_size = vocab_size
        self.register_buffer('idf', torch.tensor(idf_weights, dtype=torch.float32))

    def forward(self, token_ids):
        batch_size, seq_len = token_ids.shape
        tf = torch.zeros(batch_size, self.vocab_size, device=token_ids.device)
        for i in range(batch_size):
            for j in range(seq_len):
                tf[i, token_ids[i, j]] += 1
        tf = tf / seq_len
        tfidf = tf * self.idf.unsqueeze(0)
        return tfidf

vocab = {"the": 0, "cat": 1, "dog": 2, "mat": 3, "log": 4, "sat": 5, "on": 6}
idf = [0.0, 0.176, 0.176, 0.477, 0.477, 0.0, 0.0]
encoder = TFIDFEncoder(len(vocab), idf)
tokens = torch.tensor([[0, 1, 5, 6, 0, 3]])
tfidf_vector = encoder(tokens)
print("TF-IDF shape:", tfidf_vector.shape)
```

## 三、词嵌入（Word Embedding）

### 3.1 词嵌入概述

**定义：** 将词映射为低维稠密向量的技术，使语义相似的词在向量空间中距离接近。

#### 词嵌入 vs 传统表示

| 维度 | One-Hot | TF-IDF | 词嵌入 |
|------|---------|--------|--------|
| 维度 | 高维稀疏 | 高维稀疏 | 低维稠密 |
| 语义信息 | 无 | 有限 | 丰富 |
| 类比能力 | 无 | 无 | 有 |
| 适用范围 | 小规模 | 通用 | 深度学习 |

#### 词向量的线性类比

$$\vec{\text{king}} - \vec{\text{man}} + \vec{\text{woman}} \approx \vec{\text{queen}}$$

### 3.2 Word2Vec

**定义：** Google提出的浅层神经网络词嵌入模型，包括CBOW和Skip-gram两种架构。

#### CBOW（Continuous Bag of Words）

**目标：** 根据上下文词预测中心词。

```mermaid
flowchart LR
    subgraph 输入层
        W1[词w(t-2)]
        W2[词w(t-1)]
        W3[词w(t+1)]
        W4[词w(t+2)]
    end

    subgraph 投影层
        P1[共享词向量矩阵]
    end

    subgraph 输出层
        W_OUT[输出词向量矩阵]
    end

    subgraph 预测
        C[Softmax]
    end

    W1 --> P1
    W2 --> P1
    W3 --> P1
    W4 --> P1
    P1 --> W_OUT
    W_OUT --> C
    C --> Y[预测词w(t)]

    style P1 fill:#4CAF50,color:white
    style W_OUT fill:#FF9800,color:white
    style C fill:#2196F3,color:white
```

**损失函数：**

$$\mathcal{L} = -\log P(w_t \mid w_{t-2}, w_{t-1}, w_{t+1}, w_{t+2})$$

$$P(w_t \mid \text{context}) = \frac{\exp(v'_{w_t}^\top \cdot \frac{1}{2k}\sum_{i=1}^{2k} v_{w_i})}{\sum_{w=1}^{|V|} \exp(v'_w^\top \cdot \frac{1}{2k}\sum_{i=1}^{2k} v_{w_i})}$$

#### Skip-gram

**目标：** 根据中心词预测上下文词。

```mermaid
flowchart LR
    subgraph 输入层
        W[中心词w(t)]
    end

    subgraph 投影层
        P[输入词向量矩阵]
    end

    subgraph 输出层
        subgraph 多个输出
            W_OUT1[预测w(t-2)]
            W_OUT2[预测w(t-1)]
            W_OUT3[预测w(t+1)]
            W_OUT4[预测w(t+2)]
        end
    end

    W --> P
    P --> W_OUT1
    P --> W_OUT2
    P --> W_OUT3
    P --> W_OUT4

    style P fill:#4CAF50,color:white
    style W_OUT1 fill:#FF9800,color:white
    style W_OUT2 fill:#FF9800,color:white
    style W_OUT3 fill:#FF9800,color:white
    style W_OUT4 fill:#FF9800,color:white
```

**损失函数：**

$$\mathcal{L} = -\sum_{i=1}^{2k} \log P(w_{t+i} \mid w_t)$$

#### CBOW vs Skip-gram 对比

| 维度 | CBOW | Skip-gram |
|------|------|-----------|
| 输入 | 上下文词 | 中心词 |
| 输出 | 中心词 | 上下文词 |
| 训练速度 | 快 | 慢 |
| 生僻词表现 | 较好 | 好 |
| 常用词表现 | 较好 | 一般 |
| 适用场景 | 大型语料库 | 小型语料库 |

#### Word2Vec PyTorch实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CBOWModel(nn.Module):
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        self.embeddings = nn.Embedding(vocab_size, embed_dim)
        self.out_layer = nn.Linear(embed_dim, vocab_size)

    def forward(self, context_ids):
        embeds = self.embeddings(context_ids)
        h = embeds.mean(dim=0)
        out = self.out_layer(h)
        return out

class SkipGramModel(nn.Module):
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        self.embeddings = nn.Embedding(vocab_size, embed_dim)
        self.out_layer = nn.Linear(embed_dim, vocab_size)

    def forward(self, center_id):
        embed = self.embeddings(center_id)
        out = self.out_layer(embed)
        return out

vocab_size = 10000
embed_dim = 300
cbow = CBOWModel(vocab_size, embed_dim)
skipgram = SkipGramModel(vocab_size, embed_dim)

context = torch.randint(0, vocab_size, (4,))
center = torch.randint(0, vocab_size, (1,))
print("CBOW output shape:", cbow(context).shape)
print("Skip-gram output shape:", skipgram(center).shape)
```

### 3.3 GloVe（Global Vectors for Word Representation）

**定义：** 基于全局词频统计的词嵌入方法，利用词的共现概率矩阵进行矩阵分解。

#### 核心思想

词 $i$ 和词 $j$ 的共现概率比可以用来衡量它们的语义关系：

$$\frac{P(k \mid i)}{P(k \mid j)} \approx \frac{\exp(w_i^\top \cdot \tilde{w}_k)}{\exp(w_j^\top \cdot \tilde{w}_k)}$$

#### 损失函数

$$\mathcal{L} = \sum_{i=1}^{|V|} \sum_{j=1}^{|V|} f(X_{ij}) (w_i^\top \cdot \tilde{w}_j - \log X_{ij})^2$$

其中：
- $X_{ij}$：词 $i$ 和词 $j$ 的共现次数
- $f(x)$：权重函数，防止高频词的主导作用

$$f(x) = \begin{cases} \left(\frac{x}{x_{\max}}\right)^\alpha & \text{if } x < x_{\max} \\ 1 & \text{otherwise} \end{cases}$$

#### GloVe vs Word2Vec 对比

| 维度 | Word2Vec | GloVe |
|------|----------|-------|
| 训练方式 | 预测式（Skip-gram/CBOW） | 基于共现矩阵的因式分解 |
| 全局统计 | 无 | 有 |
| 训练速度 | 较慢 | 快 |
| 词向量质量 | 好 | 好 |
| 实现复杂度 | 简单 | 较复杂 |

### 3.4 词嵌入对比总结

| 方法 | 类型 | 维度 | 语义能力 | 适用场景 |
|------|------|------|----------|----------|
| One-Hot | 稀疏 | 高 | 无 | 小规模任务 |
| TF-IDF | 稀疏 | 高 | 弱 | 信息检索 |
| Word2Vec | 稠密 | 低 | 强 | 通用NLP |
| GloVe | 稠密 | 低 | 强 | 通用NLP |
| FastText | 稠密 | 低 | 强（子词级） | 多语言、OOV问题 |

## 四、考前速记卡

### TF-IDF公式速记

$$\boxed{\text{TF-IDF}(t, d) = \frac{f_{t,d}}{\sum_{w} f_{w,d}} \times \log\frac{|D|}{1 + \text{DF}(t)}}$$

### Word2Vec架构速记

- **CBOW**：上下文→中心词（快，常用词好）
- **Skip-gram**：中心词→上下文（慢，生僻词好）

### LSTM核心公式速记

- **遗忘门**：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$
- **输入门**：$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$
- **候选值**：$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$
- **细胞状态**：$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$
- **输出门**：$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$
- **隐藏状态**：$h_t = o_t \odot \tanh(C_t)$

### 注意力机制核心公式速记

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$
