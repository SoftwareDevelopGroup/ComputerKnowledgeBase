# 4.2 基础控件：TextView、Button、EditText

> [!abstract] 本节概述
> 布局解决了"控件摆在哪里"的问题，控件本身则解决"显示什么内容、接收什么输入"。本节介绍 Android 最常用的基础控件：TextView（文本显示）、Button（按钮）、EditText（输入框）、ImageView（图片显示），以及若干辅助控件（CheckBox/RadioButton/Switch/ProgressBar）。每个控件都通过 XML 属性配置外观、通过 Java 方法操作内容，是构建表单、详情页、设置页等界面的最小积木。

## 1. View 通用属性

> [!definition] 所有控件继承自 View 的通用属性
> 以下属性对所有 View 子类生效，是配置控件外观与位置的基础。

| 属性 | 作用 | 常见取值 |
| ---- | ---- | -------- |
| `android:id` | 控件唯一标识 | `@+id/xxx` |
| `android:layout_width` / `layout_height` | 宽高 | `match_parent` / `wrap_content` / 具体尺寸 |
| `android:layout_margin*` | 外边距 | 如 `16dp` |
| `android:padding*` | 内边距 | 如 `8dp` |
| `android:background` | 背景 | 颜色 / drawable |
| `android:visibility` | 可见性 | `visible` / `invisible` / `gone` |
| `android:enabled` | 是否可用 | `true` / `false` |
| `android:clickable` | 是否可点击 | `true` / `false` |

> [!note] visibility 三种状态
> - `visible`：可见且占空间（默认）。
> - `invisible`：不可见，但仍**占布局空间**。
> - `gone`：不可见且**不占空间**，相当于从布局中移除。

## 2. TextView 文本显示

> [!definition] TextView
> Android 中用于显示一段不可编辑文本的控件，是所有带文字显示能力控件（Button、EditText、CheckBox 等）的父类。通过 `text`、`textSize`、`textColor`、`textStyle` 等属性控制文字内容与样式。

### 2.1 常用属性

| 属性 | 作用 | 示例 |
| ---- | ---- | ---- |
| `android:text` | 显示的文本 | `android:text="登录"` |
| `android:textSize` | 文字大小（推荐 sp） | `android:textSize="16sp"` |
| `android:textColor` | 文字颜色 | `android:textColor="#FF333333"` |
| `android:textStyle` | 文字样式 | `normal` / `bold` / `italic`（可用 `\|` 组合） |
| `android:maxLines` | 最大行数 | `android:maxLines="2"` |
| `android:ellipsize` | 超长截断方式 | `end` / `middle` / `marquee` 等 |
| `android:gravity` | 文字在控件内的对齐 | `center` / `left` / `right` |
| `android:lineSpacingExtra` | 行间距额外像素 | `android:lineSpacingExtra="4dp"` |
| `android:drawable*` | 文字四周加图标 | `drawableLeft` / `drawableTop` 等 |

### 2.2 XML 与 Java 示例

```xml
<TextView
    android:id="@+id/tv_title"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="欢迎使用本应用"
    android:textSize="20sp"
    android:textColor="#333333"
    android:textStyle="bold"
    android:gravity="center"
    android:maxLines="2"
    android:ellipsize="end" />
```

```java
TextView tvTitle = findViewById(R.id.tv_title);
tvTitle.setText("新内容");                  // 设置文本
String text = tvTitle.getText().toString(); // 读取文本
tvTitle.setTextColor(Color.RED);            // 动态改颜色
tvTitle.setTextSize(18);                    // 动态改字号
tvTitle.setVisibility(View.GONE);            // 隐藏并释放空间
```

> [!tip] 文字大小单位用 sp
> `sp`（scale-independent pixel）会随系统字号设置缩放，保证用户调整系统字号时应用文字同步放大。**所有文字尺寸都应使用 sp，不要用 dp 或 px**。

## 3. Button 按钮

> [!definition] Button
> Button 是 TextView 的子类，用于触发动作。除了具备 TextView 的全部属性外，还默认带有点击反馈背景。点击事件可通过 XML 的 `onClick` 属性或 Java 的 `setOnClickListener` 绑定。

### 3.1 XML 与事件绑定

```xml
<Button
    android:id="@+id/btn_submit"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="提交"
    android:textSize="16sp"
    android:backgroundTint="#1976D2"
    android:textColor="#FFFFFF" />
```

```java
// 方式一：匿名内部类（最常用）
Button btnSubmit = findViewById(R.id.btn_submit);
btnSubmit.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        Toast.makeText(this, "已提交", Toast.LENGTH_SHORT).show();
    }
});

// 方式二：Lambda（Java 8+，推荐）
btnSubmit.setOnClickListener(v ->
    Toast.makeText(this, "已提交", Toast.LENGTH_SHORT).show());

// 方式三：让 Activity 实现 View.OnClickListener 接口
public class MainActivity extends AppCompatActivity
        implements View.OnClickListener {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        findViewById(R.id.btn_submit).setOnClickListener(this);
    }
    @Override
    public void onClick(View v) {
        if (v.getId() == R.id.btn_submit) {
            // 处理点击
        }
    }
}
```

### 3.2 通过 XML onClick 属性绑定

```xml
<Button
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="提交"
    android:onClick="onSubmitClick" />
```

```java
// 方法签名必须为 public void xxx(View view)
public void onSubmitClick(View view) {
    Toast.makeText(this, "XML onClick 触发", Toast.LENGTH_SHORT).show();
}
```

> [!warning] onClick XML 属性的局限
> - 方法必须 `public`、返回 `void`、参数为 `View`，否则运行时反射调用会抛 `NoSuchMethodException`。
> - 方法名硬编码在 XML 中，重构易出错；现代写法更推荐 `setOnClickListener`。

## 4. EditText 输入框

> [!definition] EditText
> EditText 是 TextView 的子类，允许用户输入与编辑文本。通过 `inputType` 控制输入类型（文本/数字/密码/邮箱等），通过 `hint` 设置占位提示，通过 `maxLength` 限制字符数。

### 4.1 常用属性

| 属性 | 作用 | 示例 |
| ---- | ---- | ---- |
| `android:hint` | 空内容时的占位提示 | `android:hint="请输入手机号"` |
| `android:inputType` | 输入类型 | `text` / `number` / `textPassword` / `phone` / `textEmailAddress` |
| `android:maxLength` | 最大字符数 | `android:maxLength="11"` |
| `android:maxLines` | 最大行数 | `android:maxLines="1"` |
| `android:drawableLeft` | 左侧图标 | `@drawable/ic_user` |
| `android:ems` | 宽度按字符数（不推荐新用） | `android:ems="10"` |

### 4.2 常用 inputType 取值

| inputType | 含义 |
| --------- | ---- |
| `text` | 普通文本 |
| `textPassword` | 密码（显示圆点） |
| `textEmailAddress` | 邮箱（带 @ 符号键） |
| `number` | 数字 |
| `numberDecimal` | 带小数点的数字 |
| `phone` | 电话号码（带拨号键盘） |
| `textMultiLine` | 多行文本 |

### 4.3 XML 与 Java 示例

```xml
<EditText
    android:id="@+id/et_phone"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:hint="请输入手机号"
    android:inputType="phone"
    android:maxLength="11"
    android:maxLines="1"
    android:drawableLeft="@drawable/ic_phone" />
```

```java
EditText etPhone = findViewById(R.id.et_phone);
String phone = etPhone.getText().toString().trim();  // 读取并去首尾空格
etPhone.setText("");                                  // 清空输入
etPhone.requestFocus();                               // 请求焦点
// 添加文字变化监听
etPhone.addTextChangedListener(new TextWatcher() {
    @Override public void beforeTextChanged(CharSequence s, int start, int count, int after) {}
    @Override public void onTextChanged(CharSequence s, int start, int before, int count) {
        // 实时输入变化
    }
    @Override public void afterTextChanged(Editable s) {}
});
```

> [!tip] 读取输入必加 trim()
> 用户输入常带前后空格，读取后调用 `.trim()` 去除可避免登录失败等诡异问题。`getText()` 返回 `Editable`，需 `.toString()` 转字符串。

## 5. ImageView 图片显示

> [!definition] ImageView
> 用于显示图片资源的控件。通过 `src` 指定图片内容，通过 `scaleType` 控制图片在控件内的缩放与对齐方式。

### 5.1 常用 scaleType

| scaleType | 含义 |
| --------- | ---- |
| `fitXY` | 拉伸填满控件（可能变形） |
| `fitCenter`（默认） | 等比缩放居中显示 |
| `fitStart` | 等比缩放顶部对齐 |
| `fitEnd` | 等比缩放底部对齐 |
| `center` | 不缩放，原图居中 |
| `centerCrop` | 等比缩放填满控件并居中裁剪（**最常用**，如头像、封面） |
| `centerInside` | 等比缩放保证完整显示在控件内 |
| `matrix` | 用矩阵变换（用于自定义变换） |

### 5.2 XML 与 Java 示例

```xml
<ImageView
    android:id="@+id/iv_avatar"
    android:layout_width="80dp"
    android:layout_height="80dp"
    android:src="@drawable/ic_avatar"
    android:scaleType="centerCrop"
    android:background="@drawable/bg_circle" />
```

```java
ImageView ivAvatar = findViewById(R.id.iv_avatar);
ivAvatar.setImageResource(R.drawable.ic_default);     // 切换图片
ivAvatar.setImageResource(android.R.color.transparent); // 清空
// 加载网络图片需第三方库（如 Glide / Picasso），ImageView 自身不支持网络图
// Glide.with(this).load(url).into(ivAvatar);
```

> [!warning] src 与 background 的区别
> - `android:src`：前景图，按 `scaleType` 缩放，保持比例。
> - `android:background`：背景图，会拉伸填满整个控件（包括 padding 区域），可设颜色或 drawable。
> - 二者可同时存在，背景在底层、前景在上层。

## 6. 其他常用控件

### 6.1 CheckBox 复选框

> [!definition] CheckBox
> 提供多个可独立勾选的选项。通过 `isChecked()` 读取状态，通过 `setOnCheckedChangeListener` 监听变化。

```xml
<CheckBox
    android:id="@+id/cb_agree"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="我已阅读并同意用户协议" />
```

```java
CheckBox cbAgree = findViewById(R.id.cb_agree);
boolean checked = cbAgree.isChecked();
cbAgree.setOnCheckedChangeListener((buttonView, isChecked) -> {
    // isChecked 即最新状态
});
```

### 6.2 RadioButton 与 RadioGroup 单选

> [!definition] RadioButton / RadioGroup
> RadioButton 单选按钮，必须放在 RadioGroup 内才能实现"互斥单选"——同组内选中一个会自动取消其他。通过 `getCheckedRadioButtonId()` 获取选中项 ID。

```xml
<RadioGroup
    android:id="@+id/rg_gender"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:orientation="horizontal">

    <RadioButton
        android:id="@+id/rb_male"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="男"
        android:checked="true" />

    <RadioButton
        android:id="@+id/rb_female"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="女" />
</RadioGroup>
```

```java
RadioGroup rgGender = findViewById(R.id.rg_gender);
int checkedId = rgGender.getCheckedRadioButtonId();   // 获取选中项 ID
rgGender.setOnCheckedChangeListener((group, checkedId1) -> {
    // checkedId1 为新选中项的 ID
});
```

### 6.3 Switch 开关

```xml
<Switch
    android:id="@+id/sw_notify"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="消息通知"
    android:checked="true" />
```

```java
Switch swNotify = findViewById(R.id.sw_notify);
swNotify.setOnCheckedChangeListener((buttonView, isChecked) -> {
    // isChecked 为最新开关状态
});
```

### 6.4 ProgressBar 进度条

```xml
<!-- 不确定进度条（旋转动画） -->
<ProgressBar
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:visibility="gone" />

<!-- 水平确定进度条 -->
<ProgressBar
    android:id="@+id/pb_download"
    style="?android:attr/progressBarStyleHorizontal"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:max="100"
    android:progress="30" />
```

```java
ProgressBar pbDownload = findViewById(R.id.pb_download);
pbDownload.setProgress(60);                    // 设置当前进度
int progress = pbDownload.getProgress();
pbDownload.setVisibility(View.VISIBLE);        // 显示加载中
```

## 7. 控件分类速览

> [!example] 常用基础控件分类
> 
> | 类别 | 控件 | 主要作用 |
> | ---- | ---- | -------- |
> | 文本显示 | TextView | 显示不可编辑文本 |
> | 文本输入 | EditText | 接收用户输入 |
> | 按钮 | Button、ImageButton | 触发动作 |
> | 图片 | ImageView | 显示图片 |
> | 选择类 | CheckBox、RadioButton、Switch | 多选 / 单选 / 开关 |

## 8. 案例：注册表单控件组合

> [!example] 综合表单：账号、密码、性别、爱好、协议
> 实现一个用户注册表单，包含账号输入框、密码输入框、性别单选、爱好多选、协议复选与注册按钮。点击注册后收集所有输入并校验。

```xml
<!-- res/layout/activity_register.xml -->
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:orientation="vertical"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:padding="20dp">

    <EditText
        android:id="@+id/et_account"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="账号（字母开头，4-16位）"
        android:inputType="text"
        android:maxLines="1" />

    <EditText
        android:id="@+id/et_password"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="密码（6-18位）"
        android:inputType="textPassword"
        android:maxLines="1" />

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginTop="12dp"
        android:text="性别：" />

    <RadioGroup
        android:id="@+id/rg_gender"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:orientation="horizontal">
        <RadioButton android:id="@+id/rb_male"
            android:layout_width="wrap_content"
            android:layout_height="wrap_content"
            android:text="男"
            android:checked="true" />
        <RadioButton android:id="@+id/rb_female"
            android:layout_width="wrap_content"
            android:layout_height="wrap_content"
            android:text="女" />
    </RadioGroup>

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginTop="12dp"
        android:text="爱好：" />

    <LinearLayout
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:orientation="horizontal">
        <CheckBox android:id="@+id/cb_read"
            android:layout_width="wrap_content"
            android:layout_height="wrap_content"
            android:text="阅读" />
        <CheckBox android:id="@+id/cb_sport"
            android:layout_width="wrap_content"
            android:layout_height="wrap_content"
            android:text="运动" />
        <CheckBox android:id="@+id/cb_music"
            android:layout_width="wrap_content"
            android:layout_height="wrap_content"
            android:text="音乐" />
    </LinearLayout>

    <CheckBox
        android:id="@+id/cb_agree"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginTop="12dp"
        android:text="我已阅读并同意《用户协议》" />

    <Button
        android:id="@+id/btn_register"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:layout_marginTop="20dp"
        android:text="注册" />
</LinearLayout>
```

```java
public class RegisterActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_register);

        EditText etAccount  = findViewById(R.id.et_account);
        EditText etPassword = findViewById(R.id.et_password);
        RadioGroup rgGender = findViewById(R.id.rg_gender);
        CheckBox cbRead   = findViewById(R.id.cb_read);
        CheckBox cbSport  = findViewById(R.id.cb_sport);
        CheckBox cbMusic  = findViewById(R.id.cb_music);
        CheckBox cbAgree  = findViewById(R.id.cb_agree);

        findViewById(R.id.btn_register).setOnClickListener(v -> {
            String account = etAccount.getText().toString().trim();
            String password = etPassword.getText().toString().trim();
            if (account.isEmpty() || password.isEmpty()) {
                Toast.makeText(this, "账号或密码不能为空", Toast.LENGTH_SHORT).show();
                return;
            }
            if (!cbAgree.isChecked()) {
                Toast.makeText(this, "请先同意用户协议", Toast.LENGTH_SHORT).show();
                return;
            }
            // 收集性别
            int genderId = rgGender.getCheckedRadioButtonId();
            String gender = genderId == R.id.rb_male ? "男" : "女";
            // 收集爱好
            StringBuilder hobbies = new StringBuilder();
            if (cbRead.isChecked())  hobbies.append("阅读 ");
            if (cbSport.isChecked()) hobbies.append("运动 ");
            if (cbMusic.isChecked()) hobbies.append("音乐 ");

            String summary = "账号：" + account + "\n性别：" + gender
                    + "\n爱好：" + hobbies.toString().trim();
            Toast.makeText(this, summary, Toast.LENGTH_LONG).show();
        });
    }
}
```

> [!note] 案例要点
> - 用 LinearLayout 垂直堆叠即可组织简单表单，无需复杂布局。
> - 性别互斥用 RadioGroup 包裹 RadioButton；爱好独立用 CheckBox。
> - 读取前 `trim()`、校验非空、检查协议勾选，是表单提交的通用范式。

## 9. 易错点与最佳实践

> [!warning] 常见易错点
> 1. **findViewById 在 setContentView 之前调用**：返回 null，后续操作 NPE。
> 2. **文字大小用 px 或 dp**：不会随系统字号缩放，影响无障碍体验，应改用 sp。
> 3. **混淆 src 与 background**：把头像设到 `background` 会被拉伸变形，应设到 `src` 配合 `scaleType="centerCrop"`。
> 4. **EditText 不设 inputType**：弹出的键盘不符合输入场景（如该输数字却弹字母键盘）。
> 5. **RadioButton 不放 RadioGroup**：无法实现互斥，会变成可多选。
> 6. **onClick XML 方法签名错误**：必须 `public void xxx(View)`，否则运行时反射调用崩溃。

> [!tip] 最佳实践
> - 文本内容统一抽到 `strings.xml`，颜色抽到 `colors.xml`，尺寸抽到 `dimens.xml`（详见 [[4.4 资源文件：图片、字符串、尺寸资源|4.4 资源文件]]）。
> - 复用样式通过 `style` 属性引用 `styles.xml`，避免重复属性堆砌。
> - 网络图片加载一律用 Glide / Picasso 等第三方库，自带缓存与异步，不要直接用 `BitmapFactory` 在主线程解码。
