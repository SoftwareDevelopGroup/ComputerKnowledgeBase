# 6.3 JSON 数据解析

> [!abstract] 本节概述
> JSON（JavaScript Object Notation）是移动应用与服务端通信最常用的数据交换格式。本节讲解 JSON 数据结构、Android 内置 JSONObject/JSONArray 的手动解析方式，以及 Gson 库的自动化序列化与反序列化，通过对比给出选型建议，并通过案例演示复杂嵌套 JSON 的解析。

## 1. JSON 数据结构

> [!definition] JSON 格式
> JSON 是轻量级数据交换格式，基于两种结构：
> - **对象（Object）**：`{ "key": value, ... }`，无序键值对集合
> - **数组（Array）**：`[ value, value, ... ]`，有序值集合
>
> value 可以是字符串（双引号）、数字、布尔、null、对象或数组。

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "city": "北京",
    "temp": 26,
    "weather": "晴",
    "aqi": 58,
    "forecast": [
      { "date": "2026-08-04", "weather": "多云", "high": 30, "low": 22 },
      { "date": "2026-08-05", "weather": "雨",   "high": 28, "low": 20 }
    ]
  }
}
```

> [!note] JSON 数据类型对照
> | JSON 类型 | Java 类型 |
> | --------- | --------- |
> | String | String |
> | Number | int / long / double |
> | boolean | boolean |
> | null | null |
> | Object | JSONObject / POJO |
> | Array | JSONArray / List |

## 2. Android 内置 JSON 解析

### 2.1 JSONObject 与 JSONArray

> [!definition] Android 内置 JSON API
> Android 提供 `org.json` 包内置 JSON 解析：
> - `JSONObject`：解析 `{}` 对象，通过 `getString/getInt/getJSONObject` 取值
> - `JSONArray`：解析 `[]` 数组，通过 `getJSONObject(i)` 遍历
> - `put` 方法可向 JSON 添加数据

```java
String json = "{ \"name\":\"Tom\", \"age\":18, \"courses\":[\"Math\",\"CS\"] }";

try {
    JSONObject obj = new JSONObject(json);
    String name = obj.getString("name");         // Tom
    int age = obj.getInt("age");                  // 18
    JSONArray courses = obj.getJSONArray("courses");
    List<String> list = new ArrayList<>();
    for (int i = 0; i < courses.length(); i++) {
        list.add(courses.getString(i));
    }
    // 可选性取值
    if (obj.has("score")) {
        double score = obj.getDouble("score");
    }
} catch (JSONException e) {
    e.printStackTrace();
}
```

### 2.2 嵌套 JSON 解析

```java
String json = "{ ... }";  // 上面的天气数据
try {
    JSONObject root = new JSONObject(json);
    int code = root.getInt("code");
    JSONObject data = root.getJSONObject("data");
    String city = data.getString("city");
    int temp = data.getInt("temp");

    JSONArray forecast = data.getJSONArray("forecast");
    for (int i = 0; i < forecast.length(); i++) {
        JSONObject day = forecast.getJSONObject(i);
        String date = day.getString("date");
        int high = day.getInt("high");
    }
} catch (JSONException e) { e.printStackTrace(); }
```

> [!warning] JSONObject 易错点
> 1. **字段不存在抛异常**：`getString("xxx")` 若字段不存在抛 `JSONException`，需用 `has()` 或 `optString()`（返回默认值）
> 2. **类型不匹配**：`getInt("name")` 抛异常，需确认类型
> 3. **嵌套层级多**：`getJSONObject("a").getJSONObject("b")...` 易出错
> 4. **空值处理**：JSON null 与字符串 "null" 不同，需分别判断

## 3. Gson 库

> [!definition] Gson
> Gson 是 Google 开源的 JSON 序列化/反序列化库，通过反射自动完成 POJO 与 JSON 互转，代码简洁、可读性强，是 Android 主流 JSON 库。

### 3.1 Gson 基础使用

```java
// 引入依赖:implementation 'com.google.code.gson:gson:2.10.1'

public class User {
    private String name;
    private int age;
    private List<String> courses;
    // 构造方法、getter/setter 省略
}

Gson gson = new Gson();

// 对象 → JSON 字符串
User user = new User("Tom", 18, Arrays.asList("Math", "CS"));
String json = gson.toJson(user);
// {"name":"Tom","age":18,"courses":["Math","CS"]}

// JSON 字符串 → 对象
User parsed = gson.fromJson(json, User.class);
```

### 3.2 TypeToken 解析泛型集合

> [!tip] TypeToken 处理泛型
> 由于 Java 泛型擦除，`List<User>.class` 无法直接获取，Gson 提供 `TypeToken` 解决：

```java
String json = "[{\"name\":\"Tom\"},{\"name\":\"Jerry\"}]";

// ❌ 错误:泛型擦除,List 元素被解析为 LinkedTreeMap
List<User> list1 = gson.fromJson(json, List.class);

// ✅ 正确:使用 TypeToken 保留泛型
Type type = new TypeToken<List<User>>(){}.getType();
List<User> list2 = gson.fromJson(json, type);
```

### 3.3 嵌套对象解析

```java
public class WeatherResp {
    private int code;
    private String message;
    private Weather data;
    // getter/setter
}

public class Weather {
    private String city;
    private int temp;
    private List<Forecast> forecast;
}

public class Forecast {
    private String date;
    private String weather;
    private int high;
    private int low;
}

String json = "{...}";   // 上面的天气 JSON
WeatherResp resp = gson.fromJson(json, WeatherResp.class);
// 直接访问 resp.getData().getForecast().get(0).getDate()
```

### 3.4 常用注解

> [!note] Gson 常用注解
> | 注解 | 作用 | 示例 |
> | ---- | ---- | ---- |
> | `@SerializedName` | 字段重命名 | `@SerializedName("user_name") String userName` |
> | `@Expose` | 控制序列化/反序列化 | `@Expose(serialize = false)` |
> | `@Since/@Until` | 版本控制 | `@Since(2.0)` |

```java
public class Article {
    @SerializedName("article_id")
    private long id;            // JSON 中是 article_id,Java 中是 id

    @SerializedName("publish_time")
    private String publishTime;

    @Expose(serialize = false)
    private String internalNote; // 序列化时忽略该字段

    // getter/setter
}
```

## 4. JSON 生成

```java
// 方式一:Gson 自动生成
Article a = new Article(1, "Hello", "World", "2026-08-03");
String json = new Gson().toJson(a);

// 方式二:JSONObject 手动构造
JSONObject obj = new JSONObject();
obj.put("title", "新闻标题");
obj.put("views", 1000);
JSONArray tags = new JSONArray();
tags.put("科技").put("AI");
obj.put("tags", tags);
String result = obj.toString();
```

## 5. JSONObject vs Gson 对比

| 维度 | JSONObject | Gson |
| ---- | ---------- | ---- |
| 实现方式 | 手动按字段名取值 | 反射自动映射 |
| 代码量 | 多，需逐字段处理 | 少，一行解析 |
| 类型安全 | 弱，运行时异常 | 强，编译期校验 |
| 嵌套处理 | 易出错 | 自动处理 |
| 性能 | 略优（无反射） | 反射有开销 |
| 包体积 | 0（系统内置） | ~240KB |
| 适用场景 | 简单 JSON、个别字段 | 复杂结构、POJO 映射 |

> [!tip] 选型建议
> - 简单 JSON（单层、几字段）：JSONObject 足够，无需引入依赖
> - 复杂 JSON（嵌套、数组、泛型）：Gson 更简洁
> - 大数据量高性能场景：考虑 Moshi 或 kotlinx.serialization

## 6. 案例：解析天气 API JSON

> [!example] 完整案例
> 服务端返回天气 JSON，App 用 Gson 解析后渲染到 UI。

```java
public class WeatherActivity extends AppCompatActivity {
    private TextView tvCity, tvTemp, tvWeather;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_weather);
        tvCity = findViewById(R.id.tv_city);
        tvTemp = findViewById(R.id.tv_temp);
        tvWeather = findViewById(R.id.tv_weather);

        loadWeather();
    }

    private void loadWeather() {
        new Thread(() -> {
            try {
                String json = doHttpRequest("https://api.example.com/weather");
                Gson gson = new Gson();
                WeatherResp resp = gson.fromJson(json, WeatherResp.class);
                if (resp.getCode() == 200) {
                    Weather w = resp.getData();
                    runOnUiThread(() -> {
                        tvCity.setText(w.getCity());
                        tvTemp.setText(w.getTemp() + "℃");
                        tvWeather.setText(w.getWeather());
                    });
                }
            } catch (Exception e) {
                runOnUiThread(() ->
                    Toast.makeText(this, "解析失败", Toast.LENGTH_SHORT).show());
            }
        }).start();
    }
}
```

## 7. 易错点与最佳实践

> [!warning] 常见易错点
> 1. **JSON 字段名与 Java 字段不一致**：Gson 解析时该字段为 null，需用 `@SerializedName`
> 2. **泛型擦除导致 List 元素为 LinkedTreeMap**：必须用 `TypeToken`
> 3. **JSON 字段缺失导致 NPE**：服务端可能返回 null，Java 对象对应字段为 null，使用前判空
> 4. **数字精度丢失**：大整数（>long 范围）解析为 double 丢精度，需自定义 TypeAdapter
> 5. **解析异常未捕获**：`fromJson` 可能抛 JsonSyntaxException，需 try-catch

> [!tip] 最佳实践
> - 服务端字段命名约定与客户端 POJO 一致，或用 `@SerializedName` 显式映射
> - 字段加 `@SerializedName` 提升可读性与稳定性
> - 解析代码包裹 try-catch，失败时记录原始 JSON 便于排查
> - 使用 ProGuard/R8 时保留 Gson 模型类：`-keep class com.example.model.** { *; }`
