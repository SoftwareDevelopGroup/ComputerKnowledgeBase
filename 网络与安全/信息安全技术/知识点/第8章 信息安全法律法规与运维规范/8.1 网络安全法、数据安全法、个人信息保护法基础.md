# 8.1 网络安全法、数据安全法、个人信息保护法基础

> [!abstract] 本节概述
> 我国网络空间治理的基础法律框架由"三法"构成：《网络安全法》（2017-06-01 施行）管**网络与系统运行安全**，《数据安全法》（2021-09-01 施行）管**数据处理与数据安全**，《个人信息保护法》（2021-11-01 施行）管**个人信息处理活动**。三者既有分工又相互衔接，共同覆盖"网络—数据—信息"三个层次。本节梳理三法的立法目的、关键概念、核心制度，并对比其覆盖范围与责任主体，最后以 APP 违规收集个人信息被处罚为案例落地。

## 安全视角

> [!info] 资产·信任边界·安全目标
> - **资产**：网络设施、信息系统、数据资源、个人信息权益。
> - **信任边界**：网络运营者（境内）↔ 数据处理者 ↔ 个人信息主体 ↔ 境外接收者（跨境）。
> - **安全目标**：保障网络运行安全、数据安全与个人信息权益，落实合规底线。
> - **前置条件**：理解 [[1.1 信息安全三大目标：保密性、完整性、可用性|CIA 三要素]] 与 [[6.1 数据分级分类、数据脱敏|数据分级分类]]。
> - **缓解措施**：等级保护制度、数据分类分级、告知同意、安全评估、合规审计。

## 一、《网络安全法》

> [!note] 法规信息
> - 全称：《中华人民共和国网络安全法》
> - 通过：2016 年 11 月 7 日第十二届全国人大常委会第二十四次会议通过
> - **施行日期：2017 年 6 月 1 日**
> - 地位：我国网络安全领域的基础性法律

### 1. 立法目的与核心制度

> [!definition] 立法目的
> 保障网络安全，维护网络空间主权和国家安全、社会公共利益，保护公民、法人和其他组织的合法权益，促进经济社会信息化健康发展。

《网络安全法》确立了多项核心制度：

| 核心制度 | 内容要点 |
| -------- | -------- |
| **网络安全等级保护制度** | 网络运营者按等级履行安全保护义务，是法定强制义务（详见 [[8.2 等保 2.0 基本概念\|8.2 等保 2.0]]） |
| **网络实名制** | 办理网络接入、域名注册、电话入网、信息发布等服务需提供真实身份信息 |
| **关键信息基础设施保护** | 对 CII 在等级保护基础上实行重点保护 |
| **个人信息保护** | 网络运营者收集、使用个人信息需遵循合法、正当、必要原则 |
| **网络安全监测预警与应急** | 建立网络安全监测预警和信息通报制度 |

### 2. 网络运营者义务

> [!definition] 网络运营者
> 网络的所有者、管理者和网络服务提供者。这是《网络安全法》最核心的责任主体。

| 义务类别 | 具体要求 |
| -------- | -------- |
| 安全保护义务 | 落实等级保护；采取防病毒、攻击检测、数据加密、备份等措施 |
| 数据保护义务 | 个人信息与重要数据分类、备份、加密；防止泄露、毁损、丢失 |
| 实名制义务 | 用户入网、注册需实名认证 |
| 留存日志义务 | 网络日志留存**不少于六个月** |
| 安全事件报告义务 | 发生安全事件立即启动应急预案、采取补救、报告主管部门 |
| 配合执法义务 | 为公安机关、国家安全机关依法维护国家安全和侦查犯罪提供技术支持与协助 |

> [!warning] 日志留存六个月是法定底线
> "网络日志留存不少于六个月"是《网络安全法》第 21 条的明文要求，也是等保 2.0 审计要求的法律来源。日志不足六个月即构成违法，可处一万以上十万以下罚款。

### 3. 关键信息基础设施保护

> [!definition] 关键信息基础设施（CII）
> 公共通信和信息服务、能源、交通、水利、金融、公共服务、电子政务、国防科技工业等重要行业和领域的，一旦遭到破坏、丧失功能或者数据泄露，可能严重危害国家安全、国计民生、公共利益的关键网络设施、信息系统。

CII 运营者在一般网络运营者义务基础上，还需承担更重的**特别义务**：

| 特别义务 | 要点 |
| -------- | ---- |
| **数据本地化** | 在境内运营中收集和产生的个人信息和重要数据应当**在境内存储** |
| **安全评估** | 数据确需跨境提供的，应通过国家网信部门组织的安全评估 |
| **供应链安全** | 采购网络产品和服务应通过网络安全审查 |
| **应急演练** | 定期开展网络安全应急演练 |
| **年度测评** | 每年至少进行一次网络安全检测评估 |

## 二、《数据安全法》

> [!note] 法规信息
> - 全称：《中华人民共和国数据安全法》
> - 通过：2021 年 6 月 10 日第十三届全国人大常委会第二十九次会议通过
> - **施行日期：2021 年 9 月 1 日**
> - 地位：数据安全领域的基础性法律

### 1. 立法目的与核心概念

> [!definition] 立法目的
> 规范数据处理活动，保障数据安全，促进数据开发利用，保护个人、组织的合法权益，维护国家主权、安全和发展利益。

《数据安全法》的**核心制度**是**数据分类分级保护制度**：

| 核心概念 | 含义 |
| -------- | ---- |
| **数据** | 任何以电子或者其他方式对信息的记录 |
| **数据处理** | 包括数据的收集、存储、使用、加工、传输、提供、公开等 |
| **数据安全** | 通过采取必要措施，确保数据处于有效保护和合法利用的状态 |
| **分类分级** | 根据数据在经济社会发展中的重要程度，以及一旦遭到篡改、破坏、泄露或者非法获取、非法利用，对国家安全、公共利益或者个人、组织合法权益造成的危害程度，对数据实行分类分级保护 |

### 2. 重要数据与核心数据

> [!definition] 数据分级
> 数据按重要程度分为一般数据、重要数据和核心数据三个层级，不同层级对应不同保护要求。

| 数据层级 | 定义 | 保护要求 |
| -------- | ---- | -------- |
| **核心数据** | 关系国家安全、国民经济命脉、重要民生、重大公共利益等的数据 | 实行更加严格的管理制度 |
| **重要数据** | 一旦遭到篡改、破坏、泄露或者非法获取、非法利用，可能危害国家安全、公共利益的数据 | 明确目录、重点保护、出境需安全评估 |
| **一般数据** | 核心数据、重要数据之外的其他数据 | 按一般数据处理活动规范管理 |

> [!tip] 重要数据目录由谁制定
> 重要数据的具体目录由**各行业、各领域的主管部门**制定并报国家网信部门。实务中企业需关注本行业的《重要数据识别指南》或目录，例如工业和信息化领域、金融领域等均有相应规范。

### 3. 数据跨境传输

> [!warning] 重要数据出境安全评估
> 重要数据的出境受严格管制：数据处理者向境外提供重要数据，应当**通过国家网信部门组织的数据出境安全评估**。未经评估不得出境。这一要求与 CII 数据本地化叠加，构成数据跨境的合规闭环。

数据出境的合规路径（含个保法衔接）主要有：

| 合规路径 | 适用情形 |
| -------- | -------- |
| **安全评估** | 重要数据出境、CII 运营者出境、处理百万级个人信息出境等 |
| **个人信息保护认证** | 跨境处理个人信息 |
| **标准合同** | 不满足安全评估门槛的个人信息出境 |

## 三、《个人信息保护法》

> [!note] 法规信息
> - 全称：《中华人民共和国个人信息保护法》
> - 通过：2021 年 8 月 20 日第十三届全国人大常委会第三十次会议通过
> - **施行日期：2021 年 11 月 1 日**
> - 地位：个人信息保护领域的基础性法律

### 1. 立法目的与处理原则

> [!definition] 立法目的
> 保护个人信息权益，规范个人信息处理活动，促进个人信息合理利用。

《个人信息保护法》确立了个人信息处理的六项基本原则：

| 原则 | 含义 |
| ---- | ---- |
| **合法、正当、必要、诚信** | 处理个人信息应当遵循的最根本原则 |
| **目的明确与最小必要** | 处理目的应当明确、合理；收集应限于实现目的的最小范围 |
| **公开透明** | 公开个人信息处理规则，明示处理目的、方式、范围 |
| **质量准确** | 保证个人信息质量，避免因不准确、不完整造成损害 |
| **安全保障** | 采取必要措施保障个人信息安全 |
| **责任明确** | 个人信息处理者对其处理活动负责 |

### 2. 告知同意规则

> [!definition] 告知同意
> 处理个人信息应当以**显著方式、清晰易懂的语言**真实、准确、完整地向个人告知处理者的名称、联系方式、处理目的、方式、信息种类、保存期限等，并取得个人的**明确同意**。

| 同意类型 | 适用情形 |
| -------- | -------- |
| **一般同意** | 一般个人信息处理 |
| **单独同意** | 敏感个人信息处理、向第三方提供、公开、出境等 |
| **书面同意** | 法律、行政法规规定应当取得书面同意的情形 |

> [!warning] "默认勾选"不构成有效同意
> 实务中 APP 默认勾选"同意隐私政策"或在用户不知情情况下收集，不构成有效同意。监管执法明确要求同意应当由个人在充分知情的前提下**自愿、明确作出**，不得通过误导、捆绑方式取得。

### 3. 敏感个人信息

> [!definition] 敏感个人信息
> 一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括**生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹**等信息，以及不满十四周岁未成年人的个人信息。

| 要求 | 说明 |
| ---- | ---- |
| **特定目的与充分必要性** | 只有在具有特定目的和充分必要性时方可处理 |
| **单独同意** | 必须取得个人单独同意；未成年人需取得监护人同意 |
| **严格保护措施** | 采取更严格的保护措施，如加密存储、访问审计 |

### 4. 个人信息跨境提供

个保法对个人信息出境规定了与数安法衔接的合规路径：

> [!info] 个人信息出境三选一
> 向境外提供个人信息，应当通过下列方式之一：
> 1. 依照本法规定通过**国家网信部门组织的安全评估**；
> 2. 按照国家网信部门的规定经专业机构进行**个人信息保护认证**；
> 3. 按照国家网信部门制定的标准合同与境外接收方订立合同。

### 三法核心要点对比

| 维度 | 《网络安全法》 | 《数据安全法》 | 《个人信息保护法》 |
| ---- | -------------- | -------------- | ------------------ |
| **施行日期** | 2017-06-01 | 2021-09-01 | 2021-11-01 |
| **保护对象** | 网络与系统运行安全 | 数据本身安全 | 个人信息权益 |
| **核心主体** | 网络运营者 | 数据处理者 | 个人信息处理者 |
| **核心制度** | 等级保护、CII 保护、实名制 | 数据分类分级、重要数据保护 | 告知同意、敏感信息保护 |
| **跨境规则** | CII 数据本地化 | 重要数据出境安全评估 | 安全评估/认证/标准合同 |
| **典型处罚** | 罚款、责令改正、关闭网站 | 罚款、吊销许可、追究刑责 | 罚款、责令改正、没收违法所得 |
| **与等保关系** | 直接规定等级保护制度 | 数据分级与等保数据安全要求衔接 | 通过安全要求落实个保法保障义务 |

> [!tip] 三法的"重叠与互补"
> - **重叠**：个人信息既受个保法规制，也属于数据受数安法规制，其载体网络受网安法规制。
> - **互补**：网安法管"载体与运行"，数安法管"数据内容与流通"，个保法管"个人权益与处理行为"。
> - **适用规则**：同一行为可能同时违反多部法律，按"特别法优于一般法"和"上位法优于下位法"适用，但行政处罚往往可以**并罚**。

## 五、案例：某 APP 违规收集个人信息被处罚

> [!example] APP 违规收集个人信息执法案例
> **背景**：某社交类 APP 拥有千万级用户，被用户举报"安装后未经阅读隐私政策即开始收集设备标识、位置信息"。
>
> **资产与边界**：APP 客户端（用户终端）↔ APP 服务端（运营者）↔ 第三方 SDK（共享方）。
>
> **违规事实（监管核查认定）**：
> 1. **未明确告知即收集**：APP 首次启动时在用户未点击"同意"前即收集 IMEI、MAC 地址、地理位置，违反"告知同意"规则；
> 2. **超范围收集**：社交功能实际不需精确位置，却默认申请精确定位权限，违反"最小必要"原则；
> 3. **未提供撤回同意方式**：用户无法在设置中撤回同意或注销账户；
> 4. **第三方 SDK 未经单独同意共享**：将用户行为数据共享给广告 SDK，未取得单独同意；
> 5. **敏感信息未单独同意**：收集人脸特征用于"滤镜"功能，未取得单独同意。
>
> **处罚依据与结果**：
> - 依据《个人信息保护法》第 66 条，责令改正，给予警告，没收违法所得，并处罚款；
> - 依据《网络安全法》第 64 条，对直接负责的主管人员罚款；
> - APP 被应用商店下架整改 30 天。
>
> **整改要点**：
> 1. 重构隐私政策与同意流程，确保"先告知、后收集、单独同意敏感信息"；
> 2. 拆分非必要权限申请，按功能最小化授权；
> 3. 提供"撤回同意""注销账户"入口；
> 4. 第三方 SDK 接入清单化、共享行为单独告知；
> 5. 建立个人信息处理活动记录与定期合规审计。
>
> **启示**：个保法执法以"告知同意"和"最小必要"为最核心抓手；APP 合规不能只看隐私政策文本，更要看实际收集行为与处理逻辑。

## 本节小结

- "三法"构成我国网络空间治理基础框架：网安法管网络运行、数安法管数据、个保法管个人信息处理活动。
- 网络运营者承担等级保护、日志留存六个月、安全事件报告等法定义务；CII 运营者承担数据本地化、安全评估等更重义务。
- 数安法建立数据分类分级制度，核心数据最严、重要数据次之；重要数据出境需安全评估。
- 个保法以"合法、正当、必要、诚信"为原则，敏感个人信息需单独同意；出境需通过安全评估、认证或标准合同。
- 三法重叠适用，企业合规需建立"三法协同"的个人信息与数据治理体系。
