## 一、选择题（6 题）

**1.** 下列关于 B2B、B2C、C2C、O2O 四种模式的说法，正确的是（ ）
A. B2C 是消费者对消费者的模式，如淘宝
B. O2O 是线上获客、线下交付的模式，如美团外卖
C. C2C 是企业对企业的模式，如阿里巴巴
D. B2B 是企业对消费者的模式，如京东自营

**2.** 双边市场中"交叉网络效应"的含义是（ ）
A. 同一侧用户数量增加会提升同侧用户的价值
B. 一侧用户数量增加会提升另一侧用户的价值
C. 两侧用户数量同时增加会降低平台价值
D. 交叉网络效应只存在于单边市场

**3.** 下列哪项不属于免费模式的变现路径？（ ）
A. 广告变现
B. 增值服务变现
C. 直接销售用户数据
D. 佣金抽成变现

**4.** 订阅经济的核心指标 LTV 指的是（ ）
A. 每月经常性收入
B. 客户生命周期价值
C. 客户流失率
D. 获客成本

**5.** 拼多多的核心商业模式创新是（ ）
A. 自营物流
B. 社交电商+下沉市场
C. 算法推荐的短视频
D. 会员制订阅

**6.** 抖音的核心变现方式是（ ）
A. 软件授权费
B. 信息流广告+电商佣金
C. 交易佣金（仅 0.6%）
D. 硬件销售

<details>
<summary>选择题答案</summary>

1. **B**。O2O 是线上获客、线下交付的模式，美团外卖是典型代表；A 错，B2C 是企业对消费者；C 错，C2C 是消费者对消费者；D 错，B2B 是企业对企业。

2. **B**。交叉网络效应是指一侧用户数量增加会提升另一侧用户的价值，这是双边市场的核心动力；A 描述的是同边网络效应；C、D 错误。

3. **C**。直接销售用户数据是违法行为（侵犯隐私权），不属于合法的变现路径；A、B、D 都是合法的免费模式变现路径。

4. **B**。LTV（Lifetime Value）是客户生命周期价值，指单个用户在订阅周期内贡献的总收入；A 是 MRR；C 是 Churn Rate；D 是 CAC。

5. **B**。拼多多的核心创新是"社交电商+下沉市场"，利用微信社交关系链快速获取下沉市场用户；A 是京东的特点；C 是抖音的特点；D 是订阅经济的特征。

6. **B**。抖音的核心变现方式是信息流广告（CPM/CPC）和电商佣金（GMV 抽成）；A 不是抖音的变现方式；C 是拼多多的变现方式；D 与抖音无关。

</details>

## 三、简答题（6 题）

**1.** 简述 B2B、B2C、C2C、O2O 四种模式的核心区别，分别举一个中国企业的例子。

**2.** 什么是双边市场的交叉网络效应？以滴滴为例说明其如何利用交叉网络效应实现快速增长。

**3.** 免费模式的本质是什么？请说明"免费"如何转化为"收入"，并举一个中国互联网企业的例子。

**4.** 订阅经济与传统"一次性购买"模式相比，有哪些核心优势？关键指标有哪些不同？

**5.** 简述商业模式画布的九大要素及其核心问题。

**6.** 分析拼多多如何通过"C2M 模式"实现极致低价，并讨论其可能的局限性。

<details>
<summary>简答题答案</summary>

**1.** 四种模式的核心区别：
| 维度 | B2B | B2C | C2C | O2O |
| ---- | --- | --- | --- | --- |
| 交易主体 | 企业↔企业 | 企业→消费者 | 消费者↔消费者 | 线上获客→线下交付 |
| 核心价值 | 降低采购成本 | 便捷购物体验 | 闲置资源流通 | 线上便捷+线下体验 |
| 中国代表 | 阿里巴巴(1688) | 京东/天猫 | 淘宝/闲鱼 | 美团/滴滴 |

**2.** 交叉网络效应是指**一侧用户数量增加会提升另一侧用户的价值**，形成正反馈循环。
以滴滴为例：
1. 冷启动阶段，滴滴同时补贴乘客（优惠券）和司机（现金奖励），快速启动双边网络；
2. 乘客越多→司机越愿意上线接单→等待时间越短→吸引更多乘客；
3. 司机越多→乘客等待时间越短→更多乘客使用→司机收益更高；
4. 这种正反馈循环使滴滴在 3 年内从零成长为日订单 3000 万+ 的出行平台。

**3.** 免费模式的本质是**用零价格获取用户注意力，再通过多元路径变现**。它是"注意力经济"的体现——用户的注意力本身就是最珍贵的资源。
转化路径：免费产品→获取用户→积累数据/流量→通过广告/增值服务/佣金/数据变现→产生收入。
例如**百度**：用户免费使用搜索→积累搜索数据→广告主竞价购买关键词（CPC）→百度获得广告费。2023 年百度广告收入占总营收的 70%+。

**4.** 订阅经济 vs 一次性购买的核心优势：
| 维度 | 订阅经济 | 一次性购买 |
| ---- | -------- | ---------- |
| 收入模式 | 持续稳定的经常性收入 | 一次性收入，后续无收入 |
| 客户关系 | 长期服务关系，粘性高 | 短期交易关系，粘性低 |
| 用户价值 | 持续创造价值，LTV 高 | 单次价值，LTV 低 |
| 风险 | 可预测收入，风险低 | 收入波动大，风险高 |

关键指标差异：
- 订阅经济关注：MRR/ARR、Churn Rate、LTV、NPS；
- 一次性购买关注：销量、客单价、毛利率。

**5.** 商业模式画布九大要素：
1. **客户细分**：为谁创造价值？
2. **价值主张**：创造了什么独特价值？
3. **渠道通路**：如何传递价值给客户？
4. **客户关系**：如何与客户建立和保持关系？
5. **收入来源**：如何从客户获取收入？
6. **核心资源**：实现商业模式需要什么资源？
7. **关键活动**：实现价值主张需要做什么？
8. **关键合作伙伴**：谁是外部合作伙伴？
9. **成本结构**：需要付出什么成本？

**6.** 拼多多 C2M（Customer to Manufacturer）模式：
- **运作方式**：拼多多直接对接制造商，通过平台大数据分析消费者需求，指导工厂生产"爆款"产品，省去品牌商、经销商等中间环节；
- **低价原因**：省去中间环节（品牌溢价 30-50%、经销商加价 20-30%），直接从工厂到消费者，实现极致低价；
- **局限性**：
  1. 品控难以保障：工厂为了低价可能降低质量标准；
  2. 品牌缺失：没有品牌背书，消费者信任度低；
  3. 创新能力弱：工厂按照平台数据生产，缺乏自主研发和设计能力；
  4. 平台依赖：工厂过度依赖拼多多的流量，议价能力弱。

</details>

## 四、案例分析题（4 题）

**1.（平台经济分析）** 阅读以下材料，回答问题：
> Airbnb（爱彼迎）成立于 2008 年，最初是两位设计师用充气床垫接待参会者的副业。如今已发展成为全球最大的住宿平台，连接 100 万+ 房东和 8000 万+ 房客，覆盖 190+ 国家。
>
> (1) Airbnb 的双边市场结构是怎样的？
> (2) Airbnb 如何利用交叉网络效应实现快速增长？
> (3) Airbnb 面临哪些平台治理挑战？

<details>
<summary>案例分析1解答</summary>

(1) Airbnb 的双边市场结构：
- **A 侧（房东）**：提供闲置房屋或房间的个人或小型酒店；
- **B 侧（房客）**：需要短期住宿的旅行者；
- **平台**：Airbnb 提供撮合交易、信任体系、支付结算、保险保障等服务。

(2) 交叉网络效应的实现：
- 冷启动：早期通过 Craigslist 抓取房源、邀请房东入驻，同时在旅游目的地推广吸引房客；
- 正反馈循环：房客越多→房东越愿意入驻→房源越丰富→房客选择越多→吸引更多房客；
- 全球化复制：每进入一个新城市，都利用同样的网络效应逻辑快速启动；
- 关键动作：Superhost 认证激励优质房东、Airbnb 保障计划（100 万美元保险）建立信任、双向评价体系保障质量。

(3) 平台治理挑战：
- **质量保障**：房东提供的房源质量参差不齐，部分照片与实物不符；
- **负外部性**：房客行为可能影响邻居（噪音、安全），引发社区反对；
- **监管风险**：各国对短租的法律法规不同（如纽约、巴黎的限制政策）；
- **信任体系**：需要持续投入资源维护评价系统和身份验证，防止刷单和欺诈。

</details>

**2.（免费模式分析）** 阅读以下材料，回答问题：
> 微信是腾讯旗下的社交平台，月活跃用户超过 13 亿。微信本身对用户完全免费，但 2023 年腾讯总营收达到 5000 亿元人民币，其中游戏收入占 50%，金融科技（微信支付）占 20%，网络广告占 15%。
>
> (1) 微信运用了哪些免费模式的变现路径？
> (2) 微信的"免费"如何转化为腾讯的"收入"？
> (3) 微信作为"流量入口"，还带动了腾讯哪些业务的发展？

<details>
<summary>案例分析2解答</summary>

(1) 微信运用的变现路径：
- **第三方付费（广告变现）**：朋友圈广告、公众号信息流广告、小程序广告；
- **免费增值**：微信会员（如视频号会员、读书会员）、虚拟礼物；
- **佣金抽成**：微信支付手续费（0.1%）、小程序交易佣金；
- **双边补贴**：对用户免费，向商家（公众号、小程序开发者）收费。

(2) 免费→收入的转化链路：
1. 微信免费提供社交服务→获取 13 亿+ 月活用户；
2. 积累用户社交关系链和行为数据；
3. 将用户注意力转化为广告收入（朋友圈广告 CPM 高达 200-300 元）；
4. 将用户行为数据赋能微信支付（2023 年交易规模超 50 万亿）；
5. 将社交流量引导至腾讯游戏、视频号、电商等业务。

(3) 微信作为流量入口带动的业务：
- **腾讯游戏**：微信社交关系链分享游戏，降低获客成本（王者荣耀日活 1 亿+）；
- **视频号**：基于社交推荐的短视频，快速追赶抖音；
- **微信电商**：小程序电商、视频号直播带货；
- **企业微信**：B 端客户沟通工具；
- **搜一搜**：搜索业务，挑战百度的搜索市场。

</details>

**3.（订阅经济分析）** 阅读以下材料，回答问题：
> 某在线教育平台"学而思网校"提供 K12 在线课程，采用"直播+录播+AI 答疑"的混合模式。2023 年推出年度会员服务，年费 499 元，涵盖数学、语文、英语三科全部课程。截至 2024 年，付费会员达 500 万，年营收 25 亿元。
>
> (1) 学而思网校的订阅经济模式有哪些特点？
> (2) 该模式的关键指标有哪些？如何衡量其健康度？
> (3) 如果你是学而思网校的 CEO，你会如何优化订阅经济模式？

<details>
<summary>案例分析3解答</summary>

(1) 订阅经济模式的特点：
- **产品形态**：教育内容订阅（年度会员），涵盖三科课程；
- **服务模式**：直播+录播+AI 答疑，提供持续服务价值；
- **定价策略**：499 元/年，低于单科购买的总价，具有吸引力；
- **客户关系**：长期学习陪伴（一年服务期），高粘性；
- **风险对冲**：订阅模式带来稳定的可预测收入，降低政策风险。

(2) 关键指标与健康度衡量：
| 指标 | 含义 | 健康标准 |
| ---- | ---- | -------- |
| **MRR/ARR** | 月度/年度经常性收入 | ARR 持续增长（年增 >20%） |
| **Churn Rate** | 年度流失率 | <15%（教育行业平均水平） |
| **LTV** | 单个用户生命周期价值 | LTV > CAC 的 3 倍 |
| **续费率** | 年度会员续费率 | >60%（教育行业平均约 50%） |
| **NPS** | 净推荐值 | >40（K12 教育平均水平） |
| **完课率** | 课程完成率 | >70%（衡量产品质量） |

(3) 优化策略：
- **内容差异化**：增加编程、艺术等素质教育内容，扩展会员价值；
- **社群化运营**：建立学习社群，促进用户交流和互助，提高留存率；
- **个性化服务**：基于 AI 分析学生薄弱环节，提供个性化学习路径；
- **增值服务**：推出 1V1 辅导、学习报告等增值付费服务；
- **口碑传播**：推荐有奖机制，利用社交裂变降低获客成本。

</details>

**4.（综合案例分析）** 阅读以下材料，回答问题：
> 京东是中国最大的自营 B2C 电商平台，2023 年营收突破 1 万亿元。京东核心竞争力是自建物流（211 限时达、极速达），拥有 30 万+ 快递员、1600 万㎡ 仓储面积。近年来京东推出 PLUS 会员（年费 149 元），截至 2024 年 PLUS 会员突破 3500 万。同时京东通过京喜（社交电商）、京东到家（O2O 生鲜）等业务下沉市场。
>
> (1) 京东的核心商业模式是什么？用商业模式画布分析。
> (2) 京东的 PLUS 会员如何体现订阅经济的特征？
> (3) 京东的商业模式融合了哪些本章学习的模式？请列举并说明。

<details>
<summary>案例分析4解答</summary>

(1) 京东核心商业模式画布：
| 要素 | 京东的具体做法 |
| ---- | ------------- |
| **客户细分** | 中高端消费者、企业客户、下沉市场用户 |
| **价值主张** | "正品行货、快速配送"——自营物流保障体验 |
| **渠道通路** | App、网页、小程序、线下实体店（京东之家） |
| **客户关系** | 自营客服、PLUS 会员专属、社群运营 |
| **收入来源** | 商品销售（主要）、PLUS 会员费、物流服务费、广告收入 |
| **核心资源** | 自营物流体系、品牌认知、供应链、技术系统 |
| **关键活动** | 商品采购与品控、物流仓储与配送、平台运营、技术研发 |
| **关键合作伙伴** | 品牌供应商、第三方商家、物流合作伙伴、支付机构 |
| **成本结构** | 商品采购、物流成本（最大支出）、技术研发、获客成本 |

(2) PLUS 会员的订阅经济特征：
- **定期付费**：年费 149 元，属于典型的订阅模式；
- **持续服务**：提供全年购物折扣（9.5 折）、运费券、专属客服、影音会员等持续权益；
- **高粘性**：PLUS 会员年均消费是非会员的 3 倍，续费率约 70%；
- **数据驱动**：基于会员消费数据提供个性化推荐和专属优惠。

(3) 京东融合的商业模式：
| 模式 | 京东的应用 | 说明 |
| ---- | ---------- | ---- |
| **B2C** | 京东自营 | 企业直接向消费者销售正品行货 |
| **平台经济** | 京东 POP 平台 | 连接第三方商家和消费者，收取佣金 |
| **O2O** | 京东到家 | 线上下单、线下 30 分钟送达 |
| **订阅经济** | PLUS 会员 | 年度订阅，持续服务 |
| **免费模式** | 京东 App/小程序 | 用户免费使用，通过商品销售和广告变现 |
| **社群商业** | 京喜（社交电商） | 利用社交关系链裂变获客 |
| **B2B** | 京东企业购 | 面向企业客户的采购平台 |

京东的商业模式是一个融合了 B2C、B2B、平台经济、O2O、订阅经济、免费模式、社群商业的"超级平台"，体现了互联网商业模式多元化融合的趋势。

</details>
