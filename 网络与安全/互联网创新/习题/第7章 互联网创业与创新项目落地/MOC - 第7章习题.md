## 一、选择题（6 题）

**1.** 下列关于创业选题的描述，最准确的是（ ）
A. 好选题必须是当下最热门的赛道
B. 好选题只需要考虑"我想做什么"
C. 好选题是"真实痛点、足够规模、可行落地"三者的交集
D. 好选题只要有技术创新就一定能成功

**2.** 商业计划书中最重要的部分是（ ）
A. 产品介绍
B. 执行摘要
C. 市场分析
D. 团队介绍

**3.** 下列关于二手调研的描述，正确的是（ ）
A. 二手调研就是在百度上搜索相关信息
B. 二手调研的优势是快、便宜、信息量大
C. 二手调研可以完全替代一手调研
D. 二手调研只能获取行业宏观数据

**4.** 创业团队中 CTO 的核心职责是（ ）
A. 制定战略和融资谈判
B. 产品开发和技术架构
C. 市场推广和用户增长
D. 财务核算和人力资源

**5.** 下列关于"互联网+"大赛评审维度的描述，错误的是（ ）
A. 创新性占最高权重
B. 商业价值是评审维度之一
C. 社会效益不是评审维度
D. 团队能力是评审维度之一

**6.** 波特五力模型中，下列哪一项不属于五力？（ ）
A. 现有竞争者的威胁
B. 新进入者的威胁
C. 政府政策的威胁
D. 替代品的威胁

<details>
<summary>选择题答案</summary>

1. **C**。好选题的三个标准是"真实痛点、足够规模、可行落地"，是用户需要、市场空缺、自身能力的交集。A 错误，热门赛道往往竞争激烈；B 错误，选题应从用户需求出发而非个人意愿；D 错误，技术创新只是成功的条件之一。

2. **B**。执行摘要是 BP 的"电梯演讲"，90% 的投资人只看执行摘要。如果摘要不能吸引读者，后面内容再好也没用。

3. **B**。二手调研的优势是快速、低成本、信息量大。A 错误，二手调研数据源远不止百度；C 错误，二手调研不能替代一手调研，两者互补；D 错误，二手调研也能获取微观数据。

4. **B**。CTO（首席技术官）负责产品开发和技术架构。A 是 CEO 的职责；C 是 COO 的职责；D 通常由 CFO 或行政负责人承担。

5. **C**。"互联网+"大赛的评审维度包括创新性（25%）、商业价值（25%）、团队能力（20%）、**社会效益（15%）**、可行性（15%）。社会效益是明确的评审维度之一。

6. **C**。波特五力包括：现有竞争者的威胁、新进入者的威胁、替代品的威胁、供应商的议价能力、买方的议价能力。政府政策不属于五力模型。

</details>

## 二、填空题（4 题）

**1.** 商业计划书的九大板块包括：封面、执行摘要、______、解决方案、市场分析、______、商业模式、竞争分析、团队与融资。

**2.** SWOT 分析中的四个维度分别是：优势（Strengths）、______、机会（Opportunities）、______。

**3.** 创业团队的"三剑客"通常指：CEO、______、______。

**4.** "互联网+"大赛评审的五个维度是：创新性、______、团队能力、社会效益、______。

<details>
<summary>填空题答案</summary>

1. **问题与痛点**、**产品介绍**。BP 九大板块：封面、执行摘要、问题与痛点、解决方案、市场分析、产品介绍、商业模式、竞争分析、团队与融资。

2. **劣势（Weaknesses）**、**威胁（Threats）**。SWOT = Strengths（优势）、Weaknesses（劣势）、Opportunities（机会）、Threats（威胁）。

3. **CTO（首席技术官）**、**COO（首席运营官）**。创业三剑客：CEO 负责战略与融资，CTO 负责技术与产品，COO 负责运营与市场。

4. **商业价值**、**可行性**。"互联网+"评审五维度：创新性（25%）、商业价值（25%）、团队能力（20%）、社会效益（15%）、可行性（15%）。

</details>

## 三、简答题（6 题）

**1.** 简述创业选题的三个核心标准，并说明为什么"真实痛点"是最重要的标准。

**2.** 什么是商业计划书（BP）？为什么说执行摘要对 BP 至关重要？

**3.** 对比二手调研和一手调研的核心区别，并说明在创业早期如何结合使用。

**4.** 简述创业团队中 CEO、CTO、COO 三个核心角色的职责分工与协作关系。

**5.** 简述"互联网+"大赛的评审维度，并说明社会效益维度的重要性。

**6.** 什么是波特五力模型？请用该模型分析外卖行业的竞争格局。

<details>
<summary>简答题答案</summary>

**1. 选题三标准**

| 标准 | 内涵 |
| ---- | ---- |
| 真实痛点 | 用户确实存在且愿意付费的需求 |
| 足够规模 | 目标市场有足够大的空间支撑商业价值 |
| 可行落地 | 团队有能力在合理时间内做出产品 |

**"真实痛点"最重要的原因**：
- 痛点是创业的"地基"——没有真实痛点，任何产品都是"空中楼阁"
- 创业的核心风险不是技术不行，而是"做了用户不需要的东西"
- 真实痛点意味着用户愿意付费，这是商业模式成立的前提
- 足够规模和可行落地都是在"真实痛点"基础上的增量考量

**2. 商业计划书与执行摘要**

> 商业计划书是面向投资人、合作伙伴、评审专家的正式文档，系统阐述创业项目的商业模式、市场分析、产品规划、竞争策略、团队构成和财务预测。

执行摘要至关重要的原因：
- **90% 的投资人只看执行摘要**——如果摘要不能吸引他，后面再好也没用
- 执行摘要是"30 秒电梯演讲"的文字版——用最精炼的语言传达项目核心价值
- 执行摘要决定了评委是否有兴趣继续阅读——它是 BP 的"第一印象"
- 执行摘要涵盖了项目最核心的信息：定位、痛点、解决方案、市场、融资需求

**3. 二手调研 vs 一手调研**

| 维度 | 二手调研 | 一手调研 |
| ---- | -------- | -------- |
| 核心目标 | 了解市场全貌 | 获取独家洞察 |
| 数据来源 | 行业报告、公开数据、搜索引擎 | 用户访谈、问卷调查、实地考察 |
| 优势 | 快、便宜、信息量大 | 深入、精准、独家 |
| 局限 | 数据可能过时、不够精准 | 成本高、耗时长 |

**创业早期结合使用**：
1. **先用二手调研**快速了解行业全貌（1-3 天），确定市场规模、竞争格局、趋势方向
2. **再用一手调研**深入验证核心假设（1-2 周），通过用户访谈获取独家痛点和需求
3. **交叉验证**：用二手数据验证一手调研的结论，确保结论的可靠性

**4. 创业三剑客分工与协作**

| 角色 | 核心职责 | 关键能力 |
| ---- | -------- | -------- |
| CEO | 制定战略、融资谈判、对外合作、团队建设 | 领导力、沟通力、商业敏感度 |
| CTO | 技术架构、产品开发、研发管理 | 技术深度、工程能力、产品思维 |
| COO | 用户增长、运营体系、市场推广 | 执行力、数据思维、用户洞察 |

**协作关系**：
- CEO 制定战略方向，CTO 和 COO 分别在技术和运营维度执行
- CTO 向 CEO 汇报技术进展，COO 向 CEO 汇报运营数据
- CTO 与 COO 协作：CTO 提供产品能力，COO 提供用户反馈，形成产品迭代闭环
- 三者形成"战略—产品—运营"的完整闭环

**5. "互联网+"评审维度**

| 维度 | 权重 | 核心评审要点 |
| ---- | ---- | ------------ |
| 创新性 | 25% | 技术创新、模式创新、理念创新 |
| 商业价值 | 25% | 市场规模、商业模式、盈利潜力 |
| 团队能力 | 20% | 团队互补性、执行力、经验 |
| 社会效益 | 15% | 社会价值、就业带动、产业促进 |
| 可行性 | 15% | 技术可行性、落地计划、资源配置 |

**社会效益的重要性**：
- 社会效益是"互联网+"区别于其他商业赛事的核心特征
- 国家通过"互联网+"大赛引导创业项目服务于社会发展目标（如乡村振兴、共同富裕）
- 社会效益维度的高分可以显著提升项目的竞争力
- 很多投资人也越来越重视项目的社会价值（ESG 投资趋势）

**6. 波特五力模型与外卖行业分析**

> 波特五力模型用于分析行业竞争格局，包含五种竞争力量：现有竞争者的威胁、新进入者的威胁、替代品的威胁、供应商的议价能力、买方的议价能力。

**外卖行业五力分析**：

| 竞争力量 | 强度 | 分析 |
| -------- | ---- | ---- |
| 现有竞争者 | ⭐⭐⭐⭐⭐ | 美团（70%）vs 饿了么（25%），双寡头竞争激烈 |
| 新进入者 | ⭐⭐⭐ | 京东、滴滴等巨头有能力进入，但需大量补贴 |
| 替代品威胁 | ⭐⭐ | 自提、堂食、预制菜等替代品威胁有限 |
| 供应商议价 | ⭐⭐⭐⭐ | 商家和骑手议价能力强，佣金和配送费是核心争议 |
| 买方议价 | ⭐⭐⭐⭐⭐ | 用户选择多、切换成本低，价格敏感度高 |

**结论**：外卖行业竞争激烈，利润空间被压缩，新进入者需要找到差异化切入点（如垂直场景、高端品质）才能生存。

</details>

## 四、案例分析题（4 题）

**1.（选题分析案例）** 某大学生团队想创业，拟从以下 5 个 idea 中选择一个：
- Idea A：面向老年人的智能用药提醒 App
- Idea B：校园二手教材交易平台
- Idea C：基于 AI 的个性化健身教练
- Idea D：面向职场人的高质量咖啡订阅
- Idea E：宠物智能穿戴设备

请用"选题三标准"（真实痛点、足够规模、可行落地）对每个 idea 进行评估，并给出最终选题建议。

<details>
<summary>案例分析1解答</summary>

**选题三标准评估：**

| Idea | 真实痛点 | 足够规模 | 可行落地 | 综合评分 |
| ---- | -------- | -------- | -------- | -------- |
| A 老年用药提醒 | ⭐⭐⭐⭐⭐（老人忘吃药是强痛点） | ⭐⭐⭐（老年智能市场万亿，但垂直赛道规模有限） | ⭐⭐⭐（需对接医疗资源，门槛较高） | 3.7 |
| B 校园二手教材 | ⭐⭐⭐⭐（学生有需求但痛点不够强） | ⭐⭐⭐（校园市场相对分散） | ⭐⭐⭐⭐（平台模式，技术门槛低） | 3.3 |
| C AI 健身教练 | ⭐⭐⭐⭐（健身人群有个性化需求） | ⭐⭐⭐⭐（健身市场千亿级） | ⭐⭐（AI 技术门槛高，数据积累慢） | 3.0 |
| D 高质量咖啡订阅 | ⭐⭐⭐（痛点存在但不够强烈） | ⭐⭐⭐⭐（咖啡市场千亿级） | ⭐⭐⭐（供应链和品牌门槛高） | 3.3 |
| E 宠物智能穿戴 | ⭐⭐⭐⭐（宠物主人有监控需求） | ⭐⭐⭐⭐（宠物市场千亿级） | ⭐⭐（硬件研发门槛高） | 3.0 |

**最终建议：选 Idea A（老年智能用药提醒 App）**

**理由**：
1. **真实痛点最强**：老年人忘吃药是刚性痛点，子女也有强烈的付费意愿（为父母健康付费）
2. **社会价值突出**：契合"银发经济"和"健康中国"政策，社会效益维度得分高
3. **差异化明显**：现有产品要么太简单（定时器），要么太复杂（智能药盒），中间有市场空白
4. **可行落地路径**：可以先从简单的提醒功能切入，逐步迭代
5. **适合参加创新创业大赛**：社会效益维度会得高分

</details>

**2.（商业计划书案例）** 某创业项目"茶香"——面向年轻人的国潮茶饮订阅平台。创始人小王第一次写 BP，结构如下：
1. 封面
2. 团队介绍（放在最前面）
3. 产品介绍
4. 技术架构
5. 市场分析
6. 商业模式
7. 竞争分析
8. 融资计划
9. 财务预测

请指出该 BP 结构的问题，并给出优化建议。

<details>
<summary>案例分析2解答</summary>

**原 BP 结构的主要问题：**

| 问题 | 说明 | 严重程度 |
| ---- | ---- | -------- |
| ❌ 缺少执行摘要 | 没有执行摘要，投资人打开后无法快速了解项目 | 致命 |
| ❌ 团队放最前面 | 投资人不认识团队，不会在不了解项目的情况下关注团队 | 严重 |
| ❌ 缺少问题与痛点 | 没有说明"用户为什么需要这个产品"，缺乏说服力 | 严重 |
| ❌ 技术架构过于靠后 | 早期项目不需要过于强调技术架构 | 中等 |
| ❌ 缺少竞争分析对比 | 竞争分析放在后面，没有形成差异化认知 | 中等 |

**优化后的 BP 结构：**

| 序号 | 板块 | 核心内容 | 优化理由 |
| ---- | ---- | -------- | -------- |
| 1 | 封面 | 茶香——国潮茶饮订阅平台 | 保留 |
| 2 | **执行摘要** | 30 秒电梯演讲：定位+痛点+解决方案+市场+融资 | **新增**，投资人第一印象 |
| 3 | **问题与痛点** | 年轻人想喝茶饮但选择难、价格高、不健康 | **新增**，建立情感连接 |
| 4 | **解决方案** | 国潮茶饮订阅+健康配方+文化体验 | **新增**，回应痛点 |
| 5 | 市场分析 | 茶饮市场千亿级，订阅模式年增长 50% | 保留，放前面 |
| 6 | 产品介绍 | 订阅模式+移动端+线下体验 | 保留，简化技术架构 |
| 7 | 商业模式 | 订阅费+联名+周边 | 保留 |
| 8 | 竞争分析 | 对比喜茶、奈雪等，突出"订阅+国潮"差异化 | 保留，强化对比 |
| 9 | **团队介绍** | 核心团队背景 | **移到后面**，先讲项目再讲团队 |
| 10 | 融资计划 | 融资 100 万，出让 15% | 保留 |
| 11 | 财务预测 | 三档预测，盈亏平衡 18 个月 | 保留 |

**核心优化逻辑**：BP 应该是**讲故事的逻辑**——"用户有痛点→我们有方案→市场够大→商业模式可行→团队能做→需要支持"，而不是"我们是谁→做了什么→技术怎么样"。

</details>

**3.（市场调研与竞品分析案例）** 某团队想做一个"面向大学生的在线刷题平台"，专注于公务员和考研备考。请完成以下任务：
(1) 设计一份市场调研方案，包括二手调研和一手调研的具体方法；
(2) 用波特五力模型分析公考/考研培训市场；
(3) 选择 3 个主要竞品（如粉笔、华图、新东方在线），设计竞品对比矩阵（至少 6 个维度）。

<details>
<summary>案例分析3解答</summary>

**(1) 市场调研方案**

**二手调研**：
| 数据源 | 调研内容 | 目的 |
| ------ | -------- | ---- |
| 艾瑞/易观报告 | 公考/考研培训市场规模、增长趋势 | 了解市场全貌 |
| 百度指数 | "公考"、"考研"搜索量变化、热门关键词 | 了解需求热度 |
| App Annie | 粉笔、华图等 App 下载量、排名 | 了解竞品实力 |
| 知乎/小红书 | 用户对现有题库的评价和吐槽 | 了解用户痛点 |

**一手调研**：
| 方法 | 对象 | 内容 | 目的 |
| ---- | ---- | ---- | ---- |
| 用户访谈 | 15 位备考大学生 | 备考习惯、刷题痛点、付费意愿 | 挖掘真实需求 |
| 问卷调查 | 300 位备考大学生 | 刷题频率、使用 App、付费能力 | 验证需求普遍性 |
| 竞品体验 | 3 个核心竞品 | 完整体验产品流程 | 评估竞品体验 |

**(2) 波特五力分析公考/考研培训市场**

| 竞争力量 | 强度 | 分析 |
| -------- | ---- | ---- |
| 现有竞争者 | ⭐⭐⭐⭐⭐ | 粉笔（线上）+华图（线下）双寡头，竞争激烈 |
| 新进入者 | ⭐⭐ | 门槛较高（内容积累、师资、品牌），新玩家威胁有限 |
| 替代品威胁 | ⭐⭐⭐ | 免费题库（如贴吧、B站）、盗版资料是主要替代品 |
| 供应商议价 | ⭐⭐⭐ | 师资和内容创作者议价能力强 |
| 买方议价 | ⭐⭐⭐⭐ | 用户选择多，价格敏感度高，续费率低 |

**(3) 竞品对比矩阵**

| 维度 | 权重 | 粉笔 | 华图 | 新东方在线 | 待创业项目 |
| ---- | ---- | ---- | ---- | ---------- | ---------- |
| 题库质量 | 20% | 5 | 4 | 4 | 3（需提升） |
| 用户体验 | 15% | 5 | 3 | 4 | 4（可差异化） |
| 价格竞争力 | 15% | 4 | 3 | 3 | 5（主打性价比） |
| AI 智能推荐 | 15% | 3 | 2 | 3 | 5（主打亮点） |
| 社区社交 | 10% | 3 | 2 | 2 | 5（做社交化） |
| 品牌知名度 | 15% | 5 | 5 | 4 | 2（需要时间） |
| **加权总分** | 100% | **4.35** | **3.55** | **3.70** | **3.85** |

**差异化策略**：主打"AI 智能推送+社交化刷题"，在 AI 推荐和社区社交两个维度实现差异化，避开粉笔的题库优势和华图的品牌优势。

</details>

**4.（赛事备赛案例）** 某团队的"AI 助农——智能农业监测系统"项目进入了"互联网+"大赛国家赛决赛。请完成以下任务：
(1) 设计决赛答辩的 PPT 结构（15 分钟），说明每页核心内容和时长分配；
(2) 准备 3 个可能被评委问到的难题及应对方案；
(3) 说明如何在答辩中突出"社会效益"维度的优势。

<details>
<summary>案例分析4解答</summary>

**(1) 决赛答辩 PPT 结构（15 分钟）**

| 页码 | 内容 | 时长 | 核心目的 |
| ---- | ---- | ---- | -------- |
| 1 | 封面：AI 助农——让农业更智能 | 10 秒 | 第一印象 |
| 2 | **核心故事**：老王的故事——种了 30 年地，最怕"看天吃饭" | 1 分钟 | 情感连接 |
| 3 | **痛点分析**：传统农业的三大痛点（靠经验、成本高、效率低） | 1 分钟 | 证明问题真实 |
| 4 | **解决方案**：AI 农业监测系统——传感器+AI+大数据 | 1.5 分钟 | 展示产品形态 |
| 5 | **核心功能**：土壤监测、病虫害预警、精准施肥、远程控制 | 1.5 分钟 | 展示产品价值 |
| 6 | **技术亮点**：AI 图像识别+多传感器融合+边缘计算 | 1 分钟 | 展示创新性 |
| 7 | **市场分析**：智慧农业千亿市场，年增 30% | 1 分钟 | 证明商业价值 |
| 8 | **商业模式**：硬件销售+订阅服务+政府项目 | 1 分钟 | 证明盈利路径 |
| 9 | **运营成果**：已在 5 个农场试点，亩增收 20% | 1 分钟 | 证明可行性 |
| 10 | **社会效益**：带动 1000 农户增收，节水 30%，减肥 25% | 1.5 分钟 | **突出社会效益** |
| 11 | **团队介绍**：农大+计算机+商科跨学科团队 | 1 分钟 | 证明团队能力 |
| 12 | **融资计划**：融资 200 万，出让 10% | 30 秒 | 明确需求 |
| 13 | **发展规划**：3 年覆盖 10 省，1 万农户 | 30 秒 | 展示未来 |
| 14 | **结尾**：让科技赋能农业，让农民增收 | 10 秒 | 留下印象 |

**(2) 评委难题及应对**

| 难题 | 应对方案 |
| ---- | -------- |
| **难题 1**："大疆也做农业，你们和大疆有什么区别？" | 承认大疆的优势（品牌、无人机），说明差异化：大疆做空中（无人机植保），我们做地面（土壤监测+精准决策），是互补而非竞争。我们聚焦小农户市场，大疆聚焦大农场 |
| **难题 2**："你们的 AI 准确率是多少？没有数据怎么训练模型？" | 给出具体数据：病虫害识别准确率 92%，土壤监测准确率 95%。说明数据来源：公开数据集+与农科院合作+试点农场积累。说明持续学习机制：用户使用越多，AI 越精准 |
| **难题 3**："农民不会用智能手机，你们怎么推广？" | 说明三层策略：① 简化产品（一键操作、语音提示）；② 与农资经销商合作（渠道下沉）；③ 政府项目背书（免费试点+培训）。已有试点数据证明农民接受度 |

**(3) 突出社会效益的策略**

1. **量化展示**：不说"帮助农民"，要说"已帮助 200 户农户增收 15-20%，每户年均增收 8000 元"
2. **故事化展示**：穿插试点农户的真实照片和反馈（如王大爷的对比照片：使用前亩产 800 斤，使用后亩产 1000 斤）
3. **政策对接**：说明项目如何对接"乡村振兴"、"科技兴农"等国家政策，争取政策支持
4. **就业创造**：说明项目不仅帮助农民增收，还创造了农技推广、设备安装等就业岗位
5. **可持续性**：说明项目不是"一次性捐助"，而是通过商业模式实现可持续发展——农民愿意付费，项目自我造血

</details>
