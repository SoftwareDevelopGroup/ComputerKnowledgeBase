## 一、选择题（6 题）

**1.** 下列关于元宇宙核心特征的描述，错误的是（ ）
A. 沉浸感——用户产生"身临其境"的体验
B. 持久性——虚拟世界不受用户上下线影响
C. 中心化——虚拟资产由单一平台管控
D. 交互性——用户可实时与虚拟环境互动

**2.** 生成式 AI 的核心技术不包括（ ）
A. 大语言模型（LLM）
B. 扩散模型（Diffusion）
C. 卷积神经网络（CNN）用于图像分类
D. 生成对抗网络（GAN）

**3.** 下列关于边缘计算与云计算的对比，正确的是（ ）
A. 边缘计算的计算能力强于云计算
B. 边缘计算的时延低于云计算
C. 边缘计算的数据处理量大于云计算
D. 边缘计算可以完全替代云计算

**4.** 下列哪一项不属于开源商业模式？（ ）
A. 服务支持模式
B. 云托管模式
C. 封闭授权模式
D. 双许可证模式

**5.** 衡量数据中心能效的核心指标是（ ）
A. CPU 利用率
B. PUE（Power Usage Effectiveness）
C. 网络带宽
D. 存储容量

**6.** 下列关于 AI Agent 的描述，错误的是（ ）
A. 能够自主规划和分解任务
B. 能够调用外部工具执行操作
C. 只能被动响应用户的单一指令
D. 具备记忆和反思能力

<details>
<summary>选择题答案</summary>

1. **C**。元宇宙的特征之一是**去中心化**，而非中心化。去中心化意味着虚拟资产和身份由用户拥有，不被单一平台控制。

2. **C**。CNN（卷积神经网络）用于图像分类属于**判别式 AI**，不是生成式 AI。生成式 AI 的核心技术包括 LLM、扩散模型、GAN、VAE 等。

3. **B**。边缘计算的时延低于云计算（1-20ms vs 100ms-秒级）。A 错误，云计算的计算能力更强；C 错误，云计算处理的数据量更大；D 错误，边缘计算是云计算的补充而非替代。

4. **C**。封闭授权模式是闭源商业模式，不属于开源商业模式。开源的六种商业模式包括：服务支持、云托管、双许可证、核心+附加、开源+硬件、基金会资助。

5. **B**。PUE（Power Usage Effectiveness）= 数据中心总用电量 / IT 设备用电量，是衡量数据中心能效的核心指标。PUE 越低，能效越高。

6. **C**。AI Agent 具备**主动性**，能够自主规划任务、调用工具、迭代执行，而非被动响应单一指令。

</details>

## 二、填空题（4 题）

**1.** 元宇宙的四大核心特征包括：沉浸感、______、______、去中心化。

**2.** 生成式 AI 的 AIGC 六大应用领域包括：文本生成、图像生成、______、______、3D 生成、代码生成。

**3.** 边缘计算的"云-边-端"三层架构中，边层的核心组件包括：边缘网关、______、______、边缘数据库。

**4.** 绿色数据中心的三大节能路径：硬件节能、______、______。

<details>
<summary>填空题答案</summary>

1. **交互性**、**持久性**。元宇宙四大核心特征：沉浸感（Immersion）、交互性（Interactivity）、持久性（Persistence）、去中心化（Decentralization）。

2. **音频生成**、**视频生成**。AIGC 六大应用领域：文本、图像、音频、视频、3D 模型、代码。

3. **边缘服务器**、**边缘 AI**。边缘层核心组件：边缘网关（协议转换）、边缘服务器（实时计算）、边缘 AI（模型推理）、边缘数据库（本地缓存）。

4. **架构节能**、**清洁能源**。绿色数据中心三大节能路径：硬件节能（液冷、低功耗芯片）、架构节能（虚拟化、边缘计算、AI 能效管理）、清洁能源（光伏、风电、水电）。

## 三、简答题（6 题）

**1.** 简述元宇宙与传统虚拟世界（如 Second Life）的三个核心区别。

**2.** 对比生成式 AI 与传统判别式 AI 的主要差异，并说明生成式 AI 为何能推动互联网产品变革。

**3.** 简述边缘计算的"云-边-端"三层协同架构，并以一个具体场景说明三者如何协作。

**4.** 列举三种开源社区治理模式，并说明各自的优缺点。

**5.** 解释 PUE 的含义，并说明 Google、阿里巴巴等企业如何将 PUE 降至 1.1 以下。

**6.** 简述 AI 时代的"能耗悖论"，并说明绿色 AI 的三个优化方向。

<details>
<summary>简答题答案</summary>

**1. 元宇宙 vs 传统虚拟世界的核心区别**

| 维度 | 传统虚拟世界 | 元宇宙 |
| ---- | -------- | -------- |
| 规模 | 面向百万级用户 | 面向数亿乃至数十亿用户 |
| 交互深度 | 依赖键鼠交互 | 支持肢体、语音、多感官交互 |
| 资产确权 | 虚拟资产归平台所有 | 通过 NFT 等实现用户资产确权 |
| 开放程度 | 封闭的"花园" | 强调跨平台互通和开放生态 |

**2. 生成式 AI vs 判别式 AI**

| 维度 | 判别式 AI | 生成式 AI |
| ---- | -------- | -------- |
| 核心任务 | 分类、预测、识别 | 生成、创造、合成 |
| 输入输出 | 输入数据→输出标签 | 输入提示→输出全新内容 |
| 应用 | 人脸识别、推荐系统 | 内容创作、智能对话、代码生成 |

生成式 AI 推动互联网产品变革的原因：
- **内容生产工业化**：AI 可自动生成文本、图像、视频等内容，成本降低 80%
- **产品设计智能化**：AI 辅助产品原型设计、用户画像构建
- **开发效率飞跃**：AI 辅助编程，开发速度提升 5 倍
- **AI Agent 自动化**：AI Agent 可自主完成多步骤任务，成为"数字员工"

**3. 云-边-端三层协同架构**

| 层级 | 核心职责 | 代表组件 |
| ---- | -------- | -------- |
| 端层 | 数据采集和简单预处理 | IoT 传感器、智能摄像头、可穿戴设备 |
| 边层 | 实时分析和快速响应 | 边缘网关、边缘服务器、边缘 AI |
| 云层 | 全局分析和模型训练 | 大数据分析、AI 模型训练、资源调度 |

**协作示例（智能工厂）**：
- 端层：工业传感器采集设备温度、振动数据
- 边层：边缘服务器实时分析数据，检测到温度异常，立即触发告警
- 云层：汇总所有车间的设备数据，进行全局设备维护规划，下发调度指令

**4. 三种开源社区治理模式**

| 治理模式 | 优点 | 缺点 | 代表项目 |
| -------- | ---- | ---- | -------- |
| **BDFL（仁慈独裁者）** | 决策高效、方向明确 | 依赖个人威望，存在"独裁者"风险 | Linux、Python |
| **基金会治理** | 制度化、可持续，避免个人依赖 | 决策流程慢，可能脱离社区 | Apache 基金会、Mozilla |
| **精英治理** | 激励贡献者，公平透明 | 可能形成精英集团，新贡献者门槛高 | Apache 项目、GitHub 项目 |

**5. PUE 含义与超低 PUE 实现路径**

PUE = 数据中心总用电量 / IT 设备用电量。PUE 越低，能效越高（理论值 1.0，实际领先水平 1.1 左右）。

**降至 1.1 以下的关键措施**：
- **浸没式液冷**：用绝缘液体替代空气散热，散热效率提升 3000 倍
- **自然冷却**：利用室外冷空气或冷水直接冷却，降低空调能耗
- **AI 智能制冷**：DeepMind AI 实时优化制冷参数，节能 15%
- **高效电源**：高压直流（HVDC）供电，减少转换损耗
- **清洁能源直供**：PPA 直购风电/光伏，减少输电损耗

**6. AI 能耗悖论与绿色 AI 方向**

**能耗悖论**：AI 提升了全社会效率，但 AI 本身消耗的能源正以指数级增长。生成式 AI 的模型训练和推理能耗巨大，预计 2027 年 AI 数据中心能耗将占全球电力的 10%。

**绿色 AI 的三个优化方向**：
1. **模型压缩**：量化、剪枝、蒸馏等技术减小模型体积，降低推理能耗
2. **专用芯片**：TPU、NPU 等 AI 专用芯片的能效比远高于通用 GPU
3. **边缘推理**：将 AI 推理任务从云端下沉到边缘设备，减少数据传输能耗

</details>

## 四、案例分析题（4 题）

**1.（元宇宙案例）** 阅读以下材料，回答问题：

> Roblox 2023 年全球月活跃用户达 7000 万，其中 60% 以上为 17 岁以下青少年。平台上有超过 1000 万创作者开发虚拟场景，Nike 在 Roblox 上推出虚拟球鞋，Gucci 推出虚拟手袋，价格甚至超过现实中的同款产品。Meta Horizon 则依托 Facebook 29 亿用户基础，从熟人社交切入，硬件亏损销售以获取 Quest 头显市场份额。

(1) 对比 Roblox 和 Meta Horizon 的元宇宙路径差异；
(2) 分析两种路径各自的优劣势；
(3) 如果你是创业者，会选择哪种路径切入元宇宙？请说明理由。

<details>
<summary>案例分析1解答</summary>

**(1) 路径差异**

| 对比维度 | Roblox | Meta Horizon |
| -------- | ------ | ------------ |
| 目标用户 | 青少年为主 | 全年龄段，侧重成人 |
| 核心驱动力 | UGC 内容生态 | 软硬件一体化体验 |
| 入口设备 | 多平台（PC、移动、VR） | Quest VR 头显为主 |
| 社交基因 | 兴趣社交 | 熟人社交 |
| 商业化 | 虚拟物品 + 品牌合作 | 硬件 + 订阅 + 企业服务 |

**(2) 优劣势分析**

**Roblox 优势**：UGC 生态网络效应强大，跨平台覆盖广，用户粘性高
**Roblox 劣势**：去中心化程度低，内容质量参差不齐，成人转化率低

**Meta Horizon 优势**：软硬件整合带来极致体验，Facebook 社交基因降低冷启动门槛
**Meta Horizon 劣势**：硬件渗透率低，内容生态封闭，用户留存待提升

**(3) 创业路径选择**

**推荐选择：细分场景切入 + 跨平台路径**

理由：
- 避开 Roblox（UGC 生态壁垒）和 Meta（硬件壁垒）的正面竞争
- 选择垂直场景（如教育、培训、企业协作）切入，需求更明确
- 采用跨平台策略（Web + 移动 + VR），降低用户硬件门槛
- 利用生成式 AI 降低内容创作门槛，快速构建内容生态
- 初期可做"轻元宇宙"——基于 Web 的 3D 虚拟空间，无需专用硬件

</details>

**2.（生成式 AI 案例）** 阅读以下材料，回答问题：

> 某互联网公司正在评估生成式 AI 的应用场景。初步筛选出 5 个方向：
> - A：用 AI 生成营销文案和配图
> - B：用 AI 做智能客服，自动处理 80% 的常见问题
> - C：用 AI 辅助程序员编程，自动生成代码片段
> - D：用 AI 分析用户反馈，自动生成用户画像和运营建议
> - E：用 AI 生成产品原型和 UI 设计稿

(1) 请用"投入-产出"分析框架对每个方向进行评估；
(2) 选出最优的 2 个方向，并说明理由；
(3) 说明 AI Agent 如何进一步提升这两个方向的价值。

<details>
<summary>案例分析2解答</summary>

**(1) 投入-产出分析**

| 方向 | 技术难度 | 投入成本 | 产出价值 | 落地风险 | 综合评分 |
| ---- | -------- | -------- | -------- | -------- | -------- |
| A 营销文案 | ⭐ 低 | ⭐ 低 | ⭐⭐⭐ 中 | 低（内容质量可控） | 4.0 |
| B 智能客服 | ⭐⭐ 中 | ⭐⭐ 中 | ⭐⭐⭐⭐ 高 | 中（需训练数据） | 3.5 |
| C AI 编程 | ⭐⭐⭐ 高 | ⭐⭐ 高 | ⭐⭐⭐⭐ 高 | 中（代码质量和安全） | 3.5 |
| D 用户画像 | ⭐⭐ 中 | ⭐⭐ 中 | ⭐⭐⭐⭐⭐ 高 | 中（数据隐私） | 3.8 |
| E 原型设计 | ⭐⭐ 中 | ⭐⭐ 中 | ⭐⭐ 中 | 中（需设计师配合） | 3.0 |

**(2) 最优两个方向：B（智能客服）和 D（用户画像）**

理由：

**智能客服 + AI Agent**：
- 从"被动回答"升级为"主动服务"——AI Agent 主动监控用户行为，发现异常主动联系
- 跨系统操作——AI Agent 可直接调用订单系统、退款系统、物流系统完成操作
- 多轮自主对话——复杂问题自主追踪到底，无需人工介入

**用户画像 + AI Agent**：
- 从"生成报告"升级为"执行行动"——AI Agent 根据用户画像自动执行个性化推荐、邮件推送、优惠策略
- 实时更新——用户数据变化时 AI Agent 自动更新画像和策略
- A/B 测试自动化——AI Agent 自动设计和执行运营 A/B 测试

</details>

**3.（边缘计算案例）** 阅读以下材料，回答问题：

> 某智慧城市项目需要部署一套智能交通系统，要求：
> 1. 实时分析路口摄像头视频，检测交通事故和拥堵
> 2. 自动调度信号灯，优化路口通行效率
> 3. 数据需要本地处理以保护隐私
> 4. 系统需要支持 1000+ 个路口的并发处理

(1) 请设计一个基于"云-边-端"架构的解决方案；
(2) 说明每层的具体部署和协作方式；
(3) 对比纯云计算方案和边缘计算方案的优劣。

<details>
<summary>案例分析3解答</summary>

**(1) 云-边-端架构设计**

```
端层：路口摄像头 + 地磁传感器 + 气象传感器
边层：路口边缘网关（AI 视频分析 + 信号控制）+ 区域边缘服务器（区域调度）
云层：城市云平台（全局优化 + 数据分析 + 模型训练）
```

**(2) 各层部署与协作**

| 层级 | 部署内容 | 核心职责 |
| ---- | -------- | -------- |
| **端层** | 每个路口部署 2-4 台 AI 摄像头 + 地磁传感器 | 采集视频和交通流量数据 |
| **边层（路口级）** | 每个路口部署边缘 AI 网关 | 实时视频分析（事故检测、车辆计数），控制信号灯 |
| **边层（区域级）** | 每个区域部署 1 台区域边缘服务器 | 汇总路口数据，区域协调调度，缓存热点数据 |
| **云层（城市级）** | 城市数据中心 | 全局交通优化、AI 模型训练、数据归档和分析 |

**协作流程**：
1. 路口摄像头采集视频 → 边缘 AI 网关实时分析（事故检测 <200ms）
2. 检测到事故 → 边缘网关立即触发信号灯配时调整 + 上报区域边缘服务器
3. 区域边缘服务器协调相邻路口 → 优化区域交通流向
4. 仅将汇总数据和事件告警上传云层 → 保护隐私 + 降低传输压力
5. 云层基于历史数据优化 AI 模型 → 定期下发到边缘设备

**(3) 纯云 vs 边缘方案对比**

| 对比维度 | 纯云计算方案 | 边缘计算方案 |
| -------- | ------------ | ------------ |
| **时延** | 3-5 秒（视频全量上传+分析+回传） | <200ms（本地分析+即时响应） |
| **带宽** | 极高（1000 路视频全量上传，约 10Gbps） | 低（仅上传事件告警和汇总数据，约 100Mbps） |
| **隐私** | 视频全部上传云端，存在风险 | 视频本地处理，保护隐私 |
| **可靠性** | 依赖网络，断网即停 | 边缘节点离线可运行 |
| **成本** | 云带宽成本极高 | 边缘硬件成本 + 较低的云成本 |
| ** AI 模型** | 云端大模型（能力强但延迟高） | 边缘轻量模型（能力有限但速度快） |

**结论**：智能交通的实时性和隐私性要求决定了必须采用边缘计算方案。纯云计算方案无法满足 <1 秒的事故响应要求。

</details>

**4.（绿色低碳案例）** 阅读以下材料，回答问题：

> 某大型互联网企业的数据中心 PUE 为 1.5，计划将 PUE 降至 1.2。请完成以下任务：
> (1) 分析当前 PUE 1.5 的主要能耗来源；
> (2) 设计一个分阶段的节能改造方案；
> (3) 估算改造后的节能效果和投资回报。

<details>
<summary>案例分析4解答</summary>

**(1) PUE 1.5 的能耗来源分析**

PUE = 1.5 意味着总用电量中，仅 67% 用于 IT 设备，33% 是非 IT 能耗。

| 能耗来源 | 占比 | 说明 |
| -------- | ---- | ---- |
| IT 设备（服务器、存储） | 67% | 核心计算设备 |
| 制冷系统（空调） | 20% | 最大的非 IT 能耗 |
| 电源转换（UPS、配电柜） | 4% | 多级转换损耗 |
| 网络设备 | 3% | 路由器、交换机 |
| 照明及其他 | 6% | 办公、照明等 |

**(2) 分阶段节能改造方案**

| 阶段 | 措施 | 预期 PUE | 投资 | 周期 |
| ---- | ---- | -------- | ---- | ---- |
| **第一阶段（3 个月）** | AI 制冷优化：部署 AI 能效管理系统，优化空调运行策略 | 1.5 → 1.35 | 500 万 | 3 个月 |
| **第二阶段（6 个月）** | 自然冷却 + 液冷试点：引入间接蒸发冷却，试点浸没式液冷机柜 | 1.35 → 1.25 | 2000 万 | 6 个月 |
| **第三阶段（12 个月）** | 全面液冷 + 绿色电力：全机房液冷改造，签订风电 PPA | 1.25 → 1.15 | 8000 万 | 12 个月 |

**(3) 节能效果与投资回报**

**节能效果估算**（假设数据中心年耗电 1 亿 kWh）：

| 阶段 | PUE | 年总能耗 | 年节电量 | 年节省电费（0.8 元/kWh） |
| ---- | --- | -------- | -------- | ------------------------ |
| 改造前 | 1.50 | 1.00 亿 kWh | — | — |
| 第一阶段后 | 1.35 | 0.90 亿 kWh | 1000 万 kWh | 800 万元 |
| 第二阶段后 | 1.25 | 0.83 亿 kWh | 1700 万 kWh | 1360 万元 |
| 第三阶段后 | 1.15 | 0.77 亿 kWh | 2300 万 kWh | 1840 万元 |

**投资回报分析**：

| 阶段 | 投资 | 累计投资 | 年节省 | 投资回收期 |
| ---- | ---- | -------- | ------ | ---------- |
| 第一阶段 | 500 万 | 500 万 | 800 万 | 0.6 年 |
| 第二阶段 | 2000 万 | 2500 万 | 1360 万 | 1.8 年 |
| 第三阶段 | 8000 万 | 10500 万 | 1840 万 | 5.7 年 |

> 第一阶段投资回报极快（0.6 年），AI 制冷优化是"必选项"。后续阶段需要较大投入，但从长期来看（5 年以上），液冷改造和绿色电力的综合收益显著。

</details>
