## 习题

### 题目1
【选择题】数据库系统的核心是（　）。
A．编译系统　B．数据库　C．操作系统　D．DBMS

### 参考答案
D。数据库系统（DBS）由数据库（DB）、DBMS、应用程序和数据库管理员组成，其中 DBMS 是核心，负责数据的统一管理与控制。

### 题目2
【选择题】在数据库设计中，用 E-R 图来描述信息结构但不涉及信息在计算机中的表示，它是数据库设计的（　）阶段。
A．需求分析　B．概念设计　C．逻辑设计　D．物理设计

### 参考答案
B。概念结构设计阶段用 E-R 模型描述信息结构，与具体 DBMS 和计算机表示无关。

### 题目3
【选择题】在数据库中下列说法不正确的是（　）。
A．数据库避免了一切数据冗余　B．数据库中的数据可以共享　C．数据库减少了数据冗余　D．数据库中的数据得到了统一管理

### 参考答案
A。数据库只能**减少**冗余而不能消除一切冗余（有时为提高效率还需保留少量受控冗余）。

### 题目4
【选择题】存储在计算机中有结构可共享的数据集合是（　）。
A．数据库系统　B．数据库　C．DBMS　D．数据结构

### 参考答案
B。数据库（DB）是长期存储在计算机内、有组织的、可共享的大量数据的集合。

### 题目5
【选择题】现有关系：学生（学号、姓名、系号、系名、系主任），为得到优化的关系模式应设计为（　）。
A．2 个表　B．3 个表　C．4 个表　D．5 个表

### 参考答案
A。存在传递依赖：学号→系号→系名、系主任。分解为：学生（学号，姓名，系号）和系（系号，系名，系主任），共 2 个表。

### 题目6
【选择题】逻辑数据独立性是指（　）。
A．模式变，应用程序不变　B．内模式变，应用程序不变　C．应用程序变，模式不变　D．子模式变，应用程序不变

### 参考答案
A。模式改变时通过外模式/模式映像使外模式和应用程序不变，即逻辑独立性；B 是物理独立性。

### 题目7
【选择题】数据库系统依靠（　）支持数据独立性。
A．具有封锁机制　B．定义完整性约束条件　C．模式分级、各级之间有映象机制　D．DDL 语言和 DML 语言互相独立

### 参考答案
C。三级模式加两级映像（外模式/模式映像、模式/内模式映像）保证了数据独立性。

### 题目8

A．UWA 完成　B．DBMS 完成　C．OS 完成　D．键盘完成

### 参考答案

### 题目9
【选择题】事务有多个性质，其中不包括（　）。
A．一致性　B．唯一性　C．原子性　D．隔离性

### 参考答案

### 题目10
【选择题】数据库的网状模型应满足的条件是（　）。
A．允许一个以上的结点无双亲，允许一个结点有多个双亲　B．必须有两个以上的结点　C．有且仅有一个结点无双亲，其余结点都只有一个双亲　D．每个结点有且仅有一个双亲

### 参考答案
A。C 是层次模型的条件；网状模型允许结点有多个双亲，且允许一个以上结点无双亲。

### 题目11
【选择题】数据库系统与文件系统的主要区别是（　）。
A．数据系统复杂，而文件系统简单　B．文件系统不能解决数据冗余和数据独立性问题，而数据库系统可以解决　C．数据库系统实现了数据的整体结构化　D．文件系统管理的数据量较小，而数据库系统可管理庞大的数据量

### 参考答案
B。文件系统冗余大、数据独立性差；数据库系统解决了这两个问题（其根本原因是实现了数据的整体结构化）。

### 题目30

### 题目31
【选择题】在并行执行多个事务时（　）。
A．正确的运行结果应该是惟一确定的　B．凡串行调度执行的结果，都认为是正确的　C．交叉调度可能产生不正确的结果，应避免使用　D．如果各事务都有遵守两段锁协议，其运行结果必惟一确定

### 参考答案
B。串行调度不破坏一致性，其结果都认为是正确的；并发调度的正确性标准是可串行化，并行执行可提高吞吐量，不能一概避免。

### 题目63
【简答题】简述关系的实体完整性规则、参照完整性规则。

### 参考答案
- **实体完整性规则**：若属性 A 是基本关系 R 的主属性，则 A 不能取空值，即主码的任何分量都不能为空。
- **参照完整性规则**：若属性（组）F 是 R 的外码，与被参照关系 S 的主码 Ks 相对应，则 R 中每个元组在 F 上的值必须：或者取空值（F 的每个属性值均为空），或者等于 S 中某个元组的主码值。

### 题目64
【简答题】简述并发事务可串行化调度的含义。

### 参考答案
多个事务的并发执行是正确的，当且仅当其结果与按某一次序串行执行这些事务的结果相同，这种并发调度称为可串行化调度。它是并发调度正确性的唯一标准，通常用两段锁协议等手段保证。

### 题目65
【简答题】简述 SQL 中为保证数据的安全性而提供的两个功能及其作用。

### 参考答案
1. **视图机制**：通过视图把无权访问的数据隐藏起来，只暴露有权操作的数据，实现逻辑隔离。
2. **授权机制**：用 `GRANT`/`REVOKE` 授予或收回用户对数据对象的操作权限，可用 `WITH GRANT OPTION` 转授权，实现灵活的存取控制。

### 题目66
【简答题】简述并发操作带来的三类数据不一致性以及产生的主要原因，如何解决？

### 参考答案
三类不一致：
1. **丢失更新**：两事务同时修改同一数据，一事务的修改被另一事务覆盖。
2. **读"脏"数据**：一事务读到了另一事务修改后又被撤销的数据。
3. **不可重复读**：一事务两次读同一数据，因另一事务在中间修改或增删，两次结果不同。

原因：并发操作破坏了事务的隔离性，多个事务交错存取同一数据而缺乏控制。
解决：采用并发控制机制，最常用封锁技术（两段锁协议、三级封锁协议），使并发调度可串行化，并结合死锁检测与解除。

### 题目67
【简答题】简述基于封锁的并发控制中共享锁的含义及作用。

### 参考答案
含义：事务 T 对数据对象 Q 加 S 锁后，可读不可写；在 T 释放前，其他事务只能再加 S 锁，不能加 X 锁。
作用：允许多个事务并发同时读同一数据，且保证读期间其他事务不能修改该数据，防止丢失更新和读脏数据。

### 题目68
【简答题】简述数据库完整性规则的三个组成部分。

### 参考答案
1. **触发条件（何时检查）**：如 INSERT、UPDATE、DELETE 操作时触发。
2. **约束条件（检查什么）**：完整性约束本身，如主码非空、外码必须引用存在的元组等。
3. **违约响应（违反时如何处理）**：拒绝执行（NO ACTION）、级联（CASCADE）、置空（SET NULL）等。

### 题目70
【简答题】说明如果关系数据库的设计不好，可能带来哪几个问题？

### 参考答案
设计不好（数据冗余大）会带来四类问题：
1. **数据冗余**：同一信息重复存储，浪费空间；
2. **更新异常**：修改一处须同步修改多处，遗漏则数据不一致；
3. **插入异常**：缺少部分信息时无法插入；
4. **删除异常**：删除某信息时连带丢失其他信息。
解决途径是对关系模式进行规范化。

3. **逻辑结构设计**：E-R 图转换为具体数据模型并规范化优化；
4. **物理结构设计**：设计存储结构和存取方法（索引、聚簇等）；

### 题目72
【简答题】简述数据库系统可能发生的故障及其恢复方法。

### 参考答案
1. **事务故障**：事务未运行到终点而终止。恢复：利用日志对该事务 **UNDO**。
2. **系统故障**：硬件故障、OS/DBMS 崩溃、断电等。恢复：重启后用日志对提交事务 **REDO**、未提交事务 **UNDO**。
3. **介质故障**：磁盘损坏、数据库丢失。恢复：装入最近的后备副本，再用日志对其后提交的事务 **REDO**。
恢复技术的基础是**数据转储（后备副本）和日志文件**。

### 题目73
【简答题】简述关系规范化的目的及步骤。

### 参考答案
**目的**：通过分解关系模式消除数据冗余和操作异常（插入、删除、更新异常），使各关系模式达到较高范式。
**步骤**：
1. 属性不可再分 → 1NF；
2. 消去非主属性对候选码的**部分函数依赖** → 2NF；
3. 消去非主属性对候选码的**传递函数依赖** → 3NF；
4. 消去主属性对候选码的部分和传递依赖 → BCNF。
每步投影分解要求**无损连接性**并尽量**保持函数依赖**。

### 题目74
【简答题】简述 DBMS 的功能。

### 参考答案
1. **数据定义**（DDL）：定义三级模式、完整性、安全性约束；
2. **数据组织、存储和管理**：数据的组织、存取（索引、聚簇）和存储方式；
3. **数据操纵**（DML）：查询、插入、删除、修改；
4. **数据库运行管理**：并发控制、安全性检查、完整性验证、事务管理与恢复（保证 ACID）；
5. **数据库的建立和维护**：初始装入、转储、恢复、重组织、性能监视与分析。

### 题目75
【简答题】封锁会带来哪些问题？如何解决？

### 参考答案
1. **活锁**：某事务总得不到锁而长期等待。解决：先来先服务，按请求先后排队。
2. **死锁**：多事务互相等待对方持有的锁，形成循环等待。解决：预防（一次封锁法、顺序封锁法）或诊断解除（超时法、等待图检测，撤销代价最小的事务并恢复）。

### 题目76
【简答题】简述码、外码的概念。

### 参考答案
- **码（候选码）**：关系中能唯一标识一个元组的最小属性组；可选定一个为主码。
- **外码**：设 F 是关系 R 的属性（组）但不是 R 的码，若 F 与另一关系 S 的主码 Ks 相对应，则称 F 为 R 的外码。外码取值须满足参照完整性：或为空，或等于被参照关系中某元组的主码值。

### 题目77
【简答题】简述模式、内模式、外模式的概念。

### 参考答案
- **模式（概念模式）**：数据库中全体数据的逻辑结构和特征的描述，是所有用户的公共数据视图，一个数据库只有一个模式。
- **外模式（子模式/用户模式）**：用户可见的局部数据的逻辑结构和特征描述，是模式的子集，一个模式可对应多个外模式。
- **内模式（存储模式）**：数据内部的物理存储结构和存取方式的描述（文件组织、索引、存储记录结构等），一个数据库只有一个内模式。

### 题目78
【简答题】对于非规范化的关系模式，怎样转变为 1NF？对于 1NF 怎样转变为 2NF？对于 2NF 怎样转变为 3NF？

### 参考答案
- **非规范化 → 1NF**：每个属性为不可再分的原子项，拆开重复组、多值属性。
- **1NF → 2NF**：消去非主属性对候选码的**部分函数依赖**——把只依赖候选码一部分的属性连同那部分候选码分解出去。
- **2NF → 3NF**：消去非主属性对候选码的**传递函数依赖**——把传递链中间的决定属性分解出去单独成关系。
各步分解要求无损连接性，并尽量保持函数依赖。

### 题目79
【简答题】在数据库的保护中有数据的安全性和完整性，它们有何区别？

### 参考答案
- **安全性**：防止非法用户的非法操作，防止数据被未授权访问、泄漏、篡改和破坏（"不让不该访问的人访问"）。措施：身份鉴别、存取控制（授权）、视图、审计、加密。
- **完整性**：防止合法用户插入语义不正确的数据，保证数据的正确性和相容性（"保证存进去的数据是对的"）。措施：实体完整性、参照完整性、用户定义完整性约束。
简言之，安全性防"非法"，完整性防"出错"。

### 题目80
【简答题】事务中的提交和回滚是什么含义？

### 参考答案
- **提交（COMMIT）**：事务正常结束，更新从日志写入数据库并永久生效（持久性）。
- **回滚（ROLLBACK）**：事务异常终止，撤销已做的全部更新，数据库恢复到事务开始前状态（原子性）。

### 题目81
【简答题】叙述等值连接与自然连接的区别和联系。

### 参考答案
联系：自然连接是一种特殊的等值连接，都按属性值相等从笛卡尔积中选取元组。
区别：
1. 等值连接的比较列不必同名，只要可比较且相等；自然连接要求比较**相同的属性组**（同名同域）。
2. 等值连接结果中相等列重复出现（R.B 与 S.B 都保留）；自然连接结果**去掉重复列**。
3. 记法：等值连接 R ⋈A=B S；自然连接 R ⋈ S。

### 题目82
【简答题】什么是数据库的数据独立性？

### 参考答案
应用程序与数据互不依赖，数据的逻辑结构或存储结构改变时应用程序不必修改，由两级映像实现：
- **物理独立性**：内模式改变时，修改模式/内模式映像使模式和应用程序不变。
- **逻辑独立性**：模式改变时，修改外模式/模式映像使外模式和应用程序不变。
逻辑独立性比物理独立性更难实现。

4. 实现复杂的安全控制（如限制特定时间的操作）。

### 题目113

### 题目115
【规范化·分解】设有关系模式 R(A,B,C,D,E)，F = { AB→C，D→E，B→D }，试将其分解为具有无损连接的 BCNF，并验证分解的结果具有无损连接性。

### 参考答案
**第一步，求候选码**：B→D，D→E，故 B→D→E；又 AB→C，所以 (AB)⁺ = ABCDE，**候选码为 AB**（A⁺=A，B⁺=BDE，均不含全部属性）。

**第二步，找违背 BCNF 的 FD**（BCNF 要求决定因素是超码）：
- B→D：B⁺ = BDE ≠ ABCDE，B 不是超码，违背 BCNF；
- D→E：D⁺ = DE，D 不是超码，违背 BCNF。

**第三步，分解**：
- 用 B→D 分解 R：得 R1(B, D)（主键 B）与 R2(A, B, C, E)；
- R2(A,B,C,E)：投影后只有 AB→C，决定因素 AB 是超码，已属 BCNF。

最终分解：ρ = { R1(B,D), R2(A,B,C,E) }。
（若进一步按 D→E 分解：{R1(B,D), R3(D,E), R4(A,B,C)}，同样满足 BCNF 与无损连接。）

**第四步，验证无损连接性**（对第一种分解）：
R1 ∩ R2 = B。判定定理：若 (R1 ∩ R2) → R1 或 (R1 ∩ R2) → R2，则分解无损。因 F 中有 B→D，即 B → R1 成立，故 ρ 具有**无损连接性**。也可用 chase 表格法验证：用 B→D 可将 R2 行的 D 列改为与 R1 一致，最终出现一行全 a 符号，得证。
