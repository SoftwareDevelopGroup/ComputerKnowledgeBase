# 2.3 表单与多媒体标签

表单是用户向服务器提交数据的入口，多媒体标签让页面承载音视频内容。本节解决的问题是：如何使用 form 及各类 input 收集用户输入，如何用 select/textarea 提供更多输入方式，如何进行表单验证，以及如何嵌入音视频与iframe。

## 表单 form

`<form>` 是表单容器，定义数据提交的目标地址、方式与编码类型。

```html
<form action="/api/login" method="POST" enctype="application/x-www-form-urlencoded">
    <label>用户名：<input type="text" name="username"></label><br>
    <label>密码：<input type="password" name="password"></label><br>
    <input type="submit" value="登录">
    <input type="reset" value="重置">
</form>
```

### form 属性

| 属性 | 作用 | 常用值 |
| --- | --- | --- |
| `action` | 提交目标 URL | 服务器接口地址 |
| `method` | 提交方法 | `GET`（默认）、`POST` |
| `enctype` | 编码类型 | `application/x-www-form-urlencoded`（默认）、`multipart/form-data`（文件上传）、`text/plain` |
| `target` | 提交后响应打开方式 | `_self`、`_blank` |

> [!warning] 文件上传必记
> 上传文件时必须设置 `method="POST"` 且 `enctype="multipart/form-data"`，否则文件无法正确传输。

## input 类型

`<input>` 是最常用的表单控件，通过 `type` 属性切换不同输入类型。

```html
<!-- 文本 -->
<input type="text" name="username" placeholder="请输入用户名">

<!-- 密码 -->
<input type="password" name="password" placeholder="密码">

<!-- 单选 -->
<label><input type="radio" name="gender" value="male" checked> 男</label>
<label><input type="radio" name="gender" value="female"> 女</label>

<!-- 复选 -->
<label><input type="checkbox" name="hobby" value="reading"> 阅读</label>
<label><input type="checkbox" name="hobby" value="coding"> 编程</label>

<!-- 提交与重置 -->
<input type="submit" value="提交">
<input type="reset" value="重置">

<!-- 文件 -->
<input type="file" name="avatar" accept="image/*">

<!-- HTML5 新增类型 -->
<input type="email" name="email">
<input type="number" name="age" min="0" max="150">
<input type="date" name="birthday">
<input type="color" name="theme">
<input type="range" name="volume" min="0" max="100">
```

### input 类型一览

| type 值 | 作用 | 说明 |
| --- | --- | --- |
| `text` | 单行文本 | 默认类型 |
| `password` | 密码 | 输入内容显示为圆点 |
| `radio` | 单选按钮 | 同 name 组内互斥 |
| `checkbox` | 复选框 | 同 name 可多选 |
| `submit` | 提交按钮 | 触发表单提交 |
| `reset` | 重置按钮 | 清空表单为初始值 |
| `button` | 普通按钮 | 需配 JS 处理 |
| `file` | 文件选择 | 配合 multipart 上传 |
| `email` | 邮箱 | HTML5，自动验证格式 |
| `number` | 数字 | 支持 min/max/step |
| `date` | 日期选择 | HTML5 日期选择器 |
| `color` | 颜色选择 | HTML5 取色器 |
| `range` | 滑块 | HTML5 范围滑块 |
| `tel` | 电话 | 移动端弹出数字键盘 |
| `url` | 网址 | HTML5 自动验证 URL 格式 |
| `search` | 搜索框 | 部分浏览器带清除按钮 |
| `hidden` | 隐藏域 | 不显示，用于携带数据 |

## label、select、textarea

### label 标签

`<label>` 为表单控件提供说明文字，点击 label 可激活关联控件，提升可用性。

```html
<!-- 方式一：用 for 关联控件 id -->
<label for="username">用户名：</label>
<input type="text" id="username" name="username">

<!-- 方式二：label 包裹控件 -->
<label>用户名：<input type="text" name="username"></label>
```

### select 下拉选择

```html
<select name="city">
    <option value="">请选择城市</option>
    <option value="beijing">北京</option>
    <option value="shanghai" selected>上海</option>
    <option value="guangzhou">广州</option>
</select>

<!-- 分组下拉 -->
<select name="province">
    <optgroup label="华东">
        <option value="shanghai">上海</option>
        <option value="hangzhou">杭州</option>
    </optgroup>
    <optgroup label="华北">
        <option value="beijing">北京</option>
    </optgroup>
</select>
```

| 标签/属性 | 作用 |
| --- | --- |
| `<select>` | 下拉选择容器 |
| `<option>` | 选项，`value` 为提交值 |
| `selected` | 默认选中项 |
| `<optgroup>` | 选项分组，`label` 为组名 |
| `multiple` | 允许多选（按 Ctrl/Cmd 点击） |

### textarea 文本域

```html
<textarea name="comment" rows="5" cols="40" placeholder="请输入评论..."></textarea>
```

| 属性 | 作用 |
| --- | --- |
| `rows` | 显示行数（高度） |
| `cols` | 显示列数（宽度） |
| `placeholder` | 占位提示文字 |
| `maxlength` | 最大字符数 |
| `readonly` | 只读 |

## 表单验证属性

HTML5 提供原生表单验证，无需 JavaScript 即可进行基本校验。

```html
<form>
    <!-- 必填 -->
    <input type="text" name="username" required>

    <!-- 正则验证 -->
    <input type="text" name="phone" pattern="^1[3-9]\d{9}$" placeholder="手机号">

    <!-- 数值范围 -->
    <input type="number" name="age" min="18" max="100">

    <!-- 最小/最大长度 -->
    <input type="text" name="username" minlength="3" maxlength="20">

    <input type="submit" value="提交">
</form>
```

### 验证属性

| 属性 | 作用 | 示例 |
| --- | --- | --- |
| `required` | 必填 | `required` |
| `pattern` | 正则匹配 | `pattern="^1[3-9]\d{9}$"` |
| `min` / `max` | 数值范围 | `min="0" max="100"` |
| `minlength` / `maxlength` | 文本长度范围 | `minlength="6" maxlength="20"` |
| `type="email"` | 邮箱格式验证 | 自动校验 |

> [!tip] 前端验证不是安全手段
> HTML5 原生验证仅提升用户体验，不能替代服务器端验证。用户可绕过前端直接发送请求，**服务器必须再次校验所有数据**。

## 完整可运行表单示例

以下是一个完整的注册表单，包含多种 input 类型与验证，保存为 `.html` 文件即可在浏览器中打开测试：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>注册表单示例</title>
    <style>
        body { font-family: "Microsoft YaHei", sans-serif; padding: 20px; }
        form { max-width: 450px; margin: 0 auto; }
        .form-item { margin-bottom: 15px; }
        label { display: inline-block; width: 80px; }
        input, select, textarea { padding: 6px; border: 1px solid #ccc; border-radius: 4px; }
        input[type="submit"] { background: #4CAF50; color: white; border: none; padding: 8px 20px; cursor: pointer; }
        input[type="submit"]:hover { background: #45a049; }
    </style>
</head>
<body>
    <h2>用户注册</h2>
    <form action="/api/register" method="POST">
        <div class="form-item">
            <label for="username">用户名：</label>
            <input type="text" id="username" name="username"
                   required minlength="3" maxlength="20" placeholder="3-20个字符">
        </div>

        <div class="form-item">
            <label for="password">密码：</label>
            <input type="password" id="password" name="password"
                   required minlength="6" placeholder="至少6位">
        </div>

        <div class="form-item">
            <label for="email">邮箱：</label>
            <input type="email" id="email" name="email" required placeholder="@example.com">
        </div>

        <div class="form-item">
            <label>性别：</label>
            <label><input type="radio" name="gender" value="male" checked> 男</label>
            <label><input type="radio" name="gender" value="female"> 女</label>
        </div>

        <div class="form-item">
            <label>兴趣：</label>
            <label><input type="checkbox" name="hobby" value="reading"> 阅读</label>
            <label><input type="checkbox" name="hobby" value="coding"> 编程</label>
            <label><input type="checkbox" name="hobby" value="music"> 音乐</label>
        </div>

        <div class="form-item">
            <label for="city">城市：</label>
            <select id="city" name="city">
                <option value="">请选择</option>
                <option value="beijing">北京</option>
                <option value="shanghai">上海</option>
                <option value="guangzhou">广州</option>
            </select>
        </div>

        <div class="form-item">
            <label for="age">年龄：</label>
            <input type="number" id="age" name="age" min="18" max="100" value="18">
        </div>

        <div class="form-item">
            <label for="phone">手机：</label>
            <input type="text" id="phone" name="phone" pattern="^1[3-9]\d{9}$"
                   placeholder="11位手机号">
        </div>

        <div class="form-item">
            <label for="bio">简介：</label>
            <textarea id="bio" name="bio" rows="3" cols="30" placeholder="自我介绍"></textarea>
        </div>

        <div class="form-item">
            <input type="submit" value="注册">
            <input type="reset" value="重置">
        </div>
    </form>
</body>
</html>
```

## 多媒体标签

### 音频 audio

```html
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    您的浏览器不支持 audio 标签。
</audio>
```

### 视频 video

```html
<video src="movie.mp4" controls width="640" height="360" poster="cover.jpg">
    您的浏览器不支持 video 标签。
</video>
```

### 音视频常用属性

| 属性 | 作用 |
| --- | --- |
| `src` | 媒体文件路径 |
| `controls` | 显示播放控件 |
| `autoplay` | 自动播放（多数浏览器需配合 muted） |
| `loop` | 循环播放 |
| `muted` | 静音 |
| `poster` | 视频封面图（仅 video） |
| `width` / `height` | 视频尺寸（仅 video） |
| `preload` | 预加载策略：`auto`、`metadata`、`none` |

> [!tip] 多 source 兼容
> 不同浏览器支持的音视频格式不同，建议用多个 `<source>` 提供备选格式。MP3/MP4 兼容性最好，OGG/WebM 作为补充。`<audio>` 或 `<video>` 标签内的文字仅在浏览器不支持时显示。

## iframe 内嵌框架

`<iframe>` 用于在页面中嵌入另一个网页。

```html
<iframe src="https://www.example.com" width="800" height="400"
        frameborder="0" title="嵌入页面"></iframe>
```

| 属性 | 作用 |
| --- | --- |
| `src` | 嵌入页面 URL |
| `width` / `height` | 宽高 |
| `frameborder` | 边框，HTML5 用 CSS 的 border 替代 |
| `title` | 无障碍说明 |
| `sandbox` | 沙箱限制，增强安全 |
| `allowfullscreen` | 允许全屏 |

> [!warning] iframe 安全注意
> 嵌入第三方页面存在安全风险（如点击劫持）。建议使用 `sandbox` 属性限制其权限，或通过 `X-Frame-Options` 响应头控制自身页面是否允许被嵌入。

## 小结

表单是 Web 应用收集用户数据的核心方式，form 定义提交方式，input 的 type 属性覆盖文本、密码、单选、复选、文件、日期、颜色等多种输入场景，select 与 textarea 补充了下拉与多行文本输入，HTML5 原生验证属性提供基本校验。audio 与 video 标签让页面原生承载多媒体，iframe 实现页面嵌套。掌握表单与多媒体标签是构建交互页面的关键。
