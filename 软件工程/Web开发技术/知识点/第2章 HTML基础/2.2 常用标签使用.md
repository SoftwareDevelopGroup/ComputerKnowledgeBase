# 2.2 常用标签使用

HTML 提供了丰富的标签来组织页面内容。本节解决的问题是：如何使用标题、段落、文本格式化、列表、超链接、图片、表格等常用标签，以及 div 与 span 这两个通用容器标签的区别与使用场景。

## 标题标签 h1-h6

HTML 提供六级标题标签，`<h1>` 级别最高，`<h6>` 最低，字体由大到小：

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

> [!warning] 标题使用注意
> - 一个页面建议只有一个 `<h1>`，作为页面主标题，利于 SEO。
> - 标题应按层级递进使用，不要跳级（如 h1 后直接 h3）。
> - 标题标签用于语义结构，不要仅为了字体大小而使用，样式应由 CSS 控制。

## 段落与文本结构标签

```html
<p>这是一个段落。段落之间会自动产生间距。</p>
<p>这是另一个段落。</p>

<p>第一行<br>第二行（换行）</p>

<hr>
<p>上面是一条水平分割线</p>
```

| 标签 | 作用 | 说明 |
| --- | --- | --- |
| `<p>` | 段落 | 块级元素，段落间有默认间距 |
| `<br>` | 换行 | 单标签，强制换行 |
| `<hr>` | 水平线 | 单标签，生成分割线 |
| `<pre>` | 预格式化文本 | 保留空格与换行，常用于代码展示 |

## 文本格式化标签

```html
<strong>加粗（强调，语义重要）</strong>
<b>加粗（无语义强调）</b>
<em>斜体（强调）</em>
<i>斜体（无语义强调）</i>
<mark>标记高亮</mark>
<del>删除线</del>
<ins>下划线（插入内容）</ins>
H<sub>2</sub>O  <!-- 下标 -->
X<sup>2</sup>  <!-- 上标 -->
```

### 语义化格式化标签对比

| 标签 | 效果 | 语义 | 对应无语义标签 |
| --- | --- | --- | --- |
| `<strong>` | 加粗 | 表示重要内容 | `<b>`（仅加粗） |
| `<em>` | 斜体 | 表示强调 | `<i>`（仅斜体） |
| `<mark>` | 高亮 | 表示标记引用 | 无 |
| `<del>` | 删除线 | 表示已删除内容 | `<s>`（仅删除线） |
| `<ins>` | 下划线 | 表示新插入内容 | `<u>`（仅下划线） |
| `<sub>` | 下标 | 下标文本 | — |
| `<sup>` | 上标 | 上标文本 | — |

> [!tip] 语义优先
> 优先使用带语义的 `<strong>`、`<em>`、`<del>`、`<ins>`，搜索引擎与屏幕阅读器能识别其强调程度。`<b>`、`<i>` 等无语义标签在 HTML5 中仍保留，但建议仅在无需表达语义时使用。

## 列表标签

### 有序列表 ol

```html
<ol>
    <li>第一步：打开编辑器</li>
    <li>第二步：编写代码</li>
    <li>第三步：运行测试</li>
</ol>
```

`<ol>` 的常用属性：

| 属性 | 作用 | 示例 |
| --- | --- | --- |
| `type` | 序号类型 | `1`（数字，默认）、`A`（大写字母）、`a`（小写字母）、`I`（罗马数字） |
| `start` | 起始序号 | `start="3"` 从 3 开始 |
| `reversed` | 倒序 | `reversed` 逆序排列 |

### 无序列表 ul

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

### 定义列表 dl

```html
<dl>
    <dt>HTML</dt>
    <dd>超文本标记语言，用于构建网页结构</dd>
    <dt>CSS</dt>
    <dd>层叠样式表，用于控制页面外观</dd>
</dl>
```

| 标签 | 作用 |
| --- | --- |
| `<dl>` | 定义列表容器 |
| `<dt>` | 定义术语（term） |
| `<dd>` | 定义描述（description） |

## 超链接 a

超链接 `<a>`（anchor）用于页面间跳转或页面内锚点定位。

```html
<!-- 外部链接 -->
<a href="https://www.example.com">访问示例网站</a>

<!-- 新窗口打开 -->
<a href="https://www.example.com" target="_blank">新标签页打开</a>

<!-- 页面内锚点跳转 -->
<a href="#section-2">跳转到第二节</a>
<h2 id="section-2">第二节标题</h2>

<!-- 邮箱链接 -->
<a href="mailto:admin@example.com">发送邮件</a>

<!-- 电话链接 -->
<a href="tel:13800138000">拨打电话</a>
```

### a 标签常用属性

| 属性 | 作用 | 常用值 |
| --- | --- | --- |
| `href` | 链接目标 URL | URL、`#锚点`、`mailto:`、`tel:` |
| `target` | 打开方式 | `_self`（当前窗口，默认）、`_blank`（新窗口）、`_parent`、`_top` |
| `title` | 悬停提示文字 | 文本 |

> [!tip] 锚点链接
> 锚点链接用于页面内定位跳转：给目标元素设置 `id`，链接 `href` 设为 `#id`。点击链接后页面滚动到该元素位置。这在长文档目录中常用。

## 图片 img

```html
<img src="logo.png" alt="网站Logo" title="鼠标悬停显示" width="200" height="100">
```

### img 标签属性

| 属性 | 作用 | 说明 |
| --- | --- | --- |
| `src` | 图片路径 | 必填，可为相对/绝对路径或 data URI |
| `alt` | 替代文本 | 必填，图片加载失败或屏幕阅读器时显示 |
| `title` | 悬停提示 | 鼠标悬停时显示的文字 |
| `width` | 宽度 | 像素值，建议用 CSS 控制尺寸 |
| `height` | 高度 | 像素值，建议用 CSS 控制尺寸 |

> [!warning] alt 属性必填
> `alt` 属性提供图片的文本描述，在图片加载失败时显示，并对视障用户通过屏幕阅读器理解图片内容至关重要。省略 alt 会影响无障碍与 SEO。

## 表格

HTML 表格由行与单元格组成，用于展示结构化数据。

```html
<table border="1">
    <thead>
        <tr>
            <th>姓名</th>
            <th>年龄</th>
            <th>城市</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>张三</td>
            <td>20</td>
            <td>北京</td>
        </tr>
        <tr>
            <td>李四</td>
            <td>22</td>
            <td>上海</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="3">合计：2 人</td>
        </tr>
    </tfoot>
</table>
```

### 表格结构标签

| 标签 | 作用 |
| --- | --- |
| `<table>` | 表格容器 |
| `<tr>` | 表格行（table row） |
| `<td>` | 标准单元格（table data） |
| `<th>` | 表头单元格（table header），默认加粗居中 |
| `<thead>` | 表头区域，语义化分组 |
| `<tbody>` | 表体区域，语义化分组 |
| `<tfoot>` | 表尾区域，常用于汇总 |

### 单元格合并

| 属性 | 作用 | 示例 |
| --- | --- | --- |
| `colspan` | 跨列合并（水平） | `<td colspan="2">` 占 2 列 |
| `rowspan` | 跨行合并（垂直） | `<td rowspan="3">` 占 3 行 |

> [!example] 合并单元格示例
> ```html
> <table border="1">
>     <tr>
>         <th>姓名</th>
>         <th colspan="2">成绩</th>
>     </tr>
>     <tr>
>         <td rowspan="2">张三</td>
>         <td>语文</td>
>         <td>90</td>
>     </tr>
>     <tr>
>         <td>数学</td>
>         <td>95</td>
>     </tr>
> </table>
> ```
> 第一行表头"成绩"跨两列，第二行"张三"跨两行（含第三行）。

## div 与 span

`<div>` 与 `<span>` 是两个没有语义的通用容器标签，用于布局与样式分组。

| 标签 | 类型 | 特点 | 典型用途 |
| --- | --- | --- | --- |
| `<div>` | 块级元素 | 独占一行，可设宽高 | 页面布局分区、容器分组 |
| `<span>` | 行内元素 | 不独占一行，无法设宽高 | 文本局部样式、行内分组 |

```html
<div class="card">
    <h3>卡片标题</h3>
    <p>这是一段文字，其中<span style="color:red">红色部分</span>用span包裹。</p>
</div>
```

> [!note] 块级与行内
> - **块级元素**（block）：独占一行，可设宽高，如 div、p、h1、ul、table。
> - **行内元素**（inline）：不独占一行，无法设宽高，如 span、a、strong、em。
> - **行内块元素**（inline-block）：不独占一行但可设宽高，如 img、input。

## 小结

HTML 常用标签覆盖了文本、列表、链接、图片、表格与通用容器的组织需求。标题 h1-h6 表达层级，段落 p 与格式化标签组织文本，列表 ol/ul/dl 组织条目，a 标签实现跳转，img 嵌入图片，table 展示结构化数据，div 与 span 作为通用容器辅助布局。掌握这些标签是编写网页的基础。
