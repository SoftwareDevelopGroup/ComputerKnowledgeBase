# 5.2 GET-POST请求、表单提交

HTTP 请求方法是客户端表达意图的语义标签，GET 与 POST 是 Web 开发中最常用的两种。本节解决的问题是：GET 与 POST 各有什么特点与差异，HTML 表单如何把用户数据提交到后端，表单数据如何编码，以及文件上传的基本原理。

## GET 请求

> [!definition] GET 请求
> GET 是 HTTP 中用于"获取资源"的请求方法。参数通过 URL 查询串（query string）传递，请求体通常为空，语义为只读查询，不应产生副作用。

### GET 请求特点

1. **参数位置**：拼接在 URL 之后，以 `?` 开始，多个参数用 `&` 分隔。
   - 示例：`/search?keyword=web&page=2`
2. **可缓存**：浏览器与代理可缓存 GET 响应，相同 URL 可能直接命中缓存。
3. **长度限制**：受浏览器与服务器对 URL 长度的约定限制（约 2KB，各浏览器不同）。
4. **不安全（语义层面）**：参数暴露在 URL、历史记录、服务器日志中，不适合传输敏感信息。
5. **幂等性**：多次执行相同 GET 请求应返回相同结果（幂等），不应修改服务端状态。

```http
GET /api/user?id=10086&fields=basic HTTP/1.1
Host: example.com
Accept: application/json
```

## POST 请求

> [!definition] POST 请求
> POST 是 HTTP 中用于"提交数据"的请求方法。参数放在请求体中，语义为创建或修改资源，会产生副作用，非幂等。

### POST 请求特点

1. **参数位置**：放在请求体中，不显示在 URL。
2. **不可缓存**：默认不被浏览器与代理缓存。
3. **无长度限制**：理论上无上限，实际受服务器配置（如 `post_max_size`、`client_max_body_size`）约束。
4. **相对安全**：参数不在 URL 暴露，但 HTTP 明文传输仍可被抓包，敏感数据必须配合 HTTPS。
5. **非幂等**：多次提交可能产生多条记录（如重复下单）。

```http
POST /api/user HTTP/1.1
Host: example.com
Content-Type: application/x-www-form-urlencoded
Content-Length: 23

name=alice&age=20&city=北京
```

## GET vs POST 对比

| 维度 | GET | POST |
| --- | --- | --- |
| 参数位置 | URL 查询串 | 请求体 |
| 可见性 | 暴露在 URL、历史、日志 | 在请求体，相对隐蔽 |
| 长度限制 | 有（约 2KB） | 理论无限制 |
| 缓存 | 可缓存 | 默认不缓存 |
| 幂等性 | 幂等 | 非幂等 |
| 语义 | 查询/获取 | 创建/提交 |
| 编码类型 | 仅 `application/x-www-form-urlencoded` | 多种（表单、JSON、multipart） |
| 书签 | 可收藏为书签 | 不可收藏 |
| 历史记录 | 保留 URL 与参数 | 不保留参数 |

> [!warning] "POST 比 GET 安全"的常见误解
> POST 的"安全"仅指参数不在 URL 暴露，**并非加密**。HTTP 明文下两者均可被中间人抓包。真正的传输安全必须依赖 HTTPS（TLS 加密），与请求方法无关。

## 表单提交

HTML 表单是前端向后端提交数据的最基本方式。一个表单由 `<form>`、输入控件与提交按钮组成。

### 表单三要素

| 属性/元素 | 作用 | 说明 |
| --- | --- | --- |
| `<form action>` | 提交目标 URL | 后端处理接口地址 |
| `<form method>` | 请求方法 | `get` 或 `post`（默认 get） |
| 提交按钮 | 触发提交 | `<button type="submit">` 或 `<input type="submit">` |

```html
<!-- GET 表单：参数拼接在 URL -->
<form action="/search" method="get">
    <input type="text" name="keyword" placeholder="搜索关键词">
    <button type="submit">搜索</button>
</form>
<!-- 提交后 URL：/search?keyword=web -->

<!-- POST 表单：参数在请求体 -->
<form action="/login" method="post">
    <input type="text" name="username" placeholder="用户名">
    <input type="password" name="password" placeholder="密码">
    <button type="submit">登录</button>
</form>
```

> [!tip] 表单控件的 name 属性
> 表单字段的 `name` 属性是后端接收参数的"键"，缺失 `name` 的控件不会提交。`value` 才是"值"。复选框与多选框需用相同 `name` 配合多个值。

## 表单数据编码

`<form>` 的 `enctype` 属性决定请求体的编码方式，仅在 `method="post"` 时生效：

| enctype | 说明 | 适用场景 |
| --- | --- | --- |
| `application/x-www-form-urlencoded` | 默认值，`key=value&key=value`，特殊字符 URL 编码 | 普通文本字段 |
| `multipart/form-data` | 分段二进制编码，每段含分隔符与头信息 | 文件上传 |
| `text/plain` | 纯文本，几乎不用 | 调试 |

### application/x-www-form-urlencoded

最常见编码，参数以 `key=value` 形式用 `&` 连接，空格转 `+`，特殊字符按百分号编码：

```http
POST /login HTTP/1.1
Content-Type: application/x-www-form-urlencoded

username=alice&password=p%40ssw0rd&city=%E5%8C%97%E4%BA%AC
```

### multipart/form-data

文件上传必须使用此编码，因为二进制数据无法用 URL 编码无损表示。请求体被分隔符分为多段，每段携带字段名、文件名、MIME 类型与内容。

```http
POST /upload HTTP/1.1
Content-Type: multipart/form-data; boundary=----WebKitFormBoundaryABC

------WebKitFormBoundaryABC
Content-Disposition: form-data; name="title"

头像
------WebKitFormBoundaryABC
Content-Disposition: form-data; name="avatar"; filename="me.png"
Content-Type: image/png

<二进制数据>
------WebKitFormBoundaryABC--
```

## 文件上传基础

文件上传需满足三个条件：

1. 表单 `method="post"`（GET 无法携带大体积二进制）。
2. 表单 `enctype="multipart/form-data"`。
3. 含 `<input type="file">` 控件。

```html
<form action="/upload" method="post" enctype="multipart/form-data">
    <label>选择文件：<input type="file" name="avatar" accept="image/*"></label>
    <button type="submit">上传</button>
</form>
```

> [!note] accept 属性
> `accept` 用于过滤文件选择器中可选文件类型（如 `image/*`、`.pdf`、`audio/*`），但仅是前端提示，**不能替代后端校验**。恶意用户可绕过限制上传任意文件，后端必须校验 MIME 与扩展名。

### 后端接收示例（Node.js + Express）

```javascript
// 需安装：npm install express multer
const express = require("express");
const multer = require("multer");
const path = require("path");

const app = express();
// 配置 multer：保存到 uploads/，文件名加时间戳防重名
const storage = multer.diskStorage({
    destination: "uploads/",
    filename: (req, file, cb) => {
        const ext = path.extname(file.originalname);
        cb(null, `${Date.now()}${ext}`);
    }
});
const upload = multer({ storage, limits: { fileSize: 2 * 1024 * 1024 } }); // 限 2MB

app.post("/upload", upload.single("avatar"), (req, res) => {
    if (!req.file) return res.status(400).json({ msg: "未收到文件" });
    res.json({ msg: "上传成功", path: req.file.path, size: req.file.size });
});

app.listen(3000, () => console.log("http://localhost:3000"));
```

> [!warning] 文件上传安全要点
> 1. 限制文件大小与类型，防止占用存储或上传恶意脚本。
> 2. 不要使用用户上传的原始文件名直接保存，避免路径穿越与重名覆盖。
> 3. 上传目录禁止执行权限，防止上传 .php/.jsp 等被当作代码执行。

## 可运行代码示例

以下 HTML 整合 GET/POST 表单与 AJAX 提交，保存为 `.html` 文件即可在浏览器中运行（POST 接口需配合后端服务）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>GET/POST 表单示例</title>
    <style>
        body { font-family: "Microsoft YaHei", sans-serif; padding: 30px; max-width: 520px; }
        form { background: #f9f9f9; padding: 20px; border-radius: 8px; margin-bottom: 20px; }
        label { display: block; margin: 10px 0 4px; }
        input[type="text"], input[type="password"] {
            width: 100%; padding: 8px; border: 1px solid #ccc; border-radius: 4px; box-sizing: border-box;
        }
        button { padding: 8px 16px; background: #4CAF50; color: #fff; border: none; border-radius: 4px; cursor: pointer; }
        button:hover { background: #45a049; }
        .result { padding: 12px; background: #e8f5e9; border-left: 4px solid #4CAF50; word-break: break-all; }
    </style>
</head>
<body>
    <h2>1. GET 表单（参数在 URL）</h2>
    <form id="getForm" action="/search" method="get">
        <label>关键词：<input type="text" name="keyword" value="Web开发"></label>
        <button type="submit">GET 搜索</button>
    </form>

    <h2>2. POST 表单（参数在请求体）</h2>
    <form id="postForm">
        <label>用户名：<input type="text" name="username" value="alice"></label>
        <label>密码：<input type="password" name="password" value="123456"></label>
        <button type="submit">POST 登录</button>
    </form>

    <div id="output" class="result" style="display:none;"></div>

    <script>
        // GET 表单提交（原生行为：跳转，这里拦截演示）
        document.getElementById("getForm").addEventListener("submit", function(e) {
            e.preventDefault();
            const url = this.action + "?" + new URLSearchParams(new FormData(this)).toString();
            document.getElementById("output").style.display = "block";
            document.getElementById("output").textContent = "GET 请求 URL：\n" + url;
        });

        // POST 表单通过 fetch 提交（application/x-www-form-urlencoded）
        document.getElementById("postForm").addEventListener("submit", async function(e) {
            e.preventDefault();
            const params = new URLSearchParams(new FormData(this));
            try {
                // 演示用，无后端时会失败
                const res = await fetch("/login", {
                    method: "POST",
                    headers: { "Content-Type": "application/x-www-form-urlencoded" },
                    body: params.toString()
                });
                const data = await res.json();
                document.getElementById("output").style.display = "block";
                document.getElementById("output").textContent = "POST 响应：\n" + JSON.stringify(data, null, 2);
            } catch (err) {
                document.getElementById("output").style.display = "block";
                document.getElementById("output").textContent =
                    "POST 请求体（演示，未连接后端）：\n" + params.toString();
            }
        });
    </script>
</body>
</html>
```

## 小结

GET 用于查询，参数在 URL 查询串中，可缓存、有长度限制、幂等；POST 用于提交，参数在请求体中，不可缓存、无长度限制、非幂等。HTML 表单通过 `action` 指定目标、`method` 指定方法、提交按钮触发提交。POST 表单默认编码为 `application/x-www-form-urlencoded`，文件上传必须使用 `multipart/form-data` 并配合 `<input type="file">`。GET 的"不安全"与 POST 的"相对安全"都仅是参数暴露层面的差异，真正的传输安全必须依赖 HTTPS。
