# 3.1 CSS引入方式、选择器

CSS（Cascading Style Sheets，层叠样式表）负责网页的视觉表现。本节解决的问题是：如何把 CSS 应用到 HTML 上（引入方式），如何精确选中要设置样式的元素（选择器），以及当多条规则冲突时如何判断优先级。

## CSS 引入方式

CSS 有四种引入方式，按使用位置分为行内、内部、外部与 @import。

### 行内样式

直接在 HTML 标签的 `style` 属性中写 CSS：

```html
<p style="color: red; font-size: 16px;">这是一段红色文字</p>
```

### 内部样式表

在 HTML 的 `<head>` 内用 `<style>` 标签定义：

```html
<head>
    <style>
        p { color: red; font-size: 16px; }
    </style>
</head>
```

### 外部样式表（推荐）

将 CSS 写在独立的 `.css` 文件中，用 `<link>` 引入：

```html
<!-- HTML 文件 -->
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

```css
/* style.css */
p { color: red; font-size: 16px; }
```

### @import 导入

在 CSS 文件或 `<style>` 内用 `@import` 引入其他 CSS：

```css
@import url("reset.css");

body { margin: 0; }
```

### 四种引入方式对比

| 引入方式 | 语法位置 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 行内样式 | 标签 style 属性 | 优先级最高，针对性强 | 无法复用，结构与样式混杂 |
| 内部样式表 | `<style>` 标签 | 单文件管理，加载快 | 无法跨页面复用 |
| 外部样式表 | `<link>` 引入 .css | 可复用、可缓存、结构与样式分离 | 多一次 HTTP 请求 |
| @import | CSS 内导入 | 模块化组织 | 加载顺序在所有 CSS 之后，可能闪屏 |

> [!tip] 推荐做法
> 实际开发中**优先使用外部样式表**，实现结构与样式分离，便于维护与缓存复用。行内样式仅用于临时调试或极特殊情况。

### 引入方式优先级

优先级从高到低：

1. `!important` 声明（最高，覆盖一切）
2. 行内样式（style 属性）
3. 内部样式表与外部样式表（按书写顺序，后写者覆盖先写者）
4. @import 引入的样式（优先级较低）
5. 浏览器默认样式（最低）

## 基础选择器

### 标签选择器

按 HTML 标签名选中所有同类元素：

```css
p { color: #333; line-height: 1.6; }
h1 { font-size: 24px; }
```

### 类选择器

以 `.` 开头，按 `class` 属性选中元素，可复用：

```css
.highlight { background: yellow; }
```

```html
<p class="highlight">高亮段落</p>
<span class="highlight">高亮文本</span>
```

### ID 选择器

以 `#` 开头，按 `id` 属性选中唯一元素：

```css
#header { background: #f0f0f0; }
```

```html
<div id="header">页头</div>
```

> [!warning] ID 唯一性
> 一个页面中每个 id 只能出现一次。ID 选择器优先级高于类选择器，但实际开发中样式优先用 class，id 多用于 JS 获取元素与锚点定位。

### 通配符选择器

以 `*` 匹配所有元素，常用于全局重置：

```css
* { margin: 0; padding: 0; box-sizing: border-box; }
```

### 基础选择器对比

| 选择器 | 符号 | 选中范围 | 优先级 |
| --- | --- | --- | --- |
| 标签 | `div` | 所有该标签 | 1 |
| 类 | `.box` | 所有该 class | 10 |
| ID | `#box` | 唯一该 id | 100 |
| 通配符 | `*` | 所有元素 | 0 |

## 复合选择器

### 后代选择器（空格）

选中某元素内部的所有后代元素（不论层级）：

```css
.nav a { color: blue; }  /* .nav 内所有 a，不论嵌套多深 */
```

### 子代选择器（>）

只选中直接子元素（仅下一层）：

```css
.nav > li { list-style: none; }  /* 仅 .nav 的直接 li，不选孙级 */
```

### 相邻兄弟选择器（+）

选中紧邻在某元素之后的第一个兄弟元素：

```css
h2 + p { color: gray; }  /* 紧跟 h2 后的第一个 p */
```

### 通用兄弟选择器（~）

选中某元素之后的所有同级兄弟元素：

```css
h2 ~ p { color: gray; }  /* h2 之后的所有同级 p */
```

```mermaid

```

## 伪类选择器

伪类以 `:` 开头，选中处于特定状态的元素。

### 交互伪类

```css
a:link { color: blue; }       /* 未访问的链接 */
a:visited { color: purple; }  /* 已访问的链接 */
a:hover { color: red; }       /* 鼠标悬停 */
a:active { color: orange; }   /* 点击瞬间 */
input:focus { border-color: blue; }  /* 获得焦点 */
```

> [!warning] 链接伪类顺序
> 链接伪类需按 `:link → :visited → :hover → :active` 顺序书写（LVHA 记忆），否则可能因优先级相同而被覆盖失效。

### 结构伪类

```css
li:first-child { color: red; }      /* 第一个子元素 */
li:last-child { color: blue; }      /* 最后一个子元素 */
li:nth-child(2) { color: green; }   /* 第2个子元素 */
li:nth-child(odd) { background: #eee; }   /* 奇数项 */
li:nth-child(even) { background: #fff; }  /* 偶数项 */
li:nth-child(3n+1) { color: red; }  /* 第1、4、7...项 */
```

### 常见伪类

| 伪类 | 作用 |
| --- | --- |
| `:hover` | 鼠标悬停 |
| `:active` | 激活（点击瞬间） |
| `:focus` | 获得焦点 |
| `:first-child` | 第一个子元素 |
| `:last-child` | 最后一个子元素 |
| `:nth-child(n)` | 第 n 个子元素，支持公式 |
| `:not(selector)` | 不匹配某选择器的元素 |

## 伪元素选择器

伪元素以 `::` 开头（CSS3 规范），用于选中元素的特定部分或插入生成内容。

```css
/* 在元素内容前插入 */
.box::before {
    content: "★";
    color: gold;
}

/* 在元素内容后插入 */
.box::after {
    content: "";
    display: block;
    clear: both;
}

/* 首字母特殊样式 */
p::first-letter {
    font-size: 2em;
    font-weight: bold;
}

/* 首行特殊样式 */
p::first-line {
    color: gray;
}
```

| 伪元素 | 作用 |
| --- | --- |
| `::before` | 在元素内容前插入生成内容 |
| `::after` | 在元素内容后插入生成内容 |
| `::first-letter` | 选中首字母 |
| `::first-line` | 选中首行 |

> [!tip] ::before 与 ::after 必备 content
> `::before` 和 `::after` 必须设置 `content` 属性（即使为空字符串 `""`）才会生效，常用于清除浮动、装饰图标、气泡箭头等效果。

## 选择器优先级

当多条 CSS 规则作用于同一元素时，按优先级决定最终生效的样式。

### 优先级排序

从高到低：

1. `!important`（强制最高）
2. 行内样式（style 属性）
3. ID 选择器（`#id`）
4. 类选择器、伪类、属性选择器（`.class`、`:hover`）
5. 标签选择器、伪元素（`div`、`::before`）
6. 通配符（`*`）
7. 继承样式
8. 浏览器默认样式

### 优先级计算

按 (ID, 类, 标签) 三元组计算，逐位比较：

```css
#nav .item a        /* (1, 1, 1) */
.menu a:hover       /* (0, 2, 1) */
div p               /* (0, 0, 2) */
```

| 选择器 | ID 数 | 类数 | 标签数 | 优先级 |
| --- | --- | --- | --- | --- |
| `#nav .item a` | 1 | 1 | 1 | (1,1,1) |
| `.menu a:hover` | 0 | 2 | 1 | (0,2,1) |
| `div p` | 0 | 0 | 2 | (0,0,2) |

> [!example] 优先级判断示例
> 对比 `#nav .item a` (1,1,1) 与 `.menu a:hover` (0,2,1)：先比 ID 数，1 > 0，故 `#nav .item a` 优先级更高。再对比 `.menu a:hover` (0,2,1) 与 `div p` (0,0,2)：ID 数相同（0=0），比类数 2 > 0，故 `.menu a:hover` 优先级更高。

> [!warning] !important 慎用
> `!important` 会破坏正常优先级规则，导致样式难以覆盖与维护。除非覆盖第三方库样式，否则应通过调整选择器结构而非 !important 来解决优先级问题。

## 可运行代码示例

以下是一个完整的 HTML 文件，演示各种引入方式与选择器效果，保存为 `.html` 文件即可在浏览器中查看：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>CSS选择器演示</title>
    <style>
        /* 通配符重置 */
        * { margin: 0; padding: 0; box-sizing: border-box; }

        /* 标签选择器 */
        body { font-family: "Microsoft YaHei", sans-serif; padding: 20px; }

        /* 类选择器 */
        .card { border: 1px solid #ddd; padding: 15px; margin-bottom: 10px; border-radius: 4px; }

        /* ID选择器 */
        #main { background: #f9f9f9; }

        /* 后代选择器 */
        .card p { color: #555; line-height: 1.6; }

        /* 子代选择器 */
        .list > li { list-style: square; margin-left: 20px; }

        /* 伪类 */
        .card:hover { border-color: #4CAF50; box-shadow: 0 2px 8px rgba(0,0,0,0.1); }
        .list li:nth-child(odd) { background: #f0f0f0; }

        /* 伪元素 */
        .card::before { content: "📌 "; }
        .card h3::after { content: ""; display: block; width: 40px; height: 3px; background: #4CAF50; margin-top: 5px; }
    </style>
</head>
<body>
    <div id="main">
        <h1>CSS选择器演示</h1>

        <div class="card">
            <h3>卡片一</h3>
            <p>鼠标悬停此卡片可看到 :hover 效果，::before 添加了图钉符号。</p>
        </div>

        <div class="card">
            <h3>卡片二</h3>
            <p>伪元素 ::after 为标题添加了下划线装饰。</p>
            <ul class="list">
                <li>第一项（奇数项灰色背景）</li>
                <li>第二项</li>
                <li>第三项（奇数项灰色背景）</li>
                <li>第四项</li>
            </ul>
        </div>
    </div>
</body>
</html>
```

## 小结

CSS 通过行内、内部、外部与 @import 四种方式引入，外部样式表是推荐做法。选择器从基础的标签、类、ID、通配符，到复合的后代、子代、兄弟选择器，再到伪类与伪元素，提供了精确选中元素的能力。优先级按 (ID, 类, 标签) 三元组计算，`!important` 最高但应慎用。掌握选择器是编写高效、可维护 CSS 的基础。
