# 6.2 JSON数据格式

前后端交换数据需要一种双方都能理解的格式。本节解决的问题是：JSON 是什么、有哪些数据类型与语法规则，如何用 JavaScript 进行序列化与反序列化，以及它为何取代 XML 成为 Web 数据交换的事实标准。

## JSON 定义

> [!definition] JSON
> JSON（JavaScript Object Notation，JavaScript 对象表示法）是一种轻量级的数据交换格式。它基于 JavaScript 的对象字面量语法，但独立于语言，几乎所有编程语言都提供解析与生成 JSON 的库。JSON 易于人阅读与编写，也易于机器解析与生成，是 Web API 的事实标准数据格式。

## JSON 数据类型

JSON 支持六种数据类型：

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `string` | 字符串，必须用双引号 | `"hello"` |
| `number` | 数值，整数或浮点 | `42`、`3.14`、`-1e5` |
| `boolean` | 布尔值 | `true`、`false` |
| `null` | 空值 | `null` |
| `array` | 数组，方括号包裹 | `[1, 2, 3]` |
| `object` | 对象，花括号包裹键值对 | `{"name": "alice"}` |

> [!warning] JSON 不支持的类型
> JSON **不支持** `undefined`、函数、`Symbol`、`Date`、`RegExp`、`Map`/`Set`。`JSON.stringify` 遇到这些值会跳过对象属性或转换为 `null`。日期通常序列化为 ISO 字符串（如 `"2026-08-02T10:00:00Z"`）。

## JSON 语法规则

1. **键必须用双引号**：`"name": "alice"`，不能用单引号或无引号。
2. **字符串必须用双引号**：不能单引号。
3. **值类型受限**：只能是上述六种类型或由它们嵌套而成。
4. **数据用逗号分隔**：最后一个键值对/元素后不能有尾逗号。
5. **无注释**：不能写 `//` 或 `/* */`。
6. **无变量与表达式**：纯数据，不能含函数或计算。

```json
{
    "id": 1001,
    "name": "alice",
    "active": true,
    "score": null,
    "tags": ["web", "frontend", 2026],
    "address": {
        "city": "北京",
        "zip": "100000"
    }
}
```

> [!warning] 常见 JSON 错误
> 1. 键用单引号：`{'name':'alice'}` ❌
> 2. 尾逗号：`{"a":1,}` ❌
> 3. 含注释：`{"a":1 // 注释}` ❌
> 4. 字符串用单引号：`'hello'` ❌
> 这些都会导致 `JSON.parse` 抛 `SyntaxError`。

## JSON 序列化与反序列化

### JSON.stringify()

> [!definition] JSON.stringify
> `JSON.stringify(value, replacer, space)` 将 JavaScript 值序列化为 JSON 字符串。`replacer` 可筛选或转换属性，`space` 控制缩进用于美化输出。

```javascript
const user = {
    id: 1001,
    name: "alice",
    password: "secret",       // 敏感字段
    birthday: new Date("2000-01-01"),
    sayHi() { console.log("hi"); }  // 方法
};

// 基本序列化（方法被跳过，Date 转 ISO 字符串）
JSON.stringify(user);
// '{"id":1001,"name":"alice","password":"secret","birthday":"2000-01-01T00:00:00.000Z"}'

// 美化输出（2 空格缩进）
JSON.stringify(user, null, 2);

// replacer：数组白名单，只保留指定字段
JSON.stringify(user, ["id", "name"], 2);
// '{\n  "id": 1001,\n  "name": "alice"\n}'

// replacer：函数，可过滤敏感字段
JSON.stringify(user, (key, value) => {
    if (key === "password") return undefined;  // 移除敏感字段
    return value;
}, 2);
```

> [!tip] 序列化要点
> 1. `undefined`、函数、`Symbol` 作为对象属性值时会被跳过；作为数组元素时转为 `null`。
> 2. `Date` 调用 `toISOString()`，`RegExp`/`Error` 转为 `{}`。
> 3. 含循环引用的对象会抛 `TypeError: Converting circular structure to JSON`。

### JSON.parse()

> [!definition] JSON.parse
> `JSON.parse(text, reviver)` 将 JSON 字符串反序列化为 JavaScript 值。`reviver` 函数可在解析时转换每个属性。

```javascript
const jsonStr = '{"id":1001,"name":"alice","tags":["web","js"]}';

// 基本反序列化
const user = JSON.parse(jsonStr);
console.log(user.name);    // "alice"
console.log(user.tags[0]); // "web"

// reviver：把日期字符串还原为 Date 对象
const jsonWithDate = '{"name":"alice","birthday":"2000-01-01T00:00:00.000Z"}';
const obj = JSON.parse(jsonWithDate, (key, value) => {
    if (key === "birthday") return new Date(value);
    return value;
});
console.log(obj.birthday instanceof Date);  // true

// 错误处理：非法 JSON 会抛 SyntaxError
try {
    JSON.parse("{'name':'alice'}");  // 单引号不合法
} catch (e) {
    console.error("解析失败：", e.message);  // Unexpected token
}
```

> [!warning] 反序列化必须 try/catch
> 从网络或 localStorage 读取的字符串可能不合法，`JSON.parse` 会抛 `SyntaxError` 中断程序。生产代码必须包裹 `try/catch` 并提供默认值。

## JSON 嵌套结构示例

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "user": {
            "id": 1001,
            "name": "alice",
            "roles": ["admin", "editor"]
        },
        "posts": [
            {
                "id": 1,
                "title": "Web 开发入门",
                "tags": ["html", "css"],
                "stats": { "views": 1200, "likes": 88 }
            },
            {
                "id": 2,
                "title": "JavaScript 进阶",
                "tags": ["js", "es6"],
                "stats": { "views": 980, "likes": 65 }
            }
        ]
    }
}
```

访问嵌套数据需逐层取值，注意空值保护：

```javascript
const res = await fetch("/api/dashboard").then(r => r.json());

// 安全访问嵌套字段（可选链 ?. 防止中间为 undefined）
const firstPostTitle = res?.data?.posts?.[0]?.title ?? "无文章";
const firstPostViews = res?.data?.posts?.[0]?.stats?.views ?? 0;
console.log(firstPostTitle, firstPostViews);
```

## JSON vs XML

| 维度 | JSON | XML |
| --- | --- | --- |
| 语法 | 简洁，键值对 | 标签嵌套，冗长 |
| 体积 | 小 | 大（大量标签开销） |
| 解析速度 | 快（原生 `JSON.parse`） | 慢（需 DOM 解析器） |
| 可读性 | 高 | 高但啰嗦 |
| 数据类型 | 支持数字、布尔、null | 仅文本，需自定义类型 |
| 注释 | 不支持 | 支持 `<!-- -->` |
| 扩展性 | 固定结构 | 可用 DTD/Schema 定义结构 |
| Web 现状 | 主流，事实标准 | 配置文件、SOAP 等场景仍有使用 |

```xml
<!-- XML 表示同样数据 -->
<response>
    <code>0</code>
    <data>
        <user>
            <id>1001</id>
            <name>alice</name>
        </user>
    </data>
</response>
```

```json
{
    "code": 0,
    "data": { "user": { "id": 1001, "name": "alice" } }
}
```

> [!note] JSON 取代 XML 的原因
> JSON 体积更小、解析更快、与 JavaScript 原生契合（无需额外解析库），且数据类型更贴近编程语言的对象模型。AJAX 早期用 XML，如今几乎全部使用 JSON。

以下 HTML 演示 JSON 的序列化、反序列化与错误处理，保存为 `.html` 文件即可在浏览器中运行：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>

        button { padding: 8px 16px; margin: 8px 8px 8px 0; background: #FF9800;
                 color: #fff; border: none; border-radius: 4px; cursor: pointer; }
        button:hover { background: #F57C00; }
        pre { background: #f4f4f4; padding: 12px; border-radius: 4px;
              white-space: pre-wrap; word-break: break-all; }
        label { display: block; margin-top: 12px; font-weight: bold; }
    </style>
</head>
<body>
    <h2>JSON 演示</h2>

    <label>JS 对象（左侧）→ JSON 字符串（右侧文本框）</label>
    <button onclick="stringifyDemo()">序列化 stringify</button>
    <textarea id="jsonStr" placeholder='{"name":"alice","age":20}'>{"name":"alice","age":20,"tags":["web","js"]}</textarea>

    <label>JSON 字符串 → JS 对象</label>
    <button onclick="parseDemo()">反序列化 parse</button>
    <pre id="output">结果将显示在此...</pre>

    <script>
        // 序列化：JS 对象 → JSON 字符串
        function stringifyDemo() {
            const obj = {
                id: 1001,
                name: "alice",
                password: "secret",      // 演示过滤
                birthday: new Date(),
                sayHi() { return "hi"; } // 方法会被跳过
            };
            // 过滤敏感字段 + 美化缩进
            const json = JSON.stringify(obj, (k, v) => {
                if (k === "password") return undefined;
                return v;
            }, 2);
            document.getElementById("jsonStr").value = json;
            document.getElementById("output").textContent =
                "序列化成功（已过滤 password，方法被跳过，Date 转 ISO 字符串）：\n" + json;
        }

        // 反序列化：JSON 字符串 → JS 对象
        function parseDemo() {
            const str = document.getElementById("jsonStr").value;
            try {
                const obj = JSON.parse(str);
                document.getElementById("output").textContent =
                    "反序列化成功，对象结构：\n" + JSON.stringify(obj, null, 2) +
                    "\n\n可访问属性：obj.name = " + obj.name +
                    ", obj.tags = " + JSON.stringify(obj.tags);
            } catch (e) {
                document.getElementById("output").textContent =
                    "❌ 解析失败：" + e.message + "\n请检查：键是否用双引号、是否有尾逗号、是否有注释。";
            }
        }
    </script>
</body>
</html>
```

## 小结

JSON 是基于 JavaScript 对象语法的轻量级数据交换格式，支持 string、number、boolean、null、array、object 六种类型。语法规则严格：键与字符串必须用双引号、不能有尾逗号与注释。`JSON.stringify()` 将 JS 值序列化为 JSON 字符串，可通过 replacer 过滤敏感字段；`JSON.parse()` 将 JSON 字符串反序列化为 JS 值，必须 try/catch 防止非法格式中断程序。JSON 相较 XML 体积更小、解析更快、与语言契合度更高，是 Web 数据交换的事实标准。
