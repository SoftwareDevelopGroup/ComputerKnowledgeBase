<summary>一、单选题答案</summary>

**5.1** B。Canvas + GraphicsContext 命令式绘图，性能高，适合高频重绘的实时曲线、画板。

**5.2** B。`fillOval(x, y, w, h)` 填充椭圆；`drawOval` 不存在；`fillEllipse`/`fillCircle` 非标准方法。

**5.3** C。`strokeType` 默认 `CENTERED`（居中），另有 `INSIDE`/`OUTSIDE`。

**5.4** B。`save()`/`restore()` 保存/恢复变换状态与样式，须配对使用，用于临时变换后恢复。

**5.5** B。打包进 jar 的资源用 `getResourceAsStream` 加载；`file:` 协议找不到 jar 内资源。

**5.6** B。`setPreserveRatio(true)` 保持原图比例缩放。

**5.7** B。`setCycleCount(Animation.INDEFINITE)` 设置无限循环。

**5.8** A。`Timeline` 用 `KeyFrame` + `KeyValue` 定义关键时间点的属性目标值。

**5.9** C。`FadeTransition` 改变透明度，实现淡入淡出。

**5.10** B。`ParallelTransition` 让多个动画同时（并行）执行。

<details>
<summary>二、多选题答案</summary>

**5.11** ABC。Canvas 用 GraphicsContext 命令式画到位图、性能高、不自动重绘。D 错误：Canvas 默认不随父容器缩放（需手动监听尺寸重设 width/height 并重绘）。E 错误：Canvas 需自行做命中检测，不能直接对绘制内容注册事件（Canvas 节点本身可注册但需手动判断坐标）。

**5.12** ABCDE。Line/Rectangle/Circle/Path/Text 都是 Shape 子类。

**5.13** ABCDE。fitWidth/fitHeight/preserveRatio/rotate/viewport/opacity 都是 ImageView 支持的变换属性。

**5.14** ABCDE。FadeTransition/TranslateTransition/RotateTransition/PathTransition/FillTransition 都是 Transition 子类。

**5.15** ABCDE。串行/并行/嵌套/cycleCount/autoReverse 都是动画组合与控制方式。

<details>
<summary>三、判断题答案</summary>

**5.16** 错误。Canvas 绘制内容不会自动重绘，窗口最小化恢复、resize 后缓冲区可能清空，需在重绘回调里重画。

**5.17** 错误。Image 是纯数据，不是节点，不能直接加入 Scene Graph，必须用 ImageView 包装。

**5.18** 正确。KeyValue 必须绑定可写属性（WritableValue），普通字段无法被插值。

**5.19** 正确。`stop()` 会将属性重置回动画开始前的值，注意与 `setOnFinished` 中状态保持的配合。

**5.20** 错误。大图像素遍历耗时，应在后台线程处理，完成后用 `Platform.runLater` 更新界面，否则 UI 卡顿。
</details>

<details>
<summary>四、简答题答案</summary>

**5.21** Canvas（命令式）：用 GraphicsContext 方法画到位图缓冲区，手动 clearRect+重画，需自行做命中检测，性能高，适合频繁绘制（实时曲线、画板、粒子）。Shape（声明式）：节点放入 Scene Graph 由框架渲染，属性变化自动刷新，可直接注册事件与绑定，节点多时开销大，适合静态/可交互图形。

**5.22** Image 负责加载并存储像素数据（非节点），ImageView 是 Node 子类，负责在 Scene Graph 中显示 Image 并提供变换（缩放/旋转/视口）。Image 加载来源：① URL（在线资源）；② 本地文件（`file:` 协议）；③ 输入流（`getResourceAsStream`，适合 jar 内资源）；④ 指定尺寸与比例。

**5.23** Transition 封装对单一属性的常用动画（淡入淡出/平移/旋转/缩放/路径），配置简单（setDuration/setNode/setToXxx），适合标准过渡效果。Timeline 基于关键帧（KeyFrame+KeyValue）自由驱动任意可写属性，灵活度高，适合复杂自定义动画。Transition 适合简单过渡，Timeline 适合需多属性协同的复杂动画。

**5.24** SequentialTransition 串行执行子动画（依次完成）；ParallelTransition 并行执行子动画（同时进行）。二者可嵌套组合复杂动画序列，如把 ParallelTransition 作为 SequentialTransition 的一环。
</details>

**5.29** 参考代码：

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.image.*;
import javafx.scene.layout.HBox;
import javafx.stage.FileChooser;
import javafx.stage.Stage;
import javafx.scene.paint.Color;
import java.io.File;

public class GrayScaleApp extends Application {
    @Override
    public void start(Stage stage) {
        FileChooser chooser = new FileChooser();
        chooser.getExtensionFilters().add(
                new FileChooser.ExtensionFilter("图片", "*.png", "*.jpg"));
        File file = chooser.showOpenDialog(stage);
        if (file == null) { stage.close(); return; }

        Image src = new Image(file.toURI().toString());
        int w = (int) src.getWidth();
        int h = (int) src.getHeight();

        WritableImage gray = new WritableImage(w, h);
        PixelReader reader = src.getPixelReader();
        PixelWriter writer = gray.getPixelWriter();
        for (int y = 0; y < h; y++) {
            for (int x = 0; x < w; x++) {
                Color c = reader.getColor(x, y);
                double g = 0.299 * c.getRed() + 0.587 * c.getGreen() + 0.114 * c.getBlue();
                writer.setColor(x, y, new Color(g, g, g, c.getOpacity()));
            }
        }

        ImageView original = new ImageView(src);
        original.setFitWidth(300); original.setPreserveRatio(true);
        ImageView grayView = new ImageView(gray);
        grayView.setFitWidth(300); grayView.setPreserveRatio(true);

        stage.setScene(new Scene(new HBox(10, original, grayView), 640, 320));
        stage.setTitle("图像灰度化");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```

**5.30** 参考代码（弹跳小球）：

```java
import javafx.animation.Animation;
import javafx.animation.KeyFrame;
import javafx.animation.KeyValue;
import javafx.animation.Timeline;
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.layout.BorderPane;
import javafx.scene.layout.HBox;
import javafx.scene.layout.Pane;
import javafx.scene.paint.Color;
import javafx.scene.shape.Circle;
import javafx.stage.Stage;
import javafx.util.Duration;

public class BouncingBall extends Application {
    private Timeline timeline;
    private double dx = 3, dy = 2;

    @Override
    public void start(Stage stage) {
        Circle ball = new Circle(20, Color.DODGERBLUE);
        ball.setCenterX(50); ball.setCenterY(50);

        Pane canvas = new Pane(ball);
        canvas.setPrefSize(400, 300);
        canvas.setStyle("-fx-background-color: #fafafa;");

        // 每帧移动并检测边界反弹
        KeyFrame frame = new KeyFrame(Duration.millis(16), e -> {
            double nx = ball.getCenterX() + dx;
            double ny = ball.getCenterY() + dy;
            if (nx <= 20 || nx >= canvas.getWidth() - 20) dx = -dx;
            if (ny <= 20 || ny >= canvas.getHeight() - 20) dy = -dy;
            ball.setCenterX(ball.getCenterX() + dx);
            ball.setCenterY(ball.getCenterY() + dy);
            // 颜色随位置变化
            double r = ball.getCenterX() / canvas.getWidth();
            double g = ball.getCenterY() / canvas.getHeight();
            ball.setFill(new Color(r, g, 0.5, 1.0));
        });
        timeline = new Timeline(frame);
        timeline.setCycleCount(Animation.INDEFINITE);

        Button startBtn = new Button("开始");
        Button pauseBtn = new Button("暂停");
        startBtn.setOnAction(e -> timeline.play());
        pauseBtn.setOnAction(e -> timeline.pause());

        BorderPane root = new BorderPane();
        root.setTop(new HBox(10, startBtn, pauseBtn));
        root.setCenter(canvas);

        stage.setScene(new Scene(root, 420, 360));
        stage.setTitle("弹跳小球");
        stage.show();
        timeline.play();
    }
    public static void main(String[] args) { launch(args); }
}
```
