**4.16** 错误。`consume()` 只影响传播方向上的后续节点，不阻止同一节点上已注册的其他同类处理器执行。

**4.19** 正确。双向绑定两端均可写，任一端变化同步到另一端。

<details>
<summary>四、简答题答案</summary>

**4.21** 事件传播分两阶段：捕获阶段自顶向下，从 Root 经 Parent 到达 Target；冒泡阶段自底向上，从 Target 经 Parent 到 Root。`addEventFilter` 注册的处理器在捕获阶段执行（自顶向下），`addEventHandler`/`setOnXxx` 注册的处理器在冒泡阶段执行（自底向上）。到达 Target 后两阶段往返一次。

**4.22** `EventHandler` 是函数式接口（仅一个抽象方法 `handle`），符合 SAM 转换条件——编译器根据目标接口类型自动实例化实现类，省去匿名内部类样板代码，因此可用 Lambda。SAM 转换即 Single Abstract Method 转换。区别：Lambda 中 `this` 指向外围类实例（词法 this），匿名内部类中 `this` 指向匿名实例本身。在 Controller 中用 Lambda 引用 `this` 不会产生歧义。

**4.23** `ChangeListener` 在属性值真正变化（被求值）时触发，回调 `changed(ObservableValue, oldVal, newVal)` 携带新旧值，适合需精确值的场景；`InvalidationListener` 在属性由有效变无效时触发一次，回调 `invalidated(Observable)` 不带新值，适合只需知道“失效了”的高效通知。惰性求值：JavaFX 属性默认惰性，连续 set 修改时若属性已无效，`InvalidationListener` 不再触发，只有被读取（求值）后才恢复有效。

**4.24** 单向绑定 `target.bind(source)`：target 跟随 source 变化，target 不可手动 set（抛 `RuntimeException`）；双向绑定 `a.bindBidirectional(b)`：任一端变化同步到另一端，两端均可写。单向绑定后对 target `set()` 抛 `RuntimeException`，需先 `unbind()` 才能恢复可写。
</details>

**4.25** 补全代码：

```java
import javafx.scene.input.MouseButton;
circle.setOnMouseClicked(e -> {
    if (e.getButton() == MouseButton.PRIMARY) {
        circle.setFill(Color.CRIMSON);
    } else if (e.getButton() == MouseButton.SECONDARY) {
        circle.setFill(Color.STEELBLUE);
    }
    System.out.println("点击次数: " + e.getClickCount());
});

root.addEventFilter(MouseEvent.MOUSE_CLICKED, e -> {
    if (e.getClickCount() == 2) {
        System.out.println("父节点拦截双击");
        e.consume();   // 圆形不会收到双击事件
    }
});
```

**4.26** 补全代码：

```java
valueLabel.textProperty().bind(slider.valueProperty().asString("值: %.0f"));
statusLabel.textProperty().bind(
        Bindings.when(slider.valueProperty().greaterThanOrEqualTo(50))
                .then("高").otherwise("低"));
```

**4.27** ① 传播路径：捕获阶段 VBox(root) → Button(target)；到达目标后冒泡阶段 Button → VBox。② 父节点 filter 中 `consume()` 后，Button 的 `setOnAction` **不会执行**。因为 filter 在捕获阶段（自顶向下）先执行，`consume()` 标记事件“已处理”，阻止事件继续向下一节点（即 Target Button）传播，故 Button 上的冒泡 Handler 不会触发。

**4.28** 原因：`count` 是局部变量，Lambda 内只能读等效 final 的外围局部变量，不能修改（`count++` 编译错误）。修正：把 `count` 改为字段，或用 `AtomicInteger`：

```java
// 方式一：改为字段
private int count = 0;
// 在 start 中：
btn.setOnAction(e -> {
    count++;
    btn.setText("点击 " + count + " 次");
});

// 方式二：用 AtomicInteger
AtomicInteger count = new AtomicInteger(0);
btn.setOnAction(e -> btn.setText("点击 " + count.incrementAndGet() + " 次"));
```

```java
        // 捕获阶段拦截 Ctrl+S
        scene.addEventFilter(KeyEvent.KEY_PRESSED, e -> {
            if (e.isControlDown() && e.getCode().toString().equals("S")) {
                System.out.println("执行保存...");
                e.consume();   // 阻止默认行为
            }
        });

        stage.setScene(scene);
        stage.setTitle("键盘移动");
        stage.show();
        rect.requestFocus();
    }
    public static void main(String[] args) { launch(args); }
}
```

```java
import javafx.application.Application;
import javafx.beans.binding.Bindings;
import javafx.collections.FXCollections;
import javafx.collections.ObservableList;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.input.MouseEvent;
import javafx.scene.layout.BorderPane;
import javafx.scene.layout.Pane;
import javafx.scene.layout.HBox;
import javafx.scene.shape.Line;
import javafx.stage.Stage;

public class DrawBoardApp extends Application {
    private final ObservableList<Line> lines = FXCollections.observableArrayList();

    @Override
    public void start(Stage stage) {
        Pane canvas = new Pane();
        canvas.setPrefSize(500, 400);
        canvas.setStyle("-fx-background-color: white; -fx-border-color: #ccc;");

        // 临时预览线段
        Line preview = new Line();
        preview.setOpacity(0.4);
        preview.setVisible(false);
        canvas.getChildren().add(preview);

        // 鼠标按下记录起点（冒泡阶段 setOnXxx）
        canvas.setOnMousePressed(e -> {
            preview.setStartX(e.getX()); preview.setStartY(e.getY());
            preview.setEndX(e.getX());   preview.setEndY(e.getY());
            preview.setVisible(true);
        });
        // 拖动实时预览
        canvas.setOnMouseDragged(e -> {
            preview.setEndX(e.getX()); preview.setEndY(e.getY());
        });
        // 释放确定终点，加入列表与画板
        canvas.setOnMouseReleased(e -> {
            preview.setVisible(false);
            Line line = new Line(preview.getStartX(), preview.getStartY(),
                                 e.getX(), e.getY());
            lines.add(line);          // ObservableList 增删触发监听
            canvas.getChildren().add(line);
        });

        Button clearBtn = new Button("清空");
        clearBtn.setOnAction(e -> {
            canvas.getChildren().removeIf(n -> n instanceof Line && n != preview);
            lines.clear();
        });

        // 属性绑定：标签显示线段数量
        Label countLabel = new Label();
        countLabel.textProperty().bind(Bindings.size(lines).asString("线段数: %d"));

        BorderPane root = new BorderPane();
        root.setTop(new HBox(10, clearBtn, countLabel));
        root.setCenter(canvas);

        stage.setScene(new Scene(root, 520, 440));
        stage.setTitle("画板");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```
