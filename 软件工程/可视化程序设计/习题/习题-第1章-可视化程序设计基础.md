<details>
<summary>四、简答题答案</summary>

**1.21** 可视化程序设计以界面为起点，通过拖拽组件、配置属性先构建 UI 再编写交互逻辑；命令式程序设计以代码逻辑为起点，通过文本输入输出驱动流程。前者强调“所见即所得”与快速反馈，后者强调算法与控制流。可视化通常采用界面优先策略，配合 MVC/MVVM 分离界面与逻辑。

**1.22** 三要素：事件源、事件对象、事件监听器。JavaFX 中：事件源通常是 `Node`/`Scene`/`Window`（如 `Button`）；事件对象为 `javafx.event.Event` 及其子类（如点击按钮产生 `ActionEvent`，鼠标操作产生 `MouseEvent`）；监听器为 `EventHandler<T extends Event>` 接口实现，常用 Lambda 写法 `button.setOnAction(e -> ...)`。

**1.23** 顺序：`main()` 调用 `launch()` → JavaFX 运行时创建 `Application` 实例并调用 `init()`（在 JavaFX 启动线程，非 EDT）→ 在 EDT 上调用 `start(Stage)` 显示主窗体 → 用户关闭窗体后调用 `stop()`（在 EDT）释放资源 → 程序退出。`init()` 与 `stop()` 在 JavaFX Application Thread 之外执行，`start()` 在 EDT 上执行。

**1.24** `Application` 是程序基类，拥有顶层窗口 `Stage`；`Stage` 持有 `Scene`；`Scene` 包含 Scene Graph 节点树（根节点 Root Pane + 子节点）。一个 Stage 同一时刻只显示一个 Scene，切换 Scene 用 `stage.setScene()`。
</details>

<summary>五、代码题与分析题答案</summary>

**1.25** 参考代码：

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class HelloWorld extends Application {
    @Override
    public void start(Stage primaryStage) {
        Label label = new Label("Hello, 可视化程序设计！");
        Button button = new Button("点击我");
        button.setOnAction(e -> label.setText("已响应事件！"));

        VBox root = new VBox(12, label, button);
        Scene scene = new Scene(root, 320, 180);

        primaryStage.setTitle("Hello World 示例");
        primaryStage.setScene(scene);
        primaryStage.show();
    }
    public static void main(String[] args) {
        launch(args);
    }
}
```

回调执行顺序：`main()` 调 `launch()` → `init()`（默认空实现，启动线程）→ `start()`（EDT）→ 事件循环 → 关闭窗体 → `stop()`（EDT）。

**1.26** 参考代码：

```java
@Override
public void init() throws Exception {
    System.out.println("应用初始化... 线程: " + Thread.currentThread().getName());
}
@Override
public void stop() throws Exception {
    System.out.println("应用关闭，释放资源... 线程: " + Thread.currentThread().getName());
}
```

线程归属：`init()` 在 JavaFX 启动线程（`JavaFX-Launcher`），`start()` 与 `stop()` 在 JavaFX Application Thread（EDT）。

**1.27** 问题：后台线程直接调用 `status.setText()` 修改 UI，违反 JavaFX 单线程模型——所有对 Scene Graph 的访问必须在 JavaFX Application Thread 上完成。运行时抛 `IllegalStateException: Not on FX application thread`。修正：用 `Platform.runLater()` 切回 EDT：

```java
Platform.runLater(() -> status.setText("done"));
```

**1.28** 节点树：

```
Scene
 └─ VBox（根）
     ├─ Label
     └─ HBox
         ├─ Button（登录）
         └─ Button（取消）
```

传播路径：捕获阶段自顶向下 Scene → VBox → HBox → 目标 Button；到达目标后冒泡阶段自底向上 目标 Button → HBox → VBox → Scene。`addEventFilter` 在捕获阶段执行，`addEventHandler`/`setOnXxx` 在冒泡阶段执行。

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.layout.VBox;
import javafx.stage.Modality;
import javafx.stage.Stage;

public class AboutDialogDemo extends Application {
    @Override
    public void start(Stage primaryStage) {
        Button openBtn = new Button("打开关于");
        openBtn.setOnAction(e -> showAbout(primaryStage));
        Scene scene = new Scene(new VBox(openBtn), 240, 120);
        primaryStage.setTitle("主窗口");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    private void showAbout(Stage owner) {
        Stage about = new Stage();
        about.initOwner(owner);                         // 父窗口
        about.initModality(Modality.APPLICATION_MODAL); // 应用级模态
        about.setTitle("关于");

        Label info = new Label("课程：可视化程序设计\n作者：张三");
        Button close = new Button("关闭");
        close.setOnAction(e -> about.close());

        about.setScene(new Scene(new VBox(12, info, close), 220, 120));
```

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.layout.BorderPane;
import javafx.scene.layout.VBox;
import javafx.scene.layout.HBox;
import javafx.stage.Stage;

public class NameCardApp extends Application {
    private BorderPane root;
    private boolean dark = false;

    @Override
    public void start(Stage primaryStage) {
        // Application 子类 → 拥有 Stage
        // 顶部标题
        Label title = new Label("个人名片卡");
        title.setStyle("-fx-font-size: 20px; -fx-font-weight: bold;");

        // 中间内容（Scene Graph 子节点）
        VBox content = new VBox(8,
                new Label("姓名：李四"),
                new Label("学号：20210001"),
                new Label("专业：计算机科学与技术"),
                new Label("简介：热爱 GUI 开发与可视化设计"));
        content.setStyle("-fx-padding: 16;");

        // 底部状态栏 + 切换按钮
        Label status = new Label("就绪");
        Button toggle = new Button("切换主题色");
        toggle.setOnAction(e -> {
            dark = !dark;
            root.setStyle(dark
                ? "-fx-background-color: #2b2b2b;"
                : "-fx-background-color: #f5f7fa;");
            status.setText(dark ? "深色主题" : "浅色主题");
        });
        HBox bottom = new HBox(10, toggle, status);

        // BorderPane 作为根，组织上中下
        root = new BorderPane();
        root.setTop(title);
        root.setCenter(content);
        root.setBottom(bottom);
        root.setStyle("-fx-background-color: #f5f7fa;");

        // Scene 承载 Scene Graph
        Scene scene = new Scene(root, 360, 240);
        primaryStage.setTitle("名片卡");      // Stage 标题
        primaryStage.setScene(scene);
        primaryStage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```
