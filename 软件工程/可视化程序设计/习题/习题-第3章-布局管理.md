<details>
<summary>四、简答题答案</summary>

**3.21** HBox 水平排列（工具栏/按钮组）、VBox 垂直排列（表单/设置项）、BorderPane 五区域（主框架）、FlowPane 流式换行（标签云）、TilePane 等大小格子（图标网格）、GridPane 行列网格可跨格（表单对齐）、StackPane 层叠居中（加载遮罩）、AnchorPane 锚定（自由拖拽布局）。选型思路：整体框架用 BorderPane，单行/单列用 HBox/VBox，表单对齐用 GridPane，需拉伸用 AnchorPane 锚定或 grow 权重，居中覆盖用 StackPane。

**3.22** 核心目标是让界面在不同窗口尺寸与分辨率下合理呈现，不必为每种情况单独写界面。实现手段：① 权重分配（HBox.hgrow/VBox.vgrow 的 Priority）；② 锚定约束（AnchorPane 双向锚定拉伸）；③ 百分比列宽（GridPane ColumnConstraints.setPercentWidth）；④ 最小/最大/偏好尺寸约束；⑤ 监听 Scene 宽高动态切换可见性（窄屏隐藏）。

**3.23** 流程：① `FXMLLoader` 定位 FXML 资源（`getResource`）；② 解析 FXML，实例化根元素与子节点；③ 根据 `fx:controller` 实例化 Controller；④ 按 `fx:id` 把节点注入 Controller 的 `@FXML` 字段；⑤ 绑定 `onAction="#method"` 到 Controller 的 `@FXML` 方法；⑥ 加载完成后调用 Controller 的 `initialize()`；⑦ 返回节点树根 `Parent`。

**3.24** `setVisible(false)` 仅隐藏节点，节点仍占用布局空间（位置留空）；`setManaged(false)` 既隐藏又让父布局不再为该节点分配空间（释放占位）。窄屏隐藏侧栏时若只用 `setVisible(false)`，侧栏虽不可见但位置仍被占用，中间内容区无法扩展到原侧栏位置，造成空白；两者配合才能真正让内容区占满宽度。
</details>

```java
import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.*;
import javafx.stage.Stage;

public class LoginLayout extends Application {
    @Override
    public void start(Stage stage) {
        Label title = new Label("用户登录");
        title.setStyle("-fx-font-size:20px;-fx-font-weight:bold;");
        BorderPane.setAlignment(title, Pos.CENTER);

        GridPane grid = new GridPane();
        grid.setHgap(10); grid.setVgap(10);
        grid.setAlignment(Pos.CENTER);
        grid.setPadding(new Insets(20));
        ColumnConstraints c1 = new ColumnConstraints(80);
```

```java
import javafx.application.Application;
import javafx.collections.FXCollections;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.*;
import javafx.stage.Stage;

public class ResponsiveNotepad extends Application {
    private ListView<String> fileList = new ListView<>(
            FXCollections.observableArrayList("a.txt", "b.txt", "c.txt"));

    @Override
    public void start(Stage stage) {
        MenuBar menuBar = new MenuBar(new Menu("文件"), new Menu("编辑"));

        TextField search = new TextField();
        search.setPromptText("搜索...");
        HBox.setHgrow(search, Priority.ALWAYS);
        search.setMaxWidth(Double.MAX_VALUE);
        HBox toolBar = new HBox(8, new Label("关键词:"), search, new Button("查询"));

        VBox topBox = new VBox(menuBar, toolBar);

        TextArea editor = new TextArea("编辑区...");
        SplitPane split = new SplitPane(fileList, editor);
        split.setDividerPositions(0.25);

        Label status = new Label("就绪");

        BorderPane root = new BorderPane();
        root.setTop(topBox);
        root.setCenter(split);
        root.setBottom(status);

        Scene scene = new Scene(root, 700, 480);
        // 窄屏隐藏文件列表
        scene.widthProperty().addListener((obs, o, n) -> {
            boolean show = n.doubleValue() >= 500;
            fileList.setVisible(show);
            fileList.setManaged(show);
        });

        stage.setScene(scene);
        stage.setTitle("响应式记事本");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```
