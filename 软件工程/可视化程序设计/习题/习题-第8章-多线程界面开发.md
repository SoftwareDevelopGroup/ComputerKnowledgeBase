<details>
<summary>四、简答题答案</summary>

**8.21** JavaFX 采用单线程 UI 模型：所有对 Scene Graph 的读写必须在 JavaFX Application Thread（FX 线程）完成，避免多线程并发修改 UI 的锁竞争与渲染不一致。后台线程不能直接修改 UI，否则抛 `IllegalStateException`。正确切回：用 `Platform.runLater(Runnable)` 把更新代码投递到 FX 线程事件队列异步执行。

**8.22** Task 一次性，执行完不可再 `start`，直接 new + 重写 `call`，自行 `new Thread(task).start()`，适合一次性长任务。Service 可多次 `start`/`reset`，重写 `createTask()` 工厂每次生成新 Task，内部 Executor 可 `setExecutor`，适合多次触发/周期性任务。

**8.23** 状态转换：`READY`（new）→ `SCHEDULED`（start）→ `RUNNING`（call 执行）→ `SUCCEEDED`（正常返回）/ `FAILED`（抛异常）/ `CANCELLED`（cancel 且 isCancelled）。终态不可逆：`SUCCEEDED`/`FAILED`/`CANCELLED` 后 Task 不可重新 start，需新建 Task 或用 Service 的 `reset()` 回到 READY。这是为了保证状态语义清晰，避免重复执行造成资源混乱。

**8.24** 标准模式：后台线程把产生的数据写入并发缓冲（如 `ConcurrentLinkedQueue`），FX 线程用 `Timeline` 或 `ScheduledService` 定时（如每 50ms）批量从缓冲取出 `addAll` 到 `ObservableList`。不直接每条 `runLater` 是因为高频 `runLater` 会塞满事件队列，每个 Runnable 排队执行，导致 UI 响应慢甚至卡顿；批量提交合并多次更新为一次，大幅减少事件队列压力。
</details>

**8.26** 补全代码：

```java
import javafx.animation.Timeline;
import javafx.animation.KeyFrame;
import javafx.util.Duration;
import java.util.ArrayList;
import java.util.List;

// 后台线程
new Thread(() -> {
    while (running) {
        buffer.add(produceData());
        try { Thread.sleep(10); } catch (InterruptedException ignored) {}
    }
}).start();

// FX 线程定时批量搬运
Timeline flusher = new Timeline(new KeyFrame(Duration.millis(50), e -> {
    if (buffer.isEmpty()) return;
    List<String> batch = new ArrayList<>();
    while (!buffer.isEmpty()) batch.add(buffer.poll());
    uiList.addAll(batch);
}));
flusher.setCycleCount(Timeline.INDEFINITE);
flusher.play();
```

**8.27** 原因：每毫秒一次 `Platform.runLater` 投递，事件队列被淹没，UI 响应变慢卡顿（runLater 风暴）。正确做法：后台批量缓冲，按时间窗口合并提交（如每 50ms 一次），或用 `Task` 的 `updateProgress`/`updateMessage`（内部已限速）。

**8.28** 原因：`ObservableList` 非线程安全，后台线程 `add` 会触发 `ListChangeListener` 在后台线程执行，监听者（ListView 皮肤）尝试更新 UI 抛 `IllegalStateException`。修正：切到 FX 线程修改：

```java
Platform.runLater(() -> uiList.add("后台产生的数据"));
```
或用并发缓冲 + 批量提交模式。

**8.29** 参考代码：

```java
import javafx.application.Application;
import javafx.concurrent.Task;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.ProgressBar;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;

public class CancelableTaskDemo extends Application {
    private Task<Integer> currentTask;

    @Override
    public void start(Stage stage) {
        ProgressBar bar = new ProgressBar(0);
        bar.setPrefWidth(260);
        Label status = new Label("就绪");
        Button startBtn = new Button("开始");
        Button cancelBtn = new Button("取消");

        startBtn.setOnAction(e -> {
            currentTask = new Task<>() {
                @Override protected Integer call() throws Exception {
                    int sum = 0;
                    for (int i = 1; i <= 100; i++) {
                        if (isCancelled()) return sum;
                        sum += i;
                        updateProgress(i, 100);
                        updateMessage("已计算 " + i + "/100");
                        Thread.sleep(30);
                    }
                    return sum;
                }
            };
            bar.progressProperty().bind(currentTask.progressProperty());
            status.textProperty().bind(currentTask.messageProperty());
            currentTask.setOnSucceeded(ev -> {
                status.textProperty().unbind();
                status.setText("完成: " + currentTask.getValue());
            });
            currentTask.setOnFailed(ev -> {
                status.textProperty().unbind();
                status.setText("失败: " + currentTask.getException().getMessage());
            });
            currentTask.setOnCancelled(ev -> {
                status.textProperty().unbind();
                status.setText("已取消");
            });
            Thread th = new Thread(currentTask, "worker");
            th.setDaemon(true);
            th.start();
        });
        cancelBtn.setOnAction(e -> {
            if (currentTask != null) currentTask.cancel(true);
        });

        VBox root = new VBox(8, startBtn, cancelBtn, bar, status);
        root.setStyle("-fx-padding: 20;");
        stage.setScene(new Scene(root, 300, 180));
        stage.setTitle("可取消进度任务");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```

import javafx.animation.Animation;
import javafx.animation.KeyFrame;
import javafx.animation.Timeline;
import javafx.application.Application;
import javafx.beans.binding.Bindings;
import javafx.collections.FXCollections;
import javafx.collections.ObservableList;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.ListView;
import javafx.scene.layout.HBox;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;
import javafx.util.Duration;
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.ConcurrentLinkedQueue;
import java.util.concurrent.atomic.AtomicBoolean;

public class LogMonitorApp extends Application {
    private final ObservableList<String> logs = FXCollections.observableArrayList();
    private final ConcurrentLinkedQueue<String> buffer = new ConcurrentLinkedQueue<>();
    private final AtomicBoolean running = new AtomicBoolean(true);

    @Override
    public void start(Stage stage) {
        ListView<String> view = new ListView<>(logs);
        Label countLabel = new Label();
        countLabel.textProperty().bind(Bindings.size(logs).asString("日志总数: %d"));

        // 后台线程：模拟产生日志
        Thread producer = new Thread(() -> {
            int i = 0;
            while (true) {
                if (running.get()) {
                    buffer.add("日志 #" + (++i) + " @ " + System.currentTimeMillis());
                }
                try { Thread.sleep(20); } catch (InterruptedException e) { break; }
            }
        }, "log-producer");
        producer.setDaemon(true);
        producer.start();

        // FX 线程：每 100ms 批量搬运
        Timeline flusher = new Timeline(new KeyFrame(Duration.millis(100), e -> {
            if (buffer.isEmpty()) return;
            List<String> batch = new ArrayList<>();
            while (!buffer.isEmpty()) batch.add(buffer.poll());
            logs.addAll(batch);
            if (logs.size() > 200) {
                logs.remove(0, logs.size() - 200);   // 移除最旧
            }
        }));
        flusher.setCycleCount(Animation.INDEFINITE);
        flusher.play();

        Button pauseBtn = new Button("暂停");
        Button resumeBtn = new Button("继续");
        pauseBtn.setOnAction(e -> running.set(false));
        resumeBtn.setOnAction(e -> running.set(true));

        VBox root = new VBox(8, new HBox(10, pauseBtn, resumeBtn, countLabel), view);
        root.setStyle("-fx-padding: 12;");
        stage.setScene(new Scene(root, 420, 360));
        stage.setTitle("实时日志监控");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
