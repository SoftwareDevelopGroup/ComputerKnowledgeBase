**2.3** B。`getText()` 返回明文，Passwordfield 仅在界面层掩码显示，不提供加密保护，传输存储须另行加密。

**2.4** C。同一 `ToggleGroup` 内的 RadioButton 互斥；与容器、id、disable 无关。

**2.8** B。`progress` 取值 0.0–1.0，`-1` 表示不确定模式（动画滚动）。

<details>
<summary>三、判断题答案</summary>

**2.16** 错误。PasswordField 仅界面掩码显示，`getText()` 返回明文，不提供加密存储。

**2.17** 正确。未加入 ToggleGroup 的 RadioButton 互相独立，可同时选中。

**2.18** 正确。ObservableList 增删元素会触发监听器，绑定的 ListView 自动刷新，无需手动重绘。

<details>
<summary>四、简答题答案</summary>

**2.21** 三者都继承自 `TextInputControl`，用于文本输入。TextField 单行输入，适合短文本（用户名、搜索词）；TextArea 多行输入，适合长文本（备注、描述），支持 `setWrapText` 自动换行；PasswordField 输入字符以掩码显示，适合密码等敏感信息，但 `getText()` 仍返回明文，需另行加密。

**2.22** 通过 `ToggleGroup` 组织多个 RadioButton，同一组内只能选中一个。关键步骤：创建 `ToggleGroup` 实例，对每个 RadioButton 调用 `setToggleGroup(group)`。未加入同组的 RadioButton 互相独立，可同时被选中，不构成互斥。

**2.23** ListView 展示一列同类型对象，适合简单列表（如姓名、文件名）；TableView 展示多列结构化数据，每列对应对象的一个属性，适合表格化数据（如学生成绩记录）。TableView 通过 `TableColumn` 定义列与单元格工厂，数据模型都是 `ObservableList`。

**2.24** 分离使界面结构（FXML）与业务逻辑（Controller Java 类）解耦，便于可视化设计（Scene Builder）与团队协作。`fx:controller` 在 FXML 根元素指定 Controller 类全名；`fx:id` 给 FXML 中控件唯一标识，对应 Controller 中 `@FXML` 字段；`@FXML` 标注 Controller 中需被 FXMLLoader 注入的字段或方法；`onAction="#xxx"` 把按钮事件路由到 Controller 中名为 `xxx` 的 `@FXML` 方法。
</details>

**2.27** 注入不能成功。原因：Controller 中 `userField` 字段和 `login` 方法均为 private 且缺少 `@FXML` 注解，FXMLLoader 无法访问 private 成员进行注入。修正：给字段和方法加 `@FXML`：

```java
@FXML private TextField userField;
@FXML private void login() {
    System.out.println(userField.getText());
}
```
（或改为 public，但推荐 private + `@FXML`。）

```java
import javafx.application.Application;
import javafx.beans.property.*;
import javafx.collections.*;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.control.cell.PropertyValueFactory;
import javafx.scene.layout.*;
import javafx.stage.Stage;

public class StudentTableApp extends Application {
    public static class Student {
        private final SimpleStringProperty id = new SimpleStringProperty();
        private final SimpleStringProperty name = new SimpleStringProperty();
        private final SimpleStringProperty gender = new SimpleStringProperty();
        private final SimpleDoubleProperty score = new SimpleDoubleProperty();
        public Student(String id, String name, String gender, double score) {
            setId(id); setName(name); setGender(gender); setScore(score);
        }
        public StringProperty idProperty() { return id; }
        public StringProperty nameProperty() { return name; }
        public StringProperty genderProperty() { return gender; }
        public DoubleProperty scoreProperty() { return score; }
        public String getId() { return id.get(); } public void setId(String v) { id.set(v); }
        public String getName() { return name.get(); } public void setName(String v) { name.set(v); }
        public String getGender() { return gender.get(); } public void setGender(String v) { gender.set(v); }
        public double getScore() { return score.get(); } public void setScore(double v) { score.set(v); }
    }

    private final ObservableList<Student> data = FXCollections.observableArrayList(
            new Student("001", "张三", "男", 88),
            new Student("002", "李四", "女", 95));
    private final Label detail = new Label("选择一行查看详情");

    @Override
    public void start(Stage stage) {
        TableView<Student> table = new TableView<>(data);

        TableColumn<Student, String> cId = new TableColumn<>("学号");
        cId.setCellValueFactory(new PropertyValueFactory<>("id"));
        TableColumn<Student, String> cName = new TableColumn<>("姓名");
        cName.setCellValueFactory(new PropertyValueFactory<>("name"));
        TableColumn<Student, String> cGender = new TableColumn<>("性别");
        cGender.setCellValueFactory(new PropertyValueFactory<>("gender"));
        TableColumn<Student, Number> cScore = new TableColumn<>("成绩");
        cScore.setCellValueFactory(new PropertyValueFactory<>("score"));
        table.getColumns().addAll(cId, cName, cGender, cScore);

        table.getSelectionModel().selectedItemProperty().addListener((obs, o, n) -> {
            if (n != null) detail.setText("详情: " + n.getId() + " " + n.getName()
                    + " " + n.getGender() + " " + n.getScore());
        });

        TextField idF = new TextField(); idF.setPromptText("学号");
        TextField nameF = new TextField(); nameF.setPromptText("姓名");
        TextField genderF = new TextField(); genderF.setPromptText("性别");
        TextField scoreF = new TextField(); scoreF.setPromptText("成绩");
        Button addBtn = new Button("添加");
        addBtn.setOnAction(e -> {
            data.add(new Student(idF.getText(), nameF.getText(),
                    genderF.getText(), Double.parseDouble(scoreF.getText())));
            idF.clear(); nameF.clear(); genderF.clear(); scoreF.clear();
        });
        Button delBtn = new Button("删除选中");
        delBtn.setOnAction(e -> {
            Student sel = table.getSelectionModel().getSelectedItem();
            if (sel != null) data.remove(sel);
        });

        HBox inputBox = new HBox(8, idF, nameF, genderF, scoreF, addBtn, delBtn);
        VBox root = new VBox(10, table, inputBox, detail);
        root.setStyle("-fx-padding: 12;");
        stage.setScene(new Scene(root, 520, 360));
        stage.setTitle("学生信息表格");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```
