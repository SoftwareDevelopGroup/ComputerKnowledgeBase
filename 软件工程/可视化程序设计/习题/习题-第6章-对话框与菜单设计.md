<details>
<summary>四、简答题答案</summary>

**6.21** 四种预定义类型：INFORMATION（信息）、CONFIRMATION（确认）、WARNING（警告）、ERROR（错误），另有 NONE（无预定义图标）。`showAndWait()` 返回 `Optional<ButtonType>`。

**6.22** 三要素：① DialogPane 内容面板，用 `setContent()` 放自定义表单节点；② ButtonType 按钮类型，用 `getDialogPane().getButtonTypes().addAll(...)` 添加；③ `setResultConverter(Callback<ButtonType, T>)` 把用户点击的 ButtonType 映射为 `Dialog<T>` 的泛型返回值，省略则返回按钮本身。

**6.23** 三级结构：MenuBar（菜单栏容器）→ Menu（可点击展开的菜单，可嵌套）→ MenuItem（菜单项，点击触发 setOnAction）。MenuItem 变体：SeparatorMenuItem（分隔线）、CheckMenuItem（开关项）、RadioMenuItem（单选项，需 ToggleGroup）、CustomMenuItem（自定义节点）。

**6.24** 助记符（Mnemonic，菜单文本中 `(_F)`）：按 Alt+F 可展开该菜单，用于定位菜单。accelerator（`setAccelerator`，如 Ctrl+N）：全局快捷键，菜单显示时无需展开即可触发，直接执行命令。两者不同：助记符定位菜单，accelerator 直接执行命令。
</details>

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.GridPane;
import javafx.scene.layout.VBox;
import javafx.stage.Stage;
import java.util.Optional;

public class LoginDialogDemo extends Application {
    @Override
    public void start(Stage stage) {
        Button openBtn = new Button("打开登录对话框");
        Label result = new Label();
        openBtn.setOnAction(e -> {
            Dialog<String> dialog = new Dialog<>();
            dialog.setTitle("登录");
            dialog.setHeaderText("请输入账号信息");

            TextField userField = new TextField();
            PasswordField pwdField = new PasswordField();
            GridPane grid = new GridPane();
            grid.setHgap(10); grid.setVgap(10);
            grid.add(new Label("用户名:"), 0, 0); grid.add(userField, 1, 0);
            grid.add(new Label("密码:"), 0, 1);   grid.add(pwdField, 1, 1);
            dialog.getDialogPane().setContent(grid);

            ButtonType loginBtn = new ButtonType("登录", ButtonBar.ButtonData.OK_DONE);
            dialog.getDialogPane().getButtonTypes().addAll(loginBtn, ButtonType.CANCEL);

            dialog.setResultConverter(btn -> {
                if (btn == loginBtn) {
                    return userField.getText() + ":" + pwdField.getText();
                }
                return null;
            });

            Optional<String> r = dialog.showAndWait();
            result.setText(r.orElse("已取消"));
        });

        VBox root = new VBox(10, openBtn, result);
        root.setStyle("-fx-padding: 20;");
        stage.setScene(new Scene(root, 320, 160));
        stage.setTitle("登录对话框");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```

**6.30** 参考代码（记事本主框架）：

```java
import javafx.application.Application;
import javafx.beans.binding.Bindings;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.BorderPane;
import javafx.scene.layout.HBox;
import javafx.scene.layout.Priority;
import javafx.stage.Stage;

public class NotepadFrame extends Application {
    @Override
    public void start(Stage stage) {
        TextArea area = new TextArea();
        area.setWrapText(true);

        // 文件菜单
        MenuItem newItem = new MenuItem("新建");
        MenuItem openItem = new MenuItem("打开");
        MenuItem saveItem = new MenuItem("保存");
        MenuItem exitItem = new MenuItem("退出");
        newItem.setOnAction(e -> area.clear());
        openItem.setOnAction(e -> System.out.println("打开"));
        saveItem.setOnAction(e -> System.out.println("保存"));
        exitItem.setOnAction(e -> stage.close());
        Menu fileMenu = new Menu("文件", null, newItem, openItem, saveItem,
                new SeparatorMenuItem(), exitItem);

        // 编辑菜单
        MenuItem copyItem = new MenuItem("复制");
        MenuItem pasteItem = new MenuItem("粘贴");
        MenuItem clearItem = new MenuItem("清空");
        copyItem.setOnAction(e -> area.copy());
        pasteItem.setOnAction(e -> area.paste());
        clearItem.setOnAction(e -> area.clear());
        Menu editMenu = new Menu("编辑", null, copyItem, pasteItem, clearItem);

        Menu helpMenu = new Menu("帮助", null, new MenuItem("关于"));

        MenuBar menuBar = new MenuBar(fileMenu, editMenu, helpMenu);

        // 右键菜单
        ContextMenu ctx = new ContextMenu(
                new MenuItem("复制"), new MenuItem("粘贴"), new MenuItem("清空"));
        ctx.getItems().get(0).setOnAction(e -> area.copy());
        ctx.getItems().get(1).setOnAction(e -> area.paste());
        ctx.getItems().get(2).setOnAction(e -> area.clear());
        area.setContextMenu(ctx);

        // 状态栏：字符数绑定
        Label status = new Label();
        status.textProperty().bind(Bindings.concat("字符数: ",
                Bindings.createIntegerBinding(() -> area.getText().length(),
                        area.textProperty()).asString()));
        HBox statusBar = new HBox(status);
        statusBar.setStyle("-fx-background-color:#f0f0f0;-fx-padding:4 8;");
        HBox.setHgrow(status, Priority.ALWAYS);

        BorderPane root = new BorderPane();
        root.setTop(menuBar);
```
