# 2.3 高级组件与自定义控件

标准控件无法覆盖所有交互需求：大内容需要滚动、多视图需要分页、数值调节需要步进、复杂业务需要专属控件。本节解决的问题是：**如何用容器型高级组件组织复杂界面，以及当标准控件不够时如何自己造一个可复用控件**。

## 容器型高级组件

| 控件 | 类 | 作用 |
| --- | --- | --- |
| 滚动面板 | `ScrollPane` | 为超出视口的内容提供滚动条 |
| 选项卡面板 | `TabPane` | 多个 `Tab` 切换不同子界面 |
| 分割面板 | `SplitPane` | 可拖拽分隔条调整子区域大小 |
| 折叠面板 | `Accordion` | 多个 `TitledPane` 折叠展开 |

## 数值与进度组件

| 控件 | 类 | 作用 |
| --- | --- | --- |
| 数值选择器 | `Spinner<T>` | 步进式调整数值/枚举 |
| 滑块 | `Slider` | 拖拽选择区间值 |
| 进度条 | `ProgressBar` | 横向进度显示 |
| 进度指示器 | `ProgressIndicator` | 圆形进度显示 |

> [!note] ProgressBar vs ProgressIndicator
> 二者都基于 `ProgressIndicator` 基类，`progress` 属性取值 `0.0`–`1.0`，`-1` 表示不确定模式（动画滚动）。`ProgressBar` 横向条形，`ProgressIndicator` 圆形转圈。

## 自定义控件

当标准库没有合适控件时，JavaFX 提供两条自定义路径：

### 方式一：继承 Control + Skin

`Control` 是“逻辑+样式”分离的控件基类，配合 `Skin` 实现外观。适合复杂、可主题化的控件。

### 方式二：继承 Region 直接组合

`Region` 是有子节点的布局基类。直接继承并组合现有节点，简单快捷，适合中小型自定义控件。

```java
// 简单自定义控件：带标题与描述的卡片
import javafx.scene.control.Label;
import javafx.scene.layout.VBox;
import javafx.scene.layout.Region;

public class InfoCard extends Region {
    private final Label title = new Label();
    private final Label desc = new Label();
    private final VBox box = new VBox(4, title, desc);

    public InfoCard(String titleText, String descText) {
        title.setText(titleText);
        title.setStyle("-fx-font-weight: bold; -fx-font-size: 14px;");
        desc.setText(descText);
        desc.setStyle("-fx-text-fill: #555;");
        getChildren().add(box);
        setStyle("-fx-background-color: #f5f5f5; -fx-background-radius: 8; "
               + "-fx-padding: 10; -fx-border-color: #ddd; -fx-border-radius: 8;");
    }
}
```

> [!example]- 自定义控件要点
> - 继承 `Region` 后通过 `getChildren().add(...)` 装入子节点；
> - 外观通过 `-fx-` CSS 属性控制，与内置控件风格一致；
> - 想暴露可绑定属性，可声明 `StringProperty` 并提供 getter。

## CSS 样式与控件主题

自定义控件与内置控件都通过 CSS 控制外观。常用做法：

```css
/* app.css */
.card {
    -fx-background-color: #ffffff;
    -fx-background-radius: 8;
    -fx-padding: 12;
    -fx-border-color: #e0e0e0;
}
.card-title {
    -fx-font-weight: bold;
    -fx-text-fill: #333;
}
```

```java
InfoCard card = new InfoCard("提示", "这是一个自定义卡片");
card.getStyleClass().add("card");
```

## FXML 与 Controller 分离

> [!concept] FXML + Controller 模式
> FXML 是 JavaFX 的声明式界面描述语言（XML 格式），负责界面结构；Controller 是普通 Java 类，负责事件与逻辑。二者通过 `FXMLLoader` 在运行时绑定，实现“界面/逻辑解耦”。

分离的好处：

1. 界面可用 Scene Builder 可视化设计（详见 [[3.3 FXML布局设计与SceneBuilder]]）；
2. 设计师与程序员可并行工作；
3. 同一 Controller 可被多个 FXML 复用，便于 A/B 界面切换。

绑定机制：

- FXML 根元素写 `fx:controller="com.example.MyController"`；
- FXML 中控件写 `fx:id="userName"`，Controller 中对应字段加 `@FXML private TextField userName;`；
- 事件处理：FXML 写 `onAction="#handleSubmit"`，Controller 中 `@FXML private void handleSubmit() { ... }`。

## JavaFX 自定义控件 + FXML 完整示例

```java
// Controller
package com.example;
import javafx.fxml.FXML;
import javafx.scene.control.Label;
import javafx.scene.control.Spinner;
import javafx.scene.control.ProgressBar;

public class ProgressController {
    @FXML private Spinner<Integer> spinner;
    @FXML private ProgressBar progressBar;
    @FXML private Label statusLabel;

    @FXML
    private void initialize() {
        // spinner 值变化时同步进度条
        spinner.valueProperty().addListener((obs, oldVal, newVal) -> {
            double p = newVal / 100.0;
            progressBar.setProgress(p);
            statusLabel.setText("进度：" + newVal + "%");
        });
    }

    @FXML
    private void onComplete() {
        progressBar.setProgress(1.0);
        statusLabel.setText("完成！");
    }
}
```

```java
// 主应用加载 FXML
import javafx.application.Application;
import javafx.fxml.FXMLLoader;
import javafx.scene.Parent;
import javafx.scene.Scene;
import javafx.stage.Stage;

public class App extends Application {
    @Override
    public void start(Stage stage) throws Exception {
        Parent root = FXMLLoader.load(
            getClass().getResource("/progress_view.fxml"));
        stage.setScene(new Scene(root, 360, 240));
        stage.setTitle("FXML + Controller 示例");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
```

> [!example]- 说明
> - `@FXML` 注解让 `FXMLLoader` 把 FXML 中同 `fx:id` 的节点注入到字段；
> - `initialize()` 在加载完成后自动调用，用于初始化监听；
> - `onAction="#onComplete"` 把按钮事件路由到 Controller 方法；
> - FXML 文件内容与 Scene Builder 用法详见 [[3.3 FXML布局设计与SceneBuilder]]。

## 小结

容器型高级组件解决“内容多、视图多”的组织问题；数值与进度组件解决“区间输入与反馈”问题；当标准控件不足时，可通过继承 `Control`/`Region` 自定义控件，并用 CSS 统一样式。FXML + Controller 分离是工程化 GUI 开发的基础模式。
