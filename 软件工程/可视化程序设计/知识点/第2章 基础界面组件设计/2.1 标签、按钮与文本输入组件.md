# 2.1 标签、按钮与文本输入组件

本节解决的问题是：**如何向界面添加最基本的文本展示、用户触发与文本采集控件**。这些控件是任何表单与交互界面的最小积木，掌握它们的属性与事件是构建复杂界面的前提。

## 组件总览

| 控件 | 类 | 作用 |
| --- | --- | --- |
| 标签 | `Label` | 显示不可编辑的文本或图标 |
| 按钮 | `Button` | 触发动作事件 |
| 文本框 | `TextField` | 单行文本输入 |
| 文本区 | `TextArea` | 多行文本输入 |
| 密码框 | `PasswordField` | 掩码显示的敏感输入 |

## Label 标签

`Label` 用于显示静态文本或图像，不响应用户输入。

常用属性：

- `text`：文本内容；
- `graphic`：附带图标（`Node`，如 `ImageView`）；
- `font`：字体（`Font.font("微软雅黑", 14)`）；
- `alignment`：内容对齐；
- `textFill`：文字颜色。

## Button 按钮

`Button` 是最常见的事件源，点击触发 `ActionEvent`。

常用属性：

- `text`：按钮文字；
- `graphic`：按钮图标；
- `tooltip`：悬停提示（`Tooltip` 对象）；
- `disable`：是否禁用；
- `onAction`：点击事件处理器。

## TextField / TextArea / PasswordField

三者均继承自 `TextInputControl`，共享文本操作能力，但形态不同：

| 属性/方法 | TextField | TextArea | PasswordField |
| --- | --- | --- | --- |
| 行数 | 单行 | 多行 | 单行 |
| 显示 | 明文 | 明文 | 掩码（默认 `•`） |
| `getText()` | 获取文本 | 获取文本 | 获取明文内容 |
| `setPromptText()` | 占位提示 | 占位提示 | 占位提示 |
| `setWrapText()` | 不适用 | 是否自动换行 | 不适用 |

> [!tip] PasswordField 安全提示
> `PasswordField` 仅在界面层掩码显示，`getText()` 仍返回明文。传输与存储时须另行加密，控件本身不提供任何加密保护。

## 组件公共属性

> [!definition] 控件通用属性
> JavaFX 所有 `Control` 继承自 `Node`/`Region`，共享一组通用属性：
> - `text`：文本内容（有文本的控件）；
> - `font`：字体名、字号、字形；
> - `alignment`：内容对齐方式（`Pos` 枚举，如 `CENTER`、`CENTER_LEFT`）；
> - `tooltip`：鼠标悬停提示；
> - `style` / `styleClass`：CSS 样式。

对齐方式 `Pos` 常用值：

| Pos | 含义 |
| --- | --- |
| `TOP_LEFT` | 左上 |
| `CENTER` | 居中 |
| `CENTER_LEFT` | 垂直居中、水平靠左 |
| `BOTTOM_RIGHT` | 右下 |

## JavaFX 代码示例

下面示例一次性演示五种基础组件及属性设置：

```java
import javafx.application.Application;
import javafx.geometry.Insets;
import javafx.geometry.Pos;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.VBox;
import javafx.scene.text.Font;
import javafx.stage.Stage;

public class BasicControlsDemo extends Application {
    @Override
    public void start(Stage stage) {
        // Label：设置文本、字体、颜色
        Label label = new Label("用户登录");
        label.setFont(Font.font("微软雅黑", 18));
        label.setStyle("-fx-text-fill: #2a4d8f;");

        // TextField：单行输入，带占位提示
        TextField userField = new TextField();
        userField.setPromptText("请输入用户名");

        // PasswordField：掩码输入
        PasswordField pwdField = new PasswordField();
        pwdField.setPromptText("请输入密码");

        // TextArea：多行输入，自动换行
        TextArea noteArea = new TextArea();
        noteArea.setPromptText("备注信息（可多行）");
        noteArea.setWrapText(true);
        noteArea.setPrefRowCount(3);

        // Button：设置 Tooltip 与点击事件
        Button loginBtn = new Button("登录");
        loginBtn.setTooltip(new Tooltip("点击提交登录信息"));
        loginBtn.setAlignment(Pos.CENTER);
        loginBtn.setStyle("-fx-background-color: #4caf50; -fx-text-fill: white;");
        loginBtn.setOnAction(e -> {
            String info = "用户：" + userField.getText()
                    + "\n备注：" + noteArea.getText();
            label.setText("已提交：" + userField.getText());
            System.out.println(info);
        });

        VBox root = new VBox(10, label, userField, pwdField, noteArea, loginBtn);
        root.setPadding(new Insets(15));
        root.setAlignment(Pos.CENTER_LEFT);

        stage.setScene(new Scene(root, 320, 320));
        stage.setTitle("基础组件示例");
        stage.show();
    }

    public static void main(String[] args) { launch(args); }
}
```

> [!example]- 示例要点
> - `setPromptText()` 提供输入引导，不作为实际值；
> - `setStyle()` 使用 JavaFX CSS 直接设置背景色、文字颜色；
> - `Tooltip` 通过悬停提供操作提示；
> - `VBox` 间距与内边距保证组件不挤在一起（布局详见 [[3.1 布局面板与容器体系]]）。

## 组件样式设置

JavaFX 支持两种样式方式：

1. **内联样式**：`node.setStyle("-fx-font-size: 14px; -fx-text-fill: red;");`
2. **样式表**：`scene.getStylesheets().add("app.css");` 配合 `node.getStyleClass().add("my-button");`

> [!note] CSS 前缀
> JavaFX CSS 属性统一以 `-fx-` 前缀，如 `-fx-background-color`、`-fx-font-size`、`-fx-text-fill`。这与 Web CSS 不同，使用时需注意。

## 小结

标签负责展示、按钮负责触发、文本控件负责采集。它们的公共属性（`text`/`font`/`alignment`/`tooltip`）与 CSS 样式机制贯穿后续所有控件，掌握本节即可搭建最基础的交互表单。
