# 9.3 图标、特效与界面增强

[[9.2 主题切换与皮肤管理]] 解决了整体配色，但界面的精致感还来自细节：图标、阴影、模糊、倒影等特效，以及过渡动画。本节解决的问题是：掌握图标（`ImageView` 与字体图标）的使用，掌握 `DropShadow`/`GaussianBlur`/`Reflection` 等内置特效，用淡入淡出、滑动过渡增强交互质感。

## 图标使用

### ImageView 嵌入位图图标

`ImageView` 用于显示 PNG/JPG/SVG（需 `javafx.svg` 或转码）等图片图标：

```java
import javafx.scene.image.Image;
import javafx.scene.image.ImageView;

Image icon = new Image(getClass().getResourceAsStream("/icons/save.png"));
ImageView view = new ImageView(icon);
view.setFitWidth(16);
view.setFitHeight(16);
Button saveBtn = new Button("保存");
saveBtn.setGraphic(view);   // 图标放在文字左侧
```

> [!tip] 资源路径与分辨率
> > 用 `getResourceAsStream` 加载图标，打包进 jar 后仍可用。高 DPI 屏幕可准备 `@2x` 资源或使用矢量图标（字体图标/SVG）避免模糊。

### 字体图标：FontAwesomeFX / Ikonli

字体图标把图标编码为字体的字符，矢量缩放、可着色、单文件包含大量图标。现代项目多用 **Ikonli**（FontAwesomeFX 已停止维护，Ikonli 是其继任者）。

```xml
<!-- pom.xml: Ikonli 核心 + 图标包 -->
<dependency>
    <groupId>org.kordamp.ikonli</groupId>
    <artifactId>ikonli-javafx</artifactId>
    <version>12.3.1</version>
</dependency>
<dependency>
    <groupId>org.kordamp.ikonli</groupId>
    <artifactId>ikonli-fontawesome5-pack</artifactId>
    <version>12.3.1</version>
</dependency>
```

```java
import org.kordamp.ikonli.javafx.FontIcon;
import org.kordamp.ikonli.fontawesome5.FontAwesomeSolid;

FontIcon icon = new FontIcon(FontAwesomeSolid.SAVE);
icon.setIconSize(18);
icon.setIconColor(javafx.scene.paint.Color.WHITE);

Button saveBtn = new Button("保存");
saveBtn.setGraphic(icon);          // 矢量图标，随字号缩放不失真
saveBtn.setStyle("-fx-background-color: #4a90d9; -fx-text-fill: white;");
```

| 对比项 | `ImageView` 位图 | 字体图标 Ikonli |
| --- | --- | --- |
| 缩放 | 位图放大失真 | 矢量，任意缩放清晰 |
| 着色 | 需多色版本 | `-fx-text-fill`/`setIconColor` 即时着色 |
| 资源管理 | 每图标一个文件 | 单字体含上千图标 |
| 高 DPI | 需多分辨率 | 自动适配 |
| 引入成本 | 无依赖 | 需 Maven 依赖 + 模块 `requires` |

## 内置特效

JavaFX 在 `javafx.scene.effect` 包提供多种特效，通过 `node.setEffect(...)` 应用。

### DropShadow 阴影

`DropShadow` 给节点添加投影，最常用于按钮、卡片的立体感：

```java
import javafx.scene.effect.DropShadow;
import javafx.scene.paint.Color;

DropShadow shadow = new DropShadow();
shadow.setRadius(10);                    // 模糊半径
shadow.setSpread(0.2);                   // 阴影实心占比 0~1
shadow.setColor(Color.rgb(0, 0, 0, 0.4));// 半透明黑
shadow.setOffsetX(2);                    // 水平偏移
shadow.setOffsetY(2);                    // 垂直偏移
button.setEffect(shadow);
```

### GaussianBlur 高斯模糊

`GaussianBlur` 对节点内容做模糊处理，常用于背景毛玻璃：

```java
import javafx.scene.effect.GaussianBlur;

GaussianBlur blur = new GaussianBlur();
blur.setRadius(15);          // 模糊半径 0~63
backgroundImage.setEffect(blur);
```

### Reflection 倒影

`Reflection` 在节点下方添加镜像倒影，常用于图片展示：

```java
import javafx.scene.effect.Reflection;

Reflection reflection = new Reflection();
reflection.setFraction(0.6);   // 倒影占原图高度比例
reflection.setTopOffset(4);    // 倒影与原图间距
reflection.setTopOpacity(0.5); // 顶部不透明度
reflection.setBottomOpacity(0);// 底部渐隐
imageView.setEffect(reflection);
```

| 特效 | 类 | 典型用途 |
| --- | --- | --- |
| 阴影 | `DropShadow` | 按钮/卡片立体感 |
| 高斯模糊 | `GaussianBlur` | 背景毛玻璃、聚焦失焦 |
| 倒影 | `Reflection` | 图片镜面反射 |
| 发光 | `Glow` | 高亮聚焦元素 |
| 外发光 | `Bloom` | 霓虹光晕 |
| 色调调整 | `ColorAdjust` | 亮度/对比度/色相 |

> [!warning] 特效的性能代价
> > 特效每帧重新计算，滥用会导致渲染变慢。`DropShadow` 的大半径、`GaussianBlur` 的高半径尤其昂贵。列表项、动画中慎用特效；可通过 `cacheHint` 与 `setCache(true)` 缓存特效结果。

## 阴影与圆角效果

阴影 + 圆角是现代卡片界面的标配。CSS 方式更易维护：

```css
.card {
    -fx-background-color: white;
    -fx-background-radius: 10;       /* 背景圆角 */
    -fx-border-radius: 10;           /* 边框圆角（与背景一致） */
    -fx-padding: 16;
    -fx-effect: dropshadow(gaussian, rgba(0,0,0,0.15), 12, 0.1, 0, 4);
    /* gaussian 模糊算法 | 颜色 | 半径 | spread | offsetX | offsetY */
}
```

```java
import javafx.scene.layout.VBox;

VBox card = new VBox(8, new Label("标题"), new Label("内容"));
card.getStyleClass().add("card");
```

> [!note] -fx-effect 参数顺序
> > CSS 中 `dropshadow(<blurType>, <color>, <radius>, <spread>, <x>, <y>)`。`blurType` 取 `gaussian`/`one-pass-box`/`two-pass-box`/`three-pass-box`，`gaussian` 质量最好但最慢。

## 界面动画增强

[[5.3 动画与过渡效果]] 介绍了动画基础，这里聚焦界面美化常用的过渡效果：

### 淡入淡出

`FadeTransition` 改变节点透明度，常用于提示框、面板切换：

```java
import javafx.animation.FadeTransition;
import javafx.util.Duration;

FadeTransition fade = new FadeTransition(Duration.millis(300), panel);
fade.setFromValue(0.0);     // 起始透明
fade.setToValue(1.0);       // 完全显示
fade.setCycleCount(1);
fade.setAutoReverse(false);
fade.play();
```

### 滑动过渡

`TranslateTransition` 平移节点，常用于侧边栏滑入滑出：

```java
import javafx.animation.TranslateTransition;

TranslateTransition slide = new TranslateTransition(Duration.millis(300), sideBar);
slide.setFromX(-sideBar.getWidth());   // 从左侧屏外
slide.setToX(0);                       // 滑到原位
slide.play();
```

### 组合动画

`ParallelTransition`（并行）/`SequentialTransition`（串行）组合多个过渡：

```java
import javafx.animation.ParallelTransition;
import javafx.animation.SequentialTransition;

// 淡入 + 上滑 同时
ParallelTransition enter = new ParallelTransition(
    makeFade(node, 0, 1, 300),
    makeSlideUp(node, 20, 0, 300)
);
enter.play();
```

## 特效综合示例

下面是一个带阴影圆角卡片 + 淡入动画的示例：

```java
import javafx.animation.FadeTransition;
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.effect.DropShadow;
import javafx.scene.layout.VBox;
import javafx.scene.paint.Color;
import javafx.stage.Stage;
import javafx.util.Duration;

public class CardEffectDemo extends Application {
    @Override public void start(Stage stage) {
        Label title = new Label("项目卡片");
        title.setStyle("-fx-font-size: 18px; -fx-font-weight: bold;");

        Label desc = new Label("这是一个带阴影与圆角的卡片示例");

        VBox card = new VBox(8, title, desc);
        card.setStyle(
            "-fx-background-color: white;" +
            "-fx-background-radius: 12;" +
            "-fx-padding: 16;" +
            "-fx-border-color: #e0e0e0;" +
            "-fx-border-radius: 12;");
        card.setPrefSize(240, 120);

        // Java 代码加阴影
        DropShadow shadow = new DropShadow(12, Color.rgb(0, 0, 0, 0.2));
        shadow.setOffsetY(4);
        card.setEffect(shadow);

        // 淡入动画
        card.setOpacity(0);
        FadeTransition fade = new FadeTransition(Duration.millis(500), card);
        fade.setToValue(1);
        fade.play();

        VBox root = new VBox(card);
        root.setStyle("-fx-background-color: #f5f7fa; -fx-padding: 30;");
        stage.setScene(new Scene(root, 320, 220));
        stage.show();
    }
}
```

## 易错点

> [!warning] 常见误区
> 1. 字体图标未在 `module-info.java` 中 `requires org.kordamp.ikonli.fontawesome5`（或对应包），运行时找不到图标。
> 2. `ImageView` 用 `new Image("file:...")` 加载打包资源失败——应用 `getResourceAsStream`。
> 3. 在列表项或高频动画中使用 `DropShadow`，导致滚动/动画卡顿——用 `setCache(true)` + `cacheHint` 缓存。
> 4. 淡入动画忘记设置初始 `opacity=0`，看不出效果；或忘记 `play()`。

## 小结

图标方面，`ImageView` 适合位图，Ikonli 字体图标矢量可着色、现代项目首选。特效方面，`DropShadow`（立体感）、`GaussianBlur`（毛玻璃）、`Reflection`（倒影）是三种最常用的内置特效，可用 Java 代码或 `-fx-effect` CSS 设置。界面增强方面，`FadeTransition`（淡入淡出）与 `TranslateTransition`（滑动）配合 `ParallelTransition`/`SequentialTransition` 实现流畅过渡。注意特效的性能代价，高频场景用缓存。至此第9章完成界面美化体系，下一章 [[10.1 调试技术与性能优化]] 进入工程化阶段。
