# 5.2 条件覆盖与判定条件覆盖

判定覆盖只关注判定整体真假，但当判定由多个条件组成时（如 `a > 0 && b > 0`），单个条件的取值错误可能被掩盖。条件覆盖与判定/条件覆盖正是针对这一不足提出的更强准则。本节明确两种覆盖的定义、计算方法及其与判定覆盖的关系。

## 条件覆盖

> [!definition] 条件覆盖
> 条件覆盖（Condition Coverage）要求**每个判定中的每个条件的“真”与“假”至少各取一次**。

注意：条件覆盖关注的是组成判定的**单个条件**，而非判定整体。一个判定可能包含多个条件（如 `a > 0 && b > 0` 含两个条件）。

### 覆盖率计算

$$\text{条件覆盖率} = \frac{\text{已覆盖的条件取值数}}{\text{条件取值总数}} \times 100\%$$

每个条件有真、假两个取值，若程序共有 $m$ 个条件，则条件取值总数为 $2m$。

### 特点

- **优点**：能发现单个条件的取值错误，比判定覆盖更细粒度；
- **缺点**：**条件覆盖不一定满足判定覆盖**——可能每个条件的真与假都取过，但未在同一用例中组合出判定的真与假。

> [!warning] 易错点
> “条件覆盖满足则判定覆盖必满足”是错误的。例如判定 `a > 0 || b > 0`：
> - 用例1：a=1, b=-1 → a>0 真, b>0 假，判定为真；
> - 用例2：a=-1, b=1 → a>0 假, b>0 真，判定为真。
> 两个用例覆盖了 a>0 与 b>0 各自的真假，但判定始终为真，**判定的假分支从未执行**，判定覆盖未满足。

## 判定/条件覆盖

> [!definition] 判定/条件覆盖
> 判定/条件覆盖（Decision/Condition Coverage）要求**同时满足判定覆盖和条件覆盖**，即每个判定的真假分支至少各执行一次，且每个条件的真假至少各取一次。

### 覆盖率计算

判定/条件覆盖需要分别计算判定覆盖率与条件覆盖率，二者均达 100% 才算满足。

$$\text{判定覆盖率} = \frac{\text{已覆盖的判定分支数}}{\text{判定分支总数}} \times 100\%$$

$$\text{条件覆盖率} = \frac{\text{已覆盖的条件取值数}}{\text{条件取值总数}} \times 100\%$$

### 特点

- **优点**：兼顾判定整体与单个条件，弥补了条件覆盖可能不满足判定覆盖的不足；
- **缺点**：仍未覆盖条件的所有组合，可能遗漏条件组合相关的错误（见 [[5.3 条件组合覆盖与路径覆盖]]）。

> [!tip] 判定/条件覆盖的必要性
> 由于条件覆盖不一定满足判定覆盖，工程实践中常直接采用判定/条件覆盖，确保“判定两分支 + 条件两取值”都被覆盖。这是较强的实用准则。

## 代码示例与测试用例设计

### 示例代码

沿用 [[5.1 语句覆盖与判定覆盖]] 的代码：

```java
public String classify(int a, int b) {
    String result;
    // 判定1: a > 0 && b > 0  (含条件 c1: a>0, c2: b>0)
    if (a > 0 && b > 0) {
        result = "both positive";
    } else {
        result = "not both positive";
    }
    // 判定2: a > 0 || b > 0  (含条件 c3: a>0, c4: b>0)
    if (a > 0 || b > 0) {
        result = result + ", at least one positive";
    } else {
        result = result + ", none positive";
    }
    return result;
}
```

**条件清单**：

- 判定1 含条件 c1（a>0）、c2（b>0）
- 判定2 含条件 c3（a>0）、c4（b>0）
- 共 4 个条件，条件取值总数 = 8

### 条件覆盖用例

需要让 c1、c2、c3、c4 各取真与假：

| 用例号 | a | b | c1 a>0 | c2 b>0 | c3 a>0 | c4 b>0 | 覆盖条件取值 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| CC1 | 1 | -1 | 真 | 假 | 真 | 假 | c1真, c2假, c3真, c4假 |
| CC2 | -1 | 1 | 假 | 真 | 假 | 真 | c1假, c2真, c3假, c4真 |

两个用例覆盖全部 8 个条件取值，**条件覆盖率 = 8/8 = 100%**。

> [!warning] 验证判定覆盖
> 检查上述两用例的判定取值：
> - CC1：判定1 = 真&&假 = 假；判定2 = 真||假 = 真
> - CC2：判定1 = 假&&真 = 假；判定2 = 假||真 = 真
> 判定1 只取了假，判定2 只取了真——**判定覆盖未满足**。这验证了“条件覆盖不一定满足判定覆盖”。

### 判定/条件覆盖用例

需要同时满足判定覆盖与条件覆盖：

| 用例号 | a | b | c1 | c2 | c3 | c4 | 判定1 | 判定2 | 覆盖 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| DCC1 | 1 | 1 | 真 | 真 | 真 | 真 | 真 | 真 | c1真,c2真,c3真,c4真,D1真,D2真 |
| DCC2 | -1 | -1 | 假 | 假 | 假 | 假 | 假 | 假 | c1假,c2假,c3假,c4假,D1假,D2假 |

两个用例覆盖了：
- 条件取值 8/8，**条件覆盖率 = 100%**；
- 判定分支 4/4，**判定覆盖率 = 100%**。

满足判定/条件覆盖。

## 覆盖率对比

| 覆盖准则 | 本例用例数 | 覆盖对象 | 是否满足判定覆盖 |
| --- | --- | --- | --- |
| 条件覆盖 | 2 | 4个条件的真假 | 否（见上分析） |
| 判定/条件覆盖 | 2 | 条件真假 + 判定真假 | 是 |

> [!example] 准则选择
> 本例中判定/条件覆盖与条件覆盖用例数相同，但前者额外保证判定覆盖。工程中常直接采用判定/条件覆盖，避免条件覆盖的判定遗漏。但二者都未覆盖条件组合（如 c1真 c2假 与 c1假 c2真 是不同组合），需条件组合覆盖进一步强化。

## 小结

条件覆盖要求每个条件的真假至少各取一次，能发现条件级错误，但**不一定满足判定覆盖**。判定/条件覆盖同时要求判定覆盖与条件覆盖，兼顾判定整体与单个条件，是实用的较强准则。二者均未覆盖条件的所有组合，需 [[5.3 条件组合覆盖与路径覆盖]] 的条件组合覆盖进一步强化。
