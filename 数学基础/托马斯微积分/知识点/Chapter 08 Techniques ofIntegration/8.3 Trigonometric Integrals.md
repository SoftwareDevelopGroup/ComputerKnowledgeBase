# 8.3 Trigonometric Integrals（三角积分）

> [!info] 📘 本节引言
> 三角积分是六种基本三角函数的代数和。核心思路是利用三角恒等式，把复杂积分化成容易处理的形式，例如
> $$\int \sec^2 x \, dx = \tan x + C.$$

## 正弦幂与余弦幂的乘积

我们从形如
$$\int \sin^m x \cos^n x \, dx$$
的积分开始，其中 $m$ 和 $n$ 是非负整数（正整数或零）。根据 $m$ 和 $n$ 的奇偶性，可把适当换元分成三种情形。

> [!definition] 📐 Products of Powers of Sines and Cosines（正弦幂与余弦幂的乘积）
>
> **Case 1** 若 $m$ 为奇数，把 $m$ 写成 $2k+1$，并用恒等式 $\sin^2 x = 1 - \cos^2 x$ 得到
> $$\sin^m x = \sin^{2k+1} x = (\sin^2 x)^k \sin x = (1 - \cos^2 x)^k \sin x. \tag{1}$$
> 然后换元 $u = \cos x$，$du = -\sin x \, dx$。
>
> **Case 2** 若 $n$ 为奇数，把 $n$ 写成 $2k+1$，并用恒等式 $\cos^2 x = 1 - \sin^2 x$ 得到
> $$\cos^n x = \cos^{2k+1} x = (\cos^2 x)^k \cos x = (1 - \sin^2 x)^k \cos x.$$
> 然后换元 $u = \sin x$，$du = \cos x \, dx$。
>
> **Case 3** 若 $m$ 和 $n$ 都为偶数，则换元
> $$\sin^2 x = \frac{1 - \cos 2x}{2}, \quad \cos^2 x = \frac{1 + \cos 2x}{2} \tag{2}$$
> 把被积函数化为 $\cos 2x$ 的较低次幂。

下面是说明每种情形的例题。

> [!example] ✏️ EXAMPLE 1 — Case 1 Integral（情形 1：正弦幂为奇数）
>
> 求 $\displaystyle \int \sin^3 x \cos^2 x \, dx$。
>
> **Solution.** 这是情形 1 的例子。
> $$\int \sin^3 x \cos^2 x \, dx = \int \sin^2 x \cos^2 x \sin x \, dx \quad \text{$m$ 为奇数}$$
>
> $$= \int (1 - \cos^2 x)(\cos^2 x) \sin x \, dx \quad \text{$\sin^2 x = 1 - \cos^2 x$}$$
>
> $$= \int (1 - u^2)(u^2)(-du) \quad \text{$u = \cos x$，$du = -\sin x \, dx$}$$
>
> $$= \int (u^4 - u^2) \, du \quad \text{展开}$$
>
> $$= \frac{u^5}{5} - \frac{u^3}{3} + C = \frac{\cos^5 x}{5} - \frac{\cos^3 x}{3} + C.$$

> [!example] ✏️ EXAMPLE 2 — Case 2 Integral（情形 2：余弦幂为奇数）
>
> 求 $\displaystyle \int \cos^5 x \, dx$。
>
> **Solution.** 这是情形 2 的例子，其中 $m = 0$ 为偶数、$n = 5$ 为奇数。
> $$\int \cos^5 x \, dx = \int \cos^4 x \cos x \, dx$$
>
> $$= \int (1 - \sin^2 x)^2 \cos x \, dx$$
>
> $$= \int (1 - u^2)^2 \, du \quad \text{$u = \sin x$，$du = \cos x \, dx$}$$
>
> $$= \int (1 - 2u^2 + u^4) \, du \quad \text{展开 $(1-u^2)^2$}$$
>
> $$= u - \frac{2}{3}u^3 + \frac{1}{5}u^5 + C = \sin x - \frac{2}{3}\sin^3 x + \frac{1}{5}\sin^5 x + C.$$

> [!example] ✏️ EXAMPLE 3 — Case 3 Integral（情形 3：两幂均为偶数）
>
> 求 $\displaystyle \int \sin^2 x \cos^4 x \, dx$。
>
> **Solution.** 这是情形 3 的例子。
> $$\int \sin^2 x \cos^4 x \, dx = \int \left( \frac{1 - \cos 2x}{2} \right) \left( \frac{1 + \cos 2x}{2} \right)^2 \, dx \quad \text{$m$ 与 $n$ 均为偶数}$$
>
> $$= \frac{1}{8} \int (1 - \cos 2x)(1 + 2\cos 2x + \cos^2 2x) \, dx$$
>
> $$= \frac{1}{8} \int (1 + \cos 2x - \cos^2 2x - \cos^3 2x) \, dx$$
>
> $$= \frac{1}{8} \left[ x + \frac{1}{2}\sin 2x - \int (\cos^2 2x + \cos^3 2x) \, dx \right]$$
>
> 对于含 $\cos^2 2x$ 的项，利用恒等式 $\cos^2 \theta = \dfrac{1 + \cos 2\theta}{2}$，取 $\theta = 2x$，得到
> $$\int \cos^2 2x \, dx = \frac{1}{2} \int (1 + \cos 4x) \, dx = \frac{1}{2} \left( x + \frac{1}{4}\sin 4x \right) + C_1.$$
>
> 对于含 $\cos^3 2x$ 的项，有
> $$\int \cos^3 2x \, dx = \int (1 - \sin^2 2x) \cos 2x \, dx \quad \text{$u = \sin 2x$，$du = 2\cos 2x \, dx$}$$
>
> $$= \frac{1}{2} \int (1 - u^2) \, du = \frac{1}{2} \left( \sin 2x - \frac{1}{3}\sin^3 2x \right) + C_2.$$
>
> 合并并化简，得到
> $$\int \sin^2 x \cos^4 x \, dx = \frac{1}{16} \left( x - \frac{1}{4}\sin 4x + \frac{1}{3}\sin^3 2x \right) + C.$$

## 消去平方根

下面例题利用恒等式 $\cos^2 \theta = \dfrac{1 + \cos 2\theta}{2}$ 消去平方根。

> [!example] ✏️ EXAMPLE 4 — Eliminating a Square Root（消去平方根）
>
> 求 $\displaystyle \int_0^{\frac{\pi}{4}} \sqrt{1 + \cos 4x} \, dx$。
>
> **Solution.** 为消去平方根，使用恒等式
> $$\cos^2 \theta = \frac{1 + \cos 2\theta}{2} \quad \text{或} \quad 1 + \cos 2\theta = 2\cos^2 \theta.$$
>
> 取 $\theta = 2x$，则
> $$1 + \cos 4x = 2\cos^2 2x.$$
>
> 因此
> $$\int_0^{\frac{\pi}{4}} \sqrt{1 + \cos 4x} \, dx = \int_0^{\frac{\pi}{4}} \sqrt{2\cos^2 2x} \, dx = \int_0^{\frac{\pi}{4}} \sqrt{2} \sqrt{\cos^2 2x} \, dx$$
>
> $$= \sqrt{2} \int_0^{\frac{\pi}{4}} \lvert \cos 2x \rvert \, dx = \sqrt{2} \int_0^{\frac{\pi}{4}} \cos 2x \, dx \quad \text{$\cos 2x \ge 0$ 在 $[0, \frac{\pi}{4}]$ 上}$$
>
> $$= \sqrt{2} \left[ \frac{\sin 2x}{2} \right]_0^{\frac{\pi}{4}} = \frac{\sqrt{2}}{2}(1 - 0) = \frac{\sqrt{2}}{2}.$$

## 正切与正割幂的积分

我们已经会积分正切、正割函数本身及其平方。要积分更高次幂，可利用恒等式 $\tan^2 x = \sec^2 x - 1$、$\sec^2 x = \tan^2 x + 1$，必要时配合分部积分把高次幂降为低次幂。

> [!example] ✏️ EXAMPLE 5 — Power of Tangent（正切幂）
>
> 求 $\displaystyle \int \tan^4 x \, dx$。
>
> **Solution.**
> $$\int \tan^4 x \, dx = \int \tan^2 x \cdot \tan^2 x \, dx$$
>
> $$= \int \tan^2 x \cdot (\sec^2 x - 1) \, dx \quad \text{$\tan^2 x = \sec^2 x - 1$}$$
>
> $$= \int \tan^2 x \sec^2 x \, dx - \int \tan^2 x \, dx$$
>
> $$= \int \tan^2 x \sec^2 x \, dx - \int (\sec^2 x - 1) \, dx \quad \text{$\tan^2 x = \sec^2 x - 1$}$$
>
> $$= \int \tan^2 x \sec^2 x \, dx - \int \sec^2 x \, dx + \int dx$$
>
> 对第一个积分，令
> $$u = \tan x, \quad du = \sec^2 x \, dx,$$
>
> 得到
> $$\int u^2 \, du = \frac{1}{3}u^3 + C_1.$$
>
> 其余积分都是标准形式，因此
> $$\int \tan^4 x \, dx = \frac{1}{3}\tan^3 x - \tan x + x + C.$$

> [!example] ✏️ EXAMPLE 6 — Power of Secant（正割幂）
>
> 求 $\displaystyle \int \sec^3 x \, dx$。
>
> **Solution.** 用分部积分，取
> $$u = \sec x, \quad dv = \sec^2 x \, dx, \quad v = \tan x, \quad du = \sec x \tan x \, dx.$$
>
> 则
> $$\int \sec^3 x \, dx = \sec x \tan x - \int (\tan x)(\sec x \tan x) \, dx \quad \text{分部积分}$$
>
> $$= \sec x \tan x - \int (\sec^2 x - 1)\sec x \, dx \quad \text{$\tan^2 x = \sec^2 x - 1$}$$
>
> $$= \sec x \tan x - \int \sec^3 x \, dx + \int \sec x \, dx$$
>
> 合并两个 $\sec^3 x$ 积分，得
> $$2\int \sec^3 x \, dx = \sec x \tan x + \int \sec x \, dx,$$
>
> 因此
> $$\int \sec^3 x \, dx = \frac{1}{2}\sec x \tan x + \frac{1}{2}\ln \lvert \sec x + \tan x \rvert + C.$$

> [!example] ✏️ EXAMPLE 7 — Product of Powers of Tangent and Secant（正切与正割幂的乘积）
>
> 求 $\displaystyle \int \tan^4 x \sec^4 x \, dx$。
>
> **Solution.**
> $$\int (\tan^4 x)(\sec^4 x) \, dx = \int (\tan^4 x)(1 + \tan^2 x)(\sec^2 x) \, dx \quad \text{$\sec^2 x = 1 + \tan^2 x$}$$
>
> $$= \int (\tan^4 x + \tan^6 x)(\sec^2 x) \, dx \quad \text{展开}$$
>
> $$= \int (u^4 + u^6) \, du = \frac{u^5}{5} + \frac{u^7}{7} + C \quad \text{$u = \tan x$，$du = \sec^2 x \, dx$}$$
>
> $$= \frac{\tan^5 x}{5} + \frac{\tan^7 x}{7} + C.$$

## 正弦与余弦的乘积

下面形式的积分
$$\int \sin mx \sin nx \, dx, \quad \int \sin mx \cos nx \, dx, \quad \text{和} \quad \int \cos mx \cos nx \, dx$$
在许多涉及周期函数的应用中出现。虽然可以用分部积分求解，但每种情形都需要分部积分两次。更简单的方法是使用下面的恒等式。

> [!definition] 📐 Product-to-Sum Identities（积化和差恒等式）
>
> $$\sin mx \sin nx = \frac{1}{2}\bigl[\cos(m - n)x - \cos(m + n)x\bigr] \tag{3}$$
>
> $$\sin mx \cos nx = \frac{1}{2}\bigl[\sin(m - n)x + \sin(m + n)x\bigr] \tag{4}$$
>
> $$\cos mx \cos nx = \frac{1}{2}\bigl[\cos(m - n)x + \cos(m + n)x\bigr] \tag{5}$$
>
> 这些恒等式来自正弦和余弦的和角公式（见 1.3 节）。它们把乘积变成容易求原函数的函数。

> [!example] ✏️ EXAMPLE 8 — Product-to-Sum Formula（积化和差公式）
>
> 求 $\displaystyle \int \sin 3x \cos 5x \, dx$。
>
> **Solution.** 在公式 (4) 中取 $m = 3$、$n = 5$，得到
> $$\int \sin 3x \cos 5x \, dx = \frac{1}{2} \int \bigl[\sin(-2x) + \sin 8x\bigr] \, dx$$
>
> $$= \frac{1}{2} \int (\sin 8x - \sin 2x) \, dx$$
>
> $$= -\frac{\cos 8x}{16} + \frac{\cos 2x}{4} + C.$$
