# 19.3 Vectors and Approximation in Three and More Dimensions（三维及高维空间中的向量与逼近）

> [!info] 📘 本节引言
> 在 19.2 节中，我们把周期函数表示为三角函数（常数、正弦、余弦）的线性组合。为了说明“最佳逼近”的含义，本节先复习三维向量，并把点积、长度、正交以及“用一组正交向量的最佳线性组合去逼近给定向量”的思想推广到更高维空间。这些结论在 19.4 节将直接用于“用三角函数系逼近函数”。

二维与三维向量已在第 12 章引入。若 $\mathbf{v}$ 是一个三维向量，其初点在原点、终点在 $(v_1, v_2, v_3)$，则其分量形式为 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$。下面复习三维向量的一些定义与事实。

> [!definition] 📐 DEFINITION — The Dot Product（数量积 / 点积）
> $\mathbf{u} = \langle u_1, u_2, u_3\rangle$ 与 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 的**数量积（dot product，也称点积）**为
> $$ \mathbf{u}\cdot\mathbf{v} = u_1v_1 + u_2v_2 + u_3v_3. $$

> [!definition] 📐 DEFINITION — Orthogonal and Orthonormal Vectors（正交向量与标准正交向量）
> 若 $\mathbf{u}\cdot\mathbf{v} = 0$，则称向量 $\mathbf{u}$ 与 $\mathbf{v}$ **正交（orthogonal）**。若进一步还有 $|\mathbf{u}| = 1$ 且 $|\mathbf{v}| = 1$，则称它们**标准正交（orthonormal）**。

注意 $\mathbf{u} - \mathbf{v} = -(\mathbf{v} - \mathbf{u})$。

> [!definition] 📐 DEFINITION — Length and Distance（长度与距离）
> 1. 向量 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 的**长度（length）**为
>    $$ |\mathbf{v}| = \sqrt{v_1^2 + v_2^2 + v_3^2}. $$
>    若 $|\mathbf{v}| = 1$，则称 $\mathbf{v}$ 为**单位向量（unit vector）**。
> 2. 两个向量 $\mathbf{u} = \langle u_1, u_2, u_3\rangle$ 与 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 之间的**距离（distance）**为
>    $$ |\mathbf{u} - \mathbf{v}| = \sqrt{(u_1 - v_1)^2 + (u_2 - v_2)^2 + (u_3 - v_3)^2}. $$

一个重要事实是：向量长度的平方等于它自身的数量积：
$$ |\mathbf{v}|^2 = v_1^2 + v_2^2 + v_3^2 = \mathbf{v}\cdot\mathbf{v}. $$
数量积与长度还有一些其他性质（见习题 21–30）。

第 12.3 节的定理 1 表明，两个非零向量的数量积满足
$$ \mathbf{u}\cdot\mathbf{v} = |\mathbf{u}||\mathbf{v}|\cos\theta, $$
其中 $\theta$ 为 $\mathbf{u}$ 与 $\mathbf{v}$ 之间的夹角。若 $\mathbf{u}$ 与 $\mathbf{v}$ 垂直，则 $\theta = \frac{\pi}{2}$，从而 $\mathbf{u}\cdot\mathbf{v} = 0$。反之亦然：若 $\mathbf{u}$ 与 $\mathbf{v}$ 是非零向量且 $\mathbf{u}\cdot\mathbf{v} = |\mathbf{u}||\mathbf{v}|\cos\theta = 0$，则 $\cos\theta = 0$，从而 $\theta = \arccos 0 = \frac{\pi}{2}$。下面的定义也允许其中一个或两个向量为零向量。

我们经常处理多于两个向量。若任意两个向量的数量积都为零，即 $\mathbf{u}\cdot\mathbf{v} = 0$、$\mathbf{u}\cdot\mathbf{w} = 0$、$\mathbf{v}\cdot\mathbf{w} = 0$，则称三个向量 $\mathbf{u}, \mathbf{v}, \mathbf{w}$ **正交**；若它们同时都是单位向量，则称 $\mathbf{u}, \mathbf{v}, \mathbf{w}$ **标准正交**。有时也使用更精确的说法：$\{\mathbf{u}, \mathbf{v}, \mathbf{w}\}$ 是一个正交向量组（或标准正交向量组）。在三维空间中，不可能存在多于三个的标准正交向量；但下文会看到，在更高维空间中可以存在更大的集合。

我们将推导一些联系长度、距离与数量积的公式。下面结果的第 3 条是向量的**勾股定理（Pythagorean Theorem）**；习题 25 表明其逆命题也成立。

> [!theorem] 📐 THEOREM 1 — Lengths, Distances, and Dot Products（长度、距离与数量积的关系）
> 设 $\mathbf{u}$ 与 $\mathbf{v}$ 为三维向量。
> 1. $|\mathbf{u} - \mathbf{v}|^2 = |\mathbf{u}|^2 - 2\mathbf{u}\cdot\mathbf{v} + |\mathbf{v}|^2$。
> 2. $|\mathbf{u} + \mathbf{v}|^2 = |\mathbf{u}|^2 + 2\mathbf{u}\cdot\mathbf{v} + |\mathbf{v}|^2$。
> 3. 若 $\mathbf{u}$ 与 $\mathbf{v}$ 正交，则 $|\mathbf{u} + \mathbf{v}|^2 = |\mathbf{u}|^2 + |\mathbf{v}|^2$。
>
> **Proof.** 第 1 条成立是因为
> $$ \begin{aligned} |\mathbf{u} - \mathbf{v}|^2 &= (u_1 - v_1)^2 + (u_2 - v_2)^2 + (u_3 - v_3)^2 \\ &= u_1^2 - 2u_1v_1 + v_1^2 + u_2^2 - 2u_2v_2 + v_2^2 + u_3^2 - 2u_3v_3 + v_3^2 \\ &= (u_1^2 + u_2^2 + u_3^2) + (v_1^2 + v_2^2 + v_3^2) - 2(u_1v_1 + u_2v_2 + u_3v_3) \\ &= |\mathbf{u}|^2 - 2\mathbf{u}\cdot\mathbf{v} + |\mathbf{v}|^2, \end{aligned} $$
> 第 2 条的证明类似。若 $\mathbf{u}$ 与 $\mathbf{v}$ 正交，则 $\mathbf{u}\cdot\mathbf{v} = 0$，故第 3 条由第 2 条推出。

我们还需要一个定义。

> [!definition] 📐 DEFINITION — Linear Combination（线性组合）
> 有限多个向量 $\mathbf{u}_1, \mathbf{u}_2, \ldots, \mathbf{u}_n$ 的**线性组合（linear combination）**是如下形式的求和：将每个向量 $\mathbf{u}_k$ 乘以一个实数 $a_k$ 后再相加，得到向量
> $$ a_1\mathbf{u}_1 + a_2\mathbf{u}_2 + \cdots + a_n\mathbf{u}_n. $$

> [!example] ✏️ EXAMPLE 1 — Linear Combinations of Standard Unit Vectors（标准单位向量的线性组合）
> 第 12.2 节引入了三维空间中的标准单位向量：
> $$ \mathbf{i} = \langle 1, 0, 0\rangle, \qquad \mathbf{j} = \langle 0, 1, 0\rangle, \qquad \mathbf{k} = \langle 0, 0, 1\rangle. $$
> 我们可以用一个、两个或三个标准单位向量做线性组合。例如，用其中两个可得
> $$ \begin{aligned} 2\mathbf{i} + 4\mathbf{j} &= \langle 2, 0, 0\rangle + \langle 0, 4, 0\rangle = \langle 2, 4, 0\rangle, \\[2pt] 5\mathbf{i} + 7\mathbf{k} &= \langle 5, 0, 0\rangle + \langle 0, 0, 7\rangle = \langle 5, 0, 7\rangle, \\[2pt] 3\mathbf{j} - 2\mathbf{k} &= \langle 0, 3, 0\rangle - \langle 0, 0, 2\rangle = \langle 0, 3, -2\rangle. \end{aligned} $$
> 用全部三个的线性组合有
> $$ \begin{aligned} 5\mathbf{i} + 2\mathbf{j} - 7\mathbf{k} &= \langle 5, 0, 0\rangle + \langle 0, 2, 0\rangle - \langle 0, 0, 7\rangle = \langle 5, 2, -7\rangle, \\[2pt] 6\mathbf{i} + 6\mathbf{j} - \mathbf{k} &= \langle 6, 0, 0\rangle + \langle 0, 6, 0\rangle - \langle 0, 0, 1\rangle = \langle 6, 6, -1\rangle, \\[2pt] \mathbf{i} - 2\mathbf{j} - 2\mathbf{k} &= \langle 1, 0, 0\rangle - \langle 0, 2, 0\rangle - \langle 0, 0, 2\rangle = \langle 1, -2, -2\rangle. \end{aligned} $$
> 仅用一个向量时，只需把它乘以一个实数：
> $$ 3\mathbf{i} = \langle 3, 0, 0\rangle, \qquad 5\mathbf{j} = \langle 0, 5, 0\rangle, \qquad 9\mathbf{k} = \langle 0, 0, 9\rangle. $$
> 我们也不限于只用三个向量。例如，给定 $\mathbf{u} = \langle 1, 1, 0\rangle$、$\mathbf{v} = \langle 2, 0, 2\rangle$、$\mathbf{w} = \langle 3, 1, 2\rangle$、$\mathbf{y} = \langle 0, 1, -3\rangle$，它们的一个线性组合为
> $$ \begin{aligned} 2\mathbf{u} + 3\mathbf{v} - \mathbf{w} - 3\mathbf{y} &= 2\langle 1, 1, 0\rangle + 3\langle 2, 0, 2\rangle - \langle 3, 1, 2\rangle - 3\langle 0, 1, -3\rangle \\ &= \langle 2, 2, 0\rangle + \langle 6, 0, 6\rangle - \langle 3, 1, 2\rangle - \langle 0, 3, -9\rangle \\ &= \langle 5, -2, 13\rangle. \end{aligned} $$

## 三维空间中的标准正交基（Orthonormal Bases in Three Dimensions）

任意向量 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 都可写成标准单位向量的线性组合：
$$ \mathbf{v} = \langle v_1, v_2, v_3\rangle = \langle v_1, 0, 0\rangle + \langle 0, v_2, 0\rangle + \langle 0, 0, v_3\rangle = v_1\mathbf{i} + v_2\mathbf{j} + v_3\mathbf{k}. $$

标准基向量 $\mathbf{i}, \mathbf{j}, \mathbf{k}$ 两两数量积为零：$\mathbf{i}\cdot\mathbf{j} = 0$、$\mathbf{i}\cdot\mathbf{k} = 0$、$\mathbf{j}\cdot\mathbf{k} = 0$；且 $\mathbf{i}, \mathbf{j}, \mathbf{k}$ 各自都是单位向量，因此它们标准正交。

我们也可以取另外一组标准正交向量 $\mathbf{r}, \mathbf{s}, \mathbf{t}$。例如，把标准单位向量 $\mathbf{i}, \mathbf{j}, \mathbf{k}$ 绕某条过原点的轴旋转，就得到新的标准正交向量 $\mathbf{r}, \mathbf{s}, \mathbf{t}$（旋转不改变向量长度与夹角）。无论如何得到三个标准正交向量，任意向量 $\mathbf{v}$ 都能写成它们的线性组合（线性代数教材中有证明）：存在实数 $c_1, c_2, c_3$ 使
$$ \mathbf{v} = c_1\mathbf{r} + c_2\mathbf{s} + c_3\mathbf{t}. $$
下面确定这些系数。对上式两边与 $\mathbf{r}$ 作数量积：
$$ \begin{aligned} \mathbf{v}\cdot\mathbf{r} &= (c_1\mathbf{r} + c_2\mathbf{s} + c_3\mathbf{t})\cdot\mathbf{r} \\ &= c_1(\mathbf{r}\cdot\mathbf{r}) + c_2(\mathbf{s}\cdot\mathbf{r}) + c_3(\mathbf{t}\cdot\mathbf{r}) \\ &= c_1|\mathbf{r}|^2 + 0 + 0 \\ &= c_1. \end{aligned} $$
类似计算可得 $c_2 = \mathbf{v}\cdot\mathbf{s}$、$c_3 = \mathbf{v}\cdot\mathbf{t}$。我们把这些事实写成定理。

> [!theorem] 📐 THEOREM 2 — Coordinates with Respect to an Orthonormal Basis（标准正交基下的坐标）
> 设 $\mathbf{r}, \mathbf{s}, \mathbf{t}$ 是三维空间中的标准正交向量，则任意向量 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 都可写成
> $$ \mathbf{v} = (\mathbf{v}\cdot\mathbf{r})\mathbf{r} + (\mathbf{v}\cdot\mathbf{s})\mathbf{s} + (\mathbf{v}\cdot\mathbf{t})\mathbf{t}. $$

利用标准单位向量，可把 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 写成 $\mathbf{v} = v_1\mathbf{i} + v_2\mathbf{j} + v_3\mathbf{k}$。定理 2 告诉我们：若 $\mathbf{r}, \mathbf{s}, \mathbf{t}$ 是三个标准正交向量，则 $\mathbf{v}$ 也是 $\mathbf{r}, \mathbf{s}, \mathbf{t}$ 的线性组合，即 $\mathbf{v} = c_1\mathbf{r} + c_2\mathbf{s} + c_3\mathbf{t}$，其中 $c_1 = \mathbf{v}\cdot\mathbf{r}$、$c_2 = \mathbf{v}\cdot\mathbf{s}$、$c_3 = \mathbf{v}\cdot\mathbf{t}$。由于每个向量 $\mathbf{v}$ 都能唯一地写成 $\mathbf{r}, \mathbf{s}, \mathbf{t}$ 的线性组合，这组向量称为一个**基（basis）**；又因为它们标准正交，我们使用下面的名称。

> [!definition] 📐 DEFINITION — Orthonormal Basis（标准正交基）
> 三维空间中三个标准正交向量 $\{\mathbf{r}, \mathbf{s}, \mathbf{t}\}$ 的集合称为三维空间的**标准正交基（orthonormal basis）**。

## 用三维标准正交基做逼近（Approximation Using an Orthonormal Basis in Three Dimensions）

设 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 是一个向量。在 $xy$ 平面上所有形如 $\mathbf{p} = \langle p_1, p_2, 0\rangle$ 的向量中，哪一个离 $\mathbf{v}$ 最近？就是“把 $\mathbf{v}$ 竖直落到 $xy$ 平面上”得到的那个向量，即 $\mathbf{p} = \langle v_1, v_2, 0\rangle$ 是 $xy$ 平面上离 $\mathbf{v}$ 最近的向量（图 19.4）。用线性组合的语言说，若把 $\mathbf{v}$ 写成 $\mathbf{v} = v_1\mathbf{i} + v_2\mathbf{j} + v_3\mathbf{k}$，则 $xy$ 平面上离 $\mathbf{v}$ 最近的是 $\mathbf{p} = v_1\mathbf{i} + v_2\mathbf{j}$。$\mathbf{v}$ 到 $xy$ 平面的距离就是 $\mathbf{v} - \mathbf{p} = v_3\mathbf{k}$ 的长度，即 $\lvert v_3\rvert$。

![[Pasted image 20260823191115.png|327]]

第 12 章第 5 节讲过如何求点到空间中一般平面的距离。现在用标准正交向量与“最佳逼近”的语言重新表述。设 $\mathbf{r}, \mathbf{s}, \mathbf{t}$ 是三维空间中的三个标准正交向量。固定一个向量 $\mathbf{v}$，由定理 2 有
$$ \mathbf{v} = (\mathbf{v}\cdot\mathbf{r})\mathbf{r} + (\mathbf{v}\cdot\mathbf{s})\mathbf{s} + (\mathbf{v}\cdot\mathbf{t})\mathbf{t}. $$
只用 $\mathbf{r}$ 和 $\mathbf{s}$ 的线性组合能在多大程度上逼近 $\mathbf{v}$？所有可能的线性组合 $a_1\mathbf{r} + a_2\mathbf{s}$ 构成三维空间中的一个平面，称为由 $\mathbf{r}$ 和 $\mathbf{s}$ **张成（determined by or spanned by）**的平面。我们要在这个平面中找使 $\mathbf{v}$ 与 $\mathbf{p}$ 之间误差最小的向量 $\mathbf{p}$——也就是离 $\mathbf{v}$ 最近的那个向量。当我们的标准正交向量是 $\mathbf{i}, \mathbf{j}, \mathbf{k}$ 时，上面的优化问题已经解决；这里的做法类似。如图 19.5 所示，把 $\mathbf{v}$ 垂直地“落”到 $\mathbf{r}, \mathbf{s}$ 张成的平面上，落点即为
$$ \mathbf{p} = (\mathbf{v}\cdot\mathbf{r})\mathbf{r} + (\mathbf{v}\cdot\mathbf{s})\mathbf{s}. $$
若 $\mathbf{v}$ 本身就在该平面内，则 $\mathbf{p} = \mathbf{v}$。

![[Pasted image 20260823191125.png|330]]

> [!theorem] 📐 THEOREM 3 — Best Approximation by a Combination of Two Basis Vectors（用两个基向量组合的最佳逼近）
> 若 $\{\mathbf{r}, \mathbf{s}, \mathbf{t}\}$ 是三维空间的标准正交基，$\mathbf{v}$ 是一个向量，则 $\mathbf{r}$ 与 $\mathbf{s}$ 的线性组合中离 $\mathbf{v}$ 最近的是
> $$ \mathbf{p} = (\mathbf{v}\cdot\mathbf{r})\mathbf{r} + (\mathbf{v}\cdot\mathbf{s})\mathbf{s}. \tag{5} $$
> 向量 $\mathbf{v} - \mathbf{p}$ 与 $\mathbf{r}$ 和 $\mathbf{s}$ 都正交。
>
> **Proof.** 设 $\mathbf{v}$ 为任意向量，$\mathbf{p}$ 由式 (5) 给出。考虑 $\mathbf{r}$ 与 $\mathbf{s}$ 的任一线性组合 $\mathbf{w} = a_1\mathbf{r} + a_2\mathbf{s}$。我们要证明 $\mathbf{v}$ 到 $\mathbf{p}$ 的距离不大于 $\mathbf{v}$ 到 $\mathbf{w}$ 的距离（取“不大于”是因为 $\mathbf{w}$ 可能与 $\mathbf{p}$ 相等），即必须证明 $|\mathbf{v} - \mathbf{p}| \le |\mathbf{v} - \mathbf{w}|$。
>
> 注意到
> $$ \mathbf{v} - \mathbf{w} = (\mathbf{v} - \mathbf{p}) + (\mathbf{p} - \mathbf{w}). $$
> 由于 $\mathbf{p}$ 与 $\mathbf{w}$ 都是 $\mathbf{r}, \mathbf{s}$ 的线性组合，它们的差 $\mathbf{p} - \mathbf{w}$ 也是 $\mathbf{r}, \mathbf{s}$ 的线性组合；而 $\mathbf{r}, \mathbf{s}$ 都与 $\mathbf{t}$ 正交，故 $\mathbf{p} - \mathbf{w}$ 与 $\mathbf{t}$ 正交，从而也与 $(\mathbf{v} - \mathbf{p}) = (\mathbf{v}\cdot\mathbf{t})\mathbf{t}$ 正交。于是
> $$ \begin{aligned} |\mathbf{v} - \mathbf{w}|^2 &= \bigl|(\mathbf{v} - \mathbf{p}) + (\mathbf{p} - \mathbf{w})\bigr|^2 \\ &= |\mathbf{v} - \mathbf{p}|^2 + |\mathbf{p} - \mathbf{w}|^2 \\ &\ge |\mathbf{v} - \mathbf{p}|^2. \end{aligned} $$
> 两边开方得 $|\mathbf{v} - \mathbf{p}| \le |\mathbf{v} - \mathbf{w}|$，说明 $\mathbf{p}$ 是 $\mathbf{r}, \mathbf{s}$ 的线性组合中离 $\mathbf{v}$ 最近者。最后，$(\mathbf{v} - \mathbf{p}) = (\mathbf{v}\cdot\mathbf{t})\mathbf{t}$ 是 $\mathbf{t}$ 的倍数，而 $\mathbf{t}$ 与 $\mathbf{r}, \mathbf{s}$ 都正交。（证明的关键在于“加上再减去 $\mathbf{p}$”这一技巧。）

## 高维空间中的向量（Vectors in Higher Dimensions）

写成分量形式，二维向量 $\mathbf{v} = \langle v_1, v_2\rangle$ 是一对有序实数，三维向量 $\mathbf{v} = \langle v_1, v_2, v_3\rangle$ 是一组有序三元实数。尽管高维向量不易可视化，我们仍可定义并理解它们。四维向量是形如 $\mathbf{v} = \langle v_1, v_2, v_3, v_4\rangle$ 的有序四元组，其长度为 $|\mathbf{v}| = \sqrt{v_1^2 + v_2^2 + v_3^2 + v_4^2}$。共有四个坐标轴方向，$v_k$ 是 $\mathbf{v}$ 在第 $k$ 个轴方向上的分量。

更一般地，若 $d$ 为正整数，$d$ 维向量是有序列表 $\mathbf{v} = \langle v_1, v_2, \ldots, v_d\rangle$（$d$ 个实数，也称 $d$ 元组）。其长度为
$$ |\mathbf{v}| = \sqrt{v_1^2 + v_2^2 + \cdots + v_d^2} = \sqrt{\sum_{k=1}^{d} v_k^2}. \tag{6} $$
两个 $d$ 维向量 $\mathbf{u} = \langle u_1, \ldots, u_d\rangle$ 与 $\mathbf{v} = \langle v_1, \ldots, v_d\rangle$ 之间的距离为 $|\mathbf{u} - \mathbf{v}|$（即二者之差的长度）；它们的数量积为
$$ \mathbf{u}\cdot\mathbf{v} = u_1v_1 + u_2v_2 + \cdots + u_dv_d = \sum_{k=1}^{d} u_kv_k. $$

向量长度与其自身数量积的关系为
$$ |\mathbf{v}|^2 = v_1^2 + v_2^2 + \cdots + v_d^2 = \mathbf{v}\cdot\mathbf{v}. $$
若 $\mathbf{u}\cdot\mathbf{v} = 0$，则称 $\mathbf{u}$ 与 $\mathbf{v}$ 正交；此时勾股定理成立（习题 24）：$|\mathbf{u} + \mathbf{v}|^2 = |\mathbf{u}|^2 + |\mathbf{v}|^2$。勾股定理的逆命题也成立（习题 25）。注意：数量积在任意维都有定义，而叉积（cross product）只在三维有意义。

## 高维空间中的标准正交基与逼近（Orthonormal Bases and Approximation in Higher Dimensions）

> [!theorem] 📐 THEOREM 5 — Best Approximation in $d$ Dimensions（$d$ 维空间中的最佳逼近）
> 设 $\{\mathbf{u}_1, \mathbf{u}_2, \ldots, \mathbf{u}_d\}$ 是 $d$ 维空间的标准正交基。若 $\mathbf{v}$ 是一个向量且 $1 \le n < d$，则 $\mathbf{u}_1, \ldots, \mathbf{u}_n$ 的线性组合中离 $\mathbf{v}$ 最近的是
> $$ \mathbf{p} = (\mathbf{v}\cdot\mathbf{u}_1)\mathbf{u}_1 + \cdots + (\mathbf{v}\cdot\mathbf{u}_n)\mathbf{u}_n = \sum_{k=1}^{n} (\mathbf{v}\cdot\mathbf{u}_k)\mathbf{u}_k. \tag{7} $$
> 向量 $\mathbf{v} - \mathbf{p}$ 与 $\mathbf{u}_1, \ldots, \mathbf{u}_n$ 都正交。

$d$ 维空间中的标准单位向量是 $d$ 个向量
$$ \mathbf{e}_1 = \langle 1, 0, 0, \ldots, 0\rangle, \quad \mathbf{e}_2 = \langle 0, 1, 0, \ldots, 0\rangle, \quad \ldots, \quad \mathbf{e}_d = \langle 0, 0, 0, \ldots, 1\rangle. $$
第 $k$ 个向量 $\mathbf{e}_k$ 的第 $k$ 个分量为 1，其余全为 0。集合 $\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_d\}$ 是标准正交的，且 $d$ 维空间中任一向量都是它们的线性组合，因此 $\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_d\}$ 构成 $d$ 维空间的一个标准正交基。

类似地，任意 $d$ 个标准正交向量也构成 $d$ 维空间的标准正交基。下面的定理（线性代数教材中有证明）给出了把任意向量写成基向量线性组合的具体公式，其中的系数正是 $\mathbf{v}$ 与各 $\mathbf{u}_k$ 的数量积。

> [!theorem] 📐 THEOREM 4 — Coordinates with Respect to a $d$-Dimensional Orthonormal Basis（$d$ 维标准正交基下的坐标）
> 若 $\mathbf{u}_1, \mathbf{u}_2, \ldots, \mathbf{u}_d$ 是 $d$ 维空间中的 $d$ 个标准正交向量（即 $\{\mathbf{u}_1, \ldots, \mathbf{u}_d\}$ 是 $d$ 维空间的标准正交基），则任意向量 $\mathbf{v} = \langle v_1, \ldots, v_d\rangle$ 都可写成
> $$ \mathbf{v} = (\mathbf{v}\cdot\mathbf{u}_1)\mathbf{u}_1 + \cdots + (\mathbf{v}\cdot\mathbf{u}_d)\mathbf{u}_d = \sum_{k=1}^{d} (\mathbf{v}\cdot\mathbf{u}_k)\mathbf{u}_k. $$
>
> 现在固定一个整数 $1 \le n < d$。若 $\{\mathbf{u}_1, \ldots, \mathbf{u}_d\}$ 是标准正交基，$\{\mathbf{u}_1, \ldots, \mathbf{u}_n\}$ 是其中前 $n$ 个向量，$\mathbf{v}$ 是 $d$ 维向量，只用这前 $n$ 个向量 $\mathbf{u}_1, \ldots, \mathbf{u}_n$ 的线性组合能多接近 $\mathbf{v}$？这类最优化问题在数学、科学与工程中极为普遍。答案（常称为**最小二乘解（least squares solution）**）由下一个定理给出，其证明与定理 3 类似（习题 31）。

所有可能的线性组合 $a_1\mathbf{u}_1 + \cdots + a_n\mathbf{u}_n$ 构成的集合称为由 $\mathbf{u}_1, \ldots, \mathbf{u}_n$ **张成的子空间（subspace spanned by）**。式 (7) 给出的 $\mathbf{p}$ 是该子空间中离 $\mathbf{v}$ 最近的向量，也就是使 $\mathbf{v}$ 到该子空间各向量的距离最小的向量，称为 $\mathbf{v}$ 在 $\mathbf{u}_1, \ldots, \mathbf{u}_n$ **张成空间上的正交投影（orthogonal projection）**。从几何上看，定理 5 告诉我们：要找最近的向量 $\mathbf{p}$，只需把 $\mathbf{v}$ 垂直地“落”到 $\mathbf{u}_1, \ldots, \mathbf{u}_n$ 张成的子空间上。

> [!example] ✏️ EXAMPLE 2 — Projection onto a Line（投影到一条直线上）
> 设 $\mathbf{u}_1$ 是 $d$ 维空间中的一个单位向量。单个向量 $\mathbf{u}_1$ 的线性组合就是某个实数 $a$ 的倍数 $a\mathbf{u}_1$，因此 $\mathbf{u}_1$ 张成的子空间就是所有倍数 $a\mathbf{u}_1$ 的集合，也称过 $\mathbf{u}_1$ 的**直线（line）**。若 $\mathbf{v}$ 是 $d$ 维空间中的一个向量，问该直线上离 $\mathbf{v}$ 最近的向量 $\mathbf{p}$ 是什么？
>
> **解答.** 在定理 5 中取 $n = 1$。由线性代数结论，从单位向量 $\mathbf{u}_1$ 出发可以找到向量 $\mathbf{u}_2, \ldots, \mathbf{u}_d$，使 $\{\mathbf{u}_1, \ldots, \mathbf{u}_d\}$ 构成 $d$ 维空间的标准正交基。于是由式 (7)（取 $n = 1$），过 $\mathbf{u}_1$ 的直线上离 $\mathbf{v}$ 最近的向量为
> $$ \mathbf{p} = (\mathbf{v}\cdot\mathbf{u}_1)\mathbf{u}_1. $$
> 这与第 12.3 节对二维、三维向量得到的公式一致，当时我们把 $\mathbf{p}$ 记作 $\mathrm{proj}_{\mathbf{u}_1}\mathbf{v}$（比较图 19.6 与图 12.27）。
