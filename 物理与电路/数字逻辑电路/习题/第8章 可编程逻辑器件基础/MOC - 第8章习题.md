## 一、选择题（6 题）

**1.** 在 PLD 阵列图中，交叉点标记为"×"表示该连接是（ ）
A. 固定连接，出厂已连好不可改
B. 可编程连接，编程后保留导通
C. 不连接，编程时已断开
D. 短路故障

**2.** 关于 PROM 作为可编程逻辑器件，下列叙述正确的是（ ）
A. 与阵列可编程，或阵列固定
B. 与阵列固定，或阵列可编程
C. 与阵列和或阵列均可编程
D. 与阵列和或阵列均固定

**3.** GAL 相比 PAL 的最关键改进是（ ）
A. 与阵列改为可编程
B. 或阵列改为可编程
C. 输出端增设可编程的 OLMC
D. 改用熔丝工艺，速度更快

**4.** 一个 4 输入查找表（LUT）实现组合逻辑，其内部需要的存储单元数为（ ）
A. 4 个
B. 8 个
C. 16 个
D. 64 个

**5.** 下列关于 FPGA 与 CPLD 的对比，正确的是（ ）
A. FPGA 基于乘积项结构，CPLD 基于查找表
B. FPGA 通常采用 SRAM 工艺，断电后配置丢失；CPLD 采用 EEPROM/Flash，断电保持
C. FPGA 规模小、CPLD 规模大
D. FPGA 上电即用，CPLD 需配置芯片

**6.** 在 Verilog HDL 中，时序逻辑 `always @(posedge clk)` 块内应使用的赋值方式是（ ）
A. 阻塞赋值 `=`
B. 非阻塞赋值 `<=`
C. 持续赋值 `assign`
D. `=` 与 `<=` 可混用

<details>
<summary>选择题答案</summary>

1. **B**。"×"表示可编程连接（编程后保留导通），"●"表示固定连接，（无标记）表示不连接。A 描述的是"●"，C 描述的是无标记。
2. **B**。PROM 的与阵列（地址译码器产生全部最小项）固定，或阵列（存储内容）可编程。A 是 PAL；C 是 PLA。
3. **C**。GAL 在 PAL 基础上增设**输出逻辑宏单元（OLMC）**，使输出模式可编程（组合/寄存器/反馈），实现一片多用。A、B 错：GAL 与阵列可编程、或阵列固定（同 PAL）；D 错：GAL 用 EEPROM 工艺可重复编程，不是熔丝。
4. **C**。$n$ 输入 LUT 需要 $2^n$ 个存储单元，4 输入需 $2^4=16$ 个。
5. **B**。FPGA 基于查找表（LUT）+ SRAM 工艺，断电丢失需配置芯片；CPLD 基于乘积项 + EEPROM/Flash，断电保持上电即用。A、C、D 均说反。
6. **B**。时序逻辑 `always` 块必须用非阻塞赋值 `<=`，组合逻辑 `always` 块用阻塞赋值 `=`。混用会导致竞争冒险。

</details>

## 二、填空题（4 题）

**1.** 在 PLD 的四种器件中：PROM 的与阵列 ______、或阵列 ______；PLA 的与阵列 ______、或阵列 ______；PAL 的与阵列 ______、或阵列 ______；GAL 的与阵列 ______、或阵列 ______，并在输出端增设 ______。

**2.** 一个 $n$ 输入查找表（LUT）可实现任意 $n$ 输入组合逻辑，其内部相当于一个 $2^n \times 1$ 位的 ______。因此 6 输入 LUT 需 ______ 个存储单元。

**3.** FPGA 典型设计流程为：设计输入 → ______ → 布局布线 → ______ → 下载配置。其中将 HDL 描述映射为门级网表的阶段称为 ______。

**4.** 在 Verilog HDL 中，`assign` 持续赋值语句的左侧变量必须是 ______ 型；`always` 块内被赋值的变量必须声明为 ______ 型。但后者在电平敏感 `always`（组合逻辑）中综合后 ______ 物理寄存器（填"是"或"不是"）。

<details>
<summary>填空题答案</summary>

1. PROM：与阵列**固定**、或阵列**可编程**；PLA：与阵列**可编程**、或阵列**可编程**；PAL：与阵列**可编程**、或阵列**固定**；GAL：与阵列**可编程**、或阵列**固定**，输出端增设**OLMC（输出逻辑宏单元）**。

   - 说明：LUT 以 $n$ 位输入作地址，从 $2^n$ 个单元读出函数值，本质是 ROM 实现组合逻辑。
3. 综合（Synthesis）→ 时序仿真 → 下载配置；将 HDL 映射为门级网表的阶段称为**综合**。
   - 完整流程：设计输入 → 功能仿真 → 综合 → 布局布线 → 时序仿真 → 下载配置。
4. `wire`（线网型）；`reg`（寄存器型）；**不是**。
   - 说明：电平敏感 `always`（组合逻辑）中的 `reg` 综合后仍是组合逻辑，仅边沿触发 `always` 的 `reg` 才映射为真实触发器。

</details>

## 三、分析与设计题（6 题）

**1.（PLD 阵列图识别）** 某 PLD 阵列图描述如下：输入 $A$、$B$ 经缓冲产生原码和反码后接入与阵列；与阵列的交叉点既有"●"固定连接又有"×"可编程连接；或阵列的所有交叉点均为"×"（可编程连接），每个或门可接收任意乘积项。请判断该器件属于 PROM、PLA、PAL、GAL 中的哪一种，并说明判断依据。

<details>
<summary>解答</summary>

**判断：该器件是 PLA（可编程逻辑阵列）。**

**判断依据**：
- **与阵列**同时存在"●"固定连接和"×"可编程连接 → 与阵列可编程（用户可定义乘积项）；
- **或阵列**所有交叉点为"×"可编程连接 → 或阵列可编程（用户可选择乘积项求和）；
- **两阵列均可编程**正是 PLA 的特征。

**对比排除**：
- PROM：与阵列固定（全为"●"产生最小项）、或阵列可编程；
- PAL/GAL：与阵列可编程、或阵列固定（"●"或硬连线）。

$$\boxed{\text{该器件为 PLA}}$$

**说明**：识别 PLD 类型的核心是看"哪个阵列可编程"——这是 PROM/PLA/PAL 的根本区别，GAL 还需看输出端是否有 OLMC。

</details>

**2.（PLA 实现逻辑函数）** 用 PLA 实现下列三输出函数（要求给出乘积项设置）：
$$F_1 = \bar A B + A\bar B$$
$$F_2 = AB$$
$$F_3 = A\bar B + AB$$

请回答：(1) 共需设置多少个乘积项？(2) 列出每个或门接收的乘积项；(3) 若改用 PROM 实现相同函数，与阵列需产生多少条乘积线（最小项）？

<details>
<summary>解答</summary>

**(1) 乘积项数量**

提取所有互不相同的乘积项（PLA 可共享乘积项）：
- $\bar A B$、$A\bar B$、$AB$ 共 **3 个**乘积项。

> [!tip] PLA 共享乘积项
> PLA 的与阵列产生的乘积项可被多个或门共享，因此不需要为每个函数重复产生相同乘积项。这是 PLA 比 PROM 节省资源的原因之一。

**(2) 各或门接收的乘积项**

| 或门（输出） | 接收乘积项 |
| ---- | ---- |
| $F_1$ | $\bar A B$、$A\bar B$ |
| $F_2$ | $AB$ |
| $F_3$ | $A\bar B$、$AB$ |

$$F_1 = \bar A B + A\bar B,\quad F_2 = AB,\quad F_3 = A\bar B + AB$$

**(3) PROM 实现所需乘积线数**

PROM 的与阵列固定产生**全部最小项**，与输入数 $n=2$ 对应：
$$2^2 = 4 \text{ 条乘积线（最小项）}$$

分别为 $\bar A\bar B$、$\bar A B$、$A\bar B$、$AB$。其中 $\bar A\bar B$ 在三个函数中均未使用，造成资源浪费。

$$\boxed{\text{PLA 需 3 个乘积项；PROM 需 4 条最小项线}}$$

**单位检验**：$n$ 输入 PROM 需 $2^n$ 条乘积线，$n=2$ 得 $4$ ✓
**说明**：PLA 通过逻辑化简减少了乘积项数，而 PROM 不论函数是否化简都产生全部最小项，这是 PLA 资源利用率更高的根本原因。

</details>

**3.（FPGA 与 CPLD 综合对比）** 请从结构、工艺、规模、断电保持、触发器数量、Pin-to-Pin 延迟、典型用途七个方面对比 FPGA 与 CPLD，并说明在"需要上电立即工作的地址译码器"和"需要大规模流水线 DSP 处理"两种场景下分别应选哪种器件及理由。

<details>
<summary>解答</summary>

**(1) 七个方面对比**

| 对比项 | FPGA | CPLD |
| ---- | ---- | ---- |
| 基本结构 | 查找表（LUT） | 乘积项（与或阵列） |
| 工艺 | SRAM（主流）/ 反熔丝 | EEPROM / Flash |
| 规模 | 大（十万~千万门） | 小（几百~几万门） |
| 断电保持 | SRAM 型断电丢失，需配置芯片 | 断电保持，上电即用 |
| 触发器数量 | 多（适合流水线） | 少（适合组合逻辑） |
| Pin-to-Pin 延迟 | 路径可变（经多级互连） | 确定（乘积项直通） |
| 典型用途 | 大规模系统、DSP、原型验证 | 控制逻辑、接口胶合、地址译码 |

**(2) 场景选型**

**场景一：上电立即工作的地址译码器**
- **选 CPLD**。
- 理由：地址译码是组合逻辑、规模小，要求**上电即用**（系统启动时地址译码必须立即有效）。CPLD 采用 EEPROM/Flash 工艺断电保持，无需配置芯片，且 Pin-to-Pin 延迟确定，适合译码这种对延迟一致性要求高的场合。FPGA 的 SRAM 型断电丢失，上电需加载配置才能工作，无法满足"立即"要求。

**场景二：大规模流水线 DSP 处理**
- **选 FPGA**。
- 理由：流水线 DSP 需要大量**触发器**（每级流水线寄存数据）和**片内 RAM/DSP 乘法器**，FPGA 触发器资源丰富、集成度高、含专用 DSP 块，适合大规模时序密集与运算密集的场合。CPLD 触发器少、规模小，无法承载大规模流水线。

$$\boxed{\text{地址译码 → CPLD；大规模流水线 DSP → FPGA}}$$

**说明**：选型本质是"规模与时序确定性"与"灵活性与密度"的工程取舍。

</details>

**4.（Verilog 代码阅读）** 阅读以下 Verilog 代码，回答问题：

```verilog
module mystery(
    input wire [1:0] sel,
    input wire [3:0] d,
    output wire y
);
    assign y = sel == 2'b00 ? d[0] :
               sel == 2'b01 ? d[1] :
               sel == 2'b10 ? d[2] :
                              d[3];
endmodule
```

(1) 该模块实现什么功能？(2) 它采用哪种建模方式？(3) 若要改用行为级建模，`y` 的声明应改为什么类型？写出 `always` 块的等价描述。

<details>
<summary>解答</summary>

**(1) 功能分析**

该模块是一个 **4 选 1 数据选择器**：根据 2 位选择信号 `sel` 从 4 路输入 `d[3:0]` 中选一路输出到 `y`。

真值表：
| `sel` | 输出 `y` |
| :---: | :---: |
| 00 | $d[0]$ |
| 01 | $d[1]$ |
| 10 | $d[2]$ |
| 11 | $d[3]$ |

对应 [[3.4 数据选择器、数据分配器|数据选择器]]的标准功能。

**(2) 建模方式**

采用**数据流建模**，使用 `assign` 持续赋值配合嵌套条件运算符 `? :` 描述组合逻辑。

**(3) 行为级建模等价描述**

`y` 应改为 `reg` 型（`always` 块内被赋值变量必须是 `reg`）：

```verilog
module mystery_behav(
    input wire [1:0] sel,
    input wire [3:0] d,
    output reg y
);
    always @(*) begin
        case (sel)
            2'b00: y = d[0];
            2'b01: y = d[1];
            2'b10: y = d[2];
            2'b11: y = d[3];
            default: y = 1'b0;
        endcase
    end
endmodule
```

> [!note] 关键点
> - `always @(*)` 表示电平敏感的组合逻辑，敏感列表由工具自动推导；
> - 组合逻辑 `always` 块内用**阻塞赋值 `=`**；
> - `default` 分支不可省，避免生成锁存器（latch）。

$$\boxed{\text{功能：4 选 1 数据选择器；建模：数据流；行为级中 } y \text{ 声明为 reg}}$$

</details>

**5.（Verilog 代码编写——D 触发器与移位）** 请用 Verilog 编写一个带同步复位和使能的 D 触发器模块 `dff_en`，端口如下：
- 输入：`clk`（时钟）、`rst_n`（同步复位，低有效）、`en`（使能）、`d`（数据）；
- 输出：`q`（寄存输出）。

要求：当 `rst_n=0` 时 `q` 在时钟上升沿清零；当 `rst_n=1` 且 `en=1` 时 `q` 在时钟上升沿接收 `d`；当 `en=0` 时保持。请说明采用非阻塞赋值的理由。

<details>
<summary>解答</summary>

**Verilog 代码**：

```verilog
module dff_en(
    input wire clk,      // 时钟
    input wire rst_n,    // 同步复位（低有效）
    input wire en,        // 使能
    input wire d,        // 数据输入
    output reg q         // 寄存输出
);
    always @(posedge clk) begin   // 同步复位：仅时钟沿触发
        if (!rst_n)
            q <= 1'b0;            // 同步清零
        else if (en)
            q <= d;               // 使能时寄存输入
        // else 保持：不写即默认保持原值
    end
endmodule
```

**采用非阻塞赋值 `<=` 的理由**：
1. 本模块是**时序逻辑**（边沿触发 `always @(posedge clk)`），按 Verilog 规范必须用非阻塞赋值；
2. 非阻塞赋值在 `always` 块结束时统一更新，保证多个触发器在同一时钟沿"同时"更新状态，避免因求值顺序产生竞争冒险；
3. 若误用阻塞赋值 `=`，在多个触发器级联（如移位寄存器）时会出现数据"提前传播"一拍的错误，仿真与综合结果不一致。

> [!warning] 同步复位与异步复位的区别
> - 本题**同步复位**：敏感列表只含 `posedge clk`，复位仅在时钟上升沿被采样生效；
> - 若改为**异步复位**：敏感列表应为 `always @(posedge clk or negedge rst_n)`，复位信号一旦有效立即生效。
>
> 二者的 `if (!rst_n)` 判断写法相同，区别在敏感列表是否包含复位信号边沿。

**功能说明**：
- `rst_n=0`：时钟上升沿到来时 `q <= 0`（同步清零）；
- `rst_n=1, en=1`：`q <= d`（寄存输入）；
- `rst_n=1, en=0`：无赋值语句执行，`q` 保持原值（寄存器特性）。

对应 [[4.4 边沿触发器特性|边沿 D 触发器]]带使能与同步复位的功能。

</details>

**6.（Verilog 综合设计——模 6 计数器）** 请用 Verilog 编写一个同步模 6 计数器模块 `counter_mod6`，要求：
- 输入：`clk`（时钟）、`rst_n`（异步复位，低有效）；
- 输出：`cnt[2:0]`（3 位计数值，0~5 循环）、`carry`（进位输出，计到 5 时为 1）。

要求：给出完整代码，并说明该设计对应 [[5.4 任意进制计数器设计|模 N 计数器设计]]中的哪种方法、LUT 与触发器如何配合实现。

<details>
<summary>解答</summary>

**Verilog 代码**：

```verilog
module counter_mod6(
    input wire clk,         // 时钟
    input wire rst_n,       // 异步复位（低有效）
    output reg [2:0] cnt,   // 3 位计数值 0~5
    output wire carry       // 进位输出
);
    // 计数逻辑：异步复位，模 6 循环
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            cnt <= 3'b000;          // 异步清零
        else if (cnt == 3'd5)
            cnt <= 3'b000;          // 到 5 回 0
        else
            cnt <= cnt + 1'b1;      // 加 1
    end

    // 进位输出：计到 5 时产生进位
    assign carry = (cnt == 3'd5);
endmodule
```

**设计说明**：

**(1) 对应模 N 计数器设计的方法**

本设计对应 [[5.4 任意进制计数器设计|模 N 计数器设计]]中的**反馈清零法（同步复位法）**：用 3 位计数器（模 8）截断为模 6，当计数值到达 $N-1=5$ 时，下一个时钟沿强制归零，形成 $0\to1\to2\to3\to4\to5\to0$ 的六进制循环。

**(2) LUT 与触发器如何配合实现**

综合工具将该模块映射到 [[8.2 FPGA 基本概念|FPGA]]的 CLB 资源：

- **触发器部分**：`cnt[2:0]` 三个位由 3 个 D 触发器存储，时钟上升沿更新，对应 `always @(posedge clk)` 描述的时序行为；
- **LUT 部分**：每个触发器的输入 $D_i$ 是当前状态 `cnt` 的组合函数（次态逻辑）：
  - $D_0 = \overline{cnt_0}$（最低位翻转，由"加 1"决定）；
  - $D_1$、$D_2$ 由进位链和"到 5 归零"条件组合；
  - 这些组合逻辑由 LUT（查找表）实现——把次态真值表存入 LUT；
- **进位输出 `carry`**：`carry = (cnt == 5)` 是纯组合逻辑，由一个 LUT 实现（3 输入 LUT 存 $carry$ 的真值表）。

> [!note] LUT + 触发器 = 时序电路标准结构
> 这正体现了 FPGA CLB 的核心结构：**LUT 产生次态组合逻辑，触发器存储当前状态**，二者配合实现任意时序电路。这与手工设计时序电路"列状态表→求状态方程→画触发器+组合逻辑"的思路完全一致，只是由综合工具自动完成。

**验证**：状态转移 $000 \to 001 \to 010 \to 011 \to 100 \to 101 \to 000$（6 个状态循环），`carry` 在 `cnt=5` 时为 1，其余为 0 ✓

**单位检验**：3 位计数器最大值为 $2^3-1=7\ge5$，足够表示 $0\sim5$ ✓

</details>

> [!tip] 复习建议
> - **PLD 结构对比速记**：PROM = 固定与 + 可编程或；PLA = 双可编程；PAL/GAL = 可编程与 + 固定或；GAL 额外有 OLMC。用"哪个阵列可编程"一条主线区分四种器件；
> - **阵列符号**：● 固定、× 可编程、无标记不连接，画图不可混用；
> - **LUT 本质是 ROM**：$n$ 输入需 $2^n$ 个存储单元，是 [[7.1 ROM 只读存储器原理|ROM 实现组合逻辑]]的延伸，务必与 CPLD 的乘积项结构区分；
> - **FPGA vs CPLD**：记"SRAM 工艺 + LUT + 大规模 + 需配置"对应 FPGA，"EEPROM + 乘积项 + 小规模 + 上电即用"对应 CPLD；
> - **Verilog 赋值铁律**：组合 `always` 用 `=`、时序 `always` 用 `<=`，`assign` 左侧 `wire`、`always` 左侧 `reg`，且 `reg` 未必是物理寄存器；
> - **代码题**：先写端口与类型声明，再写功能（组合用 `assign`/电平 `always`，时序用边沿 `always`），最后加复位与使能逻辑，注意 `always @(*)` 避免 latch；
> - **综合设计题**（分析6）：把"次态组合逻辑"交给 LUT、"状态存储"交给触发器，正是 FPGA CLB 的标准结构，与手工时序电路设计思路一一对应。
