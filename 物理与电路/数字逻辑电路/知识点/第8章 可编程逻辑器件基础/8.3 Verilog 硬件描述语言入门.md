# 8.3 Verilog 硬件描述语言入门

> [!abstract] 本节概述
> 硬件描述语言（HDL）是用文本描述数字电路结构和行为的语言。本节解决的核心问题是——**掌握 Verilog HDL 的模块结构、数据类型与三种建模方式（门级、数据流、行为级），并能用 Verilog 描述组合逻辑、触发器、计数器等典型电路。** 这是从 [[3.2 组合电路设计步骤|手工画逻辑图]]和 [[5.4 任意进制计数器设计|手工设计计数器]]走向"文本描述 → 工具自动综合"现代设计方法的关键一步，也是 [[8.2 FPGA 基本概念|FPGA]] 设计输入的主要方式。

## 一、Verilog HDL 基本概念

> [!definition] 硬件描述语言（HDL）
> Verilog HDL 是一种用文本描述数字电路**结构**与**行为**的语言。与 C 语言等过程式编程语言的本质区别在于：HDL 描述的是**并发执行的硬件电路**而非顺序执行的程序——每条 `assign` 语句、每个 `always` 块都对应一段独立并行的硬件。
>
> HDL 的两种主流语言：
> - **Verilog HDL**：语法接近 C，简洁直观，工业界和学术界广泛使用；
> - **VHDL**：语法接近 Ada，强类型，多见于欧洲和军工。

> [!note] Verilog 与编程语言的本质区别
> | 特性 | C/Python 等编程语言 | Verilog HDL |
> | ---- | -------- | -------- |
> | 执行方式 | 顺序执行（逐行） | 并发执行（硬件并行） |
> | 变量含义 | 内存中的存储单元 | 导线（wire）或寄存器（reg） |
> | 时间概念 | 抽象指令序列 | 真实物理时间与时钟 |
> | 目标 | CPU 上运行的程序 | 硬件电路结构 |

## 二、模块结构

> [!definition] module ... endmodule
> Verilog 的基本设计单元是**模块（module）**，一个模块描述一个电路块。模块结构如下：
>
> ```verilog
> module 模块名(端口列表);
>     // 端口声明
>     // 内部信号声明
>     // 功能描述（assign / always / 例化）
> endmodule
> ```

> [!example] 模块框架示例
> ```verilog
> module example(
>     input wire clk,        // 输入端口
>     input wire [3:0] din,  // 4 位总线输入
>     output wire [3:0] dout, // 输出端口
>     output reg done        // reg 型输出
> );
>     // 内部信号
>     wire sel;
>     // 功能描述
>     assign dout = din;     // 持续赋值
>     always @(posedge clk)  // 时序逻辑
>         done <= 1'b1;
> endmodule
> ```

> [!note] 端口类型
> - `input`：输入端口；
> - `output`：输出端口；
> - `inout`：双向端口（用于三态总线）。
>
> 端口可同时声明类型（`wire`/`reg`）与方向，如 `output reg [7:0] q` 表示 `q` 是 8 位寄存器型输出。

## 三、数据类型

> [!definition] wire 与 reg
> Verilog 中两种最常用的数据类型：
>
> | 类型 | 含义 | 适用场景 | 赋值方式 |
> | ---- | ---- | -------- | -------- |
> | `wire`（线网型） | 表示物理导线，无存储能力 | 组合逻辑连线、`assign` 赋值 | `assign`（持续赋值） |
> | `reg`（寄存器型） | 表示有存储能力的变量 | `always` / `initial` 块内被赋值 | `=` 或 `<=`（过程赋值） |
>
> > [!warning] **`reg` 不一定对应物理寄存器！** 若 `reg` 在电平敏感 `always` 块（组合逻辑）中被赋值，综合后仍是组合逻辑（导线+门），仅当代码描述了触发行为（边沿触发 `always`）时才综合为真实触发器。

> [!note] 常用数据类型与常量
> - **位宽与向量**：`wire [7:0] bus` 表示 8 位总线，`bus[3]` 取第 3 位，`bus[3:0]` 取低 4 位；
> - **数值字面量**：`8'b1010_0011`（8 位二进制）、`4'hA`（4 位十六进制）、`2'd3`（2 位十进制）；
> - **常量**：`parameter N = 8;` 定义参数，便于模块参数化；
> - **逻辑值**：`1'b0`（低电平）、`1'b1`（高电平）、`1'bz`（高阻）、`1'bx`（不确定）。

## 四、三种建模方式

> [!definition] ① 门级结构建模
> 用 Verilog 内置的**基本门原语**（`and`、`or`、`not`、`nand`、`nor`、`xor`、`xnor`、`buf`）描述电路连接关系，对应直接画逻辑图。
>
> ```verilog
> module gate_half_adder(
>     input a, b,
>     output sum, carry
> );
>     xor (sum, a, b);    // 异或门：sum = a ^ b
>     and (carry, a, b);  // 与门：carry = a & b
> endmodule
> ```
>
> 门级建模直观但繁琐，仅用于小规模电路或验证基本门连接。

> [!definition] ② 数据流建模
> 用 `assign` 语句进行**持续赋值**，描述信号之间的逻辑关系，左侧必须是 `wire`。
>
> ```verilog
> module dataflow_half_adder(
>     input a, b,
>     output sum, carry
> );
>     assign sum   = a ^ b;   // 持续赋值，随时更新
>     assign carry = a & b;
> endmodule
> ```
>
> `assign` 语句在右操作数变化时立即更新左侧 wire，适合描述组合逻辑表达式。

> [!definition] ③ 行为级建模
> 用 `always` 块描述电路**行为**，内部用过程赋值语句。`always` 块的敏感列表决定触发条件：
> - **电平敏感**（组合逻辑）：`always @(*)` 或 `always @(a or b)`；
> - **边沿敏感**（时序逻辑）：`always @(posedge clk)`。
>
> ```verilog
> module behavioral_half_adder(
>     input a, b,
>     output reg sum, carry
> );
>     always @(*) begin
>         sum   = a ^ b;   // 阻塞赋值
>         carry = a & b;
>     end
> endmodule
> ```

> [!summary] 三种建模对比
> | 建模方式 | 关键语法 | 抽象层级 | 适用电路 | 左侧变量 |
> | ---- | ---- | ---- | -------- | ---- |
> | 门级结构 | `and/or/not` 原语 | 最低（接近版图） | 小规模、验证连线 | `wire` |
> | 数据流 | `assign` | 中（表达式） | 组合逻辑 | `wire` |
> | 行为级 | `always` | 最高（算法描述） | 组合+时序 | `reg` |

## 五、阻塞赋值与非阻塞赋值

> [!theorem] = 与 <= 的使用规则
> | 赋值符 | 名称 | 执行方式 | 适用 always 块 | 综合 |
> | :---: | ---- | -------- | -------- | ---- |
> | `=` | 阻塞赋值 | 立即执行，按顺序完成 | 组合逻辑（电平敏感） | 组合逻辑 |
> | `<=` | 非阻塞赋值 | 在块结束时统一更新 | 时序逻辑（边沿触发） | 触发器 |
>
> > [!warning] **铁律**：组合逻辑 `always` 用 `=`，时序逻辑 `always` 用 `<=`，**不可在同一 `always` 块内混用**，否则会产生竞争冒险，综合结果不可预期。

## 六、典型电路示例

### 6.1 2 选 1 数据选择器

```verilog
module mux2to1(
    input wire d0, d1,   // 两路数据输入
    input wire sel,       // 选择信号
    output wire y         // 输出
);
    // 数据流建模：sel=0 选 d0，sel=1 选 d1
    assign y = sel ? d1 : d0;
endmodule
```

> [!example] 等效的行为级描述
> ```verilog
> module mux2to1_behav(
>     input wire d0, d1, sel,
>     output reg y
> );
>     always @(*) begin
>         case (sel)
>             1'b0: y = d0;
>             1'b1: y = d1;
>             default: y = 1'b0;
>         endcase
>     end
> endmodule
> ```
> 两种描述综合后的电路功能完全相同，均实现 $Y=\bar S \cdot D_0 + S \cdot D_1$，对应 [[3.4 数据选择器、数据分配器|数据选择器]]的布尔表达式。

### 6.2 D 触发器

```verilog
module dff(
    input wire clk,      // 时钟
    input wire rst_n,    // 异步复位（低有效）
    input wire d,        // 数据输入
    output reg q         // 输出
);
    // 边沿触发：时钟上升沿更新；rst_n=0 立即清零
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            q <= 1'b0;       // 异步复位
        else
            q <= d;          // 寄存输入
    end
endmodule
```

> [!note] 同步复位与异步复位的区别
> - **异步复位**：`always @(posedge clk or negedge rst_n)`，复位信号一旦有效立即生效，不等待时钟沿；
> - **同步复位**：`always @(posedge clk)`，复位信号仅在时钟有效沿被采样生效，需要时钟配合。
>
> 本例采用异步复位，对应 [[4.4 边沿触发器特性|边沿 D 触发器]]带异步清零端的功能。

### 6.3 4 位计数器

```verilog
module counter4(
    input wire clk,      // 时钟
    input wire rst_n,    // 异步复位
    input wire en,       // 计数使能
    output reg [3:0] cnt // 4 位计数值
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            cnt <= 4'b0000;     // 复位清零
        else if (en)
            cnt <= cnt + 1'b1;  // 使能时加 1，模 16 自然溢出
    end
endmodule
```

> [!example] 改为模 10 计数器（十进制）
> ```verilog
> module counter_mod10(
>     input wire clk, rst_n, en,
>     output reg [3:0] cnt,
>     output wire carry    // 进位输出
> );
>     always @(posedge clk or negedge rst_n) begin
>         if (!rst_n)
>             cnt <= 4'b0000;
>         else if (en) begin
>             if (cnt == 4'd9)
>                 cnt <= 4'b0000;  // 到 9 回 0
>             else
>                 cnt <= cnt + 1'b1;
>         end
>     end
>     assign carry = (cnt == 4'd9) & en;  // 9 且使能时产生进位
> endmodule
> ```
> 这正对应 [[5.4 任意进制计数器设计|模 N 计数器设计]]中"反馈清零法"的硬件描述语言实现：检测到 $N-1$ 时强制归零。

## 七、与手工设计的对比

> [!summary] 手工设计 vs HDL 设计
> | 方面 | 手工设计（前 7 章） | Verilog HDL 设计 |
> | ---- | -------- | -------- |
> | 描述方式 | 真值表→卡诺图→逻辑图 | 文本描述行为 |
> | 化简 | 手工卡诺图/代数法 | 综合工具自动优化 |
> | 实现 | 74 系列芯片连线 | FPGA/CPLD 下载配置 |
> | 修改 | 重新连线，硬件改动 | 修改代码重新综合 |
> | 规模 | 几十门级 | 十万~千万门级 |
> | 适合 | 教学、理解原理 | 工程实际、复杂系统 |
>
> > [!tip] 本质联系
>> HDL 设计并未抛弃手工设计的原理，而是**把真值表化简、状态机设计、触发器选用等工作交给综合工具自动完成**。理解 [[3.2 组合电路设计步骤|组合电路设计步骤]]和 [[5.4 任意进制计数器设计|计数器设计]]的原理，是写出高质量、可综合 Verilog 代码的基础。

## 八、易错点

> [!warning] 易错点
> 1. **`wire` 与 `reg` 混用**：`assign` 左侧必须是 `wire`，`always` 内被赋值变量必须是 `reg`，否则编译报错；
> 2. **`reg` 未必是寄存器**：电平敏感 `always`（组合逻辑）中的 `reg` 综合后仍是组合逻辑，只有边沿触发 `always` 的 `reg` 才映射为触发器；
> 3. **阻塞与非阻塞混用**：时序逻辑 `always` 块内若混用 `=` 和 `<=`，会导致仿真与综合不一致，是隐蔽且危险的错误；
> 4. **敏感列表遗漏**：组合 `always` 块若手动列敏感信号而漏掉某信号，会导致仿真与综合结果不符，应统一用 `always @(*)` 让工具自动推导；
> 5. **在多个 `always` 块给同一 `reg` 赋值**：一个 `reg` 只能在一个 `always` 块内被赋值，否则属于多驱动冲突；
> 6. **初始值不可综合**：`initial` 块仅用于仿真，FPGA 综合后实际初值由复位逻辑决定，不能依赖 `initial` 设初值。

## 九、与其他小节的联系

- Verilog 描述的**组合逻辑**直接对应 [[3.2 组合电路设计步骤|组合电路设计]]和 [[3.3 编码器、译码器原理|编码器译码器]]、[[3.4 数据选择器、数据分配器|数据选择器]]等模块；
- D 触发器示例对应 [[4.4 边沿触发器特性|边沿 D 触发器]]，计数器示例对应 [[5.3 同步计数器与异步计数器|同步计数器]]和 [[5.4 任意进制计数器设计|模 N 计数器设计]]；
- Verilog 综合后映射到 [[8.2 FPGA 基本概念|FPGA]]的 LUT 与触发器，是 FPGA 设计输入的主要方式；
- `assign` 持续赋值的表达式本质是 [[1.3 逻辑代数定律、摩根定律|逻辑代数]]的运算符表达，`&`、`|`、`^`、`~` 对应与、或、异或、非；
- Verilog 与 [[8.1 PLA、PAL、GAL 基础|PLD]]的关系：PLD 提供可编程硬件，Verilog 是描述"如何编程"的语言，二者结合实现现代数字系统设计。
